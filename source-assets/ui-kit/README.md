# 街区信号 UI 资产

资产 ID `AST-005`，服务主菜单、调查工作台与后续页面的可编辑文字和统一视觉语义。风格、页面与状态的权威规范见[UI 设计](../../docs/dev/design/systems/ui.md)，本包维护结构化试验参数与可分发字体

## 源与导出

`tokens.json` 是本轮色彩、字号、间距和动效参数的唯一结构化源，状态为试验；Rust 编译时读取同一文件，不维护另一份运行色板。页面正文仍是 Bevy 文本，底板、边框与焦点是 UI 组件，不把整页效果图当运行贴图

`fonts/NotoSansSC-VF.ttf` 为 Noto Sans SC 2.004，上游原样的简体中文可变字体，字重轴 100–900，共用一个字体文件。正文试用 450，标题试用 800（后续比较 700–900），具体可读性与显示尺寸由引擎样板检验。无本地裁字、变形或轮廓修改；中文覆盖范围与原件 SHA-256 见[资产清单](asset-manifest.json)

来源为 [notofonts/noto-cjk 固定版本](https://github.com/notofonts/noto-cjk/tree/523d033d6cb47f4a80c58a35753646f5c3608a78)，版权原文保留在 [COPYRIGHT](licenses/COPYRIGHT.txt)，完整 [OFL 1.1](licenses/OFL.txt) 随运行字体一起导出。字体由 Adobe 与 Noto 贡献者提供；未使用开发机专有字体，不需要额外服务或授权费用

```fish
bun tools/export-ui.ts
bun tools/export-ui.ts --check
```

导出器核对主文件哈希和大小，将原字体与声明逐字节复制到 `game/assets/ui/`；`--check` 只读核对，不修改文件。参数不属于字体许可，项目自行制作的布局、图形及代码沿用项目规则

## 制作与验证

首轮先以现有城市实景为背景检查标题比例、厚按钮、荧亮焦点、来源标签和长中文；场景没有完成小店室内或角色演出时保留样板说明。暂不添加扫描线、噪点和独立装饰贴图，先验证轮廓、字重、输入与对比

源字体、许可和试验参数进入本包；截图、录屏、字符覆盖检查与本轮观察归 `todo/evidence/TASK-026/`，原尺寸帧序列归忽略的 `output/ui-signal/`。机器字形覆盖与色板对比不能代替实际字形、长文本溢出和合成画面的视觉自查
