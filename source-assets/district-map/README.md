# N街区地图数据

[district.json](district.json) 是 Wiki 街区简图的唯一主数据，地点索引由同一份数据生成

| 字段 | 值 |
| --- | --- |
| 资产 ID | `AST-002` |
| 状态 | `working` |
| 来源 | 地点索引参考 `n-side-district-map.html` 概念地图，布局依据街区空间设计重绘 |
| 原始参考作者与许可 | 待确认 |
| 用途 | 街区位置关系、地势与地点总览 |

`nodes` 保存道路节点的平面位置与示意高度，`roads` 引用节点并记录道路类型。地形底色由附近地面节点的高度插值生成，低处为浅沙色，高处逐渐转为深绿色；桥面高度不参与地形插值，水面单独着色

`places` 与 `groups` 维护地点编号、名称、位置及生活空间分组。`terrain` 保存水面边界，`buildings`、`trees` 和 `labels` 描述简图外观，地点索引与静态总览共用数据

坐标与高度表达示意关系，不作为测绘或工程尺寸。地点编号与正式地点 ID 独立，生活设定与制作要求维护于 Wiki

修改后运行 `bun run check:map` 和 `bun run docs:build`，检查总览、地势配色与地点索引。发布使用显式资产清单，不另存独立修改的地图副本
