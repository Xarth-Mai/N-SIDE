# 开发任务

任务使用 `TASK-编号-名称.md`，记录目标、资料、工作内容、验收与交付结果。

状态：`backlog` 待安排，`ready` 可执行，`in_progress` 制作中，`blocked` 等待依赖，`done` 已交付，`cancelled` 已取消。`evidence` 保存产物与检查记录。
