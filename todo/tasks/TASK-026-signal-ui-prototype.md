# 街区信号引擎样板与输入验证

## 目标与范围

用 Bevy 原生 UI 和已有真实世界场景，验证粗标题、深色框架、亮色焦点、长中文、缩放与输入隔离。先制作工作菜单、调查工作台、可用设置与返回场景，复用 Viewer 和 capture，不复制一套伪场景

本项是 G0 技术与视觉实验，不计作人物移动、正式菜单、委托、取得线索、存档或潜梦功能完成。记录内容明确标注为实验样例，尚未接入的页面显示原因

## 验收条件

1. 字体来源与许可、中文覆盖、结构化 token 和真实运行入口可追溯，代码格式、编译及适用测试通过
2. 实际输入能够打开菜单、切换焦点、查看长中文记录、进入并返回设置、返回场景，打开与关闭那次输入不泄漏到后层
3. 缩放和 Reduced Motion 设置实际生效，按相应样板画幅检查文字、底板、按钮和提示；鼠标、键盘及模拟手柄状态分别记录，真实手柄操作没有完成时写 NOT RUN
4. capture 使用同一 UI 系统与输入路径，状态断言检查页面、焦点、设置与返回；获取连续画面并实际查看，验证至少一条明确失败的断言
5. 记录实验结论、限制与下一步，技术通过不代签作者的风格或手感验收

## 当前工作与下一步

第 2 轮，步骤 6/6「记录与下一步」：主菜单、调查工作台与设置已在同一真实城市场景接入，三种画幅、20秒主流程、输入隔离、缩放、减少动态效果与代表性失败断言通过；作者已认可首轮比例，第二轮据此强化标签、标题底片和面板厚度

本项按技术实验范围完成，不代签TASK-015的完整设计与实际手感。鼠标实操、物理手柄和Windows为NOT RUN；下一步沿已认可比例接HUD/对话与真实任务数据，读取TASK-012对应机制结果，不把样例记录当游戏进度
