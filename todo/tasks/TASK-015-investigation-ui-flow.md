# 街区信号与调查事实、推测的界面设计

## 目标与范围

落实已获授权的都市电子 UI 方向，形成工作菜单、调查记录、HUD、对话、潜梦与产品外壳共用的视觉和信息规范。信息架构与双输入路径在 G0 形成可判断方案，游戏内完整实现和手感仍归 G1

整体方向直接沿用作者 2026-09-27 的「街区信号」提案；色板、尺寸、圆角、动效时长和菜单构图保留试验状态。术语、世界规则、角色关系与 Demo 范围保持各自权威来源

## 验收条件

1. 权威规格覆盖页面、颜色、字号、布局、组件状态、动效、输入隔离、返回与恢复，文档检查和双站构建通过
2. 覆盖接收、获得、回看事实与推测及双输入返回，空、不可用、加载、错误与长中文有明确处理
3. 有同一方向的主菜单与调查工作台样板，区分实验文本、实际剧情信息和未实现入口
4. 作者对真实样板的视觉强度、阅读与操作反馈给出可引用判断；设计确认不表示整个 UI 或委托系统已实现
