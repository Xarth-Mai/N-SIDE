# 小店—采购街材质与光影对照样板

## 目标与范围

以 README 月台杂货概念预览的完成度为目标，在已有真实街区和人物入口上完成一段可连续游走的白天样板。固定小店门前、橱窗近景与采购街回望机位，围绕墙、地、木、金属、玻璃形成同一套材质家族，补足实际店窗纵深、局部陈列、灯具及对应光源，保留地图尺度、稳定 ID、公共通路与既定美术方向

优先复用现有有许可素材和标准 PBR，按真实尺寸规范化 UV、颜色与法线色彩空间、粗糙度、透明边缘和导出设置；确需补充的素材继续登记既有资产包。光照从固定曝光的太阳、天空、环境与阴影基线调整，室内灯具和光源按用途配对，不通过统一提亮或增加无归属灯光掩盖材质问题

正式人物和完整动画、夜景与雨后状态、河面表现作为后续工作，本项仅检查现有角色与 UI 在样板中的可读性，不扩大城市或接入新玩法。依赖的是 TASK-024 的真实城市场景与 TASK-034 的地点和人物路径，可直接开始室外对照，不等待整个 G1 放行；小店公共室内复用 TASK-044 的可用结果，保持其独立验收范围

## 验收条件

- 固定机位、分辨率、视场角、曝光与实际画质参数，以同机位实机前后对照说明变化；概念图仅作近似构图目标，明确机位差异
- 五类材质在近景与正常行走距离下可区分，纹理按米重复，无明显拉伸、边缘瑕疵、尺度跳变或过强高频噪声，来源、许可与导出可追溯
- 店窗在斜视和移动中呈现真实前后层次，门框、窗台、陈列和玻璃不互相穿插；灯具有用途与空间归属，阴影保留入口和踏步可读性
- 通过正式游戏的真实输入走完采购街、小店门前与可用店内对照路线，再返回街道，检查碰撞、遮挡、材质闪烁与拖影；状态断言、画面自查与作者审美反馈分别记录
- 在同设备、同路线下记录加载、帧时间与资源使用的前后变化，说明材质和光源增量成本；适用的格式、资产导出、文档、编译与运行检查通过，未测环境明确标为 NOT RUN

## 当前工作与下一步

待开始，先读取美术目标、既有材质源、真实场景和最近 capture 记录，保存固定机位的当前画面对照，再优先处理墙地与店窗。每轮只调整可比较的一组因素，机器正确性与视觉完成度分开判断；具体美术反馈在交付可运行对照后收集
