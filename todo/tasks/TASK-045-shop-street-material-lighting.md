# 小店—采购街材质与光影对照样板

## 目标与范围

以 README 月台杂货概念预览的完成度为目标，在已有真实街区和人物入口上完成一段可连续游走的白天样板。固定小店门前、橱窗近景与采购街回望机位，围绕墙、地、木、金属、玻璃形成同一套材质家族，补足室外立面层次、店招、铺装、街道物件、植被与光影，保留地图尺度、稳定 ID、公共通路与既定美术方向

优先复用现有有许可素材和标准 PBR，按真实尺寸规范化 UV、颜色与法线色彩空间、粗糙度、透明边缘和导出设置；确需补充的素材继续登记既有资产包。光照从固定曝光的太阳、天空、环境与阴影基线调整，室外灯具和光源按用途配对，不通过统一提亮或增加无归属灯光掩盖材质问题

当前完整游戏目标先推进人物、地图与画面，完整人物建模、骨骼与基础动作另项制作；TASK-046 剧情基线已提交，后续正文调整继续协调，室内、战斗和新玩法后置。已有可运行入口和漫游控制仅用于检验地图与画面，保留现有 TASK-044 结果，但不追加室内工作。依赖 TASK-024 的真实城市场景与 TASK-034 的地点和人物路径，不等待 G1 玩法放行

## 验收条件

- 固定机位、分辨率、视场角、曝光与实际画质参数，以同机位实机前后对照说明变化；概念图仅作近似构图目标，明确机位差异
- 五类材质在近景与正常行走距离下可区分，纹理按米重复，无明显拉伸、边缘瑕疵、尺度跳变或过强高频噪声，来源、许可与导出可追溯
- 外立面在斜视和移动中呈现门框、窗台、雨棚与店招层次，室外装饰不互相穿插；灯具有用途与空间归属，阴影保留入口和踏步可读性
- 通过正式游戏的真实输入走完采购街、小店门前与采购街对照路线，检查碰撞、遮挡、材质闪烁与拖影；状态断言、画面自查与作者审美反馈分别记录
- 在同设备、同路线下记录加载、帧时间与资源使用的前后变化，说明材质和光源增量成本；适用的格式、资产导出、文档、编译与运行检查通过，未测环境明确标为 NOT RUN

## 当前工作与下一步
