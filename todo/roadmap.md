# 从基线到可玩 Demo

本页只记录成果与门槛；状态由[任务卡与看板](README.md)维护。保留既定生活—调查—潜梦—现实后续—回家的完整体验，25—40 分钟等建议预算仍按[Demo 定义](../docs/dev/direction/demo-scope.md)验证。城市、Viewer 与历史视觉成果继续复用，不换算成游戏完成比例

## G0 有效设计与验证基线

结果：已确认体验、首委托方向、最小动作与空间范围，并明确 UI、资产来源、平台与保存约束。体验支柱与《最后的玩具》优先方向已经获作者确认；细化操作与预算尚待相应任务走查

门槛：能说明玩家为什么入梦、哪个观察改变判断、怎样行动、后果与回家；未知参数有可执行实验，不以文档齐备冒充实现。承接旧 M0；风险是过早锁定未经实际操作验证的数值与内容量

## G1 可操作的生活调查与潜梦闭环

结果：复用真实世界，人物能移动、观察、交互、进出、暂停；日常与调查产生信息变化；潜梦规则、工具与有效支援可操作；退出、失败、重入及存档恢复一致

门槛：真实输入完成代表路线，状态断言与连续画面说明行为和结果；操作与危险可理解，故事谜底按线索揭示。承接旧 M1—M3，工作依赖具体接口与实验结果，不等待整个阶段；风险是镜头尺度、碰撞、信息死锁和恢复缺口

## G2 完整体验与生产样板

结果：在同一构建连续完成日常、请求、现实调查、潜梦、处理、现实后续与回家，同时具有代表性的角色、场景、UI、动画和声音

门槛：作者认可完整体验与目标品质；有实际制作与返工成本、性能预算和剩余资产清单。承接旧 M4；成本过高时先收缩地点、角色和分支，不批量扩大半成品

## G3 内容齐备的 Alpha

结果：已确认范围的主线、日常、教学、后续、界面、声音与资源全部接入，能从新游戏完成到结尾并恢复进度

门槛：核心内容不依赖开发者改变量或口头补全；作者确认内容冻结，新增范围记录替代与重测影响。承接旧 M5；资产做完与运行接入分开验收

## G4 真实试玩与独立 Demo 交付

结果：陌生玩家独立完成，主要理解、手感与性能问题复验；Linux/Windows × 键鼠/手柄有实际主流程、失败与恢复证据；固定发布包含资源、许可和说明

门槛：无已知主线阻断与不可恢复进度损坏，满足样板实际预算；干净环境无需开发工具能玩，作者批准发布版本。承接旧 M6—M7；缺设备、真实玩家或发布证据时明确 NOT RUN，不以 Viewer 或 cargo run 代替交付

## DOCS-PIPELINE 文档、Skills 与任务管线修复

结果：R0 门禁、R1 规范和映射、R2 样板与双构建、R3 全量迁移与手册、R4 单一任务源、R5 回归与实际小任务均有真实证据

门槛：缺失输入会失败，来源与补丁可核对，player 产物无开发混入，任务可追溯且生成稳定；不新增游戏能力完成数。迁移索引见 [R1](evidence/TASK-007/r1/migration-map.md)，历史输入保留在 archive/legacy
