# N街区扩容与轻近未来都市设计

## 1. 目标与已确认方向

将 N街区深化为一片建筑连续、目的地丰富、具有立体街巷和昼夜生活的轻近未来城市片区。

世界以现实城市关系为基础，科技通过交通、设备、商业服务与居民日常进入空间。小店继续作为熟悉的生活中心，周围形成可以购物、娱乐、工作、学习、吃饭、见朋友和安静停留的现代都市。

当前目标是完成 N街区的城市框架：全区建筑外部形态、街坊、道路、地形高差、公共空间及必要到达关系。建筑做到轮廓、高度、楼层用途、入口、院落和后场，图纸做到总平面、必要沿街立面及场地剖面

当前范围不包含室内房间划分、内门、家具、陈列、设备内部布局或施工图。已提交的室内方案保留为后续参考，室内完成度不作为本阶段验收条件。原 P5 的学校、公园与室外公共空间并入城市框架，室内设计与细致生活场景后置

完成标准是：隐藏地点编号后仍能辨认街坊与主要建筑，沿道路能连续抵达公共目的地，建筑、坡地、台阶、屋顶及河岸的上下关系成立。完成框架后再按实际需要选择可进入室内，分题开展细化

## 3. 总体布局与扩容起案

### 3.1 两个活动中心

**站前科技与兴趣中心**：以 N站、现代混合商业、游戏兴趣街和设备服务为主。这里承担通勤到达、约朋友、购物和娱乐，形成较完整的现代建筑群。

**滨水—东侧文娱中心**：以影院会客厅、社交综合体、音乐场所、夜食和城市花园为主。原东侧公共生活空间向滨水方向形成连续街道与目的地联系。

两者之间由商住街、采购街、小店生活街坊及住宅连接。小店位于有日常人流经过的中段，保留与上坡住宅和山路的联系。

### 3.2 扩容方向

向站前两侧增加完整街坊；向东补足学校、住宅和文娱建筑；沿河增加多个有建筑、街道及活动内容的岸段。中上部发展平台住宅和坡地混合建筑，逐步过渡至山林。

扩容同步体现在街坊数量、建筑总量、道路联系、建筑进深和立体空间。地图需要表现连续街面、内部院落、成组住宅和多种建筑尺度。

### 3.4 统计口径与尺度

建筑体量按具有明确边界的建筑单元统计；同一建筑内的商铺、楼层和房间归入该建筑。校园等复合场所的各栋建筑进入建筑统计，校园整体作为一个场所档案。

特色场所按可单独辨认的生活目的地统计。同一影院会客厅在 D3 与 E1a 中共用一份场所档案。综合体记录建筑与经营单元的父子关系，统计表说明采用的层级。

地图图幅和街区面积通过地块、道路、校园、公共空间及地形的面积关系确定。首轮总图同时给出比例假设、建成区范围与统计口径。

站前到小店约300米、增加约12米高程，小店到摘星台约1公里、增加约60米高程，继续作为现有路线的起算条件。新增街坊优先在横向及侧向连接中展开，再根据总体设计校核路线。

### 4.2 立体关系

地面生活路承担连续街面、住宅入口和必要服务到达。局部平台、公共楼梯、电梯与扶梯共同联系不同标高，成为清楚可识别的到达节点。

重点研究三种组合：

- 低处街道进入商业层，高处道路进入住宅或公共平台。
- 商业建筑屋顶与附近坡地街道形成可达的公共花园。
- 公共平台横向连接相邻建筑，同时保留地面生活街和内部服务空间。

每个立体节点配套平面与剖面，记录入口高度、步行关系、开放时段、设备维护以及连续的替代路线。[R1]

### 4.3 重点场所组合

**游戏兴趣街**：以音游店为主要目的地，周边配置模型、桌游卡牌、设备维修和餐饮。店内外都安排等候、观看和会合空间；制作场景可来自模型上色、设备检修和陈列更新。

**音乐夜间街坊**：乐器与音频店、排练录音楼、Live House和餐饮共同形成工作与娱乐活动。场所布局同时记录乐器搬运、观众进出、夜间交通、建筑隔声与邻近住宅的关系。[R2]

**影院社交综合体**：原阅览室更新为小型影院与城市会客厅，并作为 D3 的核心设施。底层可以会合、喝东西和看海报，中部组织放映及活动房间，高处连接公共露台与屋顶公园。实际层数和高程以剖面设计为准。[R2][R3]

**夜食采购街**：以普通居民的日常需求组织生鲜、超市、烘焙、甜品和餐饮。清晨、放学后、晚饭前后与演出散场后各有经营与人流变化，商铺后方安排收货、清洁和垃圾收集。

**社区中学与放学街**：学校保留教学与体育的完整地块。校外生活街以可负担餐饮、文具、体育用品、日常采购和等候空间为主，与周边住户共享普通城市服务。

**两种公园**：屋顶公园承担高处眺望、休息、会合和花园步行；地面城市花园承担树荫、活动草坪、野餐和小型公共活动。两处分别记录免费停留空间、开放安排、绿化养护、排水和到达方式。[R4]

### 4.4 24处首批重点设计对象

小店与住家、N站、音游店、模型店、桌游卡牌店、游戏设备维修店、乐器音频店、排练录音楼、Live House、小型影院与城市会客厅、餐饮共享空间、屋顶公园、城市花园与活动草坪、夜食转角、甜品店、烘焙店、生鲜小超市、社区中学、校外文具与日常用品店、社区诊所、渡口入口、河岸安静露台、坡地公共到达节点、摘星台。

每个对象使用同一套场所卡：身份、使用者、到达理由、建筑与空间形态、时段变化、可观察活动、相邻关系、后勤维护、现实参考与设计选择。

## 5. 轻近未来技术与微场景

### 5.1 技术进入生活的方式

城市层设计电子交通信息、公共照明管理、数字导览、取件设施和设备服务。[R1]

商业层设计音游设备、录音与音频设备、交互展示、自助服务、维修和商品检验。公共区域保留清楚的空间导向和可获得的人工帮助。

家庭与小店层以现有家庭 Agent 为依据，继续体现接待、记忆、设备连接和维护活动。新增公共或商业机器人设定，逐项记录能力、所有者、使用范围、维护方式及与家庭 Agent 的关系。

每项科技设施同时写明使用者、实际作用、物理位置、电力与网络需求、维护者，以及停用时的日常处理方式。

### 5.3 日常场景串联

**放学后**：校门 → 买饮料或文具 → 找同学 → 经过模型橱窗 → 从住宅街回家。

**朋友聚会**：N站 → 音游 → 夜食街 → 坡地公共平台 → 各自回家。

**看电影**：东侧会合 → 影院与会客厅 → 餐饮共享空间 → 屋顶公园 → 从另一条街返回。

**音乐之夜**：排练或看演出 → 乐器与设备收拾 → 散场餐饮 → 夜间交通节点。

**安静的一天**：采购 → 小店 → 城市花园 → 河岸露台 → 沿住宅缓路回家。

在这些活动之间布置普通住宅、办公室、公共服务和日常店铺，形成完整的生活环境。
