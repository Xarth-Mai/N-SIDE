# 十篇主线的严格读者复审与重构

基线为 `4801b81bc3c91b5b4eebe04ebd86aa1f245b52c3`，审读对象为序章至尾声十篇玩家正文，原始结构发现见 [独立结构审读](structure-review.md)

本组先通读十篇，再分成前六篇与末四篇互斥改稿；前段另有独立因果只读复审，最后由主线统稿者重读两段相接处。比较重点为读者何时知道答案、人物是否改变彼此处境、高潮是否产生新取舍、后果是否仍在场；没有使用静态检查通过或闭环表数量代替故事判断

## 必须跨规格同步的事实

- 两次预约是不同的下午：第二章错失首轮校样，第三章使用替补校样并改约同一维修件的当面检查，第六章才是该单正式交付失约；世界任务 QST-023 继续办理已选退款取回或经同意转修，不再造一件新的失约物品
- 第六章转运是既有上层服务通道的一次有人协助的窗口，不是全城只剩一条路；行人绕行正常，作业口本轮转运后交回维护人员、余下批次另约，拆批苗与备料占满本轮，必要整套音响无法赶上已排的试音；苗是已安置与补种之外的新当批，不撤销 QST-025 可提前取得的成果
- 第七章仍是联合演练，包含跨点协同、独立位置与固定确认、当前连接及安全中止；正式拆除改变接触，未发生的全部组合不能在原状反复演完
- 第八章新取舍来自六、七章已看到并勘测的檐段附属接触：它同时承托檐段，抽走无法原位悬留，独立承托须重新设计，按旧法挂回会恢复接触；现实人员核准并操作拆除；玲提供观察与窗口，曜始终守在身体和设备旁，A 始终是安全回退
- 卸下的檐段留样，普通原位遮雨暂失，终章中止也不回滚已发生的拆改；尾声缺口与新候船位置继续存在，修缮按进度进行
- 稳定初秋、遥与维恩的家、巧克力的身份记忆、历史源头已终止、既有隔离有效等边界保留

## 验证与结论范围

对十篇正文逐项比较 `quest_id` 与全部显式 HTML 锚点，和提交基线一致；主线目录 `git diff --check` 通过。文档链接、结构检查、全 Wiki 构建及跨规格同步由根任务统一执行并记录

本轮修掉了 S1–S4 的具体结构缺陷，并把 S5 的多种不完全满意结尾放回主线：准确记录不等于喜欢变化，演出成功不消灭艺术分歧，道歉不自动换回生意，家人可以走不同的路。是否达到顶级影视作品的表演张力、读者持续投入与长流程体验，不能由改稿者自证；本记录支持的是文本中新增的因果、代价、可见行动与后果，真实读者及游戏试玩均未执行
