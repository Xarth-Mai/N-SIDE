## 如何对照影视叙事

“顶级”不是可由静态检查认证的分数。本轮使用具体可观察标准：读者先遇到问题再获得答案；主角的决定改变后续；合理欲望互相妨碍；取舍产生无法用一句道歉撤销的后果；高潮使用已铺垫的条件解决新组合；各篇对主题有不同立场；人物通过动作、语气和未说出口的部分呈现自己

[Michael Arndt 在 WGA East 的结局访谈](https://www.wgaeast.org/onwriting/michael-arndt-endings/)比较外部行动、关系与价值选择怎样在高潮相互作用，并以《阳光小美女》说明如何跳出预期的二选一；他也明确这只是有效结局的一种。[美国电影艺术与科学学院编剧资料](https://www.oscars.org/sites/oscars/files/complete_screen_writing_activities_guide.pdf)用于区分可见行动与梗概解释。[Celine Song 与 Greta Lee 的《过往人生》采访](https://time.com/6284223/past-lives-celine-song-greta-lee-interview/)中关于告别等待和沉默的说明，用于检查低烈度故事是否能在事情结束后留下情感余波

本轮阅读的是上述一手创作者访谈文字与教学资料，没有声称逐帧重看整部影片；网页夹带的广告内容未作为创作依据。修稿采用本作自身的物件、职业、生活规模及玩家行动，不照搬影片人物、台词或时长

## 五项结构修复

| 差距 | 修订后的具体行动与后果 |
| --- | --- |
| 高潮把演练再做一遍 | 第七章演练协作、缺项中止与安全回退；第八章实际拆改才让剩余联系中的两轮归返重叠，玲放弃此前争取保留的檐段，重新建立窗口并等待现实核验 |
| 旁白过早讲出答案 | 玩具先看归还与实物差异，学校先比较影像和交接，渡口先确认旧提示已停而构件仍动；解释由取得的证据支持，提前看懂不强制补一次误判 |
| 双主角分别受教，少有相互影响 | 第二章曜代报玲的核验时间，令她错过首轮校样；第三章玲又代报两人到场，迫使曜改顾客试用；第七章各自承担，不以互有过错相抵，重新安排各自工作 |
| 城市规模只体现在更多异常节点 | 第六章同一有限转运时段容不下苗盘、备料和必要音响，维护安排排除无限追加运输；首演取消、交付失约和新苗转运分别留有实际后果 |
| 支线都被正确沟通抚平 | 唐惠仍遗憾朋友错过；读者查清版次后仍争论；月城修拒绝具名；育苗两路都会失去一部分用途；安可与遥保留创作分歧；遥与维恩听完两首歌仍不喜欢同一种音乐 |

拆檐代价先有物理依据：附属连件也承担支承，原位保留需要新的独立设计，已核验工序允许支撑后整段卸下。旧材料留样、临时遮雨失去与小册重画持续到尾声；A 仍可安全收住现场，代价是更广临时停用与后续施工，不能靠回退复原已经拆下的实物
