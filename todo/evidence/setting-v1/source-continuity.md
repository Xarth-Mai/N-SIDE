## 2. 对现有文字需要作出的兼容修订

**《噩梦与梦魇》的现实影响段。** 保留肉体直接损伤为零的边界，补入非生物介质的有限物理输出，避免“只有精神影响”与已确认的现实投影相互冲突。

**《最后的玩具》的“消失”。** 将其明确为实物离开原位、滑入附近容器或夹层；数量、位置、路径和痕迹可以核对。梦中的保留室继续复制内部空间与物件，现实不跟随无限增生。本文将其发展成完整游戏候选第一章，不自动确认 Demo 范围。

**城市名称与局部气候。** 将已确认的 Null 来历与独立维持条件写入世界设定；气候变化持续需要能量交换，日期、年龄和生活继续。摘星台具体成因仍保持未定，其既定视觉与用途不改。

**家庭和人物档案。** 三名既有角色 ID 继续使用；工作名与新增经历是本稿发展内容。新增配角 ID 在真正合入前再与当时仓库检查冲突，不以本稿预占影响其他开发。

## 3. 制作时的关卡与信息检查

每个主要调查片段需要同时具备人物目标、玩家行动、获得或修正的信息，以及可观察的状态结果。第一章已列出 12 个主要动作节点，其余章节提供可拆分的处理序列；细分到正式 Beats 时按仓库流程推进，而不是直接将长篇梗概作为对话文本。[R06]

同一关键事实需要不同来源支撑。照片不是自动可信的全部真相，梦境不是万能审讯，熟悉的语气不是身份验证。玩家的错误推测可以通过可恢复结果修正，提前作出正确判断则获得承认并推进。

主线关键事实不依赖纯生活支线。没玩桌游、没买某种面包、没让某位居民出镜，都不会使终章缺少必需支持。准备阶段的地点列表表示可选分工与替代会面，不是强制收集清单。

失败读档使用游戏状态恢复。正式任务资产需要记录真实退出、检查点、一次性事件、再次访问与分支结果，避免物品重复交付或 NPC 永远保持危机状态。

## 4. 空间、同意与角色职责

91 个场所的名称与建筑归属按现有地图整理，新增故事关系作为独立叙事层。校内访问、诊疗、住宅、寄存物件、客户照片、设备数据与研究材料各有授权和管理。公共台阶、公共屋顶到达与私人内梯不混同。

影院、餐饮层、屋顶公园和共享工作室共用 V-15，但有不同入口与使用边界。渡口低层按水位和船班管理，上层通路独立；公共球场位于校外，不从校园内部随意穿行。

专业人员在现实安全、照护、场地维护和大范围行动中承担自己的工作。兄妹擅长已经深入理解的局部结构与街坊联系，既不是所有职业的替代者，也不是只负责给专家跑腿。

各地点的叙事关联尚未经过游戏内路线实走、碰撞或导航验证，不能从本文宣称所有进入路线已经可玩。地图数据中的建筑尺度也不因本次写作被重新批准。

## 6. 后续真正需要制作的内容

下一阶段从第一章候选中选取代表性片段，形成可执行 Beats、场景与对白、物件检查状态和潜梦处理灰盒。试玩重点是玩家能否自己说明“为什么改变这个条件会产生结果”，以及离开事件后是否记得当事人的生活。

完整游戏的篇幅、演出规模、资产预算和最终关卡数量由原型与生产决定，本稿不虚构完成日期或成本。工作名可以统一调整，不必为每个配角重新展开长访谈；影响因果的大改再回到所属设定讨论。

自动检查覆盖：91 个场所 ID 完整且唯一、12 街坊归属有效、64 个关联建筑号去重、V-15 四个场所一致；35 角色和 18 任务 ID 唯一；人物、任务、连接地点引用可解析；角色住宅归属有效；有潜梦安排的任务只配置一名兄妹潜梦；本地文档链接与整合阅读稿锚点可解析。

人工文字审阅针对以上连续性项，属于设计核对，不是科学验证、临床验证或游戏测试。机器检查也不能证明戏剧效果、设备安全与世界物理真实可行。
