## 1. 三类信息

**已经确认的设计。** 本轮对话中用户明确选择与修正的规则，以及用户认可的前一版背景续写，构成本稿设定基础。它们不是研究论文里的事实，也不因仓库尚未同步就失去本轮创作意义。

**仓库既有事实。** 建筑和场所名称、地图 ID、空间功能、家庭基本关系、Agent 身份与潜梦分工、现有叙事流程来自实际读取的仓库资料。地图和本次新增读取以 `9a56ec7e1f541db2b5f0fe6fa74b795fdd9039f5` 固定版本为基线；先前对话已经读取的角色与世界正文继续作为本轮已知设定沿用。

**本次新增创作。** 林屿、林澄、粒粒、季闻、许遥及配角工作名，具体年龄扩展、职业联系、章节事件、当下主线、生活支线和 91 场所叙事联结为本次发展稿。新增关系不冒充仓库已经存在的条目或已实现的游戏内容。

## 3. 关键决定台账

| 类别 | 本轮确认内容 |
| --- | --- |
| 现实影响 | 允许有限物理改变；不直接改写空间；梦中受击不直接损伤现实肉体。 |
| 科幻依据 | 生物电、电磁耦合和磁性留存为类比；介质是普通物质的特殊状态；电路不是所有故事的字面机制。 |
| 通道与能源 | 活体信息接入，非生物异常介质承担物理输出；外部供能与有限蓄能；休眠保留记录。 |
| 连接 | 有可追查的连接，当前有效通路传递新活动；离线留存与本地独立活动区分。 |
| Black Case | 梦魇活动投影到现实的具体异常；传递有条件，可有意或无意，后果可被现实连锁过程放大。 |
| 历史 | 异常古已有之；研究在先；近代重大事件推动公共认知；Null City 为核心；正篇前十至十五年，本稿排十二年。 |
| 事件条件 | 天时地利人和；持久联合梦境实验与天然环境相遇；自然介质为传播基础。 |
| 伴侣 | 早期研究者与遭遇普通事故的伴侣；对方真实参与；继续共同生活是目的，联合梦境是手段。 |
| 恐惧 | 健康一方受早期独立验证缺口所困，无法确认回应是否由自己幻想。 |
| 梦魇 | 来自二人共同梦境内部，无自我意识，旧片段反复侵入当下。 |
| 后续 | 事件先自行停止扩张；后来确认真实共梦、实际终止原始梦魇；独立局部异常与共同生活继续。 |
| 已认可的续写 | 伴侣为图书编辑；小店独立事件；父母与普通童年；城市当下变化引出新的联系而非旧源头复活。 |

## 4. 数据索引说明

`place-catalog.json` 是从已读取主数据整理的场所目录，保留 ID、名称、街坊与建筑号。`city-story-map.json` 在这些字段之外增加叙事关联，不覆盖原地图数据。`characters.json`、`quests.json` 是作者查阅索引，任务的关联场所包含可选、替代和重访，不是必须逐点访问的执行清单。

相关文件可以用于后续拆分正文，但不等价于仓库规定的正式 `narrative.json`、`dialogue.csv` 或资产清单。生成文件、修改仓库、实现任务和完成试玩是不同的交付动作，本次只完成前者与设计整理。
