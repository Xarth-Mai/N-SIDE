## 原有内容与边界

完整故事中米娜离城，Demo 仍不包含站前送行。《最后的玩具》16 个节点及 22 个信息状态保持，运行 JSON 只改变人物展示名称。旧八支线 ID 不重分配；新增四条故事保持可选。亲属、场所使用边界与人物主体性沿用当前设定

地图仅改变 22 个展示字段；对象键、数量、数值、位置和拓扑保持。改名页有旧 URL 跳转，历史正文和证据不批量重写。原任务验收不由这次文档迁入自动推进
