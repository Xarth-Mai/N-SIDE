# 短登高回程坡形 r3

基线 `f93af27`，接续 [r6 画面自查](../visual-r6/review.md) 的直切楔面问题。本轮修改已有地形生成器及其烘焙后缀，不改最高点、道路走法、建筑基底、平台、入口或稳定 ID

## 定位与取舍

原真实第 44 帧射线对应的源三角包括 `[156,732,277.626]`、`[168,732,282.934]`、`[156,744,292.634]`，仅 12m 水平距离就升高约 15m；相关三点坡度约 53°–55°。楔形已存在于未裁切 Ground，裁切和草岩分批将它显示出来，没有证据表明材质或道路裁切创造了这些高度

生成器的自然山峰公式与最近道路之间使用 45m 的路槽过渡，但旧近景细化只覆盖道路两侧 30m，外部仍为 60m 网格。两套形状叠加后形成规则路槽及其上方突起，仅增加点数不能改变这个目标高度函数

先试算将过渡加宽，固定窗口的坡度 p95 反而从约 56°升至约 63°，因此没有采用。最终复用现有 `buildGround`，以手工点、真实道路与场地控制建立共同包络，只削减第二段短路上坡侧高于该包络的突起，并保留固定种子的局部变化；坡面不是统一平面，外围与峰顶继续使用原规则

补充点曾使邻接第三段路缘失去支承，现已一起补齐受影响的真实路幅边缘控制。新增支撑只进入局部包络，不重复改变外围残差权重。源坐标不动，改变的是自然坡面怎样连接这些既有标高
