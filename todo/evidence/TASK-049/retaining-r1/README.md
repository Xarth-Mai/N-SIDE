## 初次失败与位置修正

初稿把 `shop-steps-low` 和 `shop-steps-middle` 南侧当作有较大填方的立面，真实窄测发现只有混凝土墙冠批次，金属泄水口全部因露高不足跳过，期望 `4` 批而实际只有 `2` 批，[失败日志](initial-failure.log)保留原结果

源数据已沿两处平台边缘约每 `2m` 烘焙同高地形控制点，边外 `0.2m` 真实落差仅约 `0.10–0.18m`，不能通过下拉地形或放宽批次断言制造两米挡墙。[Rust/Spade 的 36 条边实测](edge-probe.log)确认了这一点；随后改选上表两条确有露高的填方边界。临时探针已从测试代码移除，正常窄测仍要求两处各有混凝土与金属构件
