## 成熟度修订

根据真实总览直接修订三组实例为 1.4–1.8 倍的可复现变体，原模型和旧街树不改。候选树高 9.1–11.7 m，树冠包络、道路与门口净空、与所有既有实例的间距、根周采样半径和摘星台视线同时按 scale 核算；根周高差仍不超过 0.55 m，真实根部埋深仍小于 0.6 m。增大树冠后允许安全筛选降低数量，不为保持 38 棵填入不合格位置

正式模型生成此前会以资产 scale 覆盖实例 scale，已改为两者相乘，使林群尺寸真实进入游戏场景；旧实例 scale 为 1，保持原倍率。根 Agent 已串行复验，独立日志 [native-mature-tests.log](native-mature-tests.log) 为 20 PASS／0 FAIL：三组最终仍为 14／14／10，但部分候选被更宽的冠幅与根周圈排除后由同一区域的其他合格点接替，源 ID 及实际 scale 逐棵列在日志中

最终安全实例覆盖 1.4–1.8 倍，真实根部最大埋深 0.447152 m，38 棵／214 个派生实例／138 棵松树的计数不变，新增三角量仍为 247,380。模型未改，几何量未因放大增加；可见覆盖、阴影及实际渲染成本仍需运行测量。初版根近景所指的 `forest:1:4` 本轮被实际避让排除，保留原机位观察同一区域可见树根，不宣称该对象仍在原位
