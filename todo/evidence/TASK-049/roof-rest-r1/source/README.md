## 修复与边界

原 4m 公共屋顶通路沿 `x=340、north=220..245、h=37`，屋面支承内半幅，既有平台只从 `north=240` 起支承外半幅；先前实际 `CollisionWorld::from_parts` 与 `CollisionWorld::from_scene` 查询均在外半幅南段发现缺口，不能因节点中心线在屋面边界上就视为整条路可通行

本轮把现有平台向南延伸至 `x=340..342.15、north=220..240`，新增 43m²，包含缺失的 2m 行走宽度及 0.15m 结构余边；新增区域在 P09-A 内，完整保留原北部平台，不变更任何节点、道路、路线、访问权限、建筑轮廓和 37m 高程

新 polygon 的 edge0、edge1、edge8 均向 V-15 承托；原建筑接触边从 edge6 改为 edge8。新增外缘依靠短梁，避免在低层 5m 公共电梯接近路与二层餐饮接近段中增设落地柱；梁本身的生成、跨度、边界和净空由同轮 Rust 检查验证

五块 `court` 铺地沿既有东侧通路、花园入口及维护路线的真实宽度铺设，并以 2m 支路连接 `[334,245]` 的既有花园入口与 `[312,237]` 的长椅；休息岛为 `x=309..315、north=235..240` 的 6×5m 平面。铺地全部带 `building=V-15、elevation=37、elevated=true`，插在原 `cinema_roof_surface` 前，利用已有同高遮罩裁切避免叠面；实际联合面积约 164.089m²，原 1200m² 屋顶仍保留约 1035.911m² 草地

`cinema-roof-planting-reserve` 是原屋面内 56m² 的普通 `park` 分区，唯一源矩形为 `x=329..336、north=228..236`；五块铺地均不侵入。该位置是本轮布局选择，承接 QST025 的待恢复植床要求，不声称故事原文已有这些坐标，不新增剧情状态；遮阳资产与围护检查直接读取此 ID

维护路径仅铺屋面内的真实带宽，北端在既有未建货梯界面收口；屋面外的道路半幅未被补成新地板，也不能作为可走出口。服务道路和货梯的 `access=service` 原样保留；公共道路及已有上街平台权限不变
