# 镜厅公共屋顶 R6：支承、铺地与遮阴

基线 `60cfed49aa5f9fc31034184c084d625596314261`，本轮施工范围为 V-15 的公共屋顶与东侧接续；所有原对象 ID、道路节点、宽度、权限和楼层标高保持。最终4组Viewer共420帧、22项原生／22项包装检查通过，机器结果与实际看图分别记录，不代签作者品质或阶段放行

## 已实施内容

[源数据记录](source/README.md)完整记录 43m² 东侧平台补板、五块同高铺地及 56m² 养护草地区划。屋顶硬铺约164.089m²，原1200m²屋面的大部分仍为种植范围；原树荫座位通过2m短支路接入公共花园入口。屋面同高遮罩避免叠面，座椅与遮阴底座保持37m

[遮阴资产](asset/README.md)使用本机 Blender 制作两根后柱、短撑、三个悬臂与十根木条，复用公共座椅及已有CC0木材图；新增1104三角、2材质、2图，正式源与运行导出字节一致。现有环境导出器处理第38个文件，没有引入新资产框架、在线服务或新许可来源

新边界采用1.15m可见金属栏，真实网格直接参与碰撞；RF与外平台接缝保持开放，北侧回栏接到原桥的侧栏。未建成的公共电梯及货梯口由端栏封闭，地图上的设计节点仍保留，不将其写成可用升降功能；实际公共上街通路保持连通

原平台承托算法把梁中心点位于范围内误当作完整截面在范围内，本轮向平台内收半截面宽并以完整梁截面判断能否延长，保留最大6m跨度、承压重叠、范围与低层净空检查。影院桥原栏不识别 building-owned RF decks，本轮只把已验证全宽支承的两个影院屋顶deck作为桥栏同高接续，不改其他桥或地形道路

## 失败与修订

- 原真实场景80个水平采样点有24处外半幅无支承；道路图连通不能证明楼板存在
- 初次把公共电梯写为外部承托井道时，被原Map契约拦下；改由已存在的V-15主体承托，未放宽外部lift要求
- 第一次角梁算法仍让延长后的截面越出平台，保留FAIL后改为检验完整截面，最终承托窄测PASS
- 首轮屋顶检查发现栏柱半截面越过局部范围断言、射线碰到新增下横杆；范围按实际半对角校验，地板探测下降到37.06并排除护栏来源
- 独立审查发现未建井口可直接走落、局部边栏端头可绕行；实际加端部防护与回栏，不以文字警告替代几何
- 第二轮完整场景胶囊在外半幅接旧桥时撞到未识别屋顶到达的桥栏；修复真实桥栏接续，保留原失败日志，未通过放宽通行断言掩盖阻挡

- 最终场景脚点检查显示右侧遮阴底座落在先绘制的同高座席支路，而非随后被裁切的休息岛；两者均为实际铺地，检查按两个明确来源与左右脚分别核验，没有放宽高度或容许护栏代替地面
