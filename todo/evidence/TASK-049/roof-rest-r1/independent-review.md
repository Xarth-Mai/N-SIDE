# R6 独立代码审查

范围为 `geometry.rs` 的承托、`scene.rs` 的屋顶围护与遮阳实例、`collision.rs` 的实网格和断言；这三个 Rust 模块由主集成与另一审查者修改。本审查者同时是源铺地作者，铺地部分属于源作者复核，不能冒充独立作者验收

## 有效发现

1. **未建垂直口不能以“测试无栏”作为到达成功**：初版护栏给 `cinema_lift_high` 与 `cinema_goods_roof` 留空，并要求跨南、北边缘的 capsule cast 无阻挡；实际边界外没有相应 37m 电梯平台，文字标注“不可作为出口”不能阻止走落。已交主集成：在未实现垂直转场前增加可见实体防护，源节点与权限保留，测试区分沿屋面通行和跨未建口
2. **局部围护需要接回既有桥栏**：初版在 `north=250` 截断本地围护，平台继续向北延伸；实际 4m 桥路栏中心与局部边界在该剖面的 x 坐标分别是 `[340.929632483,345.737034184]` 与 `[340,350.470588235]`，两侧留下约 0.930m / 4.734m 的可绕行边带。已交主集成：增加局部回栏接回真实桥路栏，只留完整桥路通道，不必重做整条北平台
3. **遮阳脚总顶点数不能证明两侧接地**：初版 `feet >= 8` 可以仅由一只底座满足。已交主集成：分左右实际几何检查接地，并要求支承来自本轮同高铺地；现有模型未发现单侧悬空，此项修复证据语义

## 承托与源复核

承托起点按 polygon 朝向向内移 0.4m，与 0.8m 截面一致；随后重新计算最近承点与入墙端点。可选外伸段采用完整截面与 `surface ∪ anchor` 比较，只有差面积不超过原有 0.01m² 容差才选用，否则保留未外伸梁；最终梁仍检查承压重叠、完整带宽、内收起点至入墙端不超过 6m 的主跨度及低层通道净空，没有用裁去悬空梁面或放宽容差来遮住空隙

原错误电梯承托的真实 `Map::load` 失败保留，最终承托全部指向 V-15；已读取 [bearing-final.log](bearing-final.log) 的实际 PASS，覆盖三个既有承托表面与原高度、低层通道反例。该单测不证明材质、构图或作者体验通过

新增六块同高表面放在原屋顶草面之前，按现有遮罩裁切，原屋面 ID、轮廓和标高保留；维护路径裁到真实屋面，原节点、路宽与访问权限不变。源检查和实际失败反例见 [source/README.md](source/README.md)，不把源宽度采样当作运行碰撞结果

## 验证边界

本审查没有启动 Cargo、GPU 或新增探测可执行文件；主集成正在执行 CPU 检查。早期 CPU 结果不能覆盖此后围护修订，必须复跑相应断言；本记录未将未运行的 GPU 验收写成通过

## 修订后复核

两个未建垂直入口已由同一套可见实体栏关闭，测试从“口能穿过”改为“口被阻挡”；屋面内维护路径和已有上街入口继续检查畅通。局部围护先将真实屋顶与平台 union 裁到 `north≤250`，在截面生成回栏，只按既有公共桥的实际 4m 道路带、每侧增加 4cm 切开；7cm 端柱与已有 16cm 桥栏有平面重合，保留原桥道通行宽度，避免从两边绕过本地栏端

护栏单测现检查八个边缘、未建口与回栏阻挡，以及五个真实已支承路径畅通。碰撞单测分别验证左右遮阳底座位于 37m 的新休息区或座席支路铺地；80 个地板采样点从下横栏以下发射支承射线，并明确拒绝 `boundary-guard` 来源，防止用护栏横梁或柱脚代替真实地板

随后 [roof-cpu-retry.log](roof-cpu-retry.log) 实际证明新围护检查通过，但东路外侧 `x=341.6` 在 `north≈243.8206` 撞到既有 `/roads/168` 桥栏。根因是原道路 mask 排除了建筑内部 deck，旧桥栏不识别本轮已补齐支承的屋顶接续；新增约 25 行仅在含 `cinema_roof` 的 bridge 生成护栏时，把 `building=V-15、surface=cinema_roof_surface、kind=deck` 的两条真实道路带加入同高栏杆邻接，复用原宽度、折点和高差裁切。普通道路顶面、地形 mask、其他桥路均未改，碰撞测试仍要求原 23m 路径无阻挡

[roof-cpu-final.log](roof-cpu-final.log) 进一步证明地板、通路和接缝断言已推进通过，随后在右遮阳底座来源断言失败：实际接触点 `[313.623,37,-238.173]` 位于先绘制的 `cinema-roof-seat-walk`，高度仍准确为 37m。最终断言接受 `cinema-roof-rest-court` 或 `cinema-roof-seat-walk` 这两块明确的同高铺地，并继续要求左右底座各自接地；这是与真实裁面归属对齐，没有降高度精度或接受任意支承来源。全库复跑仍由主集成记录，不能把此份一过一失败日志当作最终通过

修订代码已完成只读复核，三个独立审查发现及随后两项真实诊断均已处理，未发现新增代码阻断；最终 CPU 复跑与 GPU 画面仍由主集成记录。本结论只确认代码与断言语义，不把 1.15m 防护表述为能够阻止所有主动跳跃，也不宣称尚未执行的玩家验收通过
