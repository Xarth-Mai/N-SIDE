## 实际变化

- `roof-bench` 与 baseline 的 59 使用同一座椅机位：原先座椅直接落在与山体同色的草面上，现在硬铺岛与后方护栏清楚界定停留面；条栅阴影实际落到椅背、椅面及砖地，支柱底板与硬铺接触，未见明显浮空或穿过座椅
- `roof-city` 31–33 显示座席、遮阴梁、硬铺支路和外缘护栏相对位置连贯，横移中未看到铺地交替闪面或构件突然错位；遮阴是有实体支撑的局部构件，没有变成一整层新屋顶
- `roof-wide` 49 与 31–33 可以辨认镜厅本体、屋面护栏、东侧铺地带、接桥平台及通往座席的支路，屋面不再视觉上直接并入后山草坡；接桥处没有观察到明显新断板或护栏横封整个公共入口
- `roof-bearing` 49 与 61–63 显示外半幅板底、伸入建筑的承托块和接桥斜撑，所看横移段未见承托与板之间的空隙、孤立悬块或与窗面明显交叉；承托目前仍是粗方块，不能将其视作已完成建筑构造细部

## 仍需保留的问题与边界

屋面大部分仍是均匀黄绿草坪，广角可见重复纹理的平行带；朝城机位的远处建筑被护栏和低天际线挤成窄条，停留区的城市视野与植栽层次仍不足。护栏远景出现密集细线和局部不均匀的像素密度，所看短横移未见大范围明暗翻转，但不能据三个连续帧宣布远距抗锯齿问题已经消失

当前护栏和遮阴的浅色与周围灰盒体量仍较接近，窗面继续平板；收益是空间边界、硬铺与真实投影成立，并非达成 README 参考图的材料、光影和生活密度

未建成的南、北井口采用可见端栏封闭，属于预览防护，不能称作可用电梯或服务货梯；公共上街平台的现有入口继续保留。碰撞与承托数值检查归 [整合记录](review.md) 和独立技术证据，本视觉自查不扩展其结论

结论：没有在本轮实际查看范围内发现应撤回屋顶修订的明显穿插、浮空或断接，可保留为局部可见改善；作者美术验收仍为 NOT RUN
