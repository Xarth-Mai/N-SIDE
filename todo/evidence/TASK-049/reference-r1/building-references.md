# 绝区零建筑参照与现有建筑家族对应

2026-09-30 的只读研究，为 N:SIDE 现有建筑选取《绝区零》中的具体视觉参照，沿用 [地图唯一源](../../../../source-assets/district-map/district.json)与[建筑规格](../../../../docs/dev/design/locations/district-architecture.md)。本轮逐张实际观察了 15 张原图；231 个建筑体量均有家族参照，16 个类型分组包含无 design.type 的 7 个背景体量。对应表是制作选择，尚未改造资产，也不代表建筑造型已验收
