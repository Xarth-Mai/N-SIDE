# 草与石块制作 r1

基线 `13397c5626c8952511ceda52d3c4a8877b901acc`，使用现有素材管线与 Blender 4.5.14 CPU 两线程制作两份原创模型，草贴图原创，石块复用已登记的 ambientCG Rock043L CC0 贴图。源文件、尺寸与再导出方法见[草石规格](../../../../source-assets/environment-kit/vegetation/ground-props.md)

## 实际结果

`ground-props.py` 首次造型及 `--export-existing --render` 再导出成功；[构造日志](build.log)、[再导出日志](reexport.log)和[最终 GLB 几何核对](contracts-final.json)，复现为 `python3 -B todo/evidence/TASK-049/ground-props-r1/check.py`记录原件 hash、面数、尺寸、非退化三角、嵌入贴图与不透明材质。两个 GLB 共 1,640 三角，按既有环境导出器复制为运行文件，`--check` 通过全部 33 个文件、73,332,914 bytes

实际查看草石 DCC 图：草叶由尖折楔体改为窄曲面，石块有岩纹、法线及不规则轮廓；首版草图把预期亮度写成过暗的 sRGB 编码值，棚拍和首轮实机均显黑，随后改为明确的 sRGB 色值。最终实机可见淡绿窄叶与有岩纹的石块，根部随坡面倾斜，连续横移没有看到整体跳位；草丛在此机位仍很小且分布稀疏。原有针叶树、灌木与布点规则保持，本轮没有完成连续林缘与全山植被

第一次原生贴地检查失败于 `understory:0:0:73`，该项为石块：旧规则把底面上方 3cm 内的侧面也当根部。读取实际 GLB 后确认石块有 28 个平面底部顶点，另有 12 个 0.004027–0.029184m 的低侧面点；草有 180 个底面顶点。现在草石仅取 `y < 0.001m` 的真实底面，灌木保持原规则，悬空／埋深容差保持原值。修正后的原生检查 PASS，46 件林下物合计 107,768 三角，草／石底部最大埋深分别 0.063427m／0.065950m；完整几何仍参与路径避让与观景视线检查

对最终地形和全部运行模型执行的构建、测试、GPU 画面、连续操作及清理结果统一在[第 9 轮集成记录](../../TASK-045/visual-r9/review.md)。环境素材的细节改善不表示作者风格验收或性能预算已完成

首次集成在开始渲染前以非零退出：Blender 的非默认高光值生成 `KHR_materials_specular`，当前静态场景加载器明确不接受该扩展。将主文件材质恢复核心 glTF metallic-roughness 参数后重建，两个最终 GLB 均无 extensionsUsed；未修改引擎依赖或放宽加载器。失败日志与两次成功复验由集成记录保留，初始 `contracts.json` 对应修复前文件，最终结果为 `contracts-final.json`
