# TASK-047 · 曜可蒙皮模型 r1 实际制作与检查

本轮读取了人物 r3 全身图及镜厅预览左侧竖幅人物海报，保留少年外观、宽短连帽外套、层叠内衫、休闲裤和运动鞋；未选择新的配色，也未改变故事年龄。运行材料仍是未批准灰阶，DCC 灯光只用于检查网格

## 已实际制作

- 新建可编辑 `source-assets/characters/CHR-001/model/yao-grey-study.blend`，配套初始重建脚本、从主文件导出入口、真实 UV/灰阶图集和逐帧 DCC 检查
- 原创人体、衣服、脸部、五指、鞋与薄片发束；32 骨和最多四权重；`Idle`、`Walk`、`Run` 都有真实变换关键帧，Root 保持 in-place
- 运行 GLB 从可编辑分件副本合并为一个图集网格、一个 primitive、一个材质和一个嵌入 PNG，场景名 `Scene`；辅助相机、灯和地板不导入运行文件

## 画面自查与实际修订

已查看同一套 CPU Cycles 固定光照和正交机位的正面、背面、三分之四、脸部近景、Walk/Run 接触和抬脚画面。它们是 DCC 渲染，不是游戏截图；本轮未占用 GPU

第一版虽然 GLB 数值通过，美术不通过：袖顶像肩甲，两袖鼓成大团；长圆柱颈与下颌形成硬切面；眼白像浮起的大白片；刘海像整齐绳股；初次步态还有双脚浮空。没有将这些结果称作完成

根据实际看图及 root 独立审查，已作以下网格与动作修改，再次用相同机位渲染

1. 头颈改为连续的关节环线，移除独立圆柱颈和下颌封口；头部整体下降 18 mm，缩短可见颈段
2. 缩小眼白，按细分后真实面部的 BVH 射线位置贴合，眼白用三角扇跟随曲率；加入上下眼睑，降低眼睑与眉毛厚度
3. 夹克衣身开真实袖窿，16 点边界直接连接袖面；取消互相穿插的袖顶封口，收窄袖山与袖肘体积，内衫肩线低于夹克肩线
4. 前发由重复的九根厚条改成五组错落尖薄片，厚度比例从宽度约 22% 改为约 3.5%；调整侧后发际线，保留闭合体积和实际法线
5. 走跑改为两骨腿部解算的脚轨迹，配合 Hips 局部升降；脚底仍靠真实关节与权重到达目标平面，Root 与世界位置不动

这轮修改直接降低已观察问题，未代替作者外观验收。面部个性、发束节奏、衣服结构和真实日漫材质仍需下一轮角色美术精修；动作还需在实际步速、转向及坡面下匹配，跑步姿态与手部表现尚未锁定

## 独立复看与合流边界

root 已实际复看修订后的三分之四、脸部和 Walk 接触图，仅准许作为显式 `--character-preview` 技术候选合流。肩袖与眼片已有改善，但脸颊→下颌→颈部仍连续锥化，五官有贴片感，袖体偏膨胀且衣料边缘有锯齿；距硬边赛璐璐日漫目标仍远，视觉状态为 `needs_revision`。下一轮应直接修改这些部位与真实游戏材质，不扩大候选覆盖，不通过“候选”措辞将它们视作完成
