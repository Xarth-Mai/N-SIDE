## 按优先级修订

1. **先分出下颌、颌下和颈部的转折**：保留短下颌与细颈，在现有连续网格上把前下巴、侧颌和后颈分别塑形，让颌下回收后再接颈柱；正面应读到独立下巴，三分之四与侧面应读到颌下空隙。入口为 `build.py:303–305` 的 `Face_Head` 环线，重点是原始 Z 为 `1.464 / 1.508 / 1.521 / 1.526` 的颈上缘与下颌环、各环 `y / rx / ry`，以及第 4 环 `.012 * cos(angle)` 的前后高度差。当前 `loft` 为整圈椭圆，单纯改半径仍容易延续圆锥；最小修法是在这些已有环线上按前／侧／后移动顶点。`build.py:408–414` 已整体下移头部 18 mm，先保持该值，避免继续压头掩盖结构问题

2. **五官跟随新脸面，先消除漂浮层次**：保留概括眼型、细上眼线和短口线，让眼角收尖、下眼线少于上眼线；鼻根贴合脸面，只让鼻尖保留小体积。入口为 `build.py:312–339` 的 `face_y`、`patch`、眼型 `.025 / .0105 / .003`、眼白至高光 `−.0018 / −.0029 / −.0035 / −.0041` 的层间偏移和眼睑半径。先收近层间距离并实际检查闪烁，不预定通用安全间距；`Nose` 与 `Mouth` 目前直接写死 Y 坐标，应随新脸轮廓重新贴合。继续复用已有 `face_y`，不为这一轮另造五官系统或加入更多眼睛零件

3. **让发束有主次，保持现有总量**：先把五组刘海组织为两组主束与较窄辅束，错开尖端与转折，额前留可读的分组间隙；侧发靠近脸侧收束，顶部保留蓬松轮廓。入口为 `build.py:369–388` 的 `bangs` 控制点与宽度、`Temple / Crown / Nape / Back_Lock` 末端位置；当前刘海宽度集中于 `.027–.031`，侧发由等步长循环生成，重复节奏是源码提示的风险，尚未经本次模型看图确认。保持 `hair_lock` 的闭合薄片结构与 `w*.035+.0004` 厚度起点，不增加细碎发丝，不把海报匿名角色发型直接搬入曜

4. **把袖筒收成布料，把衣边收成完整线**：保留 r3 的宽短与松弛感，先减肘部一圈突起，再压袖筒内侧厚度、保留外侧下垂，使肩到肘再到袖口有连续收束。入口为 `build.py:258–268` 的 `arm_points` 中 `rw / rd` 和袖口曲线；重点复看 Z=`1.113` 处 `rw=.065` 相对上下环的膨胀。衣边先检查 `build.py:238–241` 的下摆环、`fold=.018 / .015` 与 `build.py:299–300` 的 3 mm 厚度、一级细分，不直接提高全模型面数。衣边锯齿究竟来自轮廓、接缝还是采样须用同机位近景区分；袖窿连接依赖 `boundary` 的硬编码环索引，若增加衣身支持环须同步核对 `build.py:245–256`，优先移动现有环以缩小改动

5. **用同一灰阶与固定光照检查新形体，再判断画法差距**：保持 `VALUES`，以正面脸、三分之四脸、侧脸及全身四个镜头对照，脸部沿用 `ortho_scale=.39`、全身 `2.06` 与 720×960，新增侧面使用同样目标高度。入口为 `build.py:73–104` 的图集与 `Principled BSDF`，及 `build.py:477–493` 的灯光、相机；当前粗糙度 `.86`、高光 `.12` 和尺寸为 `4 / 3 / 3` 的三盏面积灯仍产生连续 PBR 明暗。下一次局部对照先保持这些参数固定，把几何改善单独看清；随后才用同一灰阶做单独的硬边明暗样本。调粗糙度或缩小软灯不能证明赛璐璐已实现，真实游戏的平涂、硬边阴影与轮廓表现仍需另做运行验证
