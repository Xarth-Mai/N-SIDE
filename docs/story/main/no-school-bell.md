# 第三章 · 没有放学的那一天

[主线总览](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

<a id="qst-004"></a>

**Black Case：“旧日点名”。场所：社区中学、照片冲印店、校外文具与日常用品店、放学饮品与外带铺、校外等候庭、居民服务中心、社区摄影工作室、街坊作品小展厅、山脚茶屋。林澄潜梦，林屿接应**

## 求助与真实因果

陈知夏参与《今天的街坊》，想拍同学放学后的路线。几次走访中，她和部分家长在校外等候庭听见同一段陌生点名，随后有人把当前的等候安排与旧日记忆混在一起。学校通知与学生去向需要人工再次核对

这一地区存在一段源于十二年前担心“还有人没接走”的反复梦境结构。顾竹当时参与教学与家庭联络，后来已经恢复自己的生活；外部留下的“点名者”却依靠本地环境独立维持，并在新的联系条件下活跃

它只会重新点名、等待回应。当前的儿童不是过去学生的复制品，旧照片也不会因为梦魇活动自动改写。现象主要是接入者的声音与识别干扰，少量门件抖动作为可观察的输出单独记录

## 调查与行动

玩家在校外公共区域先核对当下出入与接送记录，再由学校安排受控访问。文具店只提供经本人同意交付的相关打印件，诊疗与学生私人材料不作为随手翻阅的收集品

陈知夏绘制现在的路线，郑澈拍摄当下布局；郑泊与顾竹分别提供授权旧照片和讲述。玩家发现“当时没有顺利放学”的片段来自临时聚集与联络安排，不能把它理解成整个校园停止了一天

梦中校园有重复的人影和会重新回到名单开头的点名者。玩家先尝试回答旧名字，发现只会被拉回原位置；返回现实后，将独立获得的新变化与固定名单比对，确认这是无法更新的活动模式，不是本人在继续执行职责

再次潜梦时，玩家沿不同等候区找到结构的返回路径，用行动建立可完成的离场顺序；战斗用于争取经过封闭队列的时机。现实一方在安全窗口处理对应的局部输出点，结束当前影响

## 人物变化与历史线索

顾竹不需要被要求“原谅自己”才能完成处置。她可以在真实材料面前重新描述当年，承认有些事自己不知道。陈知夏学会给亲历、转述和推测分别标注，而不是挑最戏剧化的故事

不同来源的记录显示，十二年前多个地点的变化并不同步，事件不是一个指令瞬间控制全城。这个差异促使兄妹找楚青比较环境记录

小展厅最后同时放出一张旧照片与陈知夏今天画的放学路线。学生仍然去买笔芯、喝饮料、等朋友，不因参与主线失去自己的生活
