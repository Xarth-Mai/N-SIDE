# 序章 · 门还开着

[主线总览](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

<a id="qst-001"></a>

**主要场所：N站、站前广场、小店与住家、树下小空地、烘焙店、小修理铺、小店货运侧院、店侧台阶。无 Black Case**

## 故事

一次普通的补货日。姚安把包裹送到侧院，粒粒已经为新陈列留出位置，林澄的包装样品等着最后确认。玩家从店内走到采购街，帮陆衡取回一件修好的物品，再带一份晚饭回家

乔音到店邀请兄妹参与《今天的街坊》：把居民当下的生活、作品和去处编成一本小册，配合轮换展墙。她希望拍下正在被使用的店，而不只拍整齐空着的橱窗。米娜随后来问，能否帮忙看一件准备带走的旧玩具

## 调查与行动

完成一次前后场交接，认识共用店门、服务门、私人内梯与公共店侧台阶；参与一处陈列选择；走到街口、烘焙店或修理铺，按自己的顺路选择带回晚饭；与乔音聊小册的第一张照片；回到楼上参与晚间生活

选择改变橱窗的一小组物件和之后被熟客提到的话题，不影响获得米娜的请求。玩家可以先认识林屿或林澄的工作视角，之后的委托由两人按各自专长分工

## 留下的状态

橱窗出现玩家参与的组合；姚安和粒粒形成可辨认的交接反应；《今天的街坊》成为持续存在的普通创作项目。夜里小店仍然营业，玩家第一次从楼上看见楼下的灯
