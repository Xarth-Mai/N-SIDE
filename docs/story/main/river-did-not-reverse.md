# 第六章 · 河没有倒流

[主线总览](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

<a id="qst-007"></a>

**Black Case：“候船处的旧提示”。场所：河岸安静露台、河岸小广场、渡口入口与候船处、城市交通服务厅、渡运旧物展屋、河岸运动补给店、桥畔轻食屋、河岸共作亭，以及已有桥下通路。林屿潜梦，林澄接应**

## 求助与真实因果

渡口附近有人把旧提示当成当前班次信息，候船区也出现可记录的重复敲击和局部设施扰动。邵敏与渡运人员先恢复清楚的人工说明，邱宁关闭受影响的低层入口，上层公共通道继续开放

活动源“候船者”来自历史时期一个反复等待离场顺序的独立结构，依靠当地条件维持。它在近期重新连接时把旧有提示投影进当下，并不真的召来过去的船，也不改变河水的时间方向

真实风险来自错认提示、走向错误入口，以及设施扰动与当下水位的叠加。专业人员负责公众安全，兄妹调查内部活动

## 调查与行动

玩家与钟帆核对旧船票、照片与运营记录；邱宁提供不同时间的岸线观察。地图比对发现某些今日相邻地点当年并未连通，而几处离得较远的天然介质区域却曾处于同一有效联系中

梦境候船厅重复排队、叫号和延迟放行。玩家先跟随旧提示，发现总回到已经走过的等候区；随后利用现实接应提供的当下变化，区分可回应当前行动的场景与固定回放

通过调查找到候船者每次返回的关键联系，利用其固定移动规律创造窗口，再与现实一方配合解除有害输出。玩家不以说服“过去的人放下”代替处置，因为眼前主要是活动结构而不是等待拯救的真实旧乘客

## 主线判断

岸线资料补齐了季闻记录中的缺项：十二年前的联系随自然条件变化而逐步形成、逐步减弱。今天的观测显示相似条件正在部分出现，但更改过的地表环境、独立结构与供能状态使当前风险不同

叶初、楚青和相关专业团队据此组织更大范围的观察。兄妹负责已经深入调查的局部结构，其他地区由各自团队处理

渡口逐步恢复正常候船，仍有个别设施要维修。钟帆把已证实的内容补到展屋说明中，也明确留下哪些地方还不知道
