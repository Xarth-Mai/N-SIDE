# 雨停之后取衣服

<a id="qst-104"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)


洗衣店有一件衣物迟迟未被取走，何芸请熟悉的住户帮忙联络。调查发现只是收件说明与日程理解不同，并无异常

玩家可以在前场核对经允许的领取信息，通过茶桌庭的正常联系找到本人。衣物和私人资料保持受控，不能为了完成支线查看所有顾客的信息

物主回来解释自己临时改变的安排，何芸调整交接提示；玩家在居家用品店帮忙选择清楚的小标牌。之后洗衣店仍有普通等候，不必每次都触发谜题

场所：自助洗衣店、东侧住宅院、邻里茶桌庭、居民服务中心、居家用品店。关联角色：何芸、叶初、梁素
