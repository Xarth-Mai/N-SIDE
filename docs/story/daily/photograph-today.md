# 把今天拍进去

<a id="qst-108"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)


郑澈与陈知夏为《今天的街坊》拍摄普通人的使用场景。玩家陪同沿河取景，带上需要的雨具或手电，在摊亭买点东西，也可以邀请父母一起上山

照片的重点是当前生活：修好的栏杆、换过菜单的摊子、有人使用的共作桌。被拍摄者可以拒绝出镜，提供匿名物件照或完全不参与；不会因此缺少主线成功条件

冲印后由本人确认展示方式。玩家重访同一地点时，看到照片中的事物又有细小变化。结尾可在摘星台合照，也可只拍风景

场所：转角观河点、城市花园与活动草坪、山脚休息台、林间缓坡、小神龛、摘星台、河岸安静露台、河岸小广场、河岸小摊、花草店、照片冲印店、社区园艺温室、屋顶公园、社区摄影工作室、滨水咖啡屋、河岸运动补给店、桥畔轻食屋、河岸共作亭、山脚茶屋、林缘自然观察庭、登高用品租修店。关联角色：郑澈、陈知夏、郑泊、温苒、顾竹、父母
