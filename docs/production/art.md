# 美术

## 视觉方向

清爽、通透的日系现代都市：动漫化角色、生活痕迹、年轻化店面、绿植与高低差。白天、黄昏、夜景和雨后共同构成城市面貌，夜景包含霓虹、广告与万家灯火

人物与街景在动漫化表达中保留生活细节：使用过的物件、用心布置的陈列、绿植与日常活动，让城市具有可以亲近的尺度。小机器人的表情、姿态和即时反应体现共同生活的熟悉感

坡路组织视线与行走节奏，高处的开阔景色与近处的日常空间相互呼应。天空、树影和远处水面的光线随时段变化，承接散步、停留和回家的情绪

两张空间参考保存在[N街区](../locations/n-district.md)。人物造型依据各角色档案，关卡空间依据各地点与玩法规格

## 制作

需求 → 概念 → 技术样板 → 源文件 → 导出 → 接入 → 场景检查

技术样板记录单位、比例、朝向、材质、透明表现、动画组织与碰撞。交付包括源文件、导出文件、依赖素材、来源与导出方法，资产关系进入清单

在实际镜头下检查轮廓、遮挡、交互辨识、动作同步、昼夜效果与资源成本
