# 玩法制作

以下规格用于玩法实现与验证，玩家介绍见游戏指南

## 操作

支持手柄和键鼠，两种输入方式覆盖相同的玩法动作。玩法使用动作名关联输入，界面根据当前设备显示提示

### 交互约定

移动、观察、交互、确认、返回、暂停与战斗动作分别记录触发方式、允许状态和反馈。菜单记录焦点顺序、默认焦点与返回层级

按键映射、长按方式、震动、屏幕抖动与字幕作为体验配置项，具体支持范围由交互规格记录

### 操作验证

检查移动与朝向、镜头和遮挡、交互目标识别、菜单导航、暂停、设备重连、焦点恢复和输入切换

## 关卡

### 空间规格

地点档案保存场所的身份、生活与空间关系。关卡规格补充入口、出口、主路、支路、地标、视线、交互点、遭遇与恢复点

灰盒验证移动距离、镜头、遮挡、碰撞、路线辨识和停留空间，结果用于确定尺寸与布局

### 时段与状态

场景记录当前季节，以及昼夜下的灯光、人流、活动、对白和可达内容。梦境关卡记录现实场所与错位空间的对应关系

### 制作与检查

模块化构件记录单位、轴向、对齐、材质与碰撞。资产接入后，在实际镜头中检查可达性、地标、交互、视觉与声音反馈

性能测量记录设备、分辨率、场景、帧时间、内存、加载时间和资源体量，场景预算由样板测量形成

## 战斗

### 角色与工具

兄妹在梦中保持日常衣着加工作装备，使用功能相对稳定的专门设备与工具。基本操作跨梦境沿用

战斗服务于[异常处理](../gameplay/dream-diving.md)，Agent 按[协作优先级](../characters/agent.md)提供辅助

### 动作与反馈

每个动作记录输入、进入条件、动作阶段、判定范围、打断和结束方式。动画事件对应玩法时间点，判定、受击、位移、VFX、SFX、镜头与 UI 共同表达结果

敌人通过姿态和预警表达攻击意图，其档案记录玩家对策。生命值、速度、冷却等当前数值保存于游戏数据

### 战败与重试

普通战败从检查点重试，正式剧情沿成功推进的路线记录。检查点恢复任务状态、场景与角色状态，具体保存点随任务设计

剧情中的受困、救援和永久影响由对应事件安排。梦境与现实伤害的关系见[梦魇](../world/nightmares.md)

### 检查

覆盖命中边界、同时命中、打断、退场、暂停、连续输入、重试与 Agent 协作效果

## 日常与时间

### 生活内容

小店经营、楼上住家、邻里往来、熟客关系、街区散步与高处观景本身承载人物与剧情

日常片段记录人物正在做的事、玩家可以参与的活动，以及人物或环境的响应。场景作用可以是关系变化、熟悉地点、观察生活或安静停留

### 昼夜

昼夜改变灯光、环境氛围、NPC 与人流、店铺活动、对白、委托及部分区域内容。异常可以出现在不同时间，具体活动按事件与时段安排

时间推进的设计让玩家能够便捷抵达目标时段，安排经营、走访与委托活动

### 区域状态

区域以自己的季节状态制作昼夜变化。主据点季节见[N街区](../locations/n-district.md)，局部气候规则见[Null City](../world/null-city.md)

### 任务实现

任务记录触发条件、阶段、参与者、分支、后续变化和结束条件。一次性事件保存完成标记，重复到访读取已有状态。存档保存任务阶段、关系、关键物件与已执行事件

检查进入、退出、重访、跳过、存读档与时段切换时的实际表现。日常内容使用[日常片段模板](../templates/daily-scene.md)，调查内容使用[委托模板](../templates/quest.md)

## 敌人

敌人使用 `ENM-*` ID，从[敌人模板](../templates/enemy.md)建立档案

档案记录来源、行为、预警、玩家对策、动画与声音需求；当前数值保存在运行数据。梦魇敌人同时记录反复噩梦、特殊形成条件、维持机制与现实影响

短档案使用 `ENM-001.md`，需要多个文件时使用 `ENM-001/README.md`

## 梦魇事件约束

委托人、受影响者和梦主分别记录，兄妹的潜梦与接应角色随剧情轮换。事件复用已有场景、工具与敌人，按需要补充内容

分别确定形成前提与维持机制、睡眠依赖和多梦连接关系。现实意外的伤害尺度为皮外伤至骨折，上限为骨折；精神影响、受困、救援和后续关系变化由具体事件记录
