# 工程

## 技术基础

游戏工程使用 Rust 2024 与 Bevy 0.19.1。空间表现、镜头与交互通过可玩实验验证，以城市生活、探索与潜梦行动的体验为判断依据

## 工程组织

源码与运行资产位于 `game/`，可编辑源文件位于 `source-assets/`

地图运行时位于 `game/src/world/`，负责地图校验、几何、表现资产与场景生成，正式游戏和独立 `map_viewer` 入口共同使用。Viewer 的窗口、白天照明和自由相机保存在独立入口，运行和验证命令见仓库中的 `game/README.md`

`source-assets/district-map/district.json` 是空间设计的唯一编辑源，启动时解析为运行数据；材质和模型规则独立保存在 `source-assets/district-scene/`。坐标统一由地图 `[x,y,h]` 转换为 Bevy `[x,h,-y]`，1 unit = 1 m，几何计算使用 f64，生成顶点时转换为 f32

启动完成以资产递归依赖和模型实例化均成功为准。地图、几何或必需资产失败返回非零退出码，日志保留文件、字段路径、源对象、材质槽和底层原因；显式可选模型可以带警告省略，启动摘要记录降级数量

实现按输入、玩法状态、数据与表现组织。内容 ID 关联设计、数据和资产；存档记录任务、阶段、物件与一次性事件的稳定标识

家庭 Agent 的云端身份属于角色设定，其游戏表现与行为按制作需求实现

## 验证

代码变更执行项目的格式、编译与测试命令。图形验证记录场景、设备、分辨率、输入方式、帧时间、内存与加载时间

按项目的平台定位，在 Linux 和 Windows 上验证 Vulkan 渲染与手柄、键鼠输入。性能目标依据原型和完整样板的实际测量制定
