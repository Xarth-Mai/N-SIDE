# 街区空间制作

城市与地点正文见 [Null City](../world/null-city.md)、[N街区](../locations/n-district.md)、[小店](../locations/shop.md)与[摘星台](../locations/stargazing-terrace.md)。本页记录将这些生活空间落实到地图、场景与互动时的制作约束

## 空间目标

第一次到达能找到回家的路，多走几次能选择更顺路、更安静或更好看的走法；长期重访能够认出谁在哪里活动、门后的空间属于谁，以及事件留下的变化

小店是玩家的生活中心，车站、学校、公共设施、其他商铺与住户也有独立的服务范围和活动。远处的大河、桥梁与对岸表现都市规模，近处的店面、院落、台阶与公共空间表现日常生活

丰富程度来自同一地点在不同方向、时段与关系中的体验。优先深化已有地点，保持普通、安静和允许不发生事件的空间

## 地理与发展层次

街区位于城市内部与低丘相接的位置，沿河与山脚道路在可游玩范围之外继续联系其他城区。两岸的开发密度来自地形、建设时期和交通条件，各自保留普通住宅、工作场所与公共设施

| 形成阶段 | 空间结果 |
| --- | --- |
| 渡口与坡脚老路 | 道路避让陡坡与既有院落，形成曲折街线、窄面宽地块与错位路口 |
| 车站带来客流 | N站入口与旧街通过商店街连接，站前公寓与旧店屋交替出现 |
| 东侧公共设施与住宅补充 | 较完整的平缓地块容纳学校、住宅与公共设施，横向道路接回旧街 |
| 岸线更新 | 在通行、候船与服务作业之外加入连续步道、绿地和停留处，少量旧设施再利用 |

发展阶段不锁定具体年代。上海的视觉参考限于宽阔河面、连续岸线、跨河联系和两岸景观；坡地依 Null City 自身地形组织，临海位置、河口与潮汐不由该参考推定

## 街坊、建筑与公共边界

商店街通过连续、略有转折的街面形成空间，店屋靠近道路排列，以墙体、门洞与少量明确的公共巷口连接。建筑背后保留后院、楼梯、采光与服务通道，店与店之间不默认都可穿行

| 位置 | 建筑与入口 |
| --- | --- |
| 站前 | 较完整的公寓体量、底层连续商业，住宅入口与店面入口分开，出口前留足人流空间 |
| 商店街 | 窄店面与深地块，楼下经营、楼上居住，雨棚和招牌贴合步行尺度 |
| 西侧老街坊 | 住宅与小工作空间围绕院落组织，公共道路经过院边，私人空间以门和边界区分 |
| 小店附近 | 建筑随坡错台，店内各层地面保持水平，通过门前平台、挡墙与相邻建筑高差表现坡度 |
| 东侧 | 学校与住宅保留完整地块，校舍、操场、院门与公共道路分别落实 |
| 上层住宅 | 逐渐疏朗的建筑、院墙和树木共同完成进入山林的过渡 |

空地分别标明公共小广场、住宅院落、绿地、服务场地、建筑间隙或未展示地块。停留活动按空间身份布置，住宅院落受到邀请后参与，服务场地保留作业用途

尽端小巷可以通向住户门口、共用花圃或小工作室。环路通过公共道路成立，不为连通而打穿私人地块

## 道路、高差与到达

### 道路分工

| 道路 | 职责 |
| --- | --- |
| 城市联络路 | 联系站前、东侧公共设施和图外城区，承担公交、较多机动车、主要配送与必要的应急到达 |
| N主路 | 联系站前、商店街、小店与住宅，服务街坊生活和步行，保留必要车辆通行 |
| 街坊支路与服务巷 | 联系住宅入口、店铺后门、收货位置与垃圾收集点，部分与行人共用 |
| 台阶与步道 | 提供跨高差的直接或安静步行路线，与缓坡道路互补 |

道路宽窄、铺装、路缘、照明与入口共同表达身份。N主路不承担穿越城区的快速交通，台阶不承担主要补货，后巷保留通道而非堆满装饰货箱

### 弯折与坡度

主要转弯分别对应坡面方向、既有地块、较平整的平台或老路遗留。小店前的缓弯来自旧路绕过高差后的平缓地段，停步、进店与侧巷连接在此形成邻里节点

窄街段、普通门前与少量停留节点交替出现，不在每个地点前扩成广场

高差与沿路距离一起记录。例如高差 12 米、水平行进距离约 300 米时平均坡度约 4%；同样高差配 80 米距离时约为 15%。这些数值仅为尺度检查算例，不是地图尺寸

核对局部陡段、转弯、平台和入口衔接，普通店铺与核心公共设施提供不依赖楼梯的到达方案。山顶步道单独设计，一条名为缓坡的路线不能代替全程无障碍核对

### 站前与过街

公交停靠、接送与自行车停放位于广场边缘，车站出口到商店街的主要步行线保持连续。向河边的路线在联络路设置明确过街节点，避免连续经过多个大型车行路口

车站形制需随交通方案落实。若采用地面入口、地下轨道，应同时安排通风、维护、排水与出入口防护空间

## 补货、服务与雨水

### 小店补货

城市配送 → 街坊道路装卸位置 → 小型车辆或推车 → 背侧服务巷 → 货运侧院 → 店内储物与陈列区

大型货车止于合适的装卸位置，收货侧院与顾客入口、公共台阶分开，也不承担必须经过的公共捷径。食品店、饭馆与小店错开配送状态，分别呈现收货、经营和整理

小店全天营业，夜间状态使用整理与交接；其他商铺根据各自作息收店。部分后巷在非配送时段可放邻里座椅或小展示桌，活动家具保持所需通道

垃圾与回收物设固定收集位置，避开食品出入口、窗下休息处和主要观景点。电表、设备箱、维修门和通风设施依建筑用途安排，设施密度来自实际需要

### 排水与公共设施

坡上来水沿道路边缘、截水设施和排水系统逐级收集，门前平台、挡墙和庭院各有排水出口，避免店侧台阶把水集中引向正门。花池承担局部调蓄，生活污水接入城市系统

雨后差异来自雨棚滴水、沟渠流水、接缝积水、湿树叶与水位变化，地面材质和积水依具体位置表现

公共厕所结合站前或滨水服务设施，饮水、垃圾收集与维护设施随使用空间设置。自行车停放靠近站前、公共设施与主要入口，避开窄巷、台阶落脚处与连续步行线

这些关系需要在场景里成立，物流、垃圾处理与城市交通不要求完整模拟

## 河岸与跨河联系

### 两层通行

较高的沿河通道承担日常连续通行，局部低层平台、台阶与候船空间由主通道分出。下层不成为回家的唯一路径，高水位或维护关闭时，在开放范围内沿较高路线绕行

台阶、护栏、关门位置、水位标记与绕行指示说明边界。较高通道的存在不代表应对所有洪水，极端天气下的关闭范围与替代路线需要与具体标高、防护能力共同确定

### 沿岸段落

| 岸段 | 主要体验与联系 |
| --- | --- |
| 河岸小广场 | 联系站前和商店街，供会合与短暂停留 |
| 渡口 | 候船、检修与上下船边界清楚，旧候船设施可遮雨、展示交通信息和旧照片 |
| 长椅段 | 稍离主要会合人流，供看水、聊天和独处 |
| 小摊段 | 联系东侧住宅与公园，经营空间从连续步道旁展开 |
| 桥下通过段 | 以桥梁结构、声音与光线变化表现通过体验，另保留安静休息岸段 |

用铺装、树荫、岸线、声音和使用者形成差异，旧候船设施保持生活尺度。临时展示与邻里摊集沿小广场边缘展开，活动后恢复普通通行

### 渡口与桥梁

渡口提供步行跨岸的便利与观看城市的方式，与轨道和桥梁互补。适应水位变化的码头形式另行确定，滨水主通道保持与局部登船设施的区别

桥梁引道沿城市道路组织，与小店门前的生活主路分开。桥面与岸边步道分层，桥下检查净空、照明、雨后通行和高水位替代路线。每处图面交叉明确实际连接层级及上下桥位置

## 六组空间的互动配置

| 空间 | 核心布置 | 活动与变化 |
| --- | --- | --- |
| 站前与商店街 | 饭馆靠站前，烘焙店在弯口，食品店与洗衣店由清楚的巷口联系正街 | 取餐、坐下吃饭、时段陈列、挑选与收摊、窗边等候；短参与不必触发完整演出 |
| 西侧老街坊 | 修理铺能够送修取件，试机角依附店面，院落入口与公共经过线分开 | 玩具与家用小设备维修、少量旧游戏设备试玩、受邀参加手作或整理；修好的物件留在熟悉位置 |
| 小店街坊 | 有限橱窗展示位、店侧台阶、独立收货侧院和树下座位 | 兄妹作品进入陈列，Agent 对熟客、到货和陈列变化作出不同反应，楼上与楼下各有生活痕迹 |
| 东侧公共生活 | 学校保持完整地块，阅览室联系公园，诊所靠方便到达的道路 | 居民照片与学生作品换展，球场按时段出现不同年龄使用者，座椅与活动区分开 |
| 滨水生活带 | 保留连续通行线，候船、长椅与小摊从侧面展开 | 备料、开摊、季节菜单与收摊，候船与散步有不同节奏，允许只看一班船离开 |
| 上层住宅与山顶 | 商业界面逐渐减少，观河转角、山脚休息台、小神龛与摘星台保持各自尺度 | 门前浇花与等人、辨认来路、上山下山体验不同、安静相处与观景 |

每家店同时具有用途、主人、动作和空间辨识点。关键店面可以有鲜明标识，普通住宅与安静界面保留余地。修理铺处理普通物件，诊所服务社区，异常调查不吞并它们原本的生活职责

洗衣店居民物品与诊所患者信息保留隐私边界。阅览室呈现玩家参与的作品时取得当事人同意，公共球场与学校操场的入口分开

小店以有限的展示位置承载变化，不承诺逐件装修整栋建筑。试机角保持店铺附属兴趣空间，普通门前不逐一配置独立任务，小神龛不扩张成大型活动中心

## 路线与回访

路线走法以 [N街区](../locations/n-district.md#几条熟悉的路)为准，地图检查各条路线的不同用途

- 直接回家线最容易理解，普通日常不强迫绕进额外巷道
- 采购短环联系食品店与社区横街，站前、饭馆和修理铺作为可选延伸
- 雨天线提供分段遮蔽和停留位置，保留露天路段，不把正常回家变成强制绕行
- 河边环去程接近商业人流，回程接近住宅生活，码头与低层亲水平台作为支路
- 山顶环上行打开城市视野，下行经过林间与住宅，店侧台阶之外保留住宅缓路

树下空地、商店街弯口与东侧公共生活路提供清楚的目的地交换点。入口朝向和视线支持临时选择，减少频繁打开全屏地图的需要

### 状态与参与

| 状态 | 内容 |
| --- | --- |
| 日常 | 营业、收货、通勤、等候、整理与收摊 |
| 天气 | 雨棚启用、室外座椅收起、河边人流减少 |
| 事件 | 修好的物件、更新的展示、改变的对白与关系 |

三类状态可以组合，以少量明确状态和共享互动承载内容。看橱窗、带晚饭、坐下听声音、玩一小局或帮忙摆展示都能成为完整参与，回报可以是反应、留下的物件或再次见面时被认出

日常片段可以停在普通小事上。普通事件允许之后重新遇见，时间推进便于抵达目标时段，关系不依赖每日签到。错过买面包、观景或看橱窗不损失关键剧情，也不触发经营惩罚；观景点不设置必须每天领取的奖励，完整取景位置避免醒目收集物

事件后的变化落在熟悉位置，以物件、对白、照片、海报或使用方式体现，具体实现遵循[玩法制作](gameplay.md#日常与时间)

## 普通生活与异常边界

初秋是局部季节状态，日期、年龄、天气和生活事件仍然推进。道路、补货、排水、公共服务与维护以正常城市关系成立，需要异常的部分另列可观察范围和影响边界

梦境错位建立在玩家已经认识的正常路线、声音和物件上。现实街区保留充足的正常生活，使异常改变了什么能够被察觉；具体事件使用叙事档案记录，不由场景概念自动生成正式委托

摘星台保留同地、同夜转向可见的两面夜景。画面要求与成因分开，普通山体遮挡不作为已经确认的完整解释。新增机制在确认前不进入玩家世界规则

## 美术、声音与尺度

### 街坊识别

| 空间 | 主要识别方式 |
| --- | --- |
| 站前 | 交通标识、大建筑界面、出入口与稳定人流 |
| 商店街 | 连续橱窗、雨棚、手写菜单、商品与经营动作 |
| 西侧老街坊 | 院门、维修物件、居民使用痕迹与近处生活声 |
| 小店附近 | 自家招牌、橱窗、台阶、树下座位与熟悉灯光 |
| 东侧 | 校门、展示窗、树荫、球场与较完整公共空间 |
| 河岸 | 水面、桥梁、候船设施、长椅与远处城市 |
| 山侧 | 逐渐退去的住宅、树木、天空与视野 |

招牌从真实来路可辨，转角用侧向标识，深处店铺可在巷口提示。大图形、局部高饱和色与夸张商品装置集中于少量关键店面，住宅、诊所、学校和安静街巷有各自密度。小店白天与夜晚都保持识别点

声音从站前交通、人流与饭馆经营，过渡到修理铺试机、洗衣店设备，向上逐渐减弱，近岸转为水、船与桥梁的层次。重要入口、危险与交互同时提供视觉信息

### 尺度与取景

可压缩重复街段与缺少内容的距离，门、楼梯、学校和车辆保留协调尺度。大型设施可展示入口与部分院区，其余体量延伸到不可进入的背景

分别标明世界存在范围、玩家可达室外与可进入室内。核心街区尽量保持连续室外行走，远端城区通过交通与场景转换联系，大河和对岸不按概念图宽度直接换算真实尺度

记录小店、观河转角、河岸和摘星台的实际取景方向，逐项检查建筑、树木与高差是否允许视线成立。两面夜景在同一场景和同一时刻核对，具体尺寸通过灰盒验证

## 地图验收

- 商店街形成连续街面与后院，站前、东西街坊及图外道路相连，设施服务范围可理解
- N主路主要弯折有地形或地块依据，高差、距离、局部坡度与入口衔接一起记录
- 回家线与采购短环成立，远距离绕行保留为可选路线
- 装卸位、服务巷、公共台阶、顾客入口与私人入口各自明确
- 滨水主通道与低层支路分层，过街、桥下通过和水位变化时的替代路线成立
- 在现有地点内落实橱窗、试机角、阅览室展示与候船空间，人物活动不堵塞通行
- 门前平台、挡墙、庭院和台阶有排水去向，公共设施与建筑用途相符
- 昼夜、天气与事件状态能够组合，重访可见事件后果，日常参与不形成签到负担
- 实际镜头检验主要取景方向、昼夜辨识与视觉提示，声音与视觉互相补充
- 摘星台区分已定画面、候选机制与待定成因，地图编号保持与正式地点 ID 分离
