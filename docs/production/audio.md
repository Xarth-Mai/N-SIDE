# 音乐、音效与配音

## 声音设计

声音覆盖生活空间、分时段街区、观景、梦境调查和战斗。每个声音记录情绪、叙事或玩法作用，以及触发情境

动作原型用临时声音验证预警、命中和交互反馈。Agent 的拟声、动作声与界面提示按其表达方式制作

## 交付

| 类型 | 记录内容 |
| --- | --- |
| 音效 | 事件、触发与停止、循环、变体、并发和空间位置 |
| 音乐 | 场景、情绪、结构、循环点与过渡；动态音乐另记分轨和同步点 |
| 配音 | 台词 ID、角色、语境、表演要求、录制批次、文本与音频对应 |

源工程放入 `source-assets/`，运行文件放入 `game/assets/`。音频交付记录采样率、声道、压缩、循环与响度；资产清单记录创作者与使用许可

对白使用稳定台词 ID，录制后修改的台词标记补录。主音量、音乐、音效和对白分别控制，字幕与视觉提示呈现关键信息

## 检查

检查触发、停止、循环、切换、暂停、存读档、音量和字幕对应
