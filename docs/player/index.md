# N:SIDE 游戏百科

N:SIDE 发生在 Null City。一对年轻兄妹经营着一家全天亮灯的生活杂货店，与家庭 Agent 一起处理异常，帮助一些人重新回到生活，然后也回到他们与街坊的日常生活

## 核心体验

在小店照看生意，与熟客聊上几句，沿着街区散步，再带着设备去回应一份求助。调查、战斗和谜团穿插在日常之中，Null City 也在一次次出门与回家之间变得熟悉

## 都市与梦境

现代都市与日系动漫化表达，都市日常和潜梦行动相互连接

每份委托背后，都有一个被异常打乱生活的人。眼前的困扰有时牵出更久远的往事，零散线索也可能通向这座城市尚未解开的谜团

异常平息后，记忆、关系和已经作出的选择仍会留下痕迹。有些遗憾无法挽回，人们带着这些经历决定生活的下一步
