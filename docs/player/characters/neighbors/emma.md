# 艾玛

## 身份与经历

34 岁，四季温室维护者

## 生活与变化

让育苗、交换和观察持续下去，找到适合本地环境的新种植方式

从只关注熟悉的局部养护，发展为与其他记录者共同识别区域变化

育苗与交换活动恢复以后，她继续照顾还能生长的苗，也承认这一轮已经失去的部分。苗架留下空位，不会因危险解除就立刻填满
