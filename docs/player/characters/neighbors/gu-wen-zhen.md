# 顾文珍

## 身份与经历

67 岁，退休教师；山脚茶屋轮值与自然观察志愿者

十二年前约 55 岁，曾在事件中参与学生与家长联络。她保存的是教学和联络方面的亲历片段，与渡运、照片等其他来源一起核对

## 生活与变化

她继续看见学生和街坊的变化，在茶屋轮值、照料植物，也保留处理自己生活的时间

十二年前，她确实帮助了许多人，也在某个时段把联络工作交给另一名值班教师，回家处理急事。交接有记录，没有失职隐情

后来反复使用的照片裁去了画面边缘，说明从“参与联络”渐渐变成“最后一个离开的老师”。她纠正过几次，却常被听成谦虚，也不是每次都愿意重讲

完整底片与交接记录纠正英雄化叙述，不使她当年做过的事变成假的。她不必完成某种自我原谅，才能结束重复的有害点名；今天仍能作为普通人继续与学生交流
