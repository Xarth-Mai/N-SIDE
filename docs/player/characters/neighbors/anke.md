# 安可

19 岁，女性，城市歌手与词曲创作者，偶尔主持本地音乐节目。安可是她公开使用的名字

粉色长发至腰，发尾略卷，琥珀色眼睛。日常将一小束头发夹在侧后方，白色布质发夹、短外套与轻便鞋形成识别点；舞台造型强调明亮的都市感。她的标志是麦克风、自己改过的演出小卡和总被翻乱的歌词页

她能售罄一场小型专场，有本地品牌工作，站内偶尔能看见她的海报。Null Site 的年轻人认得她，但不是每个店主都听过她的新歌。出了这座城，也可能没人抬头。她有真本事：台风稳、会调动现场、懂得面对突发的冷场；编曲和复杂设备工作则需要悠真等人的专业合作

成名曲《下一站晴天》让她成为“看见就觉得生活会顺利”的那种人。她喜欢这份喜欢，也喜欢漂亮衣服、好看的照片、活动后台和工作报酬。问题不是她不该想红，而是所有人越来越期待她一直像成名曲一样顺利

### 她现在具体想要什么

她正在写新歌《晚点见》，计划做一次属于当前合作团队的首演，再把它带到城外。旋律已有雏形，副歌和现场版本却没完全定。她对外说“差不多了”，对悠真说“剩下一点你帮我顺一下”，对玲说“海报可以先做”。她想同时拥有已经成熟的外观和仍可随时修改的自由

另一份外地宣传工作向她发出邀请，主要使用成名曲与既有形象。工作正规、酬劳不错，档期却与新作品的制作承诺冲突。她最初不愿拒绝任何一边，打算等临近了再想办法

她的成长是：把“大家喜欢一个已经完成的我”，改成“我可以决定现在要交付什么，并亲自承担它还不完美的结果”。她最终依然想去更大的舞台，也仍然会看评论和挑照片

### 第一场出场

序章，玲正在给店里陈列拍照。一位粉发少女蹲在橱窗边，把自己上次活动的小卡往前挪了半指。巧克力立即又把它移回标好的位置

安可抬头：“这个位置真的比较好看。”

巧克力亮出价签：“这里是商品展示位。”

她只好拿起一包封口袋结账。收据打印时，她又探头问玲：“顺便问一下，你接演出海报吗？”

离开小店的人可能在车站看到她的海报，才意识到刚才挪动小卡的女孩确实是位明星

### 她不完美的地方

她会把照片挑得太久，嘴上说不在意反馈，手指却不停刷新。她能敏锐察觉别人有没有生气，但有时把“暂时把气氛哄好”误认为事情已经解决。被问到新歌进度时，她很会转移话题；真要面对删掉一段喜欢的旋律，又能坐下来反复试

她也不总是被原谅。悠真会要求她明确决定，不替她无限修订；玲会坚持修改次数与署名；苏弥会直接说一段试听“记不住”。关系变好后，这些人并不会统一变成夸她的粉丝

### 主线中的三次决定

第二章，她停止发布一段无法确认的成功宣传，亲自解释试听录制改期，把悠真从模糊的责任暗示中拉出来。这不是拯救城市，而是把自己工作里的问题说清楚

第六、七章，她承认无法同时完成外地宣传与本地新作，把选择从“你们再帮我想想”改成自己回答。她选择完成新作品的既有合作，失去这一次宣传档期，也处理已约定工作的调整与协商成本；这个决定源于她想成为怎样的创作者，不是因为离开 Null Site 等于背叛

尾声，她唱完一个规模较小的新歌现场，没有立刻得到全网爆红的补偿。几天后，她仍然要带作品出城。她和米娜一样拥有离开的权利，也和留下的人继续联系

### 和其他人的关系

玲是同龄创作伙伴。安可总想让自己的名字再大一点，玲总能给她看第三个版本。她们会为图像是否把一个尚未完成的作品包装得过分确定而争论，后来也会在不谈工作的晚上一起挑便利店新品

苏弥不太吃她的场面话，又真的愿意认真试玩、认真听歌。安可擅长把人拉进门，苏弥擅长指出进门之后到底有没有东西。两人可以互相帮忙，也会互相嫌弃；不以一方治好另一方的性格作为关系终点

悠真是合作的音乐人，不是专门替她收拾烂摊子的万能搭档。她学习提早交付，他学习及时说明自己不愿再承担的部分。两人仍可以为一个和弦争到晚饭凉掉

贺佳熟悉她成名前的工作，既支持她争取报酬，也会明确告诉她场地什么时候必须关。巧克力能认得她，却不会因为她是明星就改变取货顺序

排练、试听、散场与私人相处让这些关系继续变化，彼此的亲近不必变成同一种关系

日常工作与来访集中在[排练录音楼](../../locations/places/b10.md#place-78)、[AFTER 9](../../locations/places/b10.md#place-79)和[月台杂货](../../locations/shop.md)，演出后也会去[LATE BITE](../../locations/places/b10.md#place-82)
