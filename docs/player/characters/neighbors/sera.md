# 塞拉

27 岁，女性，Null Response Bureau（NRB）现场负责人之一，受训潜梦者

黑色利落短发，浅灰工作外套内有高可见度标识，耳侧经常夹着暂时不用的细发夹。她说话短、行动稳定，习惯先看出口与现实接应位置，再看异常形体

她了解某些局部个案被分散处理的难处，但必须对进入现场的同事和居民负责。她的目标是让一份工作真正结束，而不是把“暂时没事”写成“永久解决”

她会在别人着急解释时先把快要滑下桌的设备托住；听完一个新手的观察，再准确指出它改变了哪一步安排

她起初倾向先让受影响区域进入可控休眠，再逐步恢复。这个办法保留稳定记录，但会打断一部分依赖现有活动的正常使用。兄妹提出更细的处置，她要求可验证的范围和停止条件。她接受证据，不接受“我们很熟悉这里，所以应该没问题”

她的变化是把居民当前如何使用场所，也纳入现场判断。她并不放弃专业方法，而是承认表格上的同一地点，可能对应几种不能相互替代的生活

下班后她会为了省一把伞的钱，算很久回家是否真的会淋雨；吃甜点则常点最简单的那一种。她逐渐愿意说“这次我不接，有值班的人”，把一份普通工作咨询交给值班同事，然后收起手机坐下来等雨

她与曜的分歧在于熟悉一个地方究竟支持多大范围的判断。局部观察与专业协作逐渐互补，掌握相应证据与职责的人作出各自判断，其他人也依据可核对的确认行动

她通过[Null Site 服务中心](../../locations/places/b08.md#place-67)参与联络，在[西环渡口](../../locations/places/b11.md#place-26)负责现场工作。下班后也会到[月台杂货](../../locations/shop.md)借伞、等雨，工作来访不让她随意进入楼上住家
