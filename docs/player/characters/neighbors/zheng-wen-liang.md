# 郑文良

## 身份与经历

58 岁，FLASHBACK经营者；地方照片提供者

## 生活与变化

把普通家庭的照片交付好，整理自己的旧底片

从认为“照片已经说明一切”，到把拍摄背景、授权和不确定一并交代

整理底片时，他同时说明取景范围与拍摄背景，把“不在镜头里”说清楚。提供旧照片不使他成为全城历史的见证者

## 关系与活动

[郑拓](zheng-tuo.md)是其女儿；[顾文珍](gu-wen-zhen.md)与[老钟](lao-zhong.md)提供授权照片；认识兄妹父母

日常联系的场所：[FLASHBACK](../../locations/places/b05.md#place-57)

保存照片方面的片段；拍摄时的背景和当事人说明需要与照片一起核对

## 表达与习惯

慢条斯理，对看不清的细节不会硬认
