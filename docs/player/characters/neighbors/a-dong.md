# 阿东

## 身份与经历

23 岁，街区配送员

## 生活与变化

把一天的配送完成，留时间和朋友玩桌游、去河边坐坐

愿意反馈实际道路变化，而不是把每次绕路都自己扛下

配送之外，他有自己的桌游和休息安排。临时交通变化需要反馈给相关的人，也需要重新约定交付，不以默默绕路证明自己可靠

## 关系与活动

与[巧克力](../agent.md)形成交接习惯；[周然](zhou-ran.md)是牌友；认识[唐惠](tang-hui.md)和乐器街工作人员

居住在[临街公寓](../../locations/places/b03.md#place-12)的一户

日常联系的场所：[小店货运侧院](../../locations/places/b05.md#place-28)、[旅行用品与寄存店](../../locations/places/b01.md#place-31)

## 表达与习惯

说话轻快，熟悉服务门但不会随意进入私人住家
