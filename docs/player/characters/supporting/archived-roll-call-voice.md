# 旧点名录音中的声音

## 相遇与记录

[《没有放学的那一天》](../../story/main/no-school-bell.md)保留了当年的点名声，录音中的发声者尚未确认身份

声音伴随旧名单与等候次序反复出现，与当年的交接记录一同留下。旧称呼的音节不全清楚，不能据此补出现实学生的姓名

## 回放与今天

现在听见的是已记录的固定指令，不是那位发声者仍在现场作出新的安排。现实学生的去向由今天的记录核对，当前出入状态也由现时校方另行确认
