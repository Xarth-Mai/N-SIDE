# 球场等候者

## 相遇与所求

在社区公共球场边等朋友的人，出现在[《球场边的一张椅子》](../../story/daily/courtside-chair.md)

来球场是为了等朋友，最正对比赛的位置并非所需。椅子移到不挡通路、能看见朋友出口的地方以后，等候才真正合用

## 行动与后续

可以同意出镜，也可以让陈知夏只留下空椅子和获准的使用说明。朋友出来后递过包，两人一起离开，没有补打一场球
