# 失约维修顾客

## 相遇与所求

向月台杂货送修普通小设备的顾客，出现在[《雨棚下的第二条路》](../../story/world/rain-shelter-route.md)

第三章为当面检查和试用留出的下午被改约，第六章又收到无法按时交付的答复。这两次失约来自同一份维修委托，顾客没有将需要使用的设备变成让曜反复证明能力的机会

## 行动与后续

退款取回与转交陆成按本人已经作出的选择办理；已交清的物件和费用不重办。后来仍来月台杂货买东西，维修暂时交给陆成或自行选择其他安排
