# 旧版读者

## 相遇与所求

偏爱《沿河慢车》旧版的读者，出现在[《一本书的几种读法》](../../story/daily/ways-to-read.md)

记得《沿河慢车》里的票留在抽屉，并认为喜欢很久的段落正被人凭印象改写。找到旧版以后，事实争执解决，偏好没有随之改变

## 行动与后续

推荐文字由本人决定是否公开，不愿分享的书签留在自己的书里。喜欢旧结尾不需要以作者后来修订为由撤回
