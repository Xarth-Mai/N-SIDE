# 悠真的晚场朋友

## 相遇与所求

与悠真相约散场后吃饭的朋友，出现在[《晚场以后》](../../story/daily/after-the-late-show.md)

散场时在门外问悠真要不要一起走，听到“你们先，我顺便”后走向车站。能留下多少时间受各自行程限制

## 行动与后续

相聚真正发生后，与悠真敲出不同的节奏，连筷子都没闲着。两个开头谁更好直到饭吃完也没定，吃饭没有变成替悠真讲工作道理的场合
