# 肖像委托人

## 相遇与所求

参加郑拓肖像拍摄、只愿私人保留成片的人，出现在[《把今天拍进去》](../../story/daily/photograph-today.md)

带来特意熨过的衣服，与郑拓想要的工作服配色并不相同。试片时先问能不能换好衣服再看，最终得到本人选定的肖像

## 行动与后续

很喜欢成片，却只愿自己留着，已经准备好放置的位置。后来又问能否再拍一张，仍然只放家里；与陈美惠可另行参加的试拍分开
