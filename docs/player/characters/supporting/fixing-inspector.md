# 固定核验员

## 相遇与所求

候船设施作业中的固定核验人员，出现在[《回声之后》](../../story/main/after-echoes.md)

候船设施出现重复动作以后，现实维护作业需要支撑与固定检查。构件到了指定位置，并不代表固定已经核验完成

## 行动与后续

联合演练和正式拆改中，固定核验结果与邱立的位置确认分别传回。檐段卸下后仍按实际支撑状态核验，退出或回退不使已拆构件自动复原
