# 取衣顾客

## 相遇与所求

在何芸的洗衣店留有一袋待领衣物的顾客，出现在[《雨停之后取衣服》](../../story/daily/collect-after-rain.md)

工作时间临时变化，又把牌上显眼的“周五”读成只在周五可取，与何芸各自猜测了对方的安排。本人觉得白跑，何芸也确实多等了两晚

## 行动与后续

在约好的小雨时段到店，核对衣物后带走。新牌终于能读懂，双方并未因此留下长谈，顾客仍要赶下一班车
