# 月城曜 · 哥哥

20 岁，生活杂货店的共同经营者，潜梦设备技术人员与异常处理者

## 经历与能力

共同异常发生前已经学习潜梦设备维修，做过学徒或初级技术支持。先掌握设备技术，随后积累调查、潜梦与处理梦魇的经验

具备软硬件综合能力，在兄妹接店后制造和整合家庭 Agent 与店员机体

## 日常与工作

参与选品、陈列、进货和店面改造，也参与潜梦与现实接应。家庭互动见[家庭关系](family.md)

他想为月台杂货建立稳定承接维修与异常支持的工作安排，也保住亲手制作小物件的时间。听见熟客说“以前你爸爸当天就能修好”，他会比自己承认的更在意；希望父母放心开始新生活，渐渐变成不能让任何人失望的自我要求

他本来就能与玲配合验证实物。跨个案调查带来的变化，是从熟悉的两人配合，走向自己不能亲自掌握全部细节的协作

## 承诺与变化

序章的普通陈列交接里，他用“差不多了”代替尚未完成的具体说明。玲拿着上次打印的完成卡白跑一趟；没有事故，却显出他先承担、再设法填平缺口的习惯

第四章的试验暴露出判断范围不足，他在相关人员面前完整说出自己不知道什么。第六章，他真的错过一项已答应的普通交付，安排退款或新的交付，收缩接单，请父母与陆成承担明确的一部分工作。顾客仍来购物，却暂时把维修交给陆成，调查的重要性没有自动换来原谅

终章里，他守着玲的身体和设备，不能去渡口亲自核验每个构件。他依据塞拉与现场团队的独立确认、玲的梦内观察，以及自己监测到的连接状态作出提交处置的决定。可靠性由不同位置的人共同建立

## 关系与认知

[月城玲](sister.md)是共同决策者，两人轮换潜梦和现实接应；[陆成](neighbors/lu-cheng.md)是技术前辈，[阿杰](neighbors/a-jie.md)会带设备来请教。家用物件、游戏设备与音频设备需要不同专长，他与街坊各自承担擅长的部分

与月城玲一起知道自己的共同异常和基础潜梦方法；[《回声之后》](../story/main/index.md)开始时，两人尚不掌握十二年前实验的细节

住在[小店楼上](../locations/shop.md)，也常往来于[小修理铺](../locations/places/b03.md#place-11)和[游戏设备维修店](../locations/places/b02.md#place-38)

## 表达与习惯

说话具体，常先复述现场情况；会把关心藏进收好工具的小动作。他喜欢把不顺手的零件改到刚好，会记住熟客设备上的贴纸，把线卷好再递回去
