# 遥

## 身份与经历

42 岁，图书编辑；真实联合梦境参与者

十二年前约 30 岁。一次与异常无关的现实事故使其长期无法以常规行为表达回应；后续接入让其与[维恩](wien.md)能够相见、交谈，共同生活。独立验证已经确认真实共梦，遥持续接受现实照护，同时参与阅读、新作品与少量编辑工作，经过见[大共梦事件](../../world/great-shared-dream.md)

## 生活与变化

她继续阅读、编辑和参与新作品，自己决定何时见客以及想怎样生活。一个人今天想说的话，不必总从十二年前的事故讲起

前期小册样稿里，她把玲写的“旧日不再的温柔角落”划掉，改成“每天有人用它等朋友”。人们先认识这位有点难说服的编辑，再了解她完整的经历

第五章的来访包含工作、家务、历史讨论与明确的结束时间。玲受邀进入授权联合梦境，帮她挪一排书；维恩觉得旧摆法方便，她最近却坐在另一边。这个家仍在变化，不是等人解谜的纪念馆

她能纠正维恩的回忆，也可以不继续某个私人话题。能够从现场重建获得的技术信息，由调查者在现场取得，不以交出全部私人交流换取正常生活

尾声的新样书仍有待改的句子。她不满意一处断句，接着做今天的工作

## 关系与活动

[维恩](wien.md)是伴侣；[诺拉](../neighbors/nora.md)协助新书交流；参与[月城玲](../sister.md)的街坊册

日常联系的场所：[MONO](../../locations/places/b09.md#place-73)、[共享工作室](../../locations/places/b09.md#place-75)

知道自己的主观经历和共同生活的变化，无法直接读取城市其他人的记忆。MONO 与共享工作室的交流采用预约远程参与或经授权的潜梦访问，现实照护与私人住处位于 Null Site 之外

## 表达与习惯

成熟、锋利，也有生活趣味；会为含糊的词追问三次，也会因为今晚有稿子要看，或不想被剧透的新书，结束会谈。她有幽默与不耐烦，会把话题拉回今天
