# 摘星台

位于 [Null Site](null-site.md)北坡最高点的观景台，登高途中有一座小神龛。从月台杂货所在的山脚出发，穿过层层抬升的住宅，经过山脚休息台，沿折返山径逐渐走进树木与开阔的视野。登上台面，山脊向两侧落下，城市与河流在脚下展开

## 两面夜景

面向城区，是霓虹与万家灯火；转向另一面，是没有城市光污染干扰的满天繁星

两面位于同一地点、同一夜晚，玩家通过转动视角直接看到反差

## 日常用途

供人散步、停留、看风景与仰望星空。可以坐一会儿，拍下景色，或和身边的人安静地聊几句

回程沿林间步道经过坡上住宅，再从住宅缓路或店侧台阶回到小店。上山时看见城市逐渐展开，下山时先经过树影与住家，再看见店里的灯光
