# 小店生活街坊

[场所总览](../place-network.md) · [主线](../../story/main/index.md) · [街坊故事](../../story/daily/index.md)

小店、树下空地、洗衣店、花草店、包装工作室、茶桌庭与冲印店构成反复回访的核心范围。顾客、家人、配送和委托各有动线

这是兄妹判断自己为什么出门工作的参照。楼上能够吃饭、创作、休息；后场处理设备与潜梦；门外台阶继续通向其他人的家。正篇危机中也保留受控的基础营业，不把住家自动变成公共指挥中心
