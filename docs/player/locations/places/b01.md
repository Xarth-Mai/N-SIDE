# 站前交通与混合商业

[场所总览](../place-network.md) · [主线](../../story/main/index.md) · [街坊故事](../../story/daily/index.md)

Null Station（N站）、站前广场、交通服务厅连接日常出入；饭馆、咖啡铺、食堂、寄存店和书店满足不同作息。邵敏知道谁常走错换乘方向，阿东熟悉实际收货门，小满会给通勤者推荐能在一程读完的书

米娜从这里出发，旧候船提示出现后这里又提供可靠的当下交通信息。剧情前后都保留普通乘客，不将车站变成只在危机中启用的集合大厅

<a id="place-01"></a>

## 01 · Null Station

**V-01｜主线与生活。** 关联人物：邵敏、米娜、安可

居民日常简称 N站。这里能偶尔看到安可的宣传海报；她也从这里前往对岸工作或带作品出城

日常：换乘、送行、散场回家

故事关联：序章[《门还开着》](../../story/main/prologue.md#qst-001)；第一章[《最后的玩具》](../../story/main/last-toy.md#qst-002)；第六章[《河没有倒流》](../../story/main/river-did-not-reverse.md#qst-007)；第八章[《回声之后》](../../story/main/after-echoes.md#qst-009)；支线[《晚场以后》](../../story/daily/after-the-late-show.md#qst-107)

连接：32 城市交通服务厅、31 旅行用品与寄存店、02 站前广场；交通咨询、行李与会合

事后重访：米娜离城后留下新生活通信；现场恢复清楚的班次提示。开放安排：站厅按运营开放，轨道区域受控
