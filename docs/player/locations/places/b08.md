# 东侧中层住宅

[场所总览](../place-network.md) · [主线](../../story/main/index.md) · [街坊故事](../../story/daily/index.md)

诊所、服务中心、家常菜、居家用品与亲子活动室服务不同住户。程嘉与叶初分别处理现实健康与社区协作，职责互补而不混同

这里把零散求助连接到适当的人，也展示事件真正影响的普通家庭。患者信息、幼儿活动和住户院落有各自边界。没有调查需要的住宅入口仍属于背景生活，而不是可闯入的奖励箱
