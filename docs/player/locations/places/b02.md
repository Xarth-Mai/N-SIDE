# 游戏与设备兴趣街

[场所总览](../place-network.md) · [主线](../../story/main/index.md) · [街坊故事](../../story/daily/index.md)

音游、模型、桌游、维修、独立游戏、旧物与材料店提供不同的活动，不合并成一家万能商店。阿杰、凯文、周然和苏弥通过设备服务、制作和朋友活动相识

第一章在这里核对玩具与交易，第二章由声音问题进入音乐街。后续重访可以看新作品、试玩一局或等待朋友，不必每次触发异常
