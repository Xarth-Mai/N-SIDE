# 食品采购与夜食街

[场所总览](../place-network.md) · [主线](../../story/main/index.md) · [街坊故事](../../story/daily/index.md)

烘焙、生鲜、面馆、熟食、早餐、香料、甜品与晚班汤饭形成不同的开门节奏。宋美香清晨开始工作，唐惠在演出收工后仍要忙一阵；同一条街白天和夜里是不同的人在使用

食品本身通常是普通食品。环境事件出现时，经营者负责备料、暂存与收摊，调查者负责异常。人们在不同的工作安排中重新坐下吃饭，有人先来，有人晚到，也有人之后另约一餐
