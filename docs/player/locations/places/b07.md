# 社区中学与放学街

[场所总览](../place-network.md) · [主线](../../story/main/index.md) · [街坊故事](../../story/daily/index.md)

校园、南门外文具店、外带铺和等候庭承接上下学；北侧体育用品与公共球场通过校外道路到达。公共球场不是学校内部操场的随意开放版本。

陈知夏从当下学生生活出发接触旧事。学校的授权、家长的接送和普通课程照常成立。章节结束以后，这里再次以同学、饮料、打印页和一场球赛被玩家认识
