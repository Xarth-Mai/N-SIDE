# 坡地平台住宅

[场所总览](../place-network.md) · [主线](../../story/main/index.md) · [街坊故事](../../story/daily/index.md)

坡上住宅、公共到达节点、阅读角、温室与小食堂让高处生活完整。米娜家、顾文珍与艾玛的住处可以安排在不同住宅单元，访问分别取得邀请

第四章比较不同高度的环境状态，公共电梯停用时使用已有缓路，而不是用一次剧情封路把所有住宅变成不可达空间。居民继续有送餐、阅读、种植和会合的日常需要
