# 山脚住宅与登高入口

[场所总览](../place-network.md) · [主线](../../story/main/index.md) · [街坊故事](../../story/daily/index.md)

茶屋、自然观察庭、用品租修、休息台、小神龛、林间缓坡与摘星台构成完整出门和回家的路线。顾文珍在茶屋轮值，学生来观察植物，租修店准备雨具与手电

人们在这里交流环境观察，也会坐下休息。摘星台的城市与星野保持同地同夜的既定视觉，不将其解释成空间裂缝；两面夜景的成因仍是未解的谜团

日常：上山前整理物品、决定是否继续

故事关联：第四章[《初秋以外》](../../story/main/beyond-autumn.md#qst-005)；尾声[《明天照常营业》](../../story/main/epilogue.md#qst-010)；支线[《把今天拍进去》](../../story/daily/photograph-today.md#qst-108)

连接：89 山脚茶屋、91 登高用品租修店、22 小神龛；补给、天气与步道
