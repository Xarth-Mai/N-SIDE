# 滨水社交花园

[场所总览](../place-network.md) · [主线](../../story/main/index.md) · [街坊故事](../../story/daily/index.md)

流光公园是这片滨水公共区域的统称。花园、广场、渡口、旧物展屋、咖啡、摊亭、补给与安静露台提供不同停留方式，各自的场所编号、建筑关系和开放范围仍然独立。渡运人员负责船班和低层入口，维护者关注水位、路面与设施，上层岸线保持连续通行

第六章借这里的真实历史与当下观察理解天然联系。河岸不是一整条暗藏控制器的机关走廊，更多时候人们只是看水、吃东西或等一班船
