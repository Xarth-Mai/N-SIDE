# Null Site

[十二街坊与场所故事](place-network.md)展开各处的使用者、日常活动、人物联系和事件后续

## 河边的生活街区

Null Site 位于 [Null City](../world/null-city.md) 内部，是一片沿河低丘上的成熟生活街区。沿河道路向两侧延伸，山脚道路绕过低丘，接向其他街坊。远处的大河、桥梁与对岸是城市的一部分，近处的店面、住宅、后巷和台阶则组成每天经过的生活空间

这里保留清爽的初秋气质，绿意未退，昼夜、天气与居民的生活仍在变化。走到街区中段，便能从建筑与树木之间望见河流和对岸

兄妹的[小店](shop.md)是回家的地方，街区里也有各自忙碌的店主、通勤者、学生和住户。中学、诊所和车站服务着周围多个街坊；有人在附近工作，也有人每天乘车去城市另一侧

站前聚集着游戏、设备与兴趣店铺，东侧与河边则有影院、音乐场所和公园。两处热闹的地方之间，采购街、商住楼与熟悉的小巷接起普通的一天；显示班次的站牌、入口旁的取件设施和街边维修服务，也在这些来来往往中被使用

## 街区的来路

最早的居民点围绕渡口、修船与坡脚老路聚集，食品、修理和小件买卖与住宅相邻。老路绕过陡坡和院落，留下弯曲的街线、窄面宽的店屋与错位路口

N站带来新的日常客流，连接车站与旧街的道路逐渐成为社区商店街。站前的临街公寓较完整，旧街仍是楼下经营、楼上住家的小店屋，新旧建筑交替出现在回家的路上

东侧较平整的地块逐步容纳中学、住宅、诊所和公共活动场所，道路与建筑间距更舒展，几条横街把它们与旧街连接起来。影院会客厅、音乐场所与公园之间，人们会合、消磨一段闲暇，再沿横街回家

河岸在原有通行、候船与服务作业的基础上，增加步道、绿地和休息处，旧候船设施与系船构件仍留在日常使用的地方。轨道改变客流以后，西环渡口不再承担全部跨河交通，仍服务近距离通行与习惯坐船的人

旧街房屋依地势开门，从不同侧面进入同一栋楼可能到达不同楼层，所以居民习惯说“上面那扇门”或“靠河那条路”。这是稳定的生活动线，并非现实空间重连；音乐与设备店相互靠近，则来自维修、排练与散场吃饭彼此需要的生意

## 地方称呼

Null Site 是核心城区的名称，所在城市为 Null City。主车站正式名称为 Null Station，居民日常说 N站；白沙河沿岸这片由花园、步道、广场和休息处组成的公共区域统称流光公园，各处设施仍保留自己的名称与开放边界

北坡是既有山地区域的日常称呼，住宅、山脚休息处、林间步道与摘星台依然沿原来的地形连接。流光公园与北坡都没有把内部场所合成一个单一建筑

## 站前与兴趣街

出站后，广场通向商店街的入口清楚可见。公交停靠、接送与自行车停放分布在边缘，人们可以顺着连续的店面往家走，也可以拐进兴趣店铺所在的街道

BYTE BEAT 里有人游玩，也有人在一旁看完一首歌；FRAME 展示制作中的作品，桌游卡牌店里有人约好了一起坐下。需要检查手柄或设备时，可以去维修店问问。买东西、动手做一件小物和约朋友玩一会儿，各自有合适的去处

## 采购街与日常生活

饭馆有人顺路取餐，也有人坐下吃晚饭。生鲜小超市、烘焙、甜品与日用品店接在日常回家的路上，清晨采购、放学后的点心和晚饭前的外带，让同一段街道有不同的热闹

商店街的店面较窄、地块较深，雨棚、橱窗和住户入口沿街交替。烘焙店在上坡弯口，早上的托盘与傍晚收拢的陈列各有模样；生鲜小超市里有人挑选家常食材，洗衣店的窗边常有人等衣物洗好

几处巷口连接正街与后街，从侧巷能看见洗衣店仍亮着的窗。傍晚以后，夜食转角陆续坐满下班或散场的人；继续上坡，才逐渐看见自己家的店

## 西侧老街坊

住宅与小工作空间围绕院落排列，公共道路沿院边经过，住户的门与院墙划出私人生活的边界。有些小巷走到住户门口、花圃或工作室便到了尽头

修理铺处理家用物件、玩具与小设备，送修与取件的人从街边进出。临街的试机角摆着恢复使用的机械小物与旧游戏设备，学生、老住户和爱好者偶尔停下来试一会儿。沿街先听见声音，再看见有人围着一件重新工作的物品

共用院里有人换盆、整理物件或做手工，熟悉之后也会招呼你加入。经过院门能看见生活，却不是每扇门都敞开

## 小店所在街坊

N主路在旧路绕过高差的地方形成缓弯，小店坐落在较平缓的一段。门前可以停步看橱窗，街道仍容得下过路的人；附近树下有安静的座位，适合等人、聊天或看街道

店侧台阶通向住宅巷，中间的平台能回望橱窗与街口。另一侧的服务巷连接收货侧院，送货的人从那里把商品送进店里

白天，橱窗与往来的客人让这里热闹起来；夜里，小店仍亮着灯，家庭 Agent 照看着店务。住得久了，你会认出从哪条路回家更顺，熟客又常在什么时候经过树下

## 东侧中学与住区

星见学园与周围住宅占据较完整的地块。穿过街坊的人沿校外道路行走，校门、操场和院墙各有自己的边界。放学后，从南门出来就能顺路买文具、带一份轻食，或者在旁边的等候庭与家人会合；北侧上街的球场和体育用品店则接着住宅生活

公共球场与地面的城市花园容纳不同年龄的人，放学后有人运动，周末有人陪家人坐一会儿。树荫、座椅与活动草坪之间留着距离，聊天、休息与玩耍可以同时发生。诊所靠近方便到达的道路，照常为附近居民提供服务

## 影院、音乐与会客厅

镜厅是东侧常用的会合地点。有人提前来喝点东西，有人看海报和展墙上的居民照片、学生作品，也有人坐下来等朋友。走过几次，会看见新的作品，或认出在其他地方见过的图案

看完电影，可以在附近吃饭，也可以沿公共通道去屋顶公园走走。高处有花园和休息位置，街道、屋顶与河岸从不同方向展开；楼下的人继续来往，坐在上面能暂时慢下来

音乐街坊里有乐器与音频店、排练录音空间和 Live House「AFTER 9」。白天有人带着乐器来工作，晚上观众在入口会合；演出结束后，附近的夜食仍有人坐着聊天。离开这段街道，住宅门前逐渐安静下来

## 滨水花园与渡口

较高的沿河通道连接街坊与城市其他岸段，小广场、候船区、长椅与小摊从旁边展开。局部台阶通向较低的亲水平台；高水位或维护时，下层入口会关闭，人们沿开放的上层道路继续走

靠近站前的小广场适合会合，渡口有人候船，也有人在旧候船设施下避雨。渡船联系两岸的日常生活，坐一班船也是观看城市的另一种方式

长椅段离会合的人流稍远，适合看水、聊天或独处。靠近东侧住宅和城市花园的小摊卖饮品与点心，手写菜单随季节与备料变化。回程经过时，摊主可能已经在收桌子

桥下的结构、声音与光线和开阔岸段不同，步道从桥下经过。继续向前，仍能走到安静的地方，坐着看一班船离开

## 上层住宅与山顶

沿 N主路向上，商业店面逐渐减少，住宅入口、院墙、树影与远景的间隙越来越多。有人在门前浇花、整理自行车或等家人回家

观河转角是住宅路上一处小扩宽，从那里能认出刚经过的屋顶、街道与河岸。山脚休息台连接铺装道路与步道，最后几栋住宅和树木一起过渡到山林

小神龛靠近山顶的[摘星台](stargazing-terrace.md)。上山时城市视野逐渐打开，下山可以沿林间步道经过坡上住宅，再回到明亮的小店

## 几条熟悉的路

| 想去的地方 | 走法 |
| --- | --- |
| 直接回家 | N站 → 站前广场 → 商店街 → 树下小空地 → 小店 |
| 买些家常食材 | 小店 → 商店街弯口 → 生鲜店后街 → 社区横街 → 小店 |
| 雨天回家 | 站前遮蔽处 → 商店街雨棚段 → 可避雨的巷口 → 小店 |
| 去河边散步 | 小店 → 社区横街 → 过街点 → 河岸小广场 → 渡口旁 → 长椅 → 东侧回街通道 → 公园外围 → 小店 |
| 看电影或听音乐 | 小店 → 社区横街 → 影院会客厅 → 音乐街坊 → 夜食转角 → 小店 |
| 在高处歇一会儿 | 影院会客厅 → 公共到达通道 → 屋顶公园 → 沿公共通道回街 |
| 上山看风景 | 小店 → 观河转角 → 山脚休息台 → 小神龛旁 → 摘星台 → 林间步道 → 坡上住宅 → 店侧台阶或住宅缓路 → 小店 |

雨棚之间仍有露天的路段。去码头、低层亲水平台、饭馆或修理铺，都可以在途中另作选择。走到树下空地、商店街弯口和东侧公共生活路时，也容易临时决定买晚饭、看河，或者先回家
