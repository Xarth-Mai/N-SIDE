# 大共梦事件

本页收录十二年前大共梦事件的完整经过、真相与后续，包含主线关键背景

[往事与时间线](history.md) · [Null City](null-city.md) · [噩梦与梦魇](nightmares.md)

## 事件与公共认知

十二年前，Null City 发生大规模共梦与现实投影。最初有人在梦中进入相似的房间，随后出现能够交叉核对的行动与细节。不同梦境逐步连接，局部梦魇活动通过特定介质投影到现实

旧声响在清醒时重现，物件与设备出现可以记录的重复动作，部分区域的环境状态偏离常态。新发生的客观变化与认知干扰相互交叠，形成后来被称作“大共梦事件”的城市级经历

居民没有共享完全相同的内容，每一处建筑受到的影响也不相同。灾情来自不同强度、不同类型的影响与现实连锁后果：有人遭遇严重后果，有人只留下几个一直无法解释的片段

事件后来停止向外扩张，救助、隔离和现场管理减少了伤害，也保留了证据。分散的经历逐渐得到可以互相核对的资料，异常进入公共认知，研究、设备与专业处理体系在之后十二年间迅速发展

## 维恩与遥的共同生活

维恩是早期潜梦研究者，正篇时四十三岁；伴侣遥是图书编辑，正篇时四十二岁。事故发生以前，他们已经共同生活，各有工作、朋友和兴趣

一次与异常无关的普通现实事故，使遥长期无法以常规行为表达回应，被外界理解为处于植物状态。在本世界的技术条件下，后续研究发现其残存认知能力足以支持特殊接入

维恩的第一目标只是重新收到一个回应。随着连接改善，两人能够相见、交谈，再逐步形成共享环境。联合梦境让他们继续共同生活，并不是一项以控制现实为目标的工程

最初的家参照旧住家布置。维恩尽量复原熟悉物件，遥却把桌子移向另一扇窗，换掉不喜欢的灯，要求看新出版的书，也会因为维恩迟到而不高兴。这些行为确实来自遥本人，其交流能力属于这个角色在虚构技术条件下的具体经历

当时的技术尚未完成严格的独立验证。设备能看到双方响应，却难以排除共享环境和维恩自身补全了具体回答的可能。熟悉的语气带来安慰，也加深了疑问：这些都是他记得的东西，所以眼前的一切也可能由他自己梦出来

## 持久梦境与“旧日回放”

两人希望新经历可以接着上一次继续。维恩与合作团队逐步发展持久化方法，让梦境在一次接入结束后仍留下完整状态

他们成功保留了共同生活，也保留了反复出现的噩梦。维恩最害怕的是眼前的回应并非遥，而是自己不自知的幻想。这种恐惧不断产生类似片段，在适合的介质条件下获得持续性

最初的梦魇“旧日回放”没有自我意识，也没有欺骗、报复或扩张的目的。它不断将过去的声音、动作和场景叠进当下，使昨天的一句话干扰今天尚未说完的回答

真实共梦从来没有因此变成假的，失常的是共同环境对当下的呈现。维恩原本缺少验证，梦魇成形后又进一步破坏了验证条件，形成相互强化的困境

## 三个条件相遇

持久联合梦境实验建立了连续活动的人为起点。与此同时，区域性自然扰动使当地介质更容易形成和保留联系，Null City 的天然环境提供可扩展的空间范围

三者相遇，触发大规模连接与现实投影。自然条件不等于地面道路或城市电网，后来的研究需要根据实际痕迹推断哪些区域曾经相连

范围扩大后，维持连接与活动的条件更加苛刻，自然窗口也逐渐变化。事件最终抵达新的稳定边界，自行停止向外扩张。现场救助减少了伤害，却不是停止扩张的根本原因

当年曾经自行停止，不意味着今天可以放任危险。当前连接与供能条件已经不同，需要重新查明正在发生的活动

## 独立验证与源头终止

事件之后，独立团队在维恩无法接触、共享环境没有提前获得相关内容的条件下，让遥接收新信息。遥在后续交流中主动使用这些信息，结果经过独立记录与重复交互确认，真实共梦的事实得到建立

验证解答了两人的疑问，并未自动清除梦魇。随后，维恩找到“旧日回放”的维持结构，将它与正常共同生活分开，实际终止了源头

已经获得本地条件的城市局部结构继续存在。部分延续了旧模式，部分与新的梦境接入形成独立关系；它们不再接收源头的新活动，也不受源头统一指挥

历史次序为：停止扩张 → 独立验证真实共梦 → 实际终止原始梦魇。保留共同生活与处理城市中的局部结构，是分别完成的工作

## 此后的日子与今天的新联动

维恩与遥至今仍在共同生活。遥持续接受现实照护，通过适当的接入与辅助通道参与沟通、阅读和少量编辑工作。两人的居住与照护安排在 Null Site 以外，私人空间的访问需要单独预约

维恩有时在影院综合体的共享工作室参加小型研究会谈，遥经授权远程参与创作讨论。两人依然会争论书架的位置、某本书的结尾，也会安排一次普通的晚饭。社区诊所承担本地日常服务，两人的照护没有将它变成大型研究设施

原始源头已经终止，是正篇早期即可核对的历史结论。第五章需要重新确认的是旧处置实际覆盖的范围，以及为什么那次成功不足以解释今天的新联系；旧图空白代表未完整观察，不代表永远没有活动

公众与专业人员掌握的信息层次不同，来自研究进展、分散记录和隐私边界。遥的病程与两人的生活并非任意开放的材料，城市名称和公共认知的形成见[Null City](null-city.md#名称与术语)

正篇的危险来自局部结构之间新形成的有害联系。原始梦魇没有复活，一年前的小店异常也具有独立来源；已经完成的处置不会被无条件撤销。结束新联动对现实生活的危险，可以与保留安全梦境及两人的共同生活同时成立
