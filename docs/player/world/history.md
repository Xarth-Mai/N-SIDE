# 往事与时间线

## 异常进入公共认知以前

异常自古存在。旧日记、地方传说和私人经历留下过零散记录，但很少能够彼此核对。近代研究逐步建立统一观察方法，早期潜梦设备已经能接触部分现象，可靠验证和长时间维持仍然困难

Null City 所在的河谷与低丘具有更容易留下异常结构的自然条件。过去有人偶然梦见相同地点，也有物件在特定环境中表现异常，这些经历没有被识别成一个始终活动的大系统

城市同时沿着渡口、坡脚道路与车站发展，学校、住宅和文化场所服务着居民的生活。研究在这座已经存在的城市中展开，而不是城市为实验建立

## 十二年前的大共梦事件

十二年前，Null City 发生大规模共梦与现实投影，异常进入公共认知。事件的形成、停止扩张、独立验证与源头终止，见[大共梦事件](great-shared-dream.md)

## 兄妹的童年与成长

大共梦事件发生时，[月城曜](../characters/brother.md)八岁，[月城玲](../characters/sister.md)七岁。父母月城修与陈美惠经营小店，努力维持孩子的生活，也照应几位熟客

兄妹记得的只是具体片段：提前关店的日子、父母带回的晚饭、熟客讲起同一个梦，以及一条当时不敢独自走的路。父母不是实验参与者，兄妹也没有与事件绑定的天赋血统

他们后来从档案和讲述中知道这些片段属于同一事件。两个人的童年是认识城市历史的一个视角，其他人的记录与经历仍然不可替代

约三年前，月城曜开始学习潜梦设备维修，在有经验的技术人员带领下接触维护和基础支持。月城玲发展插画与小商品设计，参与选品、包装和陈列。两人都喜欢店里的工作，也各有朋友和去处

## 一年前的小店共同异常

一位准备搬离街区的熟客，反复梦见自己来到小店，却找不到记得的人与物。梦中店铺不断整理，所有东西被强行归入一套已经不适用于当下的分类

在特殊条件下，一个重复“归位”的局部梦魇形成，并与店内长期摆放的一件旧物建立联系。兄妹与少数熟客开始梦见同一家不太对劲的店，醒来后出现商品、人物和经历的错认

求助最初被分散受理，看起来分别像记错、睡眠困扰和店务纠纷。兄妹对照不同人的讲述，才发现稳定重复的关联。月城曜检查设备与现场，月城玲整理布局和叙述差异；陆成和合作处理者提供设备、接应训练与首次行动支持

他们后来辨认并改变梦魇的维持条件，结束了有害影响。熟客按照原定计划搬家，大家另选一天道别。解决异常没有要求这个人留下，也没有要求以某种固定方式证明自己已经放下过去

这是一件具有独立来源的 Black Case。这段经历成为兄妹后来帮助熟人、逐步承接异常委托的动机，也让他们理解：即时身体伤害不明显的小事件，仍可能让人难以继续日常生活

## 接店与正篇起点

父母原本已有调整生活安排的计划，兄妹主动接下小店。两人更新部分商品与设计，保留熟客关系，继续把楼上作为共同生活的家

月城曜在接店后制造店员机体，整合[家庭 Agent 巧克力](../characters/agent.md)。巧克力从基础店务逐渐融入家人的习惯，记得谁常来、哪些东西还没收好、谁答应给橱窗换一个新摆件

兄妹从帮助熟人开始，通过介绍与联系网络逐渐承接委托。正篇开始时，他们已经能够处理有边界的工作，复杂事件仍然需要专业协作

## 相对时间线

| 时段 | 关键变化 |
| --- | --- |
| 更早的历史 | 异常存在于世界，留下零散记载；城市按普通交通与生活需要发展 |
| 大事件以前数年 | 维恩参与研究；遥遭遇普通事故；交流接入、联合梦境与持久化逐步建立 |
| 正篇十二年前 | 自然条件与实验相遇，发生大规模共梦与 Black Case；扩张自行停止 |
| 此后数年 | 独立验证确认真实共梦；原始梦魇后来被实际终止；局部结构继续存在 |
| 正篇三年前左右 | 月城曜学习设备维护，月城玲继续设计与店务，安可开始稳定参加小型演出；能力来自积累与联系 |
| 正篇两年前左右 | 安可以《下一站晴天》被本地听众广泛认识，已经成为城市歌手 |
| 正篇一年前左右 | 小店共同异常；兄妹在支持下参与处理，之后逐渐接手小店并建立 Agent |
| 正篇前数月 | 维护、降雨与新自然窗口叠加，局部介质出现新的接触与连接条件 |
| 正篇 | 米娜离城、新歌、小册与委托交错；兄妹从具体个案主动进入跨案调查 |

安可与塞拉在十二年前分别约七岁、十五岁，不是早期研究的专业见证者。维恩与遥在大事件时分别约三十一岁、三十岁；顾文珍约五十五岁，是当时的教师亲历者。陈知夏当时约五岁，记得幼年片段，后来通过调查了解更多往事；她对当年的认识需要与成人见证者和记录相互核对

## 记录之外仍在继续的生活

顾文珍当年参与学生联络，真实完成过工作，也有记录证明的交接。后来照片与说明把这段经历压成“最后一个离开的老师”，她几次纠正又被当作谦虚。完整底片与交接表让后来的人补回其他工作人员，而不是把她真正做过的事一笔抹去

老钟的旧船票说明某次候船，不能说明当晚所有人的去向；郑文良的底片比展览照片宽一点，却也只能证明镜头里的事。兄妹童年害怕走的一条路，当年曾临时留给工作人员通行。记忆里的恐惧是真实的，后来需要补上的则是当时不知道的背景

具体证据能够纠正具体错误。纠正之后，人们对过去的感受仍可以不同

## 当前联系的形成

正篇前数月，持续降雨、历年修缮和新的自然窗口逐步叠加：过去干燥的接缝雨后长期潮湿，构件与填充层的实际接触已经不同，自然条件又降低了建立有效联系的门槛。原本独立活动的局部结构因此出现新的交叉路径

修缮曾解决真实的排水与使用问题，当时的局部判断并非失职；条件改变后，需要重新确认今天的范围。道路相邻不等于异常相连，构件声源、雨后边界、旧处置范围、水位与材料接触记录分别提供不同尺度的证据

已经隔离的直接输出仍然有效，新通路不使前面的帮助作废。安可的走红、小册传播和米娜搬家让变化被人们注意到，却不是异常扩张的能源或介质
