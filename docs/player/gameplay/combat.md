# 战斗

## 角色与工具

兄妹在梦中保持日常衣着，携带专门的工作设备与工具。基本操作跨梦境沿用

观察敌人的姿态和攻击预警，判断危险与出手时机。家庭 Agent 会协助探索、保护同伴并干扰敌人

## 处理异常

战斗可以为调查创造机会，接近核心、解除联系或改变异常的维持条件，才能让生活恢复平静。参见[委托与潜梦工作](dream-diving.md)

<a id="战败与重试"></a>

## 梦境伤害

梦中的受击不会直接损伤现实中的身体，异常仍可能干扰判断和生活。参见[梦魇](../world/nightmares.md)
