# 委托与潜梦工作

## 工作方式

兄妹由帮助熟人起步，通过口碑逐渐承接更多请求。渠道包括熟客介绍、线上匿名渠道和逐渐形成的联系网络

前来求助的人不一定就是梦主，梦主也不一定仍是异常的唯一维持条件。调查可以从一处异常现象开始，在梦境与现实的线索中逐步确认与梦境关联的人

求助者、受影响者、梦主与连接载体可能分处不同地点。先辨认现实后果和即时危险，再追查输出点、有效连接与梦中活动，才能区分形成经历和当前维持条件

## 潜梦连接

意识进入梦境，身体留在现实。使用专门设备建立连接，主要追踪已经出现的异常

行动以携带设备上门调查和处理为主，店内接待或潜梦为辅；时间按事件条件安排

哥哥和妹妹都能潜梦、也都能现实接应。一次一人入梦，另一人保持清醒、留在现实。入梦者负责调查与行动，接应者照看身体、设备和现场

[家庭 Agent](../characters/agent.md)依托已经建立的人类连接进入梦境，以探索、标记、工具操作、保护与干扰提供支援。现实中的店员机体可以继续接待顾客；潜梦者退出后，梦中支援形体随之撤出

下一次行动可以交换职责；需要换人进入时，先退出并完成交接。潜梦和查看私人记录都需要相应同意，梦境接入不会免除现实中的访问边界

## 联合梦境与调查

联合梦境中的真实参与者共享环境状态，能够共同改变其中的物件和事件，各自的想法仍是私人体验。设备维持接入与同步，没有建立相应连接的旁观者不会自动读取整个梦境

一个人把杯子放在窗边，另一个人能够看见这个变化；他放下杯子时想起了谁，仍然属于自己的体验。不同的大脑通过各自的接入关系理解共同环境，设备维持这些关系的对应，而不是把所有脑电活动变成同一个频率

同一环境中可能同时出现真实参与者、保存片段、当下想象与梦魇活动。外表逼真、语气熟悉不能单独证明一个形象正由本人自主回应，需要独立信息来源、时间记录与可重复的交互来核对

梦境也不是准确无误的历史录像。进入梦境不会凭空获得无人知晓的信息，梦中线索需要与现实证词、物件、记录和现场变化相互核对

## 梦境空间

以熟悉都市的错位版本为主：场所和物件的连接、比例、用途或规则发生变化，保持与 Null City 日常经验的联系。更抽象、更异质的空间可用于特殊段落

现实与梦境互相提供线索。现实中的物件、关系和生活痕迹帮助理解梦境规则，梦中的发现则引导玩家返回现实核对证词、重新观察场所。调查在两者之间推进，新的理解改变下一步行动

## 处理结果

主流方式为调查规则，通过战斗创造处理条件：接近核心、解除联系或改变异常的维持因素。简单委托可以直接清除，少数事件可以采用约束、转化或无害共存

处理目标是结束异常对生活的不良干扰。采用何种办法由事件条件决定，当事人的后续选择留给当事人。潜梦者可以帮助解除有害联系，也可以在安全条件下保留共同梦境；接入能力不赋予任何人强行改变他人性格或揭露私人生活的权利

结束危险不要求删除所有记忆或安全梦境。停止活动、断开联系、保留记录以及修复现实后果，需要分别处理；详见[梦魇的保存与活动](../world/nightmares.md#保存活动与连接)

主动退出、停机与处置失败按事件条件产生后果，梦境不会让世界时间倒流

## 内容循环

小店与街区日常 → 得到请求 → 现实调查 → 潜梦与接应 → 调查并处理异常 → 现实后续 → 回店与回家

有的委托只涉及一个问题，有的则需要多次往返现实与梦境，才能看清事情的全貌
