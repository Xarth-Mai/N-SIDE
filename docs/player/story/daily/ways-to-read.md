# 一本书的几种读法

<a id="qst-106"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

小满为小册整理阅读路线，只收录读者愿意分享的书签与意见。旧书交换屋流通着小说《沿河慢车》。两位读者争论女主人公最后是否离开：有人记得她买了车票，有人记得她把票留在抽屉里。兄妹先比较版本与原文，发现一次修订确实改变了相关段落

事实层面得到明确答案：他们读的不是同一版。意义层面仍可以不同：一位读者把买票看成终于决定，一位认为真正重要的是她此后怎样生活。兄妹不需要评出最懂作者的人

遥谈的是编辑如何让修订说明被读到，而不是拿自己的病程解释小说。顾文珍也可以坦率地说，她就是不喜欢其中一个结局

小册并列记录不同读法，并清楚标注版次。事实核对与主观理解分别成立，这段阅读经历没有把不同意见变成一场必须分出胜负的比赛

场所：白页书店、旧书交换屋、平台阅读角、MONO、滨水咖啡屋、山脚茶屋。关联角色：小满、诺拉、遥、顾文珍
