# 一本书的几种读法

<a id="qst-106"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)


小满整理旧书交换屋时，发现同一本书留下了不同读者的书签。她想为小册做一页阅读路线，邀请玩家询问愿意分享的人

玩家在白页书店、平台阅读角、MONO与茶屋遇见不同意见。无需找出“正确理解”，也不把书签当未经同意的私人日记。遥可以提供一段当前的编辑意见，而不是泄露病程

最后把得到授权的读法并列展示。一本旧书回到流通中，新的读者会继续留下不同的反应

场所：白页书店、旧书交换屋、平台阅读角、MONO、滨水咖啡屋、山脚茶屋。关联角色：小满、诺拉、遥、顾文珍
