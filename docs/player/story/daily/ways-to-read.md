# 一本书的几种读法

<a id="qst-106"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 两张夹在同一页的书签

小满为《今天的街坊》整理阅读路线，希望读者带着自己的书签，从白页书店走到旧书交换屋，再在路上找地方坐一会儿。她只收愿意公开的几行感想，原以为一本熟悉的小说能让不熟的人很快聊起来

《沿河慢车》偏偏先让两位读者吵起来。一张书签写女主人公终于买了车票，另一张记得票还留在抽屉里。两人说得都很肯定，一个认为对方跳过了结尾，另一个觉得自己喜欢了很久的那几页正被人凭印象改写

小满起初想打圆场，说开放结局本来就可以不同理解。顾文珍从旁边放下茶：“他说书里没有，那可不只是喜不喜欢。”

诺拉把两张书签并排放在桌上，原本为封面拍照摆好的漂亮位置空了出来。小满已经答应当天整理完推荐页，现在才发现自己还不知道该把哪一句放到书旁

## 翻到纸张颜色不一样的地方

兄妹随小满到旧书交换屋找来两位读者当时借过的版本。书背和封面很像，内页的修订说明却不在同一个位置。逐段翻到相应章节，一版确实保留把票留在抽屉的描写，另一版修订了相关段落，让她走去买票。不是谁在故意撒谎，也不是书页随人心改变

一位读者赶紧说自己果然没记错，另一位也拿着自己的书不肯放。小满正要宣布误会解决，前者又问：“那后来作者改了，就是承认旧结尾不好？”

顾文珍伸手要过旧版：“我还是喜欢这一版。作者后来不喜欢，也不能替我不喜欢。”

两位读者各自把手里的书翻给对方看。记得买票的那位终于撤回“你没看完”，却又说作者果然也觉得该走；偏爱旧版的人收回自己的书，没接受这半句道歉：“他改他的。我没欠她一趟旅行。”诺拉递来的茶放在两本书中间，谁也没急着去拿

## 编辑也不能替所有人下结论

诺拉在 MONO 按约请遥通过辅助通道看看这一页。她谈的是怎样让版次说明进入读者真正会看的位置：只在末尾补一行很小的字，书签仍会被当成同一段情节的互相否定。她请小满先把两处原文各自对应的版本放清，再决定推荐文字怎样并排

小满担心说明太多会让推荐页像纠错公告，又怕两种意见并排显得自己没有判断。遥没有替她选一句最深刻的话，只问如果书店只能留下一张，哪位读者愿意被那张代表

小满试着删去一张书签里最刺人的半句，原作者一眼就认出来，把纸抽了回去。她只得说明原版措辞可以保留，请他再决定愿不愿意公开；不愿意的书签归还本人，页面只用获准的意见，不凑成两张假想的一致推荐

为了放清版次和不同读法，小满撤下原本留给自己最喜欢的一本书的位置，另向推荐它的朋友说明顺延。朋友说那就下次吧，也没立刻夸她这页处理得好。她将没用上的小封面塞进抽屉；读者愿意公开时，保留他确认的原句，仍不愿意时，书签留在本人手里，页面不替他补一句意见

遥在传回的样张上留着几道批注，获准采用的原话里，有一处她特意没改掉口语。诺拉问要不要润得再漂亮一点，遥说：“这是他写给一本书的话。他又没来应聘编辑。”小满笑了一声，也另写了自己的短评。无论那张被退回的书签最后是否刊出，她都有一句自己想推荐这本书的话

## 书里买的票与口袋里的票

在平台阅读角重新摆开两版小说时，玲把一张空白样片误当书签递给顾文珍。那是[《旧外套的新口袋》](new-pocket.md)试版留下的纸，边上还画着票夹露出的长度；改衣尚未开始时，则只是母亲交来的口袋尺寸草图，不预先出现完成的版型

有人笑说故事里买票的人总要来一次精彩出发。玲却指着纸上票夹的尺寸；试穿已经发生时，她还会说起母亲为拿票不卡手试过的几种动作。旅行有具体要去的地方，也有东西拿不顺手的麻烦。她没有借此宣判哪版小说更真实，只问顾文珍，若接着读下去，还想知道女主人公什么事

“她下车以后吃什么。”顾文珍说，“前面写了那么多早餐，最后一页忽然不饿了。”

另一位读者不认同，认为停在买票处已经足够。兄妹可以帮两位写下各自想推荐的理由，也可以只留下经本人允许的原话；私人书签与不愿分享的经历收回书里。大家最后连下一本要读什么也没达成一致，却各自带走了想看的书

## 再翻开的时候

小册中的这一页标清版本，并列愿意公开的读法，原先误当成同一段事实的两张书签终于各有来处。小满把书送回流通的位置，读者仍能选择自己偏爱的版本，不以改成相同意见作为结束

后来[《不是备用的那一天》](../world/a-day-of-their-own.md)准备普通阅读折页，小满拿出这次留下的版次说明；维恩与遥对同一本书的不同意见，则让她进一步发现，即使已经读到完全相同的文字，两个人也可以没有共同结论。若折页先完成，她把那份已经确认采用的折页样张拿回来参考，再处理眼前真正不同的两个版本

在[《仍在一起》](../main/still-together.md)的来访中，玲也能认出遥留在新稿上的同一种批注习惯：一处要求具体，一处允许原来的语气留下。她认识的是仍在挑句子、赶稿、说今晚不再加一页的编辑，阅读讨论不会转成索取私人经历的机会

错过这一场可到白页书店看已获授权的说明，再参加下一次讨论。旧版仍然流通，修订版也继续被借走；印期已过就将新增意见留给后续页，不抽走别人拿在手里的书，假装他们曾经读到相同结尾

场所：白页书店、旧书交换屋、平台阅读角、MONO、滨水咖啡屋、山脚茶屋。关联角色：小满、诺拉、遥、顾文珍
