# 还没写完的第二首

<a id="qst-020"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 只是随便听听

安可在排练录音楼约了一次小范围试听，给每个人拿来饮料，强调“不用认真点评”。第一段还没放完，她已经看了三次玲的表情。悠真伸手调音量，她立即问是不是这一段太长；他回答只是有人坐得离音箱太近

苏弥来时还带着自己的游戏草稿。做过[《橱窗还差一点》](unfinished-window.md)的人知道，那段漂亮演示曾让实际试玩者停在起飞处；若没有参与，她只简单讲起这次经历，承认自己也很难让别人先用作品、再听解释

“你不是说不用认真吗？”她问

安可把饮料往她面前推了一点：“你也不用那么不认真。”

## 不看歌词再听一遍

悠真准备两个简短副歌版本，一版容易记住，却更接近安可已经成名的风格；另一版留下她很喜欢的停顿，现场演唱和衔接需要重新安排。兄妹先不看歌词与作者说明试听，再说自己记住哪一处、在哪里开始走神，而不是替她投票选出唯一正确版本

苏弥记不住第二版接下去的旋律，玲偏偏喜欢停顿前那一句。安可想删掉的也是那一句，因为它没有把情绪收成一个人人都容易点头的答案。唱旧歌时，她知道观众会在哪里跟上；这里一旦安静下来，她会忍不住抢先把下一句唱出去。悠真让她站起来连着唱，安可真正换气时才发现，录音里能接得上的部分，站在台上要付出另一种力气

兄妹帮助切换音箱和借来的监听耳机，听出贴近耳边的细节与房间里完整一段的差别。若先完成[《晚场以后》](after-the-late-show.md)，耳机是为这次试听重新借入的，旧借还已结束；没有做过那段故事，也有本次明确的借用安排。它提供一种聆听方式，不替任何人的偏好宣布答案

## 翻到小卡背面

安可拿出一张没采用的宣传小卡，正面还留着比歌名更醒目的自己。若[《把我的名字写大一点》](make-my-name-bigger.md)已经完成，就是那张留下来的单面小样；尚未发生时，她用手边同类废样记下这次意见，之后可以在海报委托中认出自己的笔迹

她在背面分两处记下版本，最先写的是“大家更喜欢哪一个”。苏弥仍说第二版接不上，安可脱口问：“你是不是就想听我再唱一遍以前那首？”苏弥没接她递来的饮料，将刚才记住的两小节哼了一遍，后面确实空着

安可低头在小卡上补下那处位置。玲说自己偏偏喜欢它前面的一句，她又把刚划掉的几个字写回去，空白不够，只好绕着折痕补在边上。她翻回正面看了一眼那张干干净净的独照，嘟囔一句“越来越不好看了”，又翻回来，终于没再擦

悠真说自己能把第一版按现有排练继续完成，第二版需要改动现场分工，不能再称为只剩一点小事。安可需要自己选择本次版本和愿意投入的工作；若暂时不定，就主动将试听结论保留为修订方向，另约正式决定，不占着别人的空档假装已经交稿

采用第一版时，她在自己的演唱稿上划掉这次不保留的长停顿，重新唱完一遍；到原来最喜欢的位置，声音慢了半拍，她停下，从上一句再来。采用第二版时，她先忍住抢入下一句的习惯，让悠真按新的衔接位置试一次，两人又为过门需要留多长争起来，改动与排练占用的时间重新约定

暂缓决定时，安可将本次两个版本分别存下，请悠真撤掉未确认的排练占位，自己先回去改刚才唱不过去的衔接，再约正式决定。悠真真的将那段时间留给别的工作，她想补一句“你先别接得太满”，话到嘴边又收了回去。无论选择哪条，苏弥都没有改口说两版一样好，安可也没有把她的那杯饮料收走

## 让多少人听到这一版

试听结束前，安可想发一段片段，手指停在发布前。苏弥担心评论会先记住草稿，玲认为标清版本也可以让人理解这份工作。两个担心都有道理，兄妹只能表达意见，选择仍由安可作出

她可以发布经过当前参与者确认、清楚标明为草稿的片段，承担它被比较和讨论的可能；也可以只让这次受邀者听，失去眼前一小段宣传机会。留在本地讨论的他人评价、随口唱出的片段和未确认素材都不自动随她的新稿公开

收东西时，她请悠真留下这一版：“别删。我下次可能又觉得它比较好。”耳机按这次约定归还，试听结束没有凭空多出一件团队公用设备。她把折过的小卡收进歌词夹，正面那张漂亮的脸终于没有盖住背面的工作

## 唱完以后还可以不同意

尾声演出前，她可以提起某个早期意见，说明自己这次为什么留下或放弃某一段。是否参加这次试听不决定主线演出能否成立，最后仍由她与实际团队完成选择

若玩家在演出之后才来，她拿出已保存的旧稿与后来修订，讨论下一次怎样唱，不将完成的首演重新退成未定稿。《晚点见》的现场也不因此获得全员一致好评，悠真仍可能觉得其中一段偏长，安可可以一边接受合作、一边继续不同意

这里的“第二首”指她想让人重新认识的下一件代表作，不意味着她此前只会唱一首歌。小卡背面的两种写法留下她曾怎样选择，却不替她决定下一首也必须怎样写

场所：排练录音楼、AFTER 9、PLAYROOM。关联角色：安可、悠真、玲、苏弥
