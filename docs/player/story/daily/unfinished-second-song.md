# 还没写完的第二首

<a id="qst-020"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

安可在排练录音楼约了一次小范围试听，说只是随便听听。她实际上把每个人的表情都看得很仔细。苏弥说有一处记不住，悠真说有一段演唱会不方便，玲却很喜欢她最想删掉的那一句

兄妹可以参与反复试听两个简短版本，表达具体偏好，不替她决定唯一正确作品。她需要决定本次是否公开一段标明为草稿的片段，或者继续只让受邀的人听。两种选择都可以适合她当前的工作，她不再用是否敢公开来评价自己的勇气

她最后主动留下一段还带修改痕迹的记录：“这版也别删。我下次可能会说它其实比较好。”

尾声演出前，她会提起某个早期意见。这里的“第二首”指她想让人重新认识的下一件代表作，不意味着她此前只会唱一首歌

场所：排练录音楼、AFTER 9、PLAYROOM。关联角色：安可、悠真、玲、苏弥
