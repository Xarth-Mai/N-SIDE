# 晚场以后

<a id="qst-107"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)


正常演出结束，贺佳与悠真要归还设备，部分朋友先去吃东西，部分人要赶末班交通。玩家选择参与一段收场，而不是接管所有人的工作

乐器工坊确认维修交件，音频店完成借还，茶食店提供安静座位，交通服务给出真实的换乘信息。赶不上末班的人采用合理替代安排，不让已经下班的员工无限等待主角

任务结尾可以只是一群人在会合广场道别。之后唱片店出现新的演出推荐，悠真会提到自己终于早一点回过家

场所：站前咖啡铺、城市交通服务厅、夜食转角、晚班汤饭店、乐器音频店、排练录音楼、AFTER 9、唱片聆听店、小型乐器工坊、LATE BITE、演出会合广场。关联角色：悠真、贺佳、唐惠、邵敏、阿东
