# 一桌不同的晚饭

<a id="qst-102"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

悠真终于有一个相对空的晚上，唐惠却恰好要接晚班，邵敏能早到却必须先走。大家原先一直想找“所有人同时有空”的日子，最后发现每次都会缺一个

兄妹和唐惠安排两段相接的饭局：有人先吃，有人晚到，明确留饭与交接方式。桌上不是同一锅菜无限放到深夜，而是按实际到场重新上菜、妥善留份；具体安排按这一顿饭的人数与到场时间决定

安可先拍了桌面，发现照片里总少一个人，想再等一下。悠真已经拿起筷子：“他来了还要再点。你可以拍第二张。”

缺席者有自己的消息和安排，也可能之后再单独吃一顿。兄妹可以选择参与取餐、布桌或留下的那一段，不需要代替所有人奔跑

下一次散场，有人记得替悠真留饭；唐惠第一次不是最后独自收桌。晚饭本身就是这次相聚的全部

场所：街口饭馆、生鲜小超市、站前咖啡铺、站前午间食堂、夜食转角、家常面馆、家常熟食店、豆制品与早餐铺、干货香料铺、晚班汤饭店、坡地小食堂、住宅家常菜店、餐饮共享空间。关联角色：唐惠、宋美香、悠真、邵敏、阿东、安可
