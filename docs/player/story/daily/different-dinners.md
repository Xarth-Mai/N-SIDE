# 一桌不同的晚饭

<a id="qst-102"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)


几位朋友下班时间不同，想找一次都能吃到合适饭菜的机会。玩家与唐惠商量场所，按实际人数和偏好选择食品店、熟食、面馆或共享餐饮

这不是在固定时间内送遍全城的跑腿竞速。部分取餐可以交给朋友，缺席者可以留下自己的安排。菜谱、预算与到场时间由情境给出，玩家选择影响桌上组合与对白

后续某位角色会记得别人替自己留过一份饭，也会在下一次主动承担收桌。事件体现食品街不同营业节奏，不把居民日常饥饿当经营惩罚

场所：街口饭馆、生鲜小超市、站前咖啡铺、站前午间食堂、夜食转角、家常面馆、家常熟食店、豆制品与早餐铺、干货香料铺、晚班汤饭店、坡地小食堂、住宅家常菜店、餐饮共享空间。关联角色：唐惠、宋美香、悠真、邵敏、阿东
