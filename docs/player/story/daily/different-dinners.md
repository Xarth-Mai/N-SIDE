# 一桌不同的晚饭

<a id="qst-102"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 总有一个人说下次

悠真说自己终于空出一个晚上，唐惠看了看晚班安排，说下星期可能更好。邵敏下星期要晚些下班，阿东那个晚上已经答应了牌友，安可则在消息里发了好几种“应该可以”的表情。约饭的消息往上翻，最早一条已经提到如今不在菜单上的点心

唐惠说都不难，再等等，总能凑齐。她把这句话说得很轻松，顺手将悠真忘在店里的空饭盒塞给他。盖子上还贴着上次的取餐纸，字迹被汤汽洇开

“那一回你也说下次坐着吃。”她说

悠真原本想解释是哪一场排练，最后将饭盒收好：“这次我今天有空。”

兄妹于是请大家先说当晚真正能留下的时段，不再重找一个谁都没事的日子。邵敏可以吃前一段，唐惠需要中途接晚班，阿东得在一轮配送后才能到；缺掉的人不是在推托，只是生活没有一起空下来

## 一份菜给谁留

宋美香想带一款刚试的新口味面包，也愿意留些熟悉的旧款。到生鲜小超市和熟食店采购时，玲照着预想的满桌人数拿了不少东西，唐惠却把其中一份放回去。人会分两拨坐下，不能把后来那一顿也做成从现在开始放凉的剩饭

有人希望最喜欢的那道菜留给晚来者，有人认为自己难得按时赶到，也想先吃。唐惠本想自己多备一份，曜问她需要提前多久起床，她报了一个时间，随即也沉默下来

最后一桌分成两段相接的饭局：早来的点这一轮真正要吃的菜，晚到的按约留份、妥善暂存，需要现做的就等到场再上。想同样尝到两份的人要接受额外花费和制作安排；不愿增加负担的便换一种菜，也不要求店主用加班补出所有愿望

阿东将配送表放到取餐袋旁，圈出能来的一段。他认识[《门还开着》](../main/prologue.md)里那条经过月台杂货和唐惠备料点的路线，别人嘴里的“顺便带来”常常落在他唯一的空隙里。唐惠这次直接把取餐交给早到的人，没有在他的纸上再加一站

## 第一张照片少了谁

早到的一桌终于开饭。安可把手机架好，发现阿东还没来，邵敏的椅子又靠得太外，想再等一会儿。邵敏看了一眼时间，没有催，先把汤匙放回碗边

悠真已经拿起筷子：“他来了还要再点。你可以拍第二张。”

安可嘴上嫌他只知道吃，还是按下了快门。第一张里有人正低头夹菜，有人的工作包还没卸，空椅子也留在画面里。她没有立即发出去，问清大家愿不愿意留这张，再把手机放到桌角

邵敏吃完先走时，阿东还在路上。她给后来的人留下一句自己已经尝过哪道菜好吃，阿东到场后回了一句恰好相反的意见。两个人没有在同一张照片里出现，却真的接上了一段谈话

兄妹可以参加取餐、布桌或后半顿中的一段。选择先走，会错过后面有人说的笑话；选择留下，也不能要求早走的人再回来。安可拍第二张时，空的位置换到了另一边，这次她没有挪来一个包假装大家都在

## 谁把最后一只碗放下

唐惠进后场照看晚班出餐，回来时习惯性地去拿空盘，发现悠真已经把客区的桌面收出一半。阿东想帮着做完再走，唐惠却指了指他圈过的时间，让他赶自己的牌局

剩下的人把可以做的收桌分了，厨房里的工作仍由经营者安排。唐惠先吃完自己那碗饭，一开始不习惯，只好不断给别人指抹布在哪里。悠真将最后一只空碗放好，她终于没再站起来

“原来坐这儿会被门口的风吹到。”她说

她知道谁常点什么，却已经很久没有从这个位置吃完一顿饭。大家为她把椅子挪开一点，话题便换成宋美香那款有点不受欢迎的新面包

## 下一顿有下一顿的样子

后来在[《晚场以后》](after-the-late-show.md)，悠真把借来的器材明确交给能接手的人，再坐进汤饭店，桌边有人记得他吃饭的时间。若散场交接先发生，这次饭局便接着问他还有哪一晚能留一整段，而不是再讲一遍同样的第一次

渡口停用以后，[《雨棚下的第二条路》](../world/rain-shelter-route.md)里的配送表又划掉几处旧时间。唐惠会调整备料与份量，阿东也重新约收件；那一桌分段的晚饭让他们知道，可以具体商量谁赶得上哪一顿。已经错过的热菜没有追回，后来仍能另约新的相聚

这次聚餐在两段约定各自结束、留份交到本人、收桌有人接好之后结束。没有赶上的朋友会有自己的回复，可以另吃一顿；重访时桌子照常接待客人，两张不同的照片只按参与者允许的方式留下，不把饭局固定成永远齐全的合照

场所：街口饭馆、生鲜小超市、站前咖啡铺、站前午间食堂、夜食转角、家常面馆、家常熟食店、豆制品与早餐铺、干货香料铺、晚班汤饭店、坡地小食堂、住宅家常菜店、餐饮共享空间。关联角色：唐惠、宋美香、悠真、邵敏、阿东、安可
