# 旧外套的新口袋

<a id="qst-101"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)


陈美惠带来一件还好穿的旧外套，想改得适合现在的使用方式。月城玲与梁素讨论口袋和布料，凯文帮助比较样片，玩家在材料店、改衣店与包装修补工作室之间完成一次合作

关键选择是尊重物主想保留或更换的部分，而不是把所有磨损都当成必须保存的纪念。可以在共用院进行最后的缝补展示，也可以只在店里安静交付。后续陈美惠来访时会实际使用新口袋，梁素与月城玲留下新的合作样品

场所：月台杂货与住家、街坊共用院、手作材料店、共享木作工坊、衣物修改店、包装修补工作室。关联角色：月城玲、陈美惠、梁素、凯文
