# 旧外套的新口袋

<a id="qst-101"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

母亲带来旧外套，希望把口袋改大一点，装得下出门要用的票夹。玲注意到口袋边一处用了很多年的绣线，想尽量保留原来的样子。梁素给出两种可行版型：保留绣线就要改变另一侧口袋的位置；直接拆下则使用更顺手

玲一开始替母亲选了“保留”的方案。陈美惠穿上试了试，伸手时还是不舒服。她并不讨厌那段绣线，只是这次想要一个能方便拿东西的口袋

凯文帮忙比较样片，兄妹在手作材料店、衣物修改店与包装修补工作室之间完成合作，也可以在共用院安静交付。兄妹可以参与样片和试穿比较，由母亲决定最后的版型。拆下的绣片可以另行留存，也可以不做纪念品；样片展示了不同版型的实际取舍，最后依陈美惠的使用感受决定

结尾，玲问母亲下次想去哪儿。母亲拿出票夹，讲的是自己的出门计划，不是又一遍孩子小时候的事

尾声母亲真的使用新口袋。玲的变化通过修改设计与提问呈现，外套不是必须保持原样的家庭圣物

场所：月台杂货与住家、街坊共用院、手作材料店、共享木作工坊、衣物修改店、包装修补工作室。关联角色：月城玲、陈美惠、梁素、凯文
