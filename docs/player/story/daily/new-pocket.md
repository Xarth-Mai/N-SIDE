# 旧外套的新口袋

<a id="qst-101"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 口袋里先放进了什么

陈美惠到月台杂货时，把一件旧外套叠在新商品旁边。玲认出口袋边绕过一处磨损的绣线，小时候等母亲关店，她常用手指沿那条线摸一圈。母亲还没说完要怎么改，玲已经去找颜色接近的线，想让它看起来仍像原来一样

陈美惠拿出出门用的票夹，塞进去，边角露出一截。她换一只手，票夹又卡在袋口

“以前不是放得下吗？”玲问

“以前我没带这个。”母亲把票夹递过来，里面夹着将要出门的资料，“你先别给我加花。”

玲笑着把线放下，手却还护着那块绣过的布。她想替母亲做好一件东西，也有一点不愿承认，母亲下一段生活需要的外套，可能与自己记得的那件不太一样

## 两张都很好看的样片

在手作材料店，玲挑的里布与原绣线很相配，凯文帮忙用样片折出口袋深度。他提醒票夹不只需要放进去，还要能取出来，便把自己的手也塞进模型里，整个纸袋立刻歪了

“这一版很适合拿来展示。”他把歪掉的边压平，“你妈妈的手大概没办法只从正面看。”

梁素在衣物修改店给出两种做法。保留原绣线，可以把另一侧口袋的位置和开口重新安排，外观会变得不对称，母亲也得习惯新的取物位置；拆下绣片后直接扩袋，使用更顺手，但原处会留下新的缝线。两种都能做好，不能同时保留所有原样和所有方便

玲先把保留绣线的一版摊到母亲面前。陈美惠说好看，梁素却没有动剪刀，先用临时针脚固定，让她真的穿上试

## 另一只手还提着东西

陈美惠站着取票时勉强顺手。曜正好带回一袋普通采购，她接过来再试，手肘便被袋口牵住。票夹抽出一半，她停了停，没有说不好，先把购物袋放下

玲伸手想替她拿，梁素将袋子轻轻推回原处：“她出门的时候，你也每一站跟着？”

母亲笑了，玲却看见她刚才已经准备接受这点不方便，好让女儿的设计留在身上。她请凯文取来第二张样片，自己拆开刚固定好的几针。漂亮的第一版不能直接变成成品，这一下午的工夫需要重来，梁素也要重新安排最后缝制的时间

兄妹陪母亲比较两种实际取物动作，由她选择。保留绣线时，梁素把偏置口袋改到母亲试过的位置；选择拆下时，玲先拍下她允许留存的细节，再按新袋口重画样片。绣片可以另存，也可以随普通余料处理，母亲没有被要求再决定一件纪念品的归宿

“我不是不喜欢它了。”母亲说

玲低头拔下一枚针：“我知道。你再伸一次手。”

## 试穿以后才问的事

包装修补工作室交回成衣后，大家在共用院找一张干净桌子试穿。凯文带来的是后来改过的样片，玲没有将失败的那张藏到桌下，梁素则先让陈美惠坐下、起身、提东西，再听她说喜不喜欢

母亲这次能自己抽出票夹。玲终于问起她准备去哪儿，才知道她和父亲各有想停留的地方，路线还得商量，有一段不是当天来回。她原以为“出门”只意味着父母不在店里，听到具体安排，才发现那里已有许多自己不知道的期待

若[《最后的玩具》](../main/last-toy.md)已经结束，玲想起米娜拿回自己选定的那件旧玩具；尚未经历时，母亲此刻的选择已让她看清同一件事：磨损、熟悉或漂亮，都不能替用它的人决定去向。母亲的票夹装着新的行程，外套仍旧，却已在为另一种日子工作

## 下一次真正出门

外套交付后，兄妹不必陪母亲走完旅行来证明改衣成功。下一次见面，她可能从新口袋里拿出带回的小票，也可能说某一段路比预想中累。玲会先听旅行本身，不把每个细节都转成对自己设计的评价

到了[《明天照常营业》](../main/epilogue.md)，改衣已经完成时，母亲从新口袋拿出下一次的票；尚未完成时，她照常安排出门，另约适合的试穿时间。后来为[米娜的新住处](../world/new-address.md)挑小物，玲先看朋友给的尺寸，再挑图样，桌上那张不太对称的旧口袋样片仍能提醒她第一版为什么改过

错过这次共用院交付，可以在店里另约。母亲已经选定的版型不会重选，已拆的绣片也不会为再次展示恢复原处；留下的旧线与新的取物习惯，各自属于外套继续被使用的经过

场所：月台杂货与住家、街坊共用院、手作材料店、共享木作工坊、衣物修改店、包装修补工作室。关联角色：月城玲、陈美惠、梁素、凯文
