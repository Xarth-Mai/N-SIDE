# 雨停之后取衣服

<a id="qst-104"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

一件衣服迟迟没被取走。店内新写的说明把“周五后可取”排得像“周五当天取”，物主又临时换了工作时间，双方各自认为对方已经知道

兄妹只核对这一单允许查看的信息，通过已有联系找到本人。物主回店时解释自己日程变了，何芸也发现标牌确实不清楚。取件说明与变更日程都有没说清的部分，两人各自补上缺漏

他们随后比较两种简单标牌，让一个不知情的普通使用者看完说出自己理解的取件时间；随后改成清楚的说明

何芸多留出一个不必一直守店的晚上。后续雨天，她可以只是请兄妹把门边的伞挪一挪。取件误会解决以后，生活回到普通节奏

场所：自助洗衣店、东侧住宅院、邻里茶桌庭、Null Site 服务中心、居家用品店。关联角色：何芸、叶真、梁素
