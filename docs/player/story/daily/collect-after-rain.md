# 雨停之后取衣服

<a id="qst-104"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 最后一袋还挂着

洗衣店的机器快结束一轮，何芸把门边一把湿伞挪开，露出挂在里面的取件袋。她说那件衣服早就处理好了，对方也说周五会来，却接连几次没有碰上。梁素在邻里茶桌庭给她留过座，茶都换过一壶，她仍说再等十分钟

兄妹路过时，何芸说自己反正要检查机器。玲看见她外套已经搭在椅背上，钥匙也握在手里，便问她原本准备去哪儿。她答了茶桌庭，又补一句大家应该还没走

曜看向取件牌，“周五”排得很大，后面的“后可取”被夹在窄边，只露出半个字。何芸每天看它，早知道完整意思，反而没注意陌生人第一眼会读成什么

何芸只取出这一单获准用于联系的号码和留话，不让兄妹查看其他取件袋。物主回拨时正在换班间隙，说自己临时改过工作时间，曾顺口提过以后要晚些来，以为何芸会一直留到那个点

何芸却记得对方说的是“我下次来告诉你”。她说衣服周五之后就能取，不是只有周五；对方听见大字“周五”，又以为错过便得等下一周，几次经过时各自猜测，都没有把具体时间问完

两人都想找到那句自己确实说过的话。玲请何芸从顾客站的位置看一眼。何芸弯下腰，先笑了一声：“这上面倒像是我不许人周六来了。”

物主承认自己也没收到更改时段的答复。双方重新约好，赶不上便提前留话，何芸也终于能告诉梁素，今天究竟几点出来

## 漂亮的那张反而没读懂

梁素正好从居家用品店带回一只大小合适的牌架。玲在店里画两张纸样，一版让日期很醒目，旁边用小字解释“可取”；另一版普通得像便条，把从哪天起、人工交付到什么时段写在同一处

一位不知前情的熟客看完纸样，对漂亮的那张回答“周五”，对普通的那张却问：“周六有空，来之前留话就行？”何芸选择后者，玲重排原来想保留的花边；改字有些可惜，下一位读者终于一次看懂

玲想起[《门还开着》](../main/prologue.md)那张上一轮的完成卡，把牌架翻面试了一下，补上当次日期。已经洗好、等候领取与实际交出分别有自己的说明，何芸改日程时也会换上新纸

## 这次真的取走

约好的时候仍下着小雨。物主到店后先报这一单，何芸将衣服取下，请本人确认，再收起对应的取件牌。对方准备开口解释迟来的几天，何芸已经把纸袋递过去，问雨衣够不够罩住

“我还以为，你是不是不想做我这单生意了。”物主说

何芸停了一下：“我以为你不急着穿。”

衣服在两种没说清的想法之间多挂了几天。下一次怎样约好已经说完，两人便聊起外面什么时候会停雨

何芸将外套穿上，给梁素回消息，说今天晚些到，但这一次已经出门。兄妹替她把门边的伞挪到不挡通路的位置，剩下的普通自助营业按店里原有安排继续

## 雨天还能去别的地方

后来处理[《雨棚下的第二条路》](../world/rain-shelter-route.md)里的维修与配送改约时，玲听见“已经好了”，会继续问那件东西现在在哪、谁等着接。小牌上容易漏掉的几行字，连着别人今天能否按时出门

若何芸更晚才请兄妹帮忙，就按那一件仍待领取的衣服和当下日程重新约定；已经交出的袋子不会再次挂回。再遇普通雨天，她可能已经从茶桌庭回来，只请兄妹挪一下湿伞。那件总准备出门的外套现在经常不在椅背上，新的取件牌旁仍留着给变化写日期的位置

场所：自助洗衣店、东侧住宅院、邻里茶桌庭、Null Site 服务中心、居家用品店。关联角色：何芸、叶真、梁素
