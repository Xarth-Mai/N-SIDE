# 球场边的一张椅子

<a id="qst-105"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

熟练的常客想保留傍晚最方便的一段时间，初学者希望有不被催促的位置，陪孩子来的人需要能坐下的地方。魏航原先想写一张统一时间表，结果每一组都能指出它不方便的地方

兄妹比较公共球场、校外等候庭和亲子活动室的实际用途，发现不能靠画线就获得所有人都满意的最好时段。真正可行的是分出一段新手时间、保留一段常规活动，再安排不会挡住通路的等候位置；有一组人必须接受不是最理想的安排

陈知夏原本想拍一张“大家一起运动”的热闹照片，最后注意到一位不会上场、却一直等朋友的人。椅子不是给最值得被照顾的人发奖，而是让原来没被注意的使用方式有位置

魏航会继续调整安排，不宣告一次讨论解决所有社区冲突。照片里仍然有人没有参加运动，却属于这个晚上

场所：星见学园、校外文具与日常用品店、体育用品店、社区公共球场、放学饮品与外带铺、校外等候庭、Null Site 服务中心、社区亲子活动室。关联角色：魏航、陈知夏、叶真、郑拓
