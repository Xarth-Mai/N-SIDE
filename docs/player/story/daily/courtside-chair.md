# 球场边的一张椅子

<a id="qst-105"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 他也带了自己的球

魏航在体育用品店门口给球充气，旁边放着两双鞋，一双是准备卖的，另一双是他自己今晚要穿的。他想让社区球场多一点人用，也想终于打一场不用随时停下来安排别人的球

常客约好下班后碰面，初学者却总在这个时段走到门口又离开：并非没人准许加入，而是一连几个回合跟不上，连捡球都像打断了别人。陪孩子来的家长还问过能否在边上坐，魏航以前每次都说可以，真正到了傍晚，球、包和来去的人已把适合的位置占满

他画出一张看似公平的轮用安排，谁都分到一样长的时间。常客指着自己还没下班的那一段，新手则问为什么练到一半就要把场地腾给更熟练的人。魏航的鞋还放在凳子下，人已经忙得满头汗

“那你们说个都行的。”他说完才意识到，自己已经把最难的一句还给了大家

## 椅子第一次搬错了地方

兄妹跟着使用者走了一遍：公共球场靠近住区，校外等候庭适合等放学的人，亲子活动室能承接部分雨天活动，却不能顶替想在户外运动的一整群人。把谁简单移到另一个有空地的地方，可能只是让他失去这次真正想做的事

曜先搬来一把允许借用的椅子，放在看球最清楚的位置。一个推着小车的人经过，只得在门边等大家把椅子再挪开。坐着看得到球，与别人能正常进出，还没有同时做到

玲和叶真沿场地边缘找不挡通路的位置，请真正要等人的那位先坐下。对方坐了一会儿，说这里能看见朋友从哪边出来，已经很好，不需要占正对球场的最佳视角。魏航原来一直替他想的是怎样看比赛，他想的却只是别与朋友错过

陈知夏举起相机，看见这把椅子正好落在热闹场面的边缘，犹豫了一下，没有马上拍

## 给别人留一段，也失去自己一段

讨论重新从谁什么时候能到开始。新手获得一段不会被催着结束的时间，常规活动保留另一段，等候位置单独留出。常客愿意缩短一部分方便时段，有人仍然不满意，宁可另约别的日子；魏航也得少打一会儿，不能既作所有人的组织者，又保住自己整晚最理想的场次

兄妹可以帮比较先新手后常规、或错开交接的一轮安排，先听真正受影响的人如何选择。定下的是这次可以尝试的时段，后续根据使用情况再改，拒绝本轮安排的人也仍然能按公共规则另约

开始交接时，魏航吹响提醒，常客那一球刚好还没结束。他差点又说“再打一下”，看见场边新手已经把东西收好，便先把自己的球放到一边，请大家完成约好的交接

“你不是也想打？”有人问

“想啊。”魏航看着篮框，“所以下一段别又叫我去搬桌子。”

有人笑了，接过本来准备让他收的物件。他终于穿上带来的鞋，虽然今晚剩下的场次比原先少，仍是真正属于他自己的一段

## 照片边上没有上场的人

陈知夏拍完第一张，发现等朋友的人从头到尾没有碰球。她原来的标题是“大家一起运动”，套到这张画面上又把一个在场的人写没了

若[《没有放学的那一天》](../main/no-school-bell.md)已经核对过照片，她还会想起边缘的接班者：那人不是主角，却改变了“最后离开”的说法。更早来球场时，眼前的等候者就是她第一次需要写清的人。她没有请对方拿一只球摆拍，而是先问愿不愿意留在照片里，再换了一个能容纳椅子和正常通路的位置。若本人不愿出镜，她就拍空下来的椅子与物件，附上允许公开的使用说明

等候者的朋友终于出来，没有热情地邀请他补打一场，只自然地把包递过来，两个人并肩离开。陈知夏这才放下相机，发现自己一直在等一个“终于加入运动”的结尾，差点没看见人家原来就等到了想见的人

## 还有下一场

时段真正试过、借来的椅子按约归还或确认继续放置、通行位置得到实际使用后，这一轮才结束。魏航在体育用品店收好自己的鞋，记下需要调整的一处，也留着一个人直说不好用的意见，没有把合照当作所有人满意的证明

后来在[《把今天拍进去》](photograph-today.md)里，陈知夏和郑拓会从这张边上有人坐着的照片谈起站位：当时留出的公共通路，也恰好让画面保住了来去的人。若拍照故事先完成，这次她便先找不挡人的角度，再发现自己原定的标题仍然不够准确，拍摄方法与理解人物不是同一件事

错过这一晚可以参加之后一场，使用当前已经商量过的安排。有人继续来，有人换了时段，有人只坐在边上等朋友。球场没有因此解决所有有限空间的矛盾，却多了一种以前很容易被忽略的用法

场所：星见学园、校外文具与日常用品店、体育用品店、社区公共球场、放学饮品与外带铺、校外等候庭、Null Site 服务中心、社区亲子活动室。关联角色：魏航、陈知夏、叶真、郑拓
