# 把我的名字写大一点

<a id="qst-019"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

月台杂货的橱窗旁，安可拿着三张海报，对每一张都说“很好看”，又分别要求把脸、名字和新歌名再大一点。玲将三版摊在桌上，请她选最重要的一个

兄妹参与比较视线顺序、实际张贴距离与需要保留的信息。安可承认她最想要的是让经过的人一下就认出自己，这并不是需要被训斥的愿望；但她也必须为其他创作者与演出信息留出清楚位置

她选了一版适合宣传的主海报，另外付费做一张自己喜欢的独照小卡。玲把修改范围说清楚，安可也认真确认了报酬

她后来仍会开同样的玩笑，但不再把“朋友嘛”当作无限修改的理由。月台杂货与 AFTER 9 张贴了他们参与选择的版本

场所：月台杂货、AFTER 9、小型印制工作室。关联角色：安可、玲、悠真
