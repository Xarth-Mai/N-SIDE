# 橱窗还差一点

<a id="qst-103"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

苏弥准备展示一个在屋顶放风筝的短游戏。演示视频里，游戏中的角色在晚风中轻松越过几段屋顶，实体模型也已经摆好；真正的试玩者却一直待在起飞位置，以为必须等一阵尚未到来的风

受邀的兄妹先不看作者说明试玩，再与她复盘。问题不是试玩者不聪明，而是她把自己已经知道的规则藏在了漂亮画面里。安可提出先剪一个更清楚的宣传片，苏弥却发现宣传片不能解决实际互动缺失

可选择做成一个有完整起落的小关卡，按期展示；或明确推迟互动演示，先以制作展示形式亮相，再修改核心部分。前者删去她很喜欢却暂时无法完成的后半段，后者失去本次现场试玩机会。两种方式均有诚实、可执行的交付

凯文的模型可以保留未来设想，但标清它与本次试玩的关系。玲也不必把删去的部分当成失败涂黑，而是为已完成内容重新设计视觉重心

后来陌生试玩者真的玩到了结束。苏弥会问一个具体问题，而不是只看大家是否称赞。展示后来在 FRAME、PLAYROOM 与小展厅轮换，展板注明创作者与许可，材料与旧物仍以普通交易取得。安可从中意识到，未完成稿也可以先交给可信的人

场所：BYTE BEAT、FRAME、桌游卡牌店、游戏设备维修店、PLAYROOM、兴趣旧物交换店、手作材料店、兴趣街会合庭、小型印制工作室、街坊作品小展厅。关联角色：安可、苏弥、凯文、阿杰、周然、月城玲、乔伊
