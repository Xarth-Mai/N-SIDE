# 橱窗还差一点

<a id="qst-103"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)


苏禾准备在独立游戏体验店展示新作品，何昕制作一个实体场景，林澄设计小卡。玩家可以先试玩给出具体反馈，再帮忙把制作过程放入橱窗

发现一个演示问题时，选择缩小展示范围或调整作品，让它诚实地呈现已经完成的内容。展板注明创作者与许可，旧物交换与材料采购保留普通交易

最终展示可以在模型店、体验店或小展厅轮换。后续玩家能看到别人试玩的反应，作品也会出现新版本，不因主线结束永远停在开幕当天

场所：音游店、模型店、桌游卡牌店、游戏设备维修店、独立游戏体验店、兴趣旧物交换店、手作材料店、兴趣街会合庭、小型印制工作室、街坊作品小展厅。关联角色：苏禾、何昕、赵晏、周然、林澄、乔音
