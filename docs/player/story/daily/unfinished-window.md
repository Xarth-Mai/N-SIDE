# 橱窗还差一点

<a id="qst-103"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 风一直没有来

FRAME 的橱窗已经为苏弥留出一小块位置。凯文做的屋顶模型有几段很漂亮的高差，玲画的风筝线从第一张屋顶绕到最后，安可看了演示视频，说开头那一下很适合剪成宣传短片。苏弥把这一句记得格外清楚

到了 PLAYROOM，阿杰坐下试游戏，角色却一直站在起飞处。苏弥忍了几次，问他怎么还不走

“在等风。”

“风不是一直在吹吗？”

“那他怎么还攥着？”阿杰指向角色手里的线

苏弥看见自己为了让画面漂亮保留的待机动作。她知道该按什么，视频也从来从放飞以后开始，第一次来的人却只看见一个似乎还没准备好的角色。她一伸手想示范，兄妹请她先让另一位受邀者独自试完，第二个人仍停在同一个地方

## 不是把风筝画得再大一点

安可建议加一段说明，或把宣传片剪得更明白。这个办法能让人走进门，苏弥也真心想要更多人愿意看；可是她关掉视频，让玲只看实际操作时，能行动的瞬间仍很像一段演出。若玲也停住，就记录她在哪一步等待；已经读懂并操作时，她说明自己认出的反馈，再与阿杰和另一位受邀者的停顿比较，不要求所有人都先误判一次

玲原先画的起飞箭头恰好被模型遮住。凯文用一只普通小夹子把试玩说明暂时固定到桌边，大家才看清图和操作反馈不是一回事：即使先读懂说明，下一次动作之后仍然没有清楚的回应。苏弥从阿杰手里接过操作器，第一次没有立刻证明自己能玩过去，而是停在他停过的位置，把那一段重新拆开

她曾对玲说“你问过他想去哪儿吗”，此时轮到自己听别人说明为什么没有动。阿杰又提到一处他其实很喜欢的转弯，苏弥抬头，以为他要安慰她；他说自己已经试了三次，只想知道那个转弯之后有没有地方落下

乔伊送来展览时间，场地不能为一个还没定的版本无限空着。苏弥还要做兼职，也不能靠连续熬夜假定自己能补完所有屋顶。她把视频最后最喜欢的一段暂停，桌边一时没人提“差一点”

## 拆掉最后一片屋顶

兄妹帮忙比较两种能交付的安排。做成一个完整起落的小关卡，可以按期让观众实际游玩，但必须删去尚未完成的后半段，把时间用于起飞、转向和落下的反馈；推迟互动展示则保留继续展开的余地，却失去这次让陌生人现场玩的机会，本轮只展示清楚标注的制作过程

决定由苏弥作出。她先问凯文那片屋顶能不能暂时卸下来，凯文说可以，然后补了一句自己已经为它打磨了很久。苏弥认真看了看断面，没有轻轻一句“以后再用”就把别人的工夫收进抽屉

若选按期小关卡，双方约好拆装与补做的范围，玲重新画出真正能抵达的终点；若选制作展示，苏弥亲自改掉试玩邀请，把预约者可以来看的东西说清，再约后续测试。模型里的未来设想单独标出，已经做好的部分仍然值得展出

“你还想留这段吗？”玲指着暂停的视频

“想。”苏弥回答得很快，随后才说，“但这次先别拿它当结尾。”

## 终于有人自己落下来

修订后的试玩里，一位没有看过视频的人完成了放飞，也在能看懂的位置落下。苏弥差点在旁边出声提示，最后只是把手按在桌沿。那人结束后先问还能不能再试一次，她高兴得忘记开口，阿杰在后面轻轻咳了一声

她终于问出那个准备过的问题：“刚才你在哪里知道可以放手？”回答没有完全符合她的预想，她将那一处留给下一轮修改。完成的小关卡不会因此变回没做完，制作展示路线也在后来约好的试玩中获得同样的独立结束

安可看着被保留的旧片段，问苏弥给朋友看的时候会不会很难受。苏弥把桌边的夹子转正：“会。你刚才说开头很好看，我其实高兴了一下午。”安可笑了，没有再催她先发一条热闹的宣传

这份尚带修改痕迹的展示，后来成为[《还没写完的第二首》](unfinished-second-song.md)中安可愿意把两个不一致版本拿给朋友听的具体经历。若新歌试听已经发生，安可会认出苏弥此刻看别人表情的样子，说出自己当时没说的紧张，两次创作各有自己的完成时间

## 橱窗之外的用处

作品按约在 FRAME、PLAYROOM 与小展厅轮换，展板注明本次内容、创作者、材料来源和许可。交换来的旧物照正常交易取得，已经删掉的后半段可以成为以后研究的材料，不假装曾经属于本次可玩版本

夹试玩说明的普通小夹子留在桌上。后来在[《寄往新地址》](../world/new-address.md)为米娜挑桌面小物时，玲想起它占地方不大，先按朋友发来的桌宽比较夹口与底座，再决定选哪一件或只发制作资料。展示里的临时帮手由此有了另一种用途；若寄送先完成，大家也能用米娜的实际反馈改桌边那只样品，不重新寄一份

这次故事在苏弥选定的展示真实交付、修订后的陌生试玩者能够独立结束之后告一段落。错过首展可以参加后来一轮，已经作出的删减和延期保留各自成本。再看橱窗时，玲可以仍然喜欢原来的长风筝线，却不会让它绕向这次并不存在的屋顶

场所：BYTE BEAT、FRAME、桌游卡牌店、游戏设备维修店、PLAYROOM、兴趣旧物交换店、手作材料店、兴趣街会合庭、小型印制工作室、街坊作品小展厅。关联角色：安可、苏弥、凯文、阿杰、周然、月城玲、乔伊
