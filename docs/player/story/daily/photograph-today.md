# 把今天拍进去

<a id="qst-108"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 镜头之外先借一步

郑拓在河岸小广场找到一个很干净的角度，想为《今天的街坊》拍新修好的街边空间。椅背遮住了暂存的用品，镜头外的苗架也不会露出空格。阿东推着配送车进来，笑着问能不能先让他过，她才发现自己选的站位挡在每天使用的线路上

她收起支架，最好的光已经越过墙边。乔伊赶来取样，提醒这一页还空着；郑拓有点烦，觉得自己刚被要求记录生活，生活就把整齐的画面拆开了。兄妹先帮忙将器材退到不挡路的位置，再陪她坐一会儿，看人从哪里来、把东西放在哪里、为什么又离开

若已经完成[《球场边的一张椅子》](courtside-chair.md)，陈知夏带来当时获准留下的人物或空椅子照片及使用说明。她用它说明当时为何挪椅子，郑拓再拿它与眼前配送车要经过的位置比较；未经历那场活动时，她们直接询问阿东需要多宽的通行位置，不预先获得那张照片

阿东卸完货，问刚才拍到没有。郑拓说没有，他指指还没推走的车：“那就这会儿。我不能再给你演一趟。”她决定按这一次实际交接拍摄，接受光不再落在原先想要的位置

## 两张都可以好看

第二张轮到肖像。愿意参加的人希望换一件衣服，郑拓起初说现在这样就很好，对方却将刚摊开的衣袋又往自己身边收了收：“那件特地熨过。”她已经想好了工作服袖口与石墙怎样配在一起，衣袋里的颜色会把整张照片带去另一个方向

第一张试片里，人站在她找好的位置，表情却比刚才摊开衣袋时拘谨。郑拓把照片递过去，对方只问能不能换好衣服再看。她放下相机，重新找光，让兄妹帮忙举反光板，自己退到原本嫌背景太杂的另一边；那片颜色终于从阴影里亮出来。对方伸手抚平领口，还没站稳就问：“这回拍到了吗？”郑拓没有要求重做一遍刚才的动作，先递过去已经拍到的那张

最后留下的一张记录场所正在怎样使用，另一张是认真准备过、由本人选定的肖像。郑拓仍更喜欢工作服与墙的颜色，只是那张构想留在自己脑子里。她把获准保留的试片与选定的照片分别存好，等待确认展示用途

若陈美惠已经在[《旧外套的新口袋》](new-pocket.md)改好外套，她可以穿来试拍，把手自然放进新口袋；尚未改好时，就穿自己今天选的衣服。玲不为延续一个漂亮的家庭主题，要求母亲换回旧样子

## 父亲没有拍下的半边

在 FLASHBACK 选片时，郑文良拿两片黑纸挡住画面边缘，建议裁掉一角的箱子，让人物更突出。郑拓看了一会儿，问这样会不会让人以为整段路都是空的；若第三章的老师照片已经得到核对，她还会提起那张反复裁切的照片：“那张也是这样，一次只剪掉一点。”父亲没有撤掉黑纸：“人家拿回家摆桌上的照片，总不能什么都往里装。”

她将记录交接动作的那张移出来，把黑纸拿开。阿东的车和人在其中各占了一块，人物小了，穿过画面的路却接上了。父亲仍嫌右边太重，用手指压住一角，她拍开他的手，又将那张私人肖像递过去：“这张你试。”他换了一个裁法，她这次凑近看了一会儿，叫他先别动

陈知夏拿着图注样条，问是不是沿用上次准备的“恢复原样”。郑拓正看两张照片，忽然发现自己今天连那只箱子为什么停在那里都差点没等到：“写阿东在这里卸货。别的我明天再问。”她写下当天的拍摄时间；父亲替她压住卷起的相纸，这一回没盖住箱子

这一角接到[《没有放学的那一天》](../main/no-school-bell.md)的完整底片，也让[《名字写回去以后》](../world/names-returned.md)中的署名和说明落回一次具体拍摄。兄妹需要查旧照片时仍要回到当时的材料，今天留下的通行位置只说明今天怎样使用这处空间

## 不能替别人答应的展示

乔伊喜欢两张并排的版式，原定页数却放不下所有照片。有人愿意公开名字，有人只愿意交一张手边物件，有人看完试片后决定只自己留着。郑拓最喜欢的肖像恰好留在了最后一类。她先想换成更小的尺寸，又试着裁窄，屏幕上的那张脸一会儿近、一会儿远，怎么摆都没有让她更舍得删掉

兄妹陪她送回照片。对方很喜欢，已经找出一个合适的放置位置，听她说到小册，却仍摇头：“这张我留着就行。”她停了停，没有再展示那个缩小后的版式，也没有追问一定要有什么理由才能只留给自己

回到乔伊旁边，她亲手将那张肖像移出待印页。旁边一张已经获准公开的照片顿时孤零零地剩在那里，她试了一次，没用更大的标题把空处遮住。两人可以缩小公开组照，以另获许可的匿名物件照补充使用细节，也可以把当天观察写在一小块版面上。乔伊需要重排，郑拓留在桌边处理自己的图注；她没有说改后的页面一定更好，只在交稿前又翻了一眼那张私人照片

如果在第四章以后走到温室，艾玛允许记录当前空盘。完成[《空着的一格》](../world/empty-planter.md)以后拍到的是新苗和下一批仍空的位置；此前拍到的是当时的存活与损失。更早到访则记录正常养护中的苗架，照片不会预先出现还没发生的损失。郑拓保留各自的日期，不请艾玛重新搬空架子复演一场旧事故

## 照片先回到一个人手里

冲印后的照片先由当事人确认，再按选定用途送去展示。被留作私人的那张，对方已经在收到时写好日期，放进自己的袋子；见郑拓后来送来小册，便问她下次能不能再拍一张，仍然只放家里。她说可以，顺手指出刚才发现的那处好光，请对方到时候先别急着站过去，等她把器材放好

之后可以去摘星台，也可以只在河岸坐到天色变暗。郑拓看见原来的椅子被人挪开，没有再冲过去摆回去；明天若想拍这处空间，她需要再来一次。重访保留今天的照片、当前展示许可和新的现实变化，撤下公开照片也不抹去这次相处
