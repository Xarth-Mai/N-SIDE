# 把今天拍进去

<a id="qst-108"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 镜头之外先借一步

郑拓在河岸小广场找到一个很干净的角度，想为《今天的街坊》拍新修好的街边空间。椅背遮住了暂存的用品，镜头外的苗架也不会露出空格。阿东推着配送车进来，笑着问能不能先让他过，她才发现自己选的站位挡在每天使用的线路上

她收起支架，最好的光已经越过墙边。乔伊赶来取样，提醒这一页还空着；郑拓有点烦，觉得自己刚被要求记录生活，生活就把整齐的画面拆开了。兄妹先帮忙将器材退到不挡路的位置，再陪她坐一会儿，看人从哪里来、把东西放在哪里、为什么又离开

若已经完成[《球场边的一张椅子》](courtside-chair.md)，陈知夏带来当时获准留下的人物或空椅子照片及使用说明。她用它说明当时为何挪椅子，郑拓再拿它与眼前配送车要经过的位置比较；未经历那场活动时，她们直接询问阿东需要多宽的通行位置，不预先获得那张照片

阿东卸完货，问刚才拍到没有。郑拓说没有，他指指还没推走的车：“那就这会儿。我不能再给你演一趟。”她决定按这一次实际交接拍摄，接受光不再落在原先想要的位置

## 两张都可以好看

第二张轮到肖像。愿意参加的人希望换一件衣服，郑拓起初说日常一些更好，玲问对方平时没有机会穿的新衣服算不算生活。对方把衣袋放到椅边，说自己就是想留一张精神一点的照片

兄妹帮助试站位、遮开无关路人的面孔，也可以举反光板或陪被拍者先看一张试片。最后保留一张能看出场所正在怎样使用的照片，以及一张由当事人认可、认真摆好姿势的肖像。前者不能替人决定形象，后者也不因为经过构图便成了谎话

若陈美惠已经在[《旧外套的新口袋》](new-pocket.md)改好外套，她可以穿来试拍，把手自然放进新口袋；尚未改好时，就穿自己今天选的衣服。玲不为延续一个漂亮的家庭主题，要求母亲换回旧样子

## 父亲没有拍下的半边

在 FLASHBACK 选片时，郑文良建议裁掉画面一角的箱子，让人物更突出。郑拓看了一会儿，问这样会不会让人以为整段路都是空的；若第三章的老师照片已经得到核对，她还会提起那张反复裁切的照片：“那张也是这样，一次只剪掉一点。”父亲将两版并排，请她先说明这一次要让读者看见什么

兄妹把临时通路、交接动作与肖像各自放回用途。用于说明空间的那张保留会影响理解的背景，私人肖像则按本人意愿裁得更近。郑文良写下拍摄时间，又将照片背面剩余的位置空出来

“这儿不写‘恢复原样’吗？”陈知夏问

“你今天问过谁？”他将笔递回去

这次空白不靠摄影师补想象填满。它连到[《没有放学的那一天》](../main/no-school-bell.md)的完整底片，也让[《名字写回去以后》](../world/names-returned.md)中的署名和说明有了落脚处：知道拍到了谁、能证明什么，再决定写下哪一句

## 不能替别人答应的展示

乔伊喜欢两张并排的版式，原定页数却放不下所有照片。有人愿意公开名字，有人只愿意交一张手边物件，有人看完试片后决定只自己留着。郑拓最喜欢的肖像恰好没有得到公开同意，她得为已经排出的那个位置另找表达

兄妹陪她把照片送回本人，听完理由，不用“这是为了街坊”争取一次例外。最终可以缩小公开组照，以匿名物件照补充使用细节，也可以留出一小块版面改写当天观察。作品少了一张她很满意的脸，交付却仍然成立

如果在第四章以后走到温室，艾玛允许记录当前空盘。完成[《空着的一格》](../world/empty-planter.md)以后拍到的是新苗和下一批仍空的位置；此前拍到的是当时的存活与损失。更早到访则记录正常养护中的苗架，照片不会预先出现还没发生的损失。郑拓保留各自的日期，不请艾玛重新搬空架子复演一场旧事故

## 照片先回到一个人手里

冲印后，照片先交给当事人确认，再按选定用途送去展示。被留作私人的那张也有结尾：对方在背面写了今天的日期，放进自己的袋子，没有必须公开才算完成的第二道门槛

之后可以去摘星台，也可以只在河岸坐到天色变暗。郑拓看见原来的椅子被人挪开，没有再冲过去摆回去；明天若想拍这处空间，她需要再来一次。重访保留今天的照片、当前展示许可和新的现实变化，撤下公开照片也不抹去这次相处
