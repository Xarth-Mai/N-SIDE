# 把今天拍进去

<a id="qst-108"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

郑拓找好一个很干净的角度，想拍新修好的街边空间。阿东推着配送车进来，笑着问能不能先让他过。郑拓这才发现，为了画面整齐，她选的站位正挡在别人每天使用的线路上

兄妹参与两种不同目的的拍摄：一张记录空间实际使用的照片，保留来去的人和必要背景；一张经过当事人同意、为其认真构图的肖像。后者可以漂亮、可以摆姿势，不因此比前者更虚假；它们分别回答不同问题

玲也参与选片。有人愿意把修补过的旧物拍进去，有人想留下自己穿新衣服的样子。人物决定怎样被表现，创作者仍然拥有构图与表达的工作

再访时，菜单、种植架和人的位置又有变化。照片没有失效，只是不能替代今天。拒绝出镜、只交匿名物件照或不参与的人，同样保有选择，冲印后由本人确认展示方式。结尾可到摘星台，也可以只把一张小照片送给当事人

场所：转角观河点、城市花园与活动草坪、山脚休息台、林间缓坡、小神龛、摘星台、河岸安静露台、河岸小广场、河岸小摊、花草店、FLASHBACK、四季温室、屋顶公园、社区摄影工作室、滨水咖啡屋、河岸运动补给店、桥畔轻食屋、河岸共作亭、山脚茶屋、林缘自然观察庭、登高用品租修店。关联角色：郑拓、陈知夏、郑文良、艾玛、顾文珍、父母
