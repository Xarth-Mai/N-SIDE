# 巧克力今天不值班

<a id="qst-022"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 图标放错地方了吗

街坊共用院准备一次很小的手作展示。巧克力帮忙整理报名信息，最后在自己名字旁边放了一个“参加”的图标。玲把它移到协助接待的一栏，夸它连自己都没忘记；片刻后，图标又回到观众栏

曜以为是界面选错，伸手想改，巧克力将自己的名字和那把小椅子一起放大。它还在旁边加上作品的图形。两个人终于停下来：它想去看，也想坐在那里做一件东西

报名时段和小店的一段基础接待重合。它平常能让店员机体与其他设备同时工作，兄妹便以为这一次也一样；巧克力把“接待”和“参加”并排显示，随后只留住后一项。它没有失去并行工作的能力，只是这次不想用同一种方式相处

## 把留下的事交出去

兄妹先看各自已经答应的事。曜接下前半段店务，玲先陪巧克力去活动，按约回店交班后再由曜过去，两人需要把一项普通整理留到之后。若当次确实无人能够接续，就重新预约下一次小型活动，不能口头让巧克力放假，再让它从院子里不断回答店务

巧克力把常见取货位置逐项展示给接手的人，遇到尚未确定的订单便留下空位。曜想请它继续盯着一项不急的查询，玲指了指已经安排好的交接，两个人自己记下要问的问题。小店仍有基础服务，参加活动也确实腾出一段不会随意被普通询问打断的时间

这一幕在[《寄往新地址》](../world/new-address.md)里得到更具体的回应：米娜的新需求到来时，兄妹可以自己核对资料与处理交付，让巧克力按约参加家庭活动。若那次包裹或资料交付已经发生，他们认出自己曾经这样接下核对的工作，需要寄物时还接手了打包；尚未发生时，今天先把轮换做成一次完整的事

## 先让我放完这一块

到了共用院，凯文把可以握住的纸材和小零件放低一点，又给它留出能操作的空间。巧克力选了两块颜色不太相配的材料，玲下意识递过去一块更协调的，它没有接，只把原来那一块转了个方向

交班后曜来到院子，差点替它扶正，巧克力先护住那一边，屏幕亮出一张很有把握的笑脸。笑脸还没收回，屋顶滑了下来。它低头看了看，又将掉落的小块推到曜手边，亮出夹子的图形；曜只帮它夹住底座，等它自己重摆。凯文忍着笑，把另一只夹子也放到旁边

安可想合照，举起手机以后才发现巧克力还在低头摆放。它指了指最后一块，又把观众图标移到她面前。她只好坐下，等它做完，顺便认真听了一遍它选择的展示声音

“玲平时也得等你选完照片。”曜说

安可放低手机：“我又没说不等。”

## 图注由谁来写

成品像一小段歪歪的屋檐，颜色也不完全统一。曜把玲离开前试写的“大家一起完成”拿给巧克力看，它将自己的图标放到最前，又把兄妹的名字移到材料与帮助的位置。曜指指还夹在底座上的夹子，它立刻在他的名字旁补了一把，随后把作品朝自己转回半圈，等他重新拍照

这件东西与[《橱窗还差一点》](unfinished-window.md)里的模型相互照面。若凯文已为那次展示保留制作过程，他拿来解释失败与成品怎样一起陈列；若尚未发生，巧克力拆下的小块就先留在旁边，让下一位初学者看见它也换过一种办法。它的作品不会冒充苏弥已经做出的游戏内容

合照可以留在家人之间，也可以在各参与者同意后用于这次小展示。安可问能不能拍一张自己更好看的，巧克力这回没有移走图标，给她留出了位置，但没有把自己的作品挤到画面外

## 回来以后，先坐一会儿

回到小店，玲说明后半段已经完成什么、还留下什么，也接过改好的图注。巧克力先看自己的作品该摆在哪里，没有立即补上所有余下店务。兄妹收好普通记录，让它把成品放进约定的展示位置，图注也使用它最后选定的版本。玲读到曜名字旁的夹子，看看屋顶：“我的材料怎么没有画上去？”它把那两块不相配的颜色放大给她看，她认出了自己没换成功的那一块

任务在这次参加、实际轮班与成品安置完成后结束。之后有人再邀请它，家人先问它想帮忙还是参加；一次休息不让全部以后都自动空闲，下一次仍需安排。若之前错过邀请，就续约真实存在的下一场活动，不倒退已结束的展出

过一会儿，玲发现那段屋檐又歪了一点，朝巧克力指了指。它正把活动里的合照翻给曜看，抬头确认屋顶还在，便将照片放大：安可等了那么久，最后还是在快门落下时眨了一只眼

场所：月台杂货与街坊共用院。关联角色：巧克力、曜、玲、安可、凯文
