# 巧克力今天不值班

<a id="qst-022"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

街坊共用院准备一次很小的手作展示。巧克力负责整理报名信息，最后在自己名字旁边放了一个“参加”的图标。大家最初以为它报名做服务，直到它把图标移到观众一栏

兄妹为基础店务安排轮换，让巧克力可以完整参与这一段活动。统一身份与多机体意味着不同工作可以并行，但不意味着所有相处都自动等价：它希望这次不用一边回答店里的问题，一边听别人介绍作品

兄妹为它留座、把一件能操作的小材料放到桌边，接受它做出的并不一定最好看的组合。安可想和它合照，它先指了指自己还没放好的作品

成品放回店里，图注由巧克力自己选。后续家庭安排中会有人先问它这次想帮忙还是参加。它始终是原来的身份与记忆，没有通过受损来换取关注

场所：月台杂货与街坊共用院。关联角色：巧克力、曜、玲、安可
