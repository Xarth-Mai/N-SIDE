# 借你一把伞

<a id="qst-021"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 雨还差半条街

塞拉下班路过月台杂货，在伞架前比较一把新伞的价格和到 N站的路程。她认为雨会在自己走到车站前变大，又觉得家里已经没有地方再放一把。玲问她是不是很急，她看了两次天色，回答“不算”，人却仍站在门边

曜正在收拾一件当天不用交付的工具，听完便拿来借用伞。塞拉先看伞骨，再看借还牌，发现一根旧伞骨旁有道颜色不太一致的补线。她没有因为它旧就拒绝，也没为了显得不挑剔直接接走，先在店外试着开合了一次

“这个修得很明显。”她说

“因为后来换了线。”曜转了一下伞，“不是后来没下雨。”

## 那道线只负责这一处

这把伞是店里正常借还的用品，补线固定的是伞布与伞骨之间曾经松开的接点。曜说明自己做过的修补，也让塞拉看仍完好的其他位置。它没有等待被揭开的灾难来历，只是被人用过、修过，又留给下一次雨天

玲原本想换一把更好看的借给她，塞拉反而问这把现在是否好用。聊起[《旧外套的新口袋》](new-pocket.md)时，玲想到母亲也曾先考虑怎样拿票；还没有改衣时，她只提起那件需要试穿的事，不预先宣布最后选择。旧补线和新口袋能一起留在生活里，各自回答不同的使用需要

兄妹可以将伞按本次约定借出，也可以陪塞拉在不挡门的地方等雨。借伞让她按原来的路线先走，等待则让她晚些到家，并可能错过原本打算买的甜点；两种安排都不需要用一场新险情证明谁选错了

## 电话另一端还有一个人

手机响起时，塞拉已经伸手去拿工作外套。来电是一份值班同事能够处理的普通咨询，对方只是想确认她之前在哪一处留了说明。她将已知情况、剩下的问题和记录位置说清，等对方复述自己的接手安排后，才结束通话

曜听见她说“这个现在由你判断”，抬了一下头。她注意到，问他是不是准备替对方再做一遍。曜说没有，手却还按在刚收起的工具上。她看着那只手，没有把话讲成一次专业训话

“它今天有人等吗？”

曜想了一会儿，把工具真正放进盒里：“没有。这个明天弄。”

这次普通交接与[《把今天带回来》](../main/bring-today-back.md)的明确分工相互照应。较早经历时，曜先看见她如何把工作交给实际值班的人；较晚经历时，两人可以谈起已经各自完成的那一段。紧急事务仍由值班安排承担，散步不会提高或降低城市处置的成功条件

## 不用每次都来问案子

塞拉问要不要一起买点吃的。借伞路线可以同走一段，再在街口分开；等雨路线可以坐下吃店里已有的普通点心，等雨势变化再各自回家。她挑了最简单的一种，吃到一半承认自己其实是想赶上那家店最后一盘，刚才算天气时漏算了这个

玲笑她说得像检查遗漏，她没有否认，只把包装纸折小。雨声之间有一段无人说话的空当，塞拉也没有找出一份工作来填满

借出的伞在后来的正常来访按约归还。塞拉先晾干，告诉曜旧补线仍在、这次还看见另一处边缘开始磨损，留下可供下一次维护的具体情况；选择等雨时没有任何虚构的借还记录。那道旧线没有被换成一把永远不会坏的伞

再来时，她可以谈天气或甜点，也可以仅仅问借伞是否方便。若兄妹正忙，她按自己的安排离开；楼上住家仍是私人空间。她不需要先遇到新的异常，才有理由出现在小店门口

场所：月台杂货、N站及街口。关联角色：塞拉、曜、玲、巧克力
