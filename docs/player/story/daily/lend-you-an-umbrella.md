# 借你一把伞

<a id="qst-021"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

塞拉下班路过月台杂货，认真比较一把新伞的价格和到 N站的路程。她判断雨可能在自己走到车站前变大，又嫌新伞回家没地方放

兄妹可以借她一把店里登记用于借还的普通伞，也可以陪她去等雨。手机响起的是一份可由值班同事处理的普通工作咨询，她把交接信息说清楚，再结束通话。真正的紧急事务仍有值班人员负责，她可以在交接后结束自己的工作日

她看见曜还在收拾工具，问要不要一起去买点吃的。轮到曜说“这个我明天再弄”

借出的伞按约定归还；选择一起等雨时，没有借还事项。之后塞拉偶尔在普通雨天来访。她不是只能在紧张现场见到的制服角色，帮助也可以是接受别人一件很小的东西

场所：月台杂货、N站及街口。关联角色：塞拉、曜、玲、巧克力
