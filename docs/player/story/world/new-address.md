# 寄往新地址

<a id="qst-027"></a>

[世界任务](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 这次想要的东西

米娜离城后，玲在月台杂货收到一封消息。米娜先说新住处的桌子比想象中窄，又附上自己量的宽度，想要一件能夹住零散纸张的小物。玲已经拿出准备寄给她的旧照片和熟悉图样，看到下一句又停下来：“别装满一整箱。我现在真的没有那么大的地方。”

巧克力调出的是第一章打包时经过确认的物件去向。它知道哪些东西米娜选择带走、寄售或留下，却不知道她的新地址和今天的需求。屏幕上，收件处空着。玲没有拿旧寄存信息去填，而是回复样品尺寸，请米娜确认想要哪一件，以及允许用于这次寄送的信息

若已经完成[《旧外套的新口袋》](../daily/new-pocket.md)，玲找尺寸纸时看见那张拆改过的口袋样片，知道留在自己桌上好看的东西未必适合朋友使用；没有改过外套时，就由米娜发来的桌宽决定比较范围。这一次先问需要，再决定图样

## 留下的人也有新一局

在[PLAYROOM](../../locations/places/b02.md#place-39)，苏弥正在改自己的短游戏。她想把米娜以前爱看的演示一起发过去，随后发现自己仍在问“你什么时候回来帮我试玩”，没有问她最近有没有时间。她改成可晚些再看的简短邀请，附上当前版本，让米娜自己决定

工作台边还有固定说明卡的小夹。若[《橱窗还差一点》](../daily/unfinished-window.md)的展示已经做过，玲认出它曾让试玩者看见被模型挡住的字；这回却得先把米娜的桌宽放在旁边，比较夹口和底座，不能因为在本地好用就直接寄出。尚未做过那次展示时，她们先留下这次尺寸比较，后来再为自己的说明卡选夹子

兄妹到[桌游卡牌店](../../locations/places/b02.md#place-37)找周然借一个适合说明夹子用途的样片。牌桌边已有新人，周然为今晚的人数改了安排：“她回来可以一起玩。今天这一局，先让今天的人坐下。”他帮忙做一张简单的折叠规则卡，留出一句可写给新朋友的话，也接受米娜这次只要实用品

玲将可寄物件拍成小图，请米娜在确认的小物之外决定是否附照片或规则卡。也可以只把尺寸和制作方法发过去，让她在当地取得合适用品；这条选择同样继续彼此的联系，不把寄出更多东西当作更在意她

## 回信不用抢在今天

需要寄送时，包装回到月台杂货的交接位，由兄妹核对米娜主动提供的新地址、物件和费用，再交给正常配送。只需发送资料时，就以收到可打开的内容作为交付回应。未收到确认的部分继续留空，巧克力不从朋友的新照片或聊天之外猜测住处

这段准备与巧克力原先想参加的一段家庭活动撞在一起。曜和玲接下资料核对，需要寄送时也负责打包与当面交接，让它按约定参加；它回来后再看已完成的记录，不必通过同时处理所有事来证明自己记得米娜

若[《巧克力今天不值班》](../daily/chocolate-off-duty.md)已经发生，巧克力将那次观众席图标放进这一次日程，兄妹直接说明各自接手的部分；尚未发生时，这次分工也能独立完成。它愿意做家人，仍可以在某一段时间只做参与者

几天后，米娜回复实际使用的情况：寄送路线中她收到夹纸小物，资料路线中则按尺寸在当地购得或自己做了一件合适的用品。她觉得东西好用，也提到仍有一项收纳不合适，下次准备自己试另一种办法。她可以只回一段文字，也可以附一张桌角照片；照片里的新课程便签和提起的新朋友，都不需要逐一向兄妹说明

愿意公开照片时，她再补一句：“这张可以贴店里。”玲只展示她允许的那张，照片里的新生活比旧合照多了一点陌生。只用于私人通信或没有照片时，店里照旧，朋友之间收到的回应已经完整

## 去向已经改变，关系仍在继续

任务在选定的物件或资料实际收到、米娜作出使用回应后结束，后续联系保留各自忙碌的间隔。橱窗旁可以多一张获准展示的近况，周然的牌桌继续迎来不同的人，苏弥也继续修改，不等待一封回信才开始今天

这件事承接[《最后的玩具》](../main/last-toy.md)中米娜完成打包和真正离城。较晚参与时，她可以已经适应新住处，重新确认当前的小需求和收件方式；先前选定的物件去向保持有效，不自动把寄售物取回，也不让她为补支线搬回旧家。若双方暂未约好，就等下一次正常通信再续接
