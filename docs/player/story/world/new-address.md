# 寄往新地址

<a id="qst-027"></a>

[世界任务](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 这次想要的东西

米娜离城后，玲在月台杂货收到一封消息。米娜先说新住处的桌子比想象中窄，又附上自己量的宽度，想要一件能夹住零散纸张的小物。玲已经拿出准备寄给她的旧照片和熟悉图样，看到下一句又停下来：“别装满一整箱。我现在真的没有那么大的地方。”

她挑中的图样原本可以做成很漂亮的底座，按米娜给的尺寸放到桌面草图上，却正好占去对方要写字的一块。玲把底座缩了一遍，图样挤得看不清，又回头看自己准备好的那张合照。曜问还要不要一起包，她先说等等，最后将它们都留在自己桌上

巧克力调出的是第一章打包时经过确认的物件去向。它知道哪些东西米娜选择带走、寄售或留下，却不知道她的新地址和今天的需求。屏幕上，收件处空着。玲先回复几个可行的尺寸，请米娜选择实物寄送，还是只要资料、在当地买或做。选好寄送后才问这次可用的地址，不拿旧寄存信息补齐空栏

若已经完成[《旧外套的新口袋》](../daily/new-pocket.md)，玲找尺寸纸时看见那张拆改过的口袋样片，知道留在自己桌上好看的东西未必适合朋友使用；没有改过外套时，就由米娜发来的桌宽决定比较范围。这一次先问需要，再决定图样

## 留下的人也有新一局

在[PLAYROOM](../../locations/places/b02.md#place-39)，苏弥正在改自己的短游戏。她想把米娜以前爱看的演示一起发过去，留言第一句已经写好：“你什么时候回来帮我试玩？”玲说米娜还在收拾新住处，她又添了半句玩笑，嫌对方走了就不管这边，打完却没有发送

“我知道她忙。”苏弥把演示倒回开头，“就是这个地方改好了，原来最想先给她看。”玲没有说米娜一定会马上看，只请她把现在最想请人试的一小段留下。苏弥删掉那句催回来的话，改成有空再看的邀请，附上当前版本；发送前仍停了一会儿。然后她叫住路过工作台的曜，先试今天这一轮，不把测试留在回信里等

工作台边还有固定说明卡的小夹。若[《橱窗还差一点》](../daily/unfinished-window.md)的展示已经做过，玲认出它曾让试玩者看见被模型挡住的字；这回却得先把米娜的桌宽放在旁边，比较夹口和底座，不能因为在本地好用就直接寄出。尚未做过那次展示时，她们先留下这次尺寸比较，后来再为自己的说明卡选夹子

兄妹到[桌游卡牌店](../../locations/places/b02.md#place-37)找周然借一个适合说明夹子用途的样片。牌桌边已有新人，玲看见有人坐在米娜以前常坐的位置，下意识把要放过去的东西收回手边。周然正按今晚的人数分牌，发现少算了一个人，索性重新摆了一遍：“她回来可以一起玩。今天这一局，先让今天的人坐下。”

新来的人问空出的那张牌该归谁，玲坐到自己这一侧，把牌接过来。她没有马上觉得这个安排很好，只是在新一轮开始后发现，那个人记规则也会漏掉同一行。周然帮忙做一张简单的折叠规则卡，留出一句可写给新朋友的话，也接受米娜这次只要实用品

玲将可寄物件拍成小图，请米娜在确认的小物之外决定是否附照片或规则卡；也可以只把尺寸和制作方法发过去，让她在当地取得合适用品。米娜选的可能是最普通的那一个，或一份连包装都用不上的资料。玲照着选择收好东西，那块没做成的底座图样留在自己的工作夹里，没有改成包裹里一份不问就加上的惊喜

## 回信不用抢在今天

需要寄送时，包装回到月台杂货的交接位，由兄妹核对米娜主动提供的新地址、物件和费用，再交给正常配送。只需发送资料时，就以收到可打开的内容作为交付回应。未收到确认的部分继续留空，巧克力不从朋友的新照片或聊天之外猜测住处

这段准备与巧克力原先想参加的一段家庭活动撞在一起。曜和玲接下资料核对，需要寄送时也负责打包与当面交接，让它按约定参加；它回来后再看已完成的记录，不必通过同时处理所有事来证明自己记得米娜

若[《巧克力今天不值班》](../daily/chocolate-off-duty.md)已经发生，巧克力将那次观众席图标放进这一次日程，兄妹直接说明各自接手的部分；尚未发生时，这次分工也能独立完成。回来后，它先讲了自己刚参与的那一段，才问米娜的事交好了没有。玲将完成记录给它看，聊天没有变成补做另一班工作

交付以后，玲有几次想再发一条消息，问夹子到底好不好用。她已经收到物件或资料安全抵达的答复，剩下的是米娜什么时候真用上，并没有一个该催促的日期。她把问到一半的话收起来，继续桌上原来的画；苏弥的游戏也先留下了曜这次试玩的结果。回信来得晚一些，今天做的事情仍有自己的去处

几天后，米娜回复实际使用的情况：寄送路线中她用上收到的夹纸小物，资料路线中则按尺寸在当地购得或自己做了一件合适的用品。“夹子很合适。纸还是会乱飞，这次是我自己堆太多。”她又说起一项还没收好的东西，准备和新认识的朋友试另一种摆法，没有请玲把剩下的桌角也设计完

她可以只回一段文字，也可以附一张桌角照片。玲差点顺口问那个朋友是谁，先看到米娜又提了一件这边熟悉的小事，便从那一句接下去。她不必立刻认得照片里的每个人，才能跟米娜聊天；米娜也可以漏看一段演示，下次联系时再问苏弥是不是已经改过版本

愿意公开照片时，她再补一句：“这张可以贴店里。”玲只展示她允许的那张，照片里的新生活比旧合照多了一点陌生。只用于私人通信或没有照片时，店里照旧，朋友之间收到的回应已经完整

## 去向已经改变，关系仍在继续

任务在选定的物件或资料实际收到、米娜作出使用回应后结束，后续联系保留各自忙碌的间隔；等待回应期间，兄妹仍能继续其他委托或进入尾声，之后再接这封普通回信。橱窗旁可以多一张获准展示的近况，周然的牌桌继续迎来不同的人。以后若收到晚来的试玩留言，苏弥会先回“这一段已经改了”，再发新版本；米娜没有参加这次试玩，两人也可以继续聊别的事情

这件事承接[《最后的玩具》](../main/last-toy.md)中米娜完成打包和真正离城。较晚参与时，她可以已经适应新住处，重新确认当前的小需求和收件方式；先前选定的物件去向保持有效，不自动把寄售物取回，也不让她为补支线搬回旧家。若双方暂未约好，就等下一次正常通信再续接
