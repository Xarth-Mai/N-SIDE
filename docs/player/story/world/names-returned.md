# 名字写回去以后

<a id="qst-024"></a>

[世界任务](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 同一个字，不是同一种空白

顾文珍那一页改过以后，陈知夏在[旧帆展屋](../../locations/places/b11.md#place-85)帮老钟整理另一张说明。旧票上保留城市旧称，旁边早期异常记录的来源栏写着 Null。她原本想用“没有名字的城市”作标题，老钟却将票翻过来：“名字一直印在这儿。那张表没填出来的，是另一件事。”

兄妹与她比较票据日期、旧称所在位置和记录字段。城市曾经怎样称呼、谁记录一次见闻、某次异常从哪里形成，是三个不同问题。票能证明这一班次和这位持票人的有限行程，不能证明当晚每个人都去了哪里

## 照片边缘的工作

[FLASHBACK](../../locations/places/b05.md#place-57)的完整底片里，普通送货箱仍摆在画面边缘。郑文良提供拍摄日期和取景方向，保留辨认不清的人脸。陈知夏想将每个身影都写上名字，他先问：“你认得他，还是觉得这会让说明完整一点？”

第三章照片与票据中的旧站章、送货箱和临时牌，使兄妹想起小时候不敢经过的那条路。他们另约父母到月台杂货，翻出当日进货记录，与临时工作人员通路说明核对，才确认那段路当时留给工作人员交接和运送物件。若第五章的家庭饭局已经核对过这些资料，兄妹认出相同记录，这次只确认可供说明使用的范围。童年的感受没有被嘲笑，今天补上的是他们当时看不到的工作

月城修认得自家那次进货，却不替镜头外的人作证。郑文良也没有因为给出完整底片就变成整晚的目击者。几份材料在同一时段和用途上相互印证，仍留下无法确认的姓名与去向

## 留下订正的来路

叶真在[Null Site 服务中心](../../locations/places/b08.md#place-67)协助调取可公开的记录沿革。部分早期条目因来源未能归属而记为 Null；后来取得的证据可以补充某一条的来源，未有充分证据的字段继续保留未知。这个词已经进入公众语言，也成为城市通行名称，补完几张记录不会把今天的城名撤销

陈知夏把说明拆成材料提供者、记录者和已经核实的事件，不再将三者写成同一个名字。兄妹可以帮助联系仍能联络的提供者确认署名，也可以先完成一版匿名公开说明，保留授权的资料出处。拒绝公开姓名的人不会因此失去自己做过的工作，无法确认的人也不会被猜出的名字替代

“那标题还叫名字写回去吗？”陈知夏问

叶真指向新说明：“这里写回的是我们现在能确认的人。下面也写清，还有什么不知道。”

## 今天的人也在经过

经提供者确认的说明回到旧帆展屋，旧版保留日期与订正缘由。旧票、完整照片和临时通路的用途各自有出处，主线已经纠正的教师交接也没有再被压回一个人的传奇

兄妹在普通开放时段经过那段旧路，看见有人交接今天的货物。玲没有把它画成被解开的禁地，只给陈知夏的页面补了一只正在搬动的箱子。下一次来访，老钟可以继续讲船，也可以指出新收到的一张尚待核对的普通票据

这件事在[《没有放学的那一天》](../main/no-school-bell.md)之后开始，追问已经公开的历史细节。较晚参与时，展屋采用当前版本继续补充，不撤回此前的正确订正；完整结束只确认这一组材料的说明与授权，仍未知的异常来源保留，不等待全城往事全部查清
