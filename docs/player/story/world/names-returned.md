# 名字写回去以后

<a id="qst-024"></a>

[世界任务](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 同一个字，不是同一种空白

顾文珍那一页改过以后，陈知夏在[旧帆展屋](../../locations/places/b11.md#place-85)帮老钟整理另一张说明。旧票上保留城市旧称，旁边早期异常记录的来源栏写着 Null。她已经知道两者不是一回事，试排的标题却还是“没有名字的城市”——下面会解释清楚，她想先让路过的人停下来

老钟拿起样张，遮住底下的小字：“只看见这一行的人呢？”陈知夏说展屋总不能连个让人想看的标题都没有。她刚把顾文珍从一张太整齐的人物介绍里放出来，仍舍不得自己这句最好看的开头

兄妹与她把票据日期、旧称所在位置和记录字段摆在样张旁边。玲请她先按大标题的说法找一件能支持它的材料，找到的却都是有名字、有日期的普通票据。陈知夏没再缩小解释字去救标题，先把那一行盖住。她要找的题目暂时空着，已经核实的城市旧称不陪她一起变成谜

## 照片边缘的工作

[FLASHBACK](../../locations/places/b05.md#place-57)的完整底片里，普通送货箱仍摆在画面边缘。郑文良提供拍摄日期和取景方向，保留辨认不清的人脸。陈知夏在工作纸上给每个身影留了姓名栏，问他还能不能认出更多人。他反问：“你认得他，还是觉得这会让说明完整一点？”她没有把那些栏撕掉，改写为这次仍未确认的人

第三章照片与票据中的旧站章、送货箱和临时牌，使兄妹想起小时候不敢经过的那条路。他们另约父母到月台杂货，翻出当日进货记录，与临时工作人员通路说明核对，才确认那段路当时留给工作人员交接和运送物件。若第五章的家庭饭局已经核对过这些资料，兄妹认出相同记录，这次只确认可供说明使用的范围。童年的感受没有被嘲笑，今天补上的是他们当时看不到的工作

月城修认得自家那次进货，却不替镜头外的人作证。陈知夏想把他的名字放在箱子旁边，写成“守住通路的人”，月城修将那行圈出来：“我送过这一批。旁边还有谁在忙，我没看全。”他同意使用经核实的进货材料，却不愿在这张展签上公开姓名，更不接受那个称呼

陈知夏一时没有收回纸：“可我刚查到是谁做的，又要把名字拿掉？”月城修将自己能确认的那几项留给她，其他的推了回来。郑文良也只在自己的拍摄范围里补充，两人的材料能相互印证一个时段和用途，不能凑成整晚都在场的一个英雄

## 留下订正的来路

叶真在[Null Site 服务中心](../../locations/places/b08.md#place-67)协助调取可公开的记录沿革。部分早期条目因来源未能归属而记为 Null；后来取得的证据可以补充某一条的来源，未有充分证据的字段继续保留未知。这个词已经进入公众语言，也成为城市通行名称，补完几张记录不会把今天的城名撤销

陈知夏带着被圈过的展签去找叶真。她担心匿名之后，货箱又会变成没人注意的背景。叶真请她看具体写了什么：一份进货记录怎样与照片对上，临时牌把哪种工作留在了画面外。陈知夏重排说明，将材料提供者、记录者和已经核实的事件分开；月城修的这份材料按他同意的范围匿名，其他仍能联络的提供者各自决定署名或匿名，也可以先完成已有授权的一版。尚未回答的联络不被当成默认同意

“那现在叫什么？总不能把核对过程全抄上去吧。”陈知夏问

叶真没有替她取新标题。陈知夏试着把“有人在送货”放到最上面，嫌它太平，又看了一眼月城修圈出的那句话。最后她把这句普通话留了下来，下面写明能确认的工作、资料出处和仍不知道的部分

## 今天的人也在经过

经提供者确认的说明回到旧帆展屋，已公开的旧版保留日期与订正缘由；“没有名字的城市”那张未发布的试排稿留在陈知夏自己的工作夹里。老钟照习惯想先讲船，看到展签又把那只旧票夹移开，让照片边缘的箱子露出来。一位来访者停下来问临时通路在哪里，陈知夏拿出能说明当日用途的图，没有给认不清的身影补名字

兄妹在普通开放时段经过那段旧路，看见有人交接今天的货物。玲没有把它画成被解开的禁地，只给陈知夏的页面补了一只正在搬动的箱子。下一次来访，老钟可以继续讲船，也可以指出新收到的一张尚待核对的普通票据

这件事在[《没有放学的那一天》](../main/no-school-bell.md)之后开始，追问已经公开的历史细节。较晚参与时，展屋采用当前版本继续补充，不撤回此前的正确订正；完整结束只确认这一组材料的说明与授权，仍未知的异常来源保留，不等待全城往事全部查清
