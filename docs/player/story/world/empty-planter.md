# 空着的一格

<a id="qst-025"></a>

[世界任务](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 空架也要画进去

温室附近的输出得到处理后，艾玛请玲来画新的育苗牌。[四季温室](../../locations/places/b06.md#place-60)里有几盘保住的苗，也有确实已经失去、不能再种回原株的空位。玲拿着画笔等她搬来替换的植物，艾玛却把空盘洗干净放回架上：“这格今天就是空的，你没看漏。”

育苗交换原先答应了几处公共种植点。现在可照顾的数量变少，承诺却还印在旧牌上。兄妹先帮艾玛核对存活苗和已答应的去向，由她说明哪些能继续，哪些需要重新播种或取消这一轮，不拿其他架的苗临时补一张照片

## 不把空位平均分掉

在[屋顶公园](../../locations/places/b09.md#place-72)，乔伊想尽快恢复入口附近的一小片种植，因为来往的人天天看得见。顾文珍则希望[林缘自然观察庭](../../locations/places/b12.md#place-90)留住学生能持续观察的一组苗，数量不用多，但中途不能反复搬换

罗宾带来的是这两处当下的环境记录。它能帮助选位置，不能保证每粒种子都发芽，也不能用一次测量解释所有枯叶。兄妹跟随两位照料者看过光照、风雨和日常浇水的安排，才发现均分苗盘会使两边都达不到原先用途

乔伊承认自己更怕一个长期空着的入口；顾文珍也承认学生需要的并不是整个架子。艾玛据此提出两种能承担的安排：先保住连续观察的小组，公共入口暂时保留较小范围；或由屋顶已经明确接班的人照顾适合那里的现存苗，林缘另开有日期的新播种记录。具体去向由照料者共同确认，兄妹帮助比较、搬运和改牌

## 日期照常往前

牌子写上实际播种日、照料联系人和本轮空缺。玲原本画了一排同样高的叶片，后来改成当前能看见的数量。顾文珍看了看空格：“下回来，再画那时候的。”

新安排在现存苗安置完成、这一轮承诺逐一答复、首批补种和照料交接完成时告一段落。之后经历几天乃至数周，才有新的出苗记录；没有出苗的格子留下实际结果，艾玛再决定是否继续，不因任务结束就一夜长满

## 再来时长成什么样

危险解除没有还回损失，城市稳定的初秋也没有停止生长和人的日程。重访时能看见新日期、小苗、仍空的格子和改变过的照料轮值，玲的图注跟着事实更新。有人只来坐一会儿，不需要加入种植才能继续使用公园

这件事承接[《初秋以外》](../main/beyond-autumn.md)留下的恢复工作。错过最初一批时，艾玛展示已经完成的移栽和记录，邀请兄妹参与下一轮真实需要的补种；已经存活或失去的苗不会重置，也不要求先完成后来的联合行动才能照料已确认可用的位置
