# 空着的一格

<a id="qst-025"></a>

[世界任务](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 空架也要画进去

温室附近的输出得到处理后，艾玛请玲来画新的育苗牌。[四季温室](../../locations/places/b06.md#place-60)里有几盘保住的苗，也有确实已经失去、不能再种回原株的空位。玲拿着画笔等她搬来替换的植物，艾玛却把空盘洗干净放回架上：“这格今天就是空的，你没看漏。”

旧牌已经被她收成一叠，原定领取的那一格还贴在最上面。她让玲先画新苗，自己去整理工具，过了一会儿仍在擦同一只盆。来共同核对新安排的人很快就要到，她知道损失已经通知过，只是不想再说一遍这一批没有了

兄妹帮她把存活苗与旧牌一一对上，艾玛将对应不上实物的牌取下来，没有借别的苗摆满架子。乔伊按改约后的时段来共同核对，上次的搬运已经收到通知取消。她仍带来推车，想确认屋顶那一份还有哪些能先接走，复核后却发现剩下的苗还不能直接分给一个地方。她把空车停在旁边：“这一轮能拿多少，我得今天告诉他们。别让大家再空出一个下午。”先前的改约没有撤销；艾玛这次亲自将数量与去向答复到各处，分别说清哪些能交、哪些必须补种，哪些领取不再安排在这一轮

## 不把空位平均分掉

在[屋顶公园](../../locations/places/b09.md#place-72)，乔伊带玲看入口附近的一小片种植。它并不影响通行，却是来往的人每天看见、照料者已经反复解释为何还空着的位置。她希望先用现存苗恢复这一小片：“不能每次都请他们再理解一下，自己却连下次做什么都不肯写。”她愿意缩小范围，不愿再挂一个没有日期的“即将恢复”

顾文珍带来的则是[林缘自然观察庭](../../locations/places/b12.md#place-90)的观察本。学生已经画过这一组苗，下一次来是要接着看它们，不是挑一盆差不多的重新从第一页开始。她把本子摊到旧叶形旁，也不肯只收一个“再补给你”的口头答复

玲先在纸上把苗盘分成两半，觉得两边各退一点就能结束争执。实际放回去时才发现，观察本上的同一组会被拆开，而入口需要有人连续照顾的那一片也不能随意拼上其他苗。罗宾提供两处当下的光照、风雨和用水记录，兄妹再跟着照料者走一遍日常取水与交班的路线；其中一处纸上看起来空闲的时段，实际没有人能来。测量帮忙排除不合适的安置位置，无法凭空补出人手，也不能保证下一轮发芽

“那就先从我的这边减。”艾玛想再留一些自己照顾，却被乔伊问到具体哪一天能抽身。她把已经排好的工作挪来挪去，没有挪出那段时间。顾文珍合上观察本：“我来挑需要连续留下的这一组。剩下的，你别替我们都许了。”她也把学生原定的观察数量缩下来，接受本轮少看几株

艾玛据此列出两种能承担的安排。先保住连续观察的小组，公共入口便只能恢复较小范围，乔伊要撤下原先铺满那一片的布置图，向已经留出时间的人重新说明；或由屋顶已经明确接班的人照顾适合那里的现存苗，林缘这次便不能续画全部原株，顾文珍在旧记录后写明去向，另开有日期的新播种页。后一种安排不是把旧观察伪装成仍在继续，前一种也不会在第二天自动补满入口

兄妹把两种去向按实物与照料时间摆出来，由照料者共同确认。乔伊还会惦记那块没能恢复的入口，顾文珍也会在旧图旁停一会儿，决定并没有使另一边的需要消失。可推车这次能装上有去处、有接手人的苗，不必在门边再等一个含糊的“都可以”

## 日期照常往前

兄妹将选定的现存苗送到确认的位置，与接手的人一同摆好；留在温室的空盘里，艾玛带着照料者完成首批补种。牌子写上实际播种日、照料联系人和本轮空缺，旧领取日期没有被新日期盖掉。玲原本画了一排同样高的叶片，最后不得不刮去画满的底色，露出当前能看见的数量

艾玛看出她舍不得那一排整齐的绿，指了指最靠边的一格：“这里先别加叶子，我还不知道会不会出。”顾文珍翻过观察本的新页：“下回来，再画那时候的。”玲把笔收起来，留了一块这次确实画不完的地方

新安排在现存苗安置完成、这一轮承诺逐一答复、首批补种和照料交接完成时告一段落。之后经历几天乃至数周，才有新的出苗记录；没有出苗的格子留下实际结果，艾玛再决定是否继续，不因任务结束就一夜长满

## 再来时长成什么样

重访时能看见新日期、仍空的格子和改变过的照料轮值。已经出苗时，艾玛会先带玲看新苗，再指出哪一格仍没有动静；尚未出苗时，她们一起看播种日期与空盘，只记下当天的实际结果。乔伊按选定的范围更新入口布置，顾文珍的本子则按当时的去向保留连续观察，或从新播种页接着往下画。有人只来坐一会儿，不需要加入种植才能继续使用公园

这件事承接[《初秋以外》](../main/beyond-autumn.md)留下的恢复工作。错过最初一批时，艾玛展示已经完成的移栽和记录，邀请兄妹参与下一轮真实需要的补种；已经存活或失去的苗不会重置，也不要求先完成后来的联合行动才能照料已确认可用的位置
