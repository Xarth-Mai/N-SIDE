# 街区还在继续

以下世界任务包含主线后续与结局信息，与[十章主线](../main/index.md)、[街坊生活](../daily/index.md)共同构成街区里的故事

渡口停用后，饭仍要做，修好的东西仍要交到人手里；旧照片补全以后，说明牌还需要有人换上；异常平息后，新的苗也不会一夜长大。兄妹参与这些事情，别人也决定怎样继续自己的工作与生活

| 世界任务 | 从哪里开始 | 留在世界里的变化 |
| --- | --- | --- |
| [雨棚下的第二条路](rain-shelter-route.md) | 第六章后的维修失约和渡口改道 | 清楚的接手人与交付、能实际使用的绕行说明、调整后的备料 |
| [名字写回去以后](names-returned.md) | 第三章完整照片边缘的旧站章和送货箱 | 有出处与署名的展签、兄妹对童年那条路的新认识 |
| [空着的一格](empty-planter.md) | 第四章受损苗架与留下的空位 | 新的照料安排、能长期使用的苗格、仍需等待的生长 |
| [不是备用的那一天](a-day-of-their-own.md) | 第五章会谈后的一次普通约定 | 遥自己的作品、维恩自己的安排和一次如约结束的相处 |
| [寄往新地址](new-address.md) | 米娜离城后主动发来的请求 | 按今天的需要寄出的包裹、更新的联系和小店分工 |

这些故事可以分别参与，也可以在之后的来访中继续。过去的事保留过去的时间，今天的路线和约定按今天的情况调整；街区不为补上一段故事重新经历已经结束的危险
