# 雨棚下的第二条路

<a id="qst-023"></a>

[世界任务](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 被划掉的交付时间

西环渡口临时停用后，阿东的配送表上多了几条改线。序章里连着月台杂货交接和唐惠晚班备料的同一张表，如今有两个时间被划掉。兄妹续接第六章失约的那件普通小设备，先拿出已经答复过的交接记录：顾客已选退款取回，便核对退款和物件何时交到本人手里；已同意转修，便按陆成实际接手的进度确认剩余交付。已经在陆成那里的设备留在那里，已经结清的费用也不重算

顾客来办交接时，手里拎着上次取件准备过的空袋。曜把已经列好的检查项目放到台上，差一点又补一句自己还能再试。顾客先将旧取件凭条放在旁边：“我把今天的事挪开了。电话里说好的，就照那样办吧。”若实物和款项早已交清，这次只核对原记录，双方不再重演一次柜台交接

曜没有用免去工钱换一次重新决定。玲把他翻到背面的凭条转回来，原来约定的日期留在两人中间；她也不能把替曜答应过的那一个下午，只算成他的失约

若兄妹已经帮[何芸改过取衣牌](../daily/collect-after-rain.md)，玲把那次分开的“做完、可领、交到谁手里”写在交接旁；尚未做过时，她直接向顾客逐项确认。这张记录说明当前状态，不再用旧完成卡代替实物检查

玲把约定、已经检查的部分和尚未确认的故障放到一起。曜得把以前那句“差一点”拆开：哪些部件试过，哪一步还没完成，自己什么时候才知道赶不上原约。他说到最后一项时停了一下，承认自己当时还想把这件事赶出来，没有及时通知。顾客核对完，指向电话里已选定的去向，兄妹就按这一项办理，不请对方再给曜一次证明能力的机会

## 真正交出去

顾客愿意了解转修安排、而实物还未交出时，兄妹先征得同意，才带着实物与检查记录到[小修理铺](../../locations/places/b03.md#place-11)。陆成没有接下“剩下一点”这个说法。他让曜指出哪一步试过，按记录重做那一步，再将未经确认的部分单独放开：“你把不知道的也交给我，才算交全了。”他自己的工作台上还有别的物件，能接的时间并不比曜刚才想许诺的更早。先前已完成转修交接时，这份记录直接留在陆成手里，本次从他的实际进度继续

顾客接受转修报价和时间，陆成才接手，曜承担原约定中应由自己处理的部分。顾客选择直接取回，或听完新安排仍不接受时，兄妹就在月台杂货核齐散件、封好物件、附上已做检查，按原约结清退款。这条路不需要陆成再修一次才算结束，也不必再听一次转修报价。曜将自己留到很晚写的排查纸也装进去，让下一位接手的人用得上；顾客核过数量，收好袋子，没有改口说下次还会来。已经取回并结清时，回访只确认原记录与后续去向，不要求顾客再把东西带来

阿东只在收件人确认后安排运输，不用另一份模糊的“尽快”覆盖原来的失约。曜仍想跟着跑完。他把外套拿起来时，月城修已经在收自己的东西，前场还有曜尚未做完的店务

“你今天还能晚走一会儿吗？”曜问出口，才看见父亲又去看了时间。月城修没有重新坐回柜台：“这次不行，我也约了人。”曜把外套放回去，先完成自己留下的店务；已经接手的那段由接手的人负责。父亲离开时，他还没把全部事情做完，但没有再叫住父亲

## 能走的路，也要来得及

店里腾出人手后，兄妹才与阿东按当前路况核对改线。在[城市交通服务厅](../../locations/places/b01.md#place-32)确认仍开放的换乘与公共通路，再走过需要调整的一段：看起来较近的步行路有台阶，装货推车过不去；能走的公共缓路更长，连着的雨棚也会在街口断开。阿东让他们把路线放回实际装车的顺序里，比空手走到终点多出的时间还得算上防雨和交接

经过候船区域时，几人按当日开放范围改走；若终章已经拆下原想保留的檐段，那一处普通遮雨空间仍不能用，玲在路线小图上补出缺口。旧图能让人记得从前怎么走，不能替货物挡今天的雨

设备尚待交接时，阿东可以把经同意转修的设备带到新交接点，或按顾客约定在月台杂货留待领取；已经取回或交到陆成手里，就只核对本次其他配送，不再搬回那件设备。唐惠算过新路程，把备料单上一部分划到下一次配送；少一趟绕行仍赶不上原饭点，这一班能出的份量只能减少。她先问清阿东几点能到，才去改营业安排，没有接那句习惯性的“我再快一点”

若[《一桌不同的晚饭》](../daily/different-dinners.md)已经办过，唐惠翻出当时分两段接人的安排，请阿东把今天能到的时刻写清，再决定哪部分提前备好；尚未办过时，两人就按这次营业直接协调。旧合照若获准展示便继续留下，眼前的配送仍要重新答复

“这条长一点，但我能照它把今天排完。”阿东把旧时间保留在改约记录里，另写双方确认的新时间

## 这次到这里

物件按顾客选定的去向完成交接，款项与剩余维修责任说清，配送和备料的新约定分别得到收件人的回应。任务在这些普通事情完成后结束，渡口是否恢复开放由现场修缮决定

后来顾客仍到月台杂货买东西。选择转修的顾客暂时继续把维修交给陆成，取回物件的顾客则自行选择其他维修安排。曜没有催问什么时候能再信任自己，营业安排旁保留清楚的接单范围。阿东收工后赶去周然的桌游，不再把“我再绕一下”当作默认答案

这件事承接[《河没有倒流》](../main/river-did-not-reverse.md)的失约与改道。较晚参与时，顾客已经选定的处置和已完成的维修保持有效，兄妹处理剩余交付或回访；渡口已经恢复后改用当日通行信息，旧配送表留下改约经过，不重新制造封路
