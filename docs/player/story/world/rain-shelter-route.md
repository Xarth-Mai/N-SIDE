# 雨棚下的第二条路

<a id="qst-023"></a>

[世界任务](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

## 被划掉的交付时间

西环渡口临时停用后，阿东的配送表上多了几条改线。序章里连着月台杂货交接和唐惠晚班备料的同一张表，如今有两个时间被划掉。曜看见第六章已经失约的那件普通小设备仍在后场，想先修完，再向顾客解释

顾客却先来取回东西：“我现在要知道交给谁。今天修不好，也请今天告诉我。”

若兄妹已经帮[何芸改过取衣牌](../daily/collect-after-rain.md)，玲把那次分开的“做完、可领、交到谁手里”写在交接旁；尚未做过时，她直接向顾客逐项确认。这张记录说明当前状态，不再用旧完成卡代替实物检查

玲把约定、已经检查的部分和尚未确认的故障放到一起。兄妹向顾客说明现状，列出退回物件并按约结清退款、或征得同意交由陆成重新报价排期的办法。顾客决定接受哪一种，不必因为他们刚完成异常调查就继续等待

## 真正交出去

在[小修理铺](../../locations/places/b03.md#place-11)，陆成没有接下“剩下一点”这个说法。他让曜指明哪一步已经试过，再亲自查看实物：“你把不知道的也交给我，才算交全了。”

选择转修时，陆成与顾客另约费用和交付时间，曜承担原约定中应由自己处理的部分；选择取回时，兄妹封好散件、附上已做检查，不把取消继续维修写成已经修复。阿东只在收件人确认后安排运输，不用另一份模糊的“尽快”覆盖原来的失约

曜想跟着跑完后续。月城修把前场工作表推过来，提醒自己只帮到约定的时刻。曜于是把这一段交给已接手的人，先完成自己留下的店务，让父亲按时赴约

## 能走的路，也要来得及

阿东在[城市交通服务厅](../../locations/places/b01.md#place-32)核对仍开放的换乘与上层通路。兄妹陪他沿商店街雨棚走过需要调整的一段，发现步行近路含有台阶，推车必须另走公共缓路；雨棚也不是一路相连，货物仍要做好普通防雨

阿东可以把经同意转修的设备带到新交接点，也可以将取回的物件留给顾客预约领取。唐惠的备料单同时改成经营者能接收的时段；少一趟绕行仍赶不上原饭点，她便调整当晚份量，不要求配送员替整条街追回时间

若[《一桌不同的晚饭》](../daily/different-dinners.md)已经办过，唐惠翻出当时分两段接人的安排，请阿东把今天能到的时刻写清，再决定哪部分提前备好；尚未办过时，两人就按这次营业直接协调。旧合照若获准展示便继续留下，眼前的配送仍要重新答复

“这条长一点，但我能照它把今天排完。”阿东把旧时间保留在改约记录里，另写双方确认的新时间

## 这次到这里

物件按顾客选定的去向完成交接，款项与剩余维修责任说清，配送和备料的新约定分别得到收件人的回应。任务在这些普通事情完成后结束，渡口是否恢复开放由现场修缮决定

后来顾客仍到月台杂货买东西。选择转修的顾客暂时继续把维修交给陆成，取回物件的顾客则自行选择其他维修安排。曜没有催问什么时候能再信任自己，营业安排旁保留清楚的接单范围。阿东收工后赶去周然的桌游，不再把“我再绕一下”当作默认答案

这件事承接[《河没有倒流》](../main/river-did-not-reverse.md)的失约与改道。较晚参与时，顾客已经选定的处置和已完成的维修保持有效，兄妹处理剩余交付或回访；渡口已经恢复后改用当日通行信息，旧配送表留下改约经过，不重新制造封路
