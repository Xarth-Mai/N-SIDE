# 尾声 · 明天照常营业

[主线总览](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

<a id="qst-010"></a>

**主要场所：月台杂货与住家、树下小空地、镜厅、摘星台、白页书店、小型印制工作室、旧书交换屋、MONO、街坊作品小展厅、AFTER 9，以及各地重访。无新增灾难**

《今天的街坊》完成一版小册。有人愿意写上名字，有人只提供匿名照片，也有人完全不参与；这些选择都被保留。遥参与编辑，月城玲负责部分图案，印制工作室完成装订，书店与交换屋让它真正被读到

展览没有将全部内容变成灾难纪念。宋美香的新面包、凯文的制作过程、陈知夏今天的放学路线、米娜寄来的新住处、悠真的当前演出，都可以占据同样真实的位置

玩家再次走过曾经调查的地方。渡口信息清楚了，温室仍在恢复，录音楼留下新的作品，校外等候庭恢复普通的人声。人物会提起共同经历，也会谈完全无关的新事

父母来店里吃饭。兄妹这次愿意多讲一点处理中间的麻烦，也认真听父母说自己的计划。之后可以上山，经过茶屋、小神龛与林间步道，在摘星台看城市与另一侧的繁星

摘星台仍是同一地点、同一夜晚的两面景色，不成为传送门或最终封印点。[摘星台](../../locations/stargazing-terrace.md)

回家时，巧克力在楼下接待一位刚下班的熟客。新贴上的营业安排旁边，留着米娜的明信片。玩家可以上楼，也可以再帮忙摆好一件商品
