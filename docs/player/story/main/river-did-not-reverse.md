# 第六章 · 河没有倒流

[主线总览](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

<a id="qst-007"></a>

**Black Case：“候船处的旧提示”。场所：河岸安静露台、河岸小广场、西环渡口入口与候船处、城市交通服务厅、旧帆展屋、河岸运动补给店、桥畔轻食屋、河岸共作亭，以及已有桥下通路。月城曜潜梦，月城玲接应**

<a id="调查与行动"></a>
<a id="主线判断"></a>

## 先处理旧提示

西环渡口出现旧班次提示，有人因此走向已经停用的入口。邵敏举着当日班次牌，把人带回上层公共通道；邱立关闭受影响的低层入口，留下行人安全绕行的位置

老钟说那个报站声他认得，连停顿都没变。他下意识望向河面，今天的船还停在另一处。兄妹先把广播时间、现场录音与班次逐项对照，再沿声音出现的位置检查，旧提示没有对应一艘正在靠岸的船

曜进入反复叫号的候船厅，玲清醒接应。队伍每次走到放行口，都会回到同一张长椅；曜让其中一轮放行完成，现场人员趁窗口隔离已定位的提示输出。报站声停了，邵敏重新试走入口，人工说明可以清楚地听见

## 声音停了，什么还在动

邱立随后回来请他们看另一份记录。浮动候船设施的一处导向构件仍在反复小幅动作，维护人员从安全位置支撑它，却始终完不成最后一步固定。设施本来会随水位升降，这一次，水面短暂停稳后，构件仍按同一个间隔往回动

曜先核对刚完成的隔离，封闭位置没有变化，旧提示也没有重新出现。玲把声音停止的时刻画在构件记录上：它已经安静了，另一条线还在起伏。兄妹暂时只能确定自己解决了第一件事

老钟在旧帆展屋摊开候船照片，指向一段低低的屋檐：“以前等船，都先往这边挤。”邱立拿来今天拍的接缝。檐口还是那个轮廓，下面却多了一组后来维修时装上的附属连件；这组连件既接住檐段，也沿支架接到浮动设施的导向部位，雨后填充层一直没有干透

玲想把原来的檐口画回小册。老钟请她先别画太新：“这块缺角也留着。”邱立让两人等现场核验：能不能留在原位，要看下面的接触；抽掉连件就不能让檐段悬在原处。若要原位保留，须另做独立承托；眼下已确认的安全操作，是先支撑、整段卸下并留样，原位新做法要重新设计。老钟看着照片，没有点头

兄妹从开放的公共位置观察水线，对照材料更换记录，再请现场人员在许可范围内复核接触。温室调查留下的潮湿接缝照片终于有了可比较的对象：同样留水的地方并不全有响应，接到导向部位的这一段却能与当前动作对上。玲把只按道路远近画出的那条线擦掉，留下逐段取得依据的接触

老钟又取出一张带城市旧称的船票。玲问他能不能记起那天谁站在檐下，他想了一会儿，摇头。她在小册上只记日期和候船处，给缺角留了位置

## 返回的路线

曜再次进入候船厅。现实中的旧报站声保持安静，梦中的叫号与等候仍在重复；另一侧有队伍绕过关闭的窗口，从檐下走回起点。玲逐段报出现实标记的变化，他据此找到会响应本轮操作的联系；那些逼真的船影仍按自己的旧次序经过

曜利用候船者转身的间隙阻断一轮回送，现实人员完成对应的局部处置。导向部位的这一项输出降下去，旁边另一份观测却开始重复刚才的间隔。曜准备追过去，玲先叫停：“先回来。它换到哪一段，我们还没对上。”

两次处置的位置都保持隔离。罗宾将今天新增的响应与已处理点分开，塞拉据此扩大协同范围：近期水位、修缮接触与当地维持条件，已经让原本各自活动的结构获得新的路径。继续追一个、封一个，可能总把下一处留在看不见的位置

曜退出时，河仍向原来的方向流。渡口继续停用，维护人员守着已支撑的构件；联合行动需要处理的是现在仍在接通的部分

## 同一个下午

上层服务通道留出了一次由现场人员协助的转运时段。阿东推来唐惠当晚要用的备料，艾玛带着新一轮已约好转运的苗盘，安可与悠真的河岸首演设备也停在入口。普通行人继续绕行，三批推车却不能同时占着操作位置。这次转运结束，作业口就要交回维护人员；其他转运需另约人员和车次，赶不上当天已经排好的试音检查

艾玛核对苗盘，先前已安置和补种的那些留在原处。这一批若赶不上接班，她可以带回去另约，明天愿意帮忙的照料者却未必还有今天的人手。阿东说备料可以拆批，余下一趟到达就要晚；安可算着试音时间，说设备若不先过去，今天的检查排不开，已经做好的宣传便要撤下

曜想让阿东顺便捎走店里的维修件。阿东把表递给他：“你替哪一车说晚一点？”玲也看着他，手里还夹着被改过两次的校样预约。曜没有接那张表

兄妹帮着量过货物、核对接班时间，能拆的小批备料和苗盘占满了当次转运安排。安可问过让整套音响先走的可能，阿东必须把晚饭备料改到下一批，艾玛也得带苗盘回去重新找人；她仍想只运一部分设备，悠真却确认必要的一整套赶不到就无法完成当天试音。她给场地拨电话，撤下河岸首演；两个人把设备推回去时，还为究竟该先取消哪一笔制作开支争了一路

邵敏更新替代路线，贺佳另查 AFTER 9 可以商量的场次。关着的河岸舞台没有因此立即在别处重新搭好，唐惠也只按实际到货调整当晚菜单

## 这一次不能再改一行日期

曜给那位已经改过检查预约的维修顾客打电话。对方只问今天能不能取。他看着自己尚未完成的交接，回答：“不能。”

“上次说改一下时间，这次又改。”顾客停了一会儿，“东西我还要用。”

曜没有再许一个最快日期。他说明可以退款取回，或者在对方同意后转交陆成，由陆成确认能否承接和新的时间。顾客选择哪一种，就按哪一种留下记录；已选择的补救不再换一张单重新答应。想继续落实配送与取件，可以从[《雨棚下的第二条路》](../world/rain-shelter-route.md)接着做

玲陪他回店找出那件东西。她说：“上次那个下午，是我替你答应的。”曜把尚未做完的检查列在单上：“后来能不能接着修，是我自己答应的。”两个人都没有说这样就算扯平

安可当晚收到外地宣传档期的最后确认。悠真摊开工作表：“你去不去都可以。你得告诉我，我这一周是在等你，还是在做别的。”她把手机翻过来，又翻回去，没有立即回答

楼上的晚饭热过一次。玲没有继续赶那张完整檐口图，曜也没有把维修单藏到别的工作下面。两张纸留在同一张桌上，第二天还得分别处理
