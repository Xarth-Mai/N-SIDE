# 主线：回声之后

以下收录完整故事与结局，可以从序章依次阅读，也可结合[故事时间轴](../index.md)查看章节关系

## 故事

让生活继续，不等于让它恢复成原来的样子

月城曜、月城玲与巧克力经营着月台杂货。玲开始承担《今天的街坊》插图和安可的新歌视觉，曜希望父母能够放心开展自己的生活，却越来越难拒绝熟人的请求。米娜搬家前不断离开原位的旧玩具，把两人带入第一份异常调查

收集者并非最初以为的破坏者，解决异常也不要求米娜先决定忘掉什么。她按自己的选择打包，真正离城。随后出现的掌声、点名与环境偏移各有当事人和局部机制，兄妹逐渐发现独立结案不能回答正在变化的联系

第二章已经能查到原始“旧日回放”终止的历史结论。第三章完整底片与交接表推翻玲画好的英雄故事，她重画版面；兄妹也主动承接跨案观察。曜此前替玲答应现场核验，挤掉她的首轮校样；玲为补救又替曜改了陪同时间，撞上他的顾客预约。两人想补好同一份生活，却开始让对方付出未曾答应的成本

四季温室的试验显示，一处输出下降可能让另一处增强。曜承认自己没有完整答案，团队开始比较协调处理与可控休眠。维恩和遥的生活、授权记录与当下资料进一步说明：过去的成功有具体适用范围，不能代替今天的调查

西环渡口的新介质路径干扰正常固定，临时停用影响配送、备料与首演。曜错过普通交付，安可无法同时保留两份档期，玲也不能把自己的作品时段一再当成可以挪走的空位。他们分别减少接单、交接未知、缩小首版、明确创作安排，让代价落在真实工作中

联合演练通过后，玲进入临时合流场，曜始终清醒接应。拆改后的剩余接触使两股返回重新挤在一起，原本争取保留的旧檐段无法同时留下。玲要求按已核验范围卸下它，再为现实固定打开窗口；曜留在自己的位置，以现场独立检查和玲的当下观察作出判断。新增联动分段解除，原有隔离保持，安全的局部生活继续，候船处留下一段暂时不能遮雨的缺口

故事发生在初秋气质的阶段，实际日历照常向前，章节之间可以跨几天至数周。危机结束后，温室仍有空架，渡口继续修缮，错过的档期没有得到自动补偿。新歌、小册和晚饭照常发生，回家的人开始用不同方式生活

## 留在街道上的后续

配送表、旧站章、育苗认领牌、编辑日程和待寄信封在不同章节出现，也各自回到普通生活中。[《雨棚下的第二条路》](../world/rain-shelter-route.md)承接停渡后的配送与履约，[《名字写回去以后》](../world/names-returned.md)核对旧称、署名和童年路线，[《空着的一格》](../world/empty-planter.md)安排实际的重新种植，[《不是备用的那一天》](../world/a-day-of-their-own.md)延续维恩与遥的日常约定，[《寄往新地址》](../world/new-address.md)继续米娜离城后的联系

这些故事从主线留下的具体需要出发，与十二条街坊故事共同组成可重访的生活。它们改变送达记录、公开说明、种植安排、作品与通信，主线的安全处置和必要判断始终有自己的完整来源。尾声按已经发生的事回应，没有完成的邀请仍可在后来继续
