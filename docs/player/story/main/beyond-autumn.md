# 第四章 · 初秋以外

[主线总览](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

<a id="qst-005"></a>

**Black Case：“越出边界的初秋”。场所：转角观河点、城市花园与活动草坪、花草店、坡地公共到达节点、平台阅读角、四季温室、坡地小食堂、屋顶公园、山脚茶屋、林缘自然观察庭。月城曜先潜梦，月城玲接应；需要换人时先完全退出**

## 求助与真实因果

艾玛发现温室与附近几处种植点出现不同寻常的温湿度变化。最初看起来像养护设备故障，但屋顶、公园与林缘记录显示，它们与地形和区域状态有关

Null Site长期初秋由当地低强度独立结构参与维持。它在梦境中表现为一处不断照料相同季节的庭院，暂称“候秋者”；没有清醒的主观意图。持续活动依靠环境能量交换，不是停止全城时钟

原本较稳定的局部边界正在变化。一处新的联系把调节作用引向不适合的区域，影响了当前种植与设施使用。要解决的是新增的有害耦合，而不是证明整个街区必须放弃已经稳定共存的气候

## 调查与行动

玩家从温室的实际损失开始，帮助把受影响苗盘转移到安全位置，再按艾玛的记录比较花草店、城市花园、屋顶公园和林缘。罗宾标出已经证实与尚未证实的区域，邱立补充近期排水与地表维护记录

梦中庭院的道路和天气随候秋者重复的照料动作变化。玩家观察某条新开放的小径总把不同区域拉到一起，先标记通行变化，退出后核对它对应的现实联系

一个初步的单点隔离试验降低了温室影响，却在另一个观察点出现增强。这个可恢复结果说明结构存在相互作用；试验立即停下，不由玩家无知引出强制灾难

玩家据此调整方案，再进入梦境，利用候秋者在不同区域切换的时机，解除新增的交叉通路，而保留原本局部闭合的活动。现实团队同步确认输出回到可接受范围

## 转折与后续

“把能看见的异常都清掉”不是可靠方案。第一次明确建立：源头、局部维持与区域联系需要分开处理。原始事件后留下的环境并非某个人仍在持续供能

苗木需要继续护理，温室不会瞬间恢复。艾玛改写记录，罗宾提出查阅早期持久梦境的终止资料，诺拉则告诉月城玲，参与小册的编辑遥正好与相关研究者合作

章末在平台阅读角或屋顶公园停留，把一段高强度调查留在身后。这里仍是居民可以免费坐下的地方
