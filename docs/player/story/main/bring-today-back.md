# 第七章 · 把今天带回来

[主线总览](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

<a id="qst-008"></a>

**重点场所：月台杂货与住家、镜厅、小店货运侧院、城市交通服务厅、小型印制工作室、坡地公共到达节点、Null Site 服务中心、共享工作室、街坊作品小展厅、河岸共作亭；与此前各案地点联系。无全城强制跑点**

## 当前问题

几种局部梦魇活动正在形成相互强化的联系。单独处理某一输出点可能把扰动转向另一处；如果只切断所有可见介质，又可能毁掉用于验证的记录并干扰原本稳定的生活

前几章已经隔离的直接输出点保持有效处置状态，本次调查针对尚未接入的新自然通路与相互加强。保留下来的局部活动不等于已被消灭的个体复活，前面的帮助也不会被剧情无条件撤销

新的自然窗口不是精确重复十二年前。没有足够依据保证它会在造成更大后果之前自行停止。团队需要抓住当下能够测到、能够验证的联系，逐段处理

## 准备不是收集信任点数

玩家选择走访几个与行动直接相关的场所，收集明确授权的现场记录、协作安排与替代路线。其余合作由此前已经建立的联系自动展开，也允许用集中会谈补齐必要信息

郑拓和郑文良整理当下照片与原始记录；悠真记录新制作、未进入旧回放的声音标记；艾玛与邱立提供持续变化的现场观察；交通人员准备人工信息；叶真协调公共场所和专业团队。书店与小册项目提供信息组织经验，不成为异常信号的神秘天线

这些记录仅作为核对当下状态的参照，不是具有驱魔力量的钥匙。真正起作用的是玩家据此识别活动、创造窗口，并由现场人员执行已经验证的处置

## 人物冲突与决定

月城曜最初想先独自把所有节点确认，月城玲指出未确认的部分应该进入共同计划，而不是靠沉默承担。两人将“我还不知道”写进交接表，分清谁能确认什么

维恩提供以前失败与成功的处置资料，并尊重遥对私人记录的授权范围。遥选择让团队使用必要的活动特征，却不交出所有日常对话。这个边界不降低成功可能

一次小范围演练暴露了旧记录可能误导现场判断的问题。团队增加独立实时参照与双重确认，修订方案后再进入正式行动。主线压力来自明确准备与现场变化，不来自玩家在茶屋多停留了几分钟

## 行动安排

家中后场作为兄妹的受控接入与接应点，使用此前已验证的有效连接。现实一方保持清醒，联络有权限的专业团队；梦中一方带巧克力进入。家庭 Agent 的店员机体继续基础营业，必要时减少复杂接待

可先从候船、演出或庭院结构切入，入口选择改变调查顺序与部分支援表现，但不改变一人潜梦、一人接应的基本安排
