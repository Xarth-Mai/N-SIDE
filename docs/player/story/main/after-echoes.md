# 第八章 · 回声之后

[主线总览](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

<a id="qst-009"></a>

**Black Case：“多点回放联动”、“候船设施次生险情”。梦境为临时联结的复合场景；现实地点沿用既有场所**

## 最终场景是什么

当前相连的局部结构把候船厅、等候庭、庭院与演出空间的片段组织成一个临时复合梦境。建筑尺度和通路可以在梦中变化，现实中的学校、河岸和影院没有真的连成同一栋楼

这不是“旧日回放”复活，也不是有意识的新幕后主使。作者暂称它为“合流场”，指相互作用的环境状态，不另造一个能解释一切的神

## 梦中行动

**第一段：辨认此刻。** 玩家进入已熟悉却混合错位的街区，旧指示与当前接应信息出现差异。利用前几章学会的核对方法找到当下有效的入口，不把每个逼真回应都当成真实同伴

**第二段：制造处理窗口。** 引座员、点名者、候船者等局部行为互相干扰。玩家根据此前掌握的移动规律、转身间隙、等待与归位动作行动，用基本工作工具牵引、打断或避开形体，接近真正的联系部位。巧克力标记和保护，不代替玩家解决全部问题

**第三段：阻止现实放大。** 候船处的局部扰动触发了一项真实设施险情，现实人员按事先安排关闭相关区域并处置。梦中玩家需要及时终止新增投影，让既有物理处置能够完成。险情通过明确现场流程表现，失败回到行动检查点，不暗中伤害没做支线的居民

**第四段：拆开新增联动。** 每完成一处现实确认，梦中对应活动不再接受其他区域的加强。复合场景逐步分开，原本独立、无害或受控的结构仍能保留。玩家不是通过摧毁所有存储来获胜

**第五段：确认退出。** 最后的危险来自回放的“已完成”信号。玩家必须等现实接应给出事先约定、当下生成的确认，再退出实际连接。它不是任意猜暗号，而是贯穿多章的证据与分工在最后一次发挥作用

整段只安排一名兄妹处于潜梦状态，另一名一直清醒；需要更换角色的版本通过明确撤出与交接分成两次行动。其他城区由其他专业团队处理，不把全城存亡押在兄妹一人能同时赶到所有地点上

## 结果与代价

新增的大范围联动被解除，危险输出停止。部分旧的活动结构转入休眠或被终止，必要记录在事先授权和可行条件下留存；未获授权的私人片段不因战斗胜利自动公开

Null Site的稳定初秋没有被一键清零。维恩与遥的受控共同梦境继续，巧克力保持原有身份与记忆。现实受损物件仍需维修，已造成的误会需要当事人澄清，工作与交通逐步恢复

本章的胜利由可观察结果组成：现场不再出现新投影、相互加强已经停止、重要通路恢复、安全的既有生活可以继续。它不是靠角色突然宣言“我相信你”解决物理机制
