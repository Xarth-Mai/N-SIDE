# 第二章 · 多出来的掌声

[主线总览](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

<a id="qst-003"></a>

**Black Case：“没有观众的掌声”。场所：BYTE BEAT、游戏设备维修店、PLAYROOM、乐器音频店、排练录音楼、AFTER 9、唱片聆听店、LATE BITE、演出会合广场。月城曜潜梦，月城玲接应**

## 求助与真实因果

悠真在录音交接时听见不属于当前作品的掌声，担心自己混入旧素材。类似声音又出现在相邻演出空间，阿杰以为是设备串音，请兄妹一起排查

直接声源是一处旧场地构件的异常振动；有限物理输出形成了可被独立录下的声响。它不是所有人的幻听，也不是联网设备自动传播了梦境。活动源是一段从历史事件时期留下、如今局部独立运行的“引座员”结构，反复等待观众就座、开始掌声，再重新等候

近期天然介质联系发生变化，才让原本局限的行为触及多个近邻空间。它没有理解演出的能力，更没有故意毁掉悠真职业的目的

## 调查与行动

玩家先比较当前工程文件、场务记录和独立现场录音，再分别观察设备停机、人员离开与场所变化之后的情况。声音在工程文件之外依然存在，调查从“错用了音轨”转向实体场地

进入梦境后，玩家来到一个始终在开场前的厅堂。引座员只按固定的入座信号移动，攻击或驱赶阻挡通路的人。玩家第一次只能沿掌声寻找它，随后从现实录音发现每次掌声之前都有同一段不自然的空白

回现实核对旧录音日期与可见修补痕迹；经场地方同意，在同一输出点进行受控观察，确认行为来自局部结构。再入梦利用入座与转身间隙改变等候区，让固定行为走到终点；现实接应同时解除有害输出联系

玩家可以先保障场地停用、走较稳的观察路线，或在安全条件满足后先完成一组现场对照，获得更完整的资料。两种方式都不要求冒险让观众继续入场

## 转折与后续

悠真不是失误来源。贺佳暂停相关空间使用、安排退款或改期，恢复演出后仍承担实际修缮与工作安排。旧掌声停止，新的演出录音留下不同的声音

一份经许可保留的旧录音与现象存在相同的活动特征，引出历史线索，但不能仅凭相似声音认定所有事件来自同一只梦魇

章末可以去LATE BITE吃东西，也可以直接回家。悠真以后在普通对白里提起新的排练，不永远停留在“被误解的工程师”状态
