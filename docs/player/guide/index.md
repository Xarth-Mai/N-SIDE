# 游玩指南

本页适用于当前的街区步行预览：从月台杂货附近出发，可以进入小店首层的三间公共房，也可以沿街道、台阶与山路走到摘星台

这是街区与操作的早期预览，人物暂用简化外形，建筑主要呈现体量、外观和通路。带有「开始门前交接」或「继续门前交接」入口的新版加入了三处公共查看、配送路线确认和交接进度保存；行走位置不保存，小店后场、楼上和其他建筑内部，以及搬货店务、人物对话、完整委托、潜梦与战斗尚未开放

旧预览包如果只有「进入街区」，仍按原版本提供街区行走，下文的门前交接与进度保存不适用于该包

## 启动预览

### 从源码启动

已安装 Rust 并取得完整仓库时，在仓库根目录执行下列命令，等待编译后选择「开始门前交接」；已有进度时选择「继续门前交接」

```fish
cargo run --manifest-path game/Cargo.toml --locked -- --project-root . --walk-preview
```

保留命令中的 `--walk-preview`，这样进入的是可以步行的预览；普通启动入口目前展示固定镜头街景

### 从 Linux 预览包启动

收到 Linux 预览包后，先完整解压，保留包内的文件夹结构。在解压目录打开终端，运行步行入口，再选择包内实际提供的「开始／继续门前交接」或旧版「进入街区」

```fish
./run-walk-preview.sh
```

预览包无需安装 Rust，运行环境需要图形桌面和支持 Vulkan 的显卡驱动。加载时可以取消并返回标题；如果提示无法进入街区，先确认文件已完整解压，再选择重试

## 基本操作

移动方向跟随镜头朝向。鼠标与手柄可以随时交替使用，画面提示会随当前输入切换

| 操作 | 键盘与鼠标 | 手柄 |
| --- | --- | --- |
| 行走 | W / A / S / D | 左摇杆 |
| 疾跑 | 按住左／右 Shift 或鼠标右键 | 按住左摇杆按钮 |
| 跳跃 | 空格；落地后松开再按 | 西键，通常为 X |
| 转动镜头 | 锁定时直接移动鼠标；解锁时按住左键拖动；Q / E 水平转动 | 右摇杆 |
| 切换鼠标锁定 | M | 使用键鼠切换 |
| 查看近处地点 | 出现提示后按 F | 出现提示后按南键，通常为 A |
| 关闭地点说明 | Esc，或点击面板上的返回按钮 | 东键，通常为 B |
| 暂停 | Tab；未打开地点说明时也可按 Esc | Start；未打开地点说明时也可按东键 |
| 返回小店附近的起点 | R | Select |
| 选择菜单项目 | ↑ / ↓；也可用鼠标点击 | 方向键 |
| 确认菜单项目 | Enter | 南键 |
| 返回上层菜单 | Esc | 东键 |

手柄按钮的字母因设备而异，南键指右侧四键中最下方的按钮，东键指最右方的按钮，西键指最左方的按钮。跳跃只在落地时起跳，空中再次按下不会连跳；疾跑需要持续按住，松开后恢复步行

进入步行时鼠标默认锁定并隐藏，直接移动鼠标转动镜头。按 M 可以释放或重新锁定；打开暂停、地点说明或切换到其他窗口时自动释放，让鼠标可以操作菜单。关闭面板并继续后恢复原先的锁定选择

## 看地名与查看地点

左上角在街道显示附近地点，进入小店公共房间后显示所在室名，离开地点附近时显示「Null Site」。附近地点名称帮助辨认位置，看到名称后仍需靠近入口才能查看说明

当前可以查看月台杂货公共入口和摘星台的用途、开放说明与到达方式；门前交接版本还可查看店侧台阶和货运侧院。靠近地点后转动镜头，使入口或平台处于视野中；出现 F / A 提示后再按对应按钮。隔着墙、站在另一层或距离较远时不会显示查看提示

说明打开时，人物与镜头停在原位。读完后按 Esc / B 或点击返回，再继续行走；按 Tab / Start 则进入暂停菜单。门前交接记录实际查看过的小店入口、店侧台阶和货运侧院，摘星台仍只提供公共地点介绍

## 门前交接与继续

在门前交接版本中，分别查看月台杂货公共入口、店侧台阶和货运侧院，顺序不限，重复查看不会重复登记。三处都已查看后，在货运侧院的说明中选择配送路线：用上下方向键／手柄方向键选择，F／南键确认，也可点击选项。店侧台阶不适合推车，选中后会说明原因，可重新选择货运侧院；确认路线后仍可回看记录，这一步尚不包括实际搬货或完成整份委托

观察与路线确认后会自动保存交接进度。返回标题或退出游戏后，下次选择「继续门前交接」，从家门口重新出发，保留已经取得的信息与确认路线；原先的行走位置和打开的说明面板不会恢复。暂停菜单的「继续」则回到当前人物位置与原来的说明

已有观察时，标题和暂停菜单会出现「重新开始交接」。打开后默认选中「保留当前进度」，选择它或返回即可取消；另选「确认重新开始」才清除交接记录并从家门口开始

菜单会显示交接进度的保存状态。如果提示存档无法读取，原文件会保留，本次交接只在当前会话中继续；此时重新开始也不会覆盖原文件。如果提示保存失败，当前仍可游玩，但下次启动可能恢复到先前保存的交接步骤。遇到这些提示时，先保留原文件与备份，排查用户目录的读写权限后重新启动；页面显示「交接进度已保存」后才表示本次写入成功

## 进入月台杂货

从街道正对小店共用店门，直接用WASD／左摇杆走进「接待与陈列」。沿前场走动，可以通过内侧门洞分别进入「主题陈列」和「预约洽谈」，左上角会显示当前室名

进出小店与普通行走使用同一组操作，不需要按F，也没有传送或切场景。查看公共地点说明后先关闭面板，再继续走动；读完店内空间后，沿原门洞回到接待区，从共用店门回到街道

后场和楼上当前由墙体封闭。遇到门框或墙边视野变近时，可以转动镜头再调整行走方向；这些空间仍是简化的步行预览，陈列物件和洽谈内容尚不能操作

## 暂停与恢复

暂停菜单可以继续当前行程、返回标题或进入设置。返回标题会结束本次行走，再次进入街区从小店附近重新出发；门前交接版本保留已取得的观察与路线结果，重新开始需另行确认

切换到其他窗口或手柄断开时，行走会暂停。回到窗口、重新连接手柄后，先放开原先按住的按键或摇杆，再明确选择「继续」；也可以直接用键鼠接管

如果暂停前正在阅读地点说明，继续后仍回到原来的说明。可在暂停期间修改设置，返回暂停菜单后再继续阅读

## 设置

标题和暂停菜单都提供「设置」，分为「通用」与「画质」选项卡。调整立即生效，窗口模式和分辨率需要确认保留；返回时保留来源菜单与原先选中的项目

| 设置 | 可选值 | 影响 |
| --- | --- | --- |
| 文字大小 | 100% / 125% | 菜单、地点提示与地点说明的文字 |
| 镜头灵敏度 | 100% / 65% | 鼠标观察、Q / E 和右摇杆的转动速度 |

画质页包含抗锯齿与质量、SSAO、锐化、动态阴影与阴影贴图／距离／过滤、接触阴影、泛光、距离雾、曝光、色调映射、去色带、视距、垂直视角、垂直同步、窗口模式与分辨率。用 Q / E、手柄肩键或点击页签切换；上下选择、左右调整，Enter / 南键或点击行切到下一值，PageUp / PageDown或页码按钮换页

开启SSAO时，MSAA会自动换为TAA；再次选择MSAA会关闭SSAO。显卡不支持的模式会回退并显示原因；FXAA／SMAA质量只影响对应算法，无边框全屏使用当前显示器尺寸。想保持原来的城市外观，可以保留默认画质，仅调整需要的项目

修改窗口模式或分辨率后，会出现15秒确认倒计时，默认选中「恢复原显示设置」。画面可用时主动选择「保留显示设置」；没有确认、按Esc／东键返回、切换到其他窗口或手柄断开，都会恢复原来的显示设置。未确认的窗口模式和分辨率不会保存，其他设置不受恢复影响

画质页末尾的「恢复默认画质」可以恢复全部画质默认值，保留字号与镜头灵敏度。如果窗口模式或分辨率也变了，同样需要确认；选择恢复原显示设置时，其他画质仍使用默认值

设置页显示「已保存」后，下次启动会继续使用所选值。设置保存在当前用户的配置目录，独立于预览包和行走位置；在同一用户下移动或重新解压预览包不需要重新调整

如果页面提示原设置无法读取，本次使用默认值，原文件会保留；如果提示保存失败，当前调整仍然有效，但下次启动可能沿用先前保存的值。这两种情况下都可以继续游玩

如果已保存的画质使游戏启动后看不清或无法操作，退出后在解压目录执行以下命令，以默认画质重新启动，保留文字大小和镜头灵敏度

```fish
./run-walk-preview.sh --reset-graphics
```

从源码启动时，在原命令的 `--walk-preview` 后追加 `--reset-graphics` 即可。该参数也会保留无法读取的原设置文件，不会用默认值覆盖坏文件

## 第一次可以这样走

先在月台杂货附近走动，试着绕到公共入口正前方，转动镜头找到查看提示。打开地点说明，再暂停、调整字号、继续阅读和关闭；随后走进接待区，探看主题陈列与预约洽谈两间房，再从前门回到街道，熟悉操作后再上山

想登高时，走这条较短的台阶路线：

**月台杂货 → 东侧上坡街道 → 上街住宅 → 山脚休息台 → 三处回望台 → 摘星台**

1. 从小店附近沿东侧街道上坡，经过弯口和公共台阶，接到上街住宅的通路
2. 继续沿铺装路与台阶向山脚休息台走，住宅逐渐让位给山林
3. 在林缘入口选择朝城市一侧的短登高台阶，依次经过三处平坦的回望台；每处都可以停下，转身看看刚走过的街区
4. 最后一段台阶接到峰顶平台，沿平台通路走到摘星台；靠近查看提示后，可以阅读地点说明
5. 回程先沿来路下山，经过三处回望台、山脚休息台和上街，回到月台杂货附近

整段登高需要走一段时间，不必一次走完；可随时暂停，或用 R / Select 返回起点。当前没有自动寻路、路线箭头或可呼出的游戏内地图，需要辨认街道与台阶；也可以先看[街区导览图](../locations/null-site.md)

台阶外的陡坡、屋顶和未开放的建筑内部不作为这条路线的捷径。遇到卡住时，先退回路面并调整方向；仍无法继续时使用返回起点，重新从小店出发

## 预览与百科的范围

[游戏百科](../index.md)收录世界、人物、地点、故事与生活方式；百科描述的完整内容不代表当前版本已经开放。阅读故事会涉及事件真相与结局

例如摘星台的夜景、街坊活动和完整室内生活属于完整游戏内容；当前预览用于白天的街区行走、观景及小店首层公共区探看，并不是一份从日常到委托结尾的完整 Demo
