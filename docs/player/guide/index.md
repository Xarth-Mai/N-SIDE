# 游玩指南

本页适用于当前的室外步行预览：从月台杂货附近出发，沿街道、台阶与山路走到摘星台，也可以在小店门前先熟悉操作

这是街区与操作的早期预览，人物暂用简化外形，建筑主要呈现体量、外观和室外通路。室内、店务、人物对话、委托、潜梦与战斗尚未开放，当前版本也没有保存行走位置或任务进度的功能

## 启动预览

### 从源码启动

已安装 Rust 并取得完整仓库时，在仓库根目录执行下列命令，等待编译和加载完成后选择「进入街区」

```fish
cargo run --manifest-path game/Cargo.toml --locked -- --project-root . --walk-preview
```

保留命令中的 `--walk-preview`，这样进入的是可以步行的预览；普通启动入口目前展示固定镜头街景

### 从 Linux 预览包启动

收到 Linux 预览包后，先完整解压，保留包内的文件夹结构。在解压目录打开终端，运行步行入口并选择「进入街区」

```fish
./run-walk-preview.sh
```

预览包无需安装 Rust，运行环境需要图形桌面和支持 Vulkan 的显卡驱动。加载时可以取消并返回标题；如果提示无法进入街区，先确认文件已完整解压，再选择重试

## 基本操作

移动方向跟随镜头朝向。鼠标与手柄可以随时交替使用，画面提示会随当前输入切换

| 操作 | 键盘与鼠标 | 手柄 |
| --- | --- | --- |
| 行走 | W / A / S / D | 左摇杆 |
| 转动镜头 | 按住鼠标右键拖动；Q / E 水平转动 | 右摇杆 |
| 查看近处地点 | 出现提示后按 F | 出现提示后按南键，通常为 A |
| 关闭地点说明 | Esc，或点击面板上的返回按钮 | 东键，通常为 B |
| 暂停 | Tab；未打开地点说明时也可按 Esc | Start；未打开地点说明时也可按东键 |
| 返回小店附近的起点 | R | Select |
| 选择菜单项目 | ↑ / ↓；也可用鼠标点击 | 方向键 |
| 确认菜单项目 | Enter | 南键 |
| 返回上层菜单 | Esc | 东键 |

手柄按钮的字母因设备而异，南键指右侧四键中最下方的按钮，东键指最右方的按钮。当前行走不需要跳跃或冲刺，沿铺装通路和台阶前进即可

## 看地名与查看地点

左上角显示附近地点；离开地点附近时显示「Null Site」。这个名称帮助辨认位置，看到名称后仍需靠近入口才能查看说明

当前可以查看月台杂货公共入口和摘星台的用途、开放说明与到达方式。靠近地点后转动镜头，使入口或平台处于视野中；出现 F / A 提示后再按对应按钮。隔着墙、站在另一层或距离较远时不会显示查看提示

说明打开时，人物与镜头停在原位。读完后按 Esc / B 或点击返回，再继续行走；按 Tab / Start 则进入暂停菜单。这里显示的是公共地点介绍，打开它不会接取委托或获得调查线索

## 暂停与恢复

暂停菜单可以继续当前行程、返回标题或进入设置。返回标题会结束本次行走，再次进入街区从小店附近重新出发

切换到其他窗口或手柄断开时，行走会暂停。回到窗口、重新连接手柄后，先放开原先按住的按键或摇杆，再明确选择「继续」；也可以直接用键鼠接管

如果暂停前正在阅读地点说明，继续后仍回到原来的说明。可在暂停期间修改设置，返回暂停菜单后再继续阅读

## 文字大小与镜头灵敏度

标题和暂停菜单都提供「设置」。两项调整立即生效，返回时保留来源菜单与原先选中的项目

| 设置 | 可选值 | 影响 |
| --- | --- | --- |
| 文字大小 | 100% / 125% | 菜单、地点提示与地点说明的文字 |
| 镜头灵敏度 | 100% / 65% | 鼠标右键拖动、Q / E 和右摇杆的转动速度 |

设置页显示「已保存」后，下次启动会继续使用所选值。设置保存在当前用户的配置目录，独立于预览包和行走位置；在同一用户下移动或重新解压预览包不需要重新调整

如果页面提示原设置无法读取，本次使用默认值，原文件会保留；如果提示保存失败，当前调整仍然有效，但下次启动可能沿用先前保存的值。这两种情况下都可以继续游玩

## 第一次可以这样走

先在月台杂货附近走动，试着绕到公共入口正前方，转动镜头找到查看提示。打开地点说明，再暂停、调整字号、继续阅读和关闭，熟悉这一组操作后再上山

想登高时，走这条较短的台阶路线：

**月台杂货 → 东侧上坡街道 → 上街住宅 → 山脚休息台 → 三处回望台 → 摘星台**

1. 从小店附近沿东侧街道上坡，经过弯口和公共台阶，接到上街住宅的通路
2. 继续沿铺装路与台阶向山脚休息台走，住宅逐渐让位给山林
3. 在林缘入口选择朝城市一侧的短登高台阶，依次经过三处平坦的回望台；每处都可以停下，转身看看刚走过的街区
4. 最后一段台阶接到峰顶平台，沿平台通路走到摘星台；靠近查看提示后，可以阅读地点说明
5. 回程先沿来路下山，经过三处回望台、山脚休息台和上街，回到月台杂货附近

整段登高需要走一段时间，不必一次走完；可随时暂停，或用 R / Select 返回起点。当前没有自动寻路、路线箭头或可呼出的游戏内地图，需要辨认街道与台阶；也可以先看[街区导览图](../locations/null-site.md)

台阶外的陡坡、屋顶和建筑内部不作为这条路线的捷径。遇到卡住时，先退回路面并调整方向；仍无法继续时使用返回起点，重新从小店出发

## 预览与百科的范围

[游戏百科](../index.md)收录世界、人物、地点、故事与生活方式；百科描述的完整内容不代表当前版本已经开放。阅读故事会涉及事件真相与结局

例如摘星台的夜景、街坊活动和室内生活属于完整游戏内容；当前预览主要用于白天的室外行走与观景，并不是一份从日常到委托结尾的完整 Demo
