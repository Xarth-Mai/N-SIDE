# 街坊生活与故事


《今天的街坊》是贯穿故事的普通创作项目。它让学生、店主、创作者、维护人员和读者自然相遇，但不承担异常传播或神秘仪式的功能

真正维系关系的还有更日常的事：送货、修理、买菜、上学、换乘、排练、照顾家人和散步。人物会在不同地方被遇见，街坊关系不是围绕主角才临时出现

91 个场所分成三种叙事参与：主线关键地点提供明确行动与证据；生活关系地点承载人物需要、支线和重访；通路与环境地点帮助玩家认识空间并看见城市变化。类别不等于美术优先级，也不意味着主线要求逐个打卡

## 日常时段与人物到达

| 时段 | 常见活动 | 可遇见的不同生活 |
| --- | --- | --- |
| 早上 | 车站通勤、早餐与烘焙、生鲜收货、设备维护 | 宋岚、邵敏、姚安与准备上学的人 |
| 白天 | 门诊、公共服务、维修、创作、种植、记录 | 程嘉、叶初、陆衡、郑澈、楚青与温苒 |
| 下午 | 放学、兴趣店铺、制作和试音、图书活动 | 陈知夏、魏航、苏禾、何昕与沈聆 |
| 晚上 | 演出、夜食、取件、看电影、回家 | 宁朗、贺秋、唐钰及不同作息的居民 |
| 深夜 | 少量夜班归来、小店基础接待、后场整理 | 粒粒先认识的熟客，以及准备结束一天的人 |

居民按各自的作息工作和休息，需要见面时可以预约或留下消息。雨天，人们转到雨棚和室内等候；公共空间关闭时，沿仍然开放的道路到达。


## 事件之后的日常

事情过后，场所留下清楚的变化：修好的实物、重新开放的入口、更新的记录、新的作品、不同的人员安排，以及经过核对的讲述。每个变化都有具体的来由，街坊也仍然有自己的新事要忙

人物也可以谈完全无关的新事。米娜有新的住处，苏禾有新版本，宋岚试新口味，许遥继续改稿。玩家帮助他们恢复的是能够继续变化的生活，而不是一张永远停留在结局的合照
