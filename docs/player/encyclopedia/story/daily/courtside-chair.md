# 球场边的一张椅子

<a id="qst-105"></a>

[街坊故事](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)


魏航安排社区活动，较熟练的玩家、初学者和陪孩子的家长希望使用同一处公共空间。陈知夏想参与，也想完成记录作业

玩家帮助比较球场、校外等候庭和亲子活动室的实际用途，安排可并行的活动，而不是替某一组抢占全部空间。校园内部与社区公共球场继续分别管理

可以参加一次低难度互动，也可只布置等候位置。后续魏航会按新的安排继续活动，陈知夏的照片记录的是不同使用者，而不只有最擅长运动的人

场所：社区中学、校外文具与日常用品店、体育用品店、社区公共球场、放学饮品与外带铺、校外等候庭、居民服务中心、社区亲子活动室。关联角色：魏航、陈知夏、叶初、郑澈
