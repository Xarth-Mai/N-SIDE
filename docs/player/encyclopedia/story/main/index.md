# 主线：回声之后

以下收录完整故事与结局，章节可以独立阅读，也可以从序章依次展开

## 故事

《回声之后》是一条从社区委托进入城市历史、再回到当下生活的主线。故事发生在一个初秋气质的阶段，实际日历照常向前；章节间留出几天至数周的生活与走访，不设置需要每天抢点的全局倒计时

林屿、林澄与粒粒经营一家全天亮灯的生活杂货店。两人一边准备参与乔音组织的《今天的街坊》小册与展览，一边帮助米娜处理搬家前不断“失踪”的旧玩具。第一次委托结束后，米娜顺利出发，新的生活并未要求她割断过去

随后，兴趣街与音乐街出现不属于当下演出的掌声，中学周边有人听见旧日点名，坡地与河岸的环境记录也逐渐偏离过去的稳定状态。每件事都有自己的受影响者和维持条件。兄妹先分别处理有害影响，再从相似的联系变化中发现：它们不是同一只梦魇到处出现，而是不同的局部结构正在重新接通

照片、教学联络和渡运记录把调查带向十二年前。兄妹原以为必须寻找一个仍然活动的古老源头，却通过季闻与许遥的现状、独立验证材料和源头终止记录，确认最初的梦魇早已结束。真实的共同生活延续至今，不需要为了清理历史而被抹去

当前风险来自另一个过程：城市日常维护与环境变化改变了部分天然介质的边界，新的自然窗口又降低了联结门槛。几种原本独立、能够长期局部共存的梦魇结构逐渐构成相互强化的活动。等待当年的自然停止并不可靠，因为如今的条件已经不同

兄妹与街坊、维护者和专业处理人员共同建立局部记录与行动方案。玩家依靠此前调查中学会的辨认方法，在梦境里创造安全的处理窗口；清醒的一方与现场人员核对真实状态，逐段终止有害输出与新联动。最初的梦魇没有复活，也没有幕后角色突然解释所有事件

危机过后，一部分场所仍需要维修，一部分记录需要重新说明，但小店、共同梦中的家、熟悉的初秋与城市生活继续存在。《今天的街坊》最后展示的是人们今天怎样生活，不是把所有人永远固定为灾难的见证者

## 从街坊委托到城市联动

| 幕 | 章节 | 主要问题 | 玩家获得的认识 |
| --- | --- | --- | --- |
| 第一幕：熟悉这里 | 序章—第三章 | 眼前的人遇到了什么，怎样让生活继续？ | 现实投影不等于梦魇意图；记录、回应和本人需要区分 |
| 第二幕：重新理解过去 | 第四—第六章 | 不同个案为什么出现共同变化？十二年前究竟留下了什么？ | 原始源头已终止；独立结构与真实生活可以继续存在 |
| 第三幕：处理今天 | 第七—第八章、尾声 | 怎样阻止新的危险，而不把所有过去和正常生活一并抹去？ | 证据、分工和具体行动改变当下；结局落实在各处真实后续 |

林屿逐渐把“我先弄明白”变成“我们分别确认”；林澄从善于看见细节发展为能承担行动判断的处理者。两人之间的信任在具体工作里加深，而不是先被强行打碎

季闻与许遥提供完整背景，但主线的当前问题由兄妹和今天的合作网络共同解决。街坊不是等待主角按开关的一排被动角色，他们管理场所、照顾家人、决定是否提供材料，并完成自己擅长的工作
