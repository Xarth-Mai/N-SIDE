# 第一章 · 最后的玩具

本章包含事件真相与结局

[主线总览](index.md) · [人物](../../characters/index.md) · [场所](../../locations/place-network.md)

<a id="qst-002"></a>

**Black Case：“离开原位的玩具”。主要场所：小店与住家、小修理铺、坡上住宅、旅行用品与寄存店、模型店、兴趣旧物交换店、手作材料店。林澄潜梦，林屿接应**

## 求助与真实因果

米娜即将离城读大学。她反复整理行李，发现几件玩具总在准备带走时离开原位。表面像丢失或家人替她处理了旧物，梦里则有一名“收集者”不断搬走它们，玩具店永远停在打烊前的时刻

反复噩梦围绕打包与留下展开。卧室一处长期使用的旧收纳柜在近期环境条件下进入异常态，保存了相关结构。“保留室”反复增生梦中副本，收集者则维持一条把物件打包送出的流程。阻断收集者，会让保留室越来越难以离开

现实投影通过收纳柜与抽屉的局部机械变化，让小物件滑入相邻的低位周转箱和柜底夹层。位置变化有有限距离和可见痕迹，物件总数可核对；没有物理抹除、传送或无限复制。梦中复制仅发生在体验空间

## 玩家行动与信息变化

1. 在小店听米娜说明问题，确认哪些是她亲眼看见、哪些是醒来后的推测
2. 受邀进入其住宅，清点玩具、箱封和柜底磨痕，先建立实物基准
3. 去修理铺与模型店核对零件和包装方式；旧物交换记录排除一件关键物品已经被转卖的解释
4. 接入梦中玩具店，追踪搬运的收集者；第一次看到它把一件玩具放回等待打包的位置
5. 玩家可暂时隔离收集者，也可沿运输线跟随。隔离会让梦中货架更密，跟随则更快发现运输受阻的部位
6. 退出现实，按新发现检查柜底与周转箱，找回部分实物，确认“被偷走”并非正确解释
7. 再次进入梦境，观察每次拆包如何与保留室增生对应，找到维持重复的局部结构
8. 利用收集者搬运时出现的间隙改变通路；必要战斗清开阻挡，目标是恢复可完成的运输而不是反复清空敌人
9. 林屿在现实按已核对的窗口隔离柜体的异常联系，停止新的物件扰动
10. 确认无新增输出后，由米娜决定随身、留存与寄售的物品，玩家协助执行
11. 将修好的玩具交付，并约好送行或留下小礼物
12. 米娜经寄存店与 N 站出发，稍后寄回自己新住处的一张照片

## 选择、结束与后续

隔离与跟随两条路线都能获得必要信息；错误假设先产生可恢复的局部反馈，不因一次选择永久丢失好结局。打包决定属于米娜，玩家不能替她强制丢弃重要物件

这份委托有自己的起因与结局，不是古老梦魇留下的一道谜语。它教会玩家：看到的形体不一定是破坏者，梦中增生与现实物件去向需要分别判断

橱窗之后多一张米娜寄来的小卡。她的缺席与新联系同时存在，回访不会把“离开”改写成关系失败
