# 街区场所与人物故事

N 街区的商店、住家、院落、广场和通路由日常用途连接起来。这里收录 91 处命名场所的使用者、生活、关联故事、事件后续与开放边界，包含主线结局信息

影院、餐饮层、屋顶公园和共享工作室共用 V-15，各自保留开放时间与使用边界。公共场所的相遇不等于拥有或居住；私人住家和受控区域需要相应邀请
