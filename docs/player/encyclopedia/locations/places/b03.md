# 西侧商住街坊

[场所总览](../place-network.md) · [主线](../../story/main/index.md) · [街坊故事](../../story/daily/index.md)

小修理铺、木作、改衣、印制和旧书交换屋围绕共用院与住宅展开。陆衡和梁素的手艺来自长期实际使用；住户院落只有在受邀时进入，公共路从院外经过

这里连接“修好一件东西”与“它之后被怎样使用”。主线的证据整理、街坊册装订和普通修补都可以发生，居民并不都隐藏着十二年前的关键档案

日常：住户换盆、受邀做手工

故事关联：支线[《旧外套的新口袋》](../../story/daily/new-pocket.md#qst-101)；支线[《橱窗还差一点》](../../story/daily/unfinished-window.md#qst-103)

连接：43 共享木作工坊、44 衣物修改店、46 旧书交换屋；修补、木作与旧书

事后重访：共同完成的椅子或小物留在使用位置。开放安排：住户共用院，活动需邀请
