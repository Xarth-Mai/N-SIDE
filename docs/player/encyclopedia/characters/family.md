# 家庭关系

## 兄妹

[林屿](brother.md)和[林澄](sister.md)相差一岁，日常温柔亲近。两人愿意分享、表达关心、认可对方，享受一起生活与经营小店

照顾和信任是双向的，工作分歧在共同经营中处理。技术与设计是各自专长，两人在经营和异常处理中互相补充

调查判断、承担责任与何时求助会带来分歧，两人通过分工、核对和具体支持解决。成长也发生在持续亲近的关系里

## 父母

小店原本由[林启明](family-members/lin-qi-ming.md)和[陈静禾](family-members/chen-jing-he.md)经营。兄妹从小接触商品与经营生活，真心喜欢这些事，因此主动接手

父母现已搬到别处生活，仍与兄妹保持家庭联系。他们知道兄妹会帮助别人处理异常，掌握的是部分工作情况。兄妹报喜不报忧，常讲“事情解决了”，较少讲处理中间的麻烦

父母保留自己的兴趣和出门计划，也逐渐参与实际的家庭支持，听孩子讲完整经过。与[顾竹](neighbors/gu-zhu.md)、[郑泊](neighbors/zheng-bo.md)、[梁素](neighbors/liang-su.md)多年的邻里联系延续着普通生活
