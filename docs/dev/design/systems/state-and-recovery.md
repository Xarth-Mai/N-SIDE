# 事实、认知与恢复契约


任务记录触发条件、阶段、参与者、分支、后续变化和结束条件。一次性事件保存完成标记，重复到访读取已有状态。存档保存任务阶段、关系、关键物件与已执行事件

检查进入、退出、重访、跳过、存读档与时段切换时的实际表现。日常内容使用[日常片段模板](../../handbook/templates/daily-scene.md)，调查内容使用[委托模板](../../handbook/templates/quest.md)

## 世界时间与重试

战败重试按[检查点](combat.md#战败与重试)恢复游戏状态。真实的主动退出、停机与处置失败则按事件条件产生后果，重试不意味着世界时间发生倒流

## 状态责任

| 层 | 保存或重建 | 例子 |
| --- | --- | --- |
| 世界事实 | 持久物件身份、位置和处理结果 | 找回的是原玩具，不能生成第二份 |
| 玩家认知 | 已观察信息与推测分别保存 | 提前发现实物得到承认，梦中仍可补足运输因果 |
| 当前尝试 | 未提交工具动作、敌人节奏与支援按检查点重建 | 双侧确认前退出恢复安全入口 |
| 一次性提交 | 持久结果幂等保存 | 双侧确认后的隔离、交付与消息不重复触发 |

运行实现需要指定唯一写入系统、稳定 ID、提交时机、失败回退和存档版本。当前 narrative.json 仅声明设计效果，不具备事务或读档执行能力；例子与完整恢复矩阵见[QST-002](../quests/QST-002/development.md#保存与恢复责任)

验证按线索乱序、跳过对白、主动退出、处理失败、确认前退出、确认后恢复、重复交付逐条记录初始状态、输入、断言和可见反馈。断言只能观察实际运行路径，不能先修改结果变量使其通过；未实现的行为进入真实功能或实验任务
