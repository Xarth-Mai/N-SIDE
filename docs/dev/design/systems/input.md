# 输入、动作与交互

支持手柄和键鼠，两种输入方式覆盖相同的玩法动作，界面根据当前使用的设备显示操作提示。玩法使用动作名关联输入

### 交互约定

移动、观察、交互、确认、返回、暂停与战斗动作分别记录触发方式、允许状态和反馈。菜单记录焦点顺序、默认焦点与返回层级；页面与组件规则见[街区信号 UI](ui.md)，输入隔离和恢复检查见[UI 制作](../../production/ui.md)

按键映射、长按方式、震动、屏幕抖动与字幕作为体验配置项，具体支持范围由交互规格记录

### 操作验证

检查移动与朝向、镜头和遮挡、交互目标识别、菜单导航、暂停、设备重连、焦点恢复和输入切换

## 设计范围与运行边界


在街区中移动和观察，靠近人物或物件进行交互；进入梦境后，使用随身工具探索和战斗

上述是 Demo 的输入设计目标。正式入口支持标题、加载、固定镜头街区预览、暂停与原会话继续，键鼠和手柄数字输入走同一状态路径；独立 Viewer 保留 FreeCamera 与捕获脚本。实际支持的按键和启动命令见仓库 `game/README.md`；追加 `--walk-preview` 可进行同地图的室外胶囊移动与跟随镜头实验，技术边界见[实验契约](../../engineering/player-preview.md)；正式角色动作、存档、实体手柄断连与完整 Demo 输入仍需对应验收

正式入口在主窗口失焦时暂停人物与镜头，回焦保持暂停并等待显式继续；先释放之前持有的菜单与玩法输入，系统重复按键不触发新菜单动作。加载期间可以继续准备资产，失焦时完成加载也不运行人物；短暂失焦再回焦与无窗口录制分别验证

当前聚合手柄输入下，任一手柄断开即进入暂停并显示原因，键鼠可接管；重新连接只更新提示，释放后明确确认才继续。加载期间断连在进入街区时暂停；同帧断开重连仍算连接中断。接入设备当帧不执行菜单操作，初次连接本身不暂停世界；真实设备断连与模拟消息分别验收

室外步行预览的基础动作包含跳跃与按住疾跑：空格／西键起跳，左右Shift／右键／左摇杆按钮疾跑。鼠标默认锁定，M切换，菜单、观察或失焦释放，恢复沿用先前偏好；具体参数、碰撞及输入边界维护在[实验契约](../../engineering/player-preview.md)，这些预览操作不增加战斗动作或角色预算
