# 街区场所与日常

## 场所配置

人物使用、关联故事与事件后续见[场所百科](../../../player/encyclopedia/locations/place-network.md)，按十二街坊分别展开。设计关联保存在[场所叙事索引](../catalogs/city-story-map.json)，名称、街坊与建筑归属由地图主数据核对；[目录](../catalogs/place-catalog.json)的 `kind` 为用途分类，与地图的 `space` 保留各自含义

## 共同制作要求

### 店铺与邻里

饭馆同时保留沿街取餐与坐下吃饭的位置，烘焙店和食品店通过陈列、挑选、收货与收摊表现时段。洗衣店的窗边等候、机器运转与衣物取走构成短参与，居民私人物品保留隐私边界

修理铺处理家用物件、玩具与小设备，送修取件能够从街边完成。少量旧游戏设备与修复物件在临街试机角展示，试机角依附店铺；专门的音游、模型与桌游卡牌场所承担各自的兴趣活动。受邀参加院落手作、换盆和公共物品整理时，住宅入口与公共经过线仍然清楚

小店以有限橱窗展示位置承载兄妹作品与商品变化，楼上与楼下各有生活痕迹。Agent 对熟客、到货与陈列变化作出不同反应，普通门前不逐一配置独立任务

### 公共活动与停留

中学保留完整校园地块与校外通行线，主要放学活动在南门同高街段的文具店、外带铺和等候庭展开。北侧公共球场与体育用品店服务上街住宅和额外运动行程，球场入口与校园操场分开。影院会客厅的展墙和活动空间呈现居民照片、学生作品与街区旧物；涉及当事人的作品取得同意后展示。诊所首先承担社区服务，患者信息保持私密

影院、音乐活动、夜食与兴趣场所同时安排到达、等候、正式参与、离场和后勤。免费停留与需要付费或预约的空间通过入口和使用方式清楚区分，屋顶公园与地面城市花园分别落实开放安排、维护和公共到达

河岸小摊呈现备料、开摊、季节菜单与收摊，候船与散步保留不同节奏，允许只看一班船离开。上层住宅门前可以浇花、等人或短谈，观河转角供辨认来路，小神龛保持小规模，摘星台承载安静相处与观景

### 技术设施

交通信息、数字导览、取件、自助服务和设备维修落在实际使用位置。每项设施记录使用者、作用、电力与网络需求、维护者，以及停用时的人工协助或替代方式

家庭与小店以已有 Agent 设定为依据。新增公共或商业机器人逐项记录能力、所有者、使用范围、维护方式及与家庭 Agent 的关系，保持角色与城市设施的职责清晰

## 小店功能与动线

| 动线 | 空间关系 |
| --- | --- |
| 顾客 | 店前平台 → 共用店门 → 橱窗与陈列 → 收银与等候；预约后进入可关闭的洽谈位 |
| 回家 | 同一店门 → 营业区 → 后场门 → 私人内楼梯 → 楼上餐厨起居与相邻创作区 → 各自休息空间 |
| 补货 | 侧院 → 受控服务门 → 验收、储物与包装 → 陈列补货 |
| 异常工作 | 预约洽谈 → 受控后场设备间；清场后安置身体、设备与接应者，潜梦与维修错时进行 |
| 夜间整理 | 后场储物与工作区为主，门口或内窗保留与 Agent 前场接待的交流联系 |

普通顾客不进入私人楼梯或设备间，公共店侧台阶保持建筑外的街区通路。设备间兼作潜梦室，启用时收起工具和待修物件，留出身体安置及接应活动范围。楼上以共同起居为中心，私人休息与共同创作保持各自空间；具体层数、面积和装饰随室内深化确定

## 场所组合与客群

站前工作与兴趣活动共享通勤配套，音游、模型、桌游和设备服务沿西侧兴趣街聚集，会合庭为等待同伴的人保留免费座位。食品采购街由早间早餐与生鲜，过渡到晚饭采购与夜食，小店的设计小物和包装创作与普通食品经营互补

东侧影院会客厅、共享餐饮、屋顶公园与音乐活动面向跨街坊来访者，也提供居民可以免费会合的公共空间。同一综合体中的影院、餐饮与花园各有独立使用理由，建筑共用一份体量，综合体本身不另加一个目的地

音乐街的设备调试、排练、演出和夜间餐饮形成活动链，器材搬运从联络路侧进入，住宅休息与夜间等候分别组织。安静河岸露台离开演出和桥下人流，山脚仍以住宅、茶屋和登高为主

这些场所序列同时保存按访问顺序连接入口的道路路径，放学后的采购和会合沿南门外步行带展开；安静日常先把采购带回家，再出门散步。屋顶关闭时从影院回到地面花园，夜间散场根据轨道运营选择城市夜间交通

路线走法以 [N街区](../../../player/encyclopedia/locations/n-district.md#几条熟悉的路)为准，地图检查各条路线的不同用途

- 直接回家线最容易理解，普通日常不强迫绕进额外巷道
- 采购短环联系食品店与社区横街，站前、饭馆和修理铺作为可选延伸
- 雨天线提供分段遮蔽和停留位置，保留露天路段，不把正常回家变成强制绕行
- 河边环去程接近商业人流，回程接近住宅生活，码头与低层亲水平台作为支路
- 山顶环上行打开城市视野，下行经过林间与住宅，店侧台阶之外保留住宅缓路

树下空地、商店街弯口与东侧公共生活路提供清楚的目的地交换点。入口朝向和视线支持临时选择，减少频繁打开全屏地图的需要

### 状态与参与

| 状态 | 内容 |
| --- | --- |
| 日常 | 营业、收货、通勤、等候、整理与收摊 |
| 天气 | 雨棚启用、室外座椅收起、河边人流减少 |
| 事件 | 修好的物件、更新的展示、改变的对白与关系 |

三类状态可以组合，以少量明确状态和共享互动承载内容。看橱窗、带晚饭、坐下听声音、玩一小局或帮忙摆展示都能成为完整参与，回报可以是反应、留下的物件或再次见面时被认出

日常片段可以停在普通小事上。普通事件允许之后重新遇见，时间推进便于抵达目标时段，关系不依赖每日签到。错过买面包、观景或看橱窗不损失关键剧情，也不触发经营惩罚；观景点不设置必须每天领取的奖励，完整取景位置避免醒目收集物

事件后的变化落在熟悉位置，以物件、对白、照片、海报或使用方式体现，具体实现遵循[玩法制作](../systems/daily-life.md)

## 场所验收

- 场所挂接实际地块与入口，使用者具有日常到达理由，活动不堵塞基本通行
- 橱窗、试机角、会客厅展示与候船空间能够留下事件变化，现场活动与后勤各有位置
- 小店顾客、回家、补货、异常工作与夜间整理动线符合已定边界，全天经营能够持续
- 昼夜、天气与事件状态可以组合，重访可见事件后果，日常参与不形成签到负担
- 公共停留、校园、住宅、设备间与经营空间的开放边界可辨，私人信息和当事人作品得到尊重
- 科技设施具备物理位置、维护与停用处理，日常活动通过人物动作与环境反馈表达
