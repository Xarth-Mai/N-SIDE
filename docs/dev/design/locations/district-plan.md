## 地理与发展层次

街区位于城市内部与低丘相接的位置，沿河与山脚道路在可游玩范围之外继续联系其他城区。两岸的开发密度来自地形、建设时期和交通条件，各自保留普通住宅、工作场所与公共设施

| 形成阶段 | 空间结果 |
| --- | --- |
| 渡口与坡脚老路 | 道路避让陡坡与既有院落，形成曲折街线、窄面宽地块与错位路口 |
| 车站带来客流 | N站入口与旧街通过商店街连接，站前公寓与旧店屋交替出现 |
| 东侧公共设施与住宅补充 | 较完整的平缓地块容纳学校、住宅与公共设施，横向道路接回旧街 |
| 岸线更新 | 在通行、候船与服务作业之外加入连续步道、绿地和停留处，少量旧设施再利用 |

发展阶段不锁定具体年代。上海的视觉参考限于宽阔河面、连续岸线、跨河联系和两岸景观；坡地依 Null City 自身地形组织，临海位置、河口与潮汐不由该参考推定

## 街坊、建筑与公共边界

商店街通过连续、略有转折的街面形成空间，店屋靠近道路排列，以墙体、门洞与少量明确的公共巷口连接。建筑背后保留后院、楼梯、采光与服务通道，店与店之间不默认都可穿行

| 位置 | 建筑与入口 |
| --- | --- |
| 站前 | 较完整的公寓体量、底层连续商业，住宅入口与店面入口分开，出口前留足人流空间 |
| 商店街 | 窄店面与深地块，楼下经营、楼上居住，雨棚和招牌贴合步行尺度 |
| 西侧老街坊 | 住宅与小工作空间围绕院落组织，公共道路经过院边，私人空间以门和边界区分 |
| 小店附近 | 建筑随坡错台，店内各层地面保持水平，通过门前平台、挡墙与相邻建筑高差表现坡度 |
| 东侧 | 学校与住宅保留完整地块，校舍、操场、院门与公共道路分别落实 |
| 上层住宅 | 逐渐疏朗的建筑、院墙和树木共同完成进入山林的过渡 |

空地分别标明公共小广场、住宅院落、绿地、服务场地、建筑间隙或未展示地块。停留活动按空间身份布置，住宅院落受到邀请后参与，服务场地保留作业用途

尽端小巷可以通向住户门口、共用花圃或小工作室。环路通过公共道路成立，不为连通而打穿私人地块

## 道路、高差与到达

### 道路分工

| 道路 | 职责 |
| --- | --- |
| 城市联络路 | 联系站前、东侧公共设施和图外城区，承担公交、较多机动车、主要配送与必要的应急到达 |
| N主路 | 联系站前、商店街、小店与住宅，服务街坊生活和步行，保留必要车辆通行 |
| 街坊支路与服务巷 | 联系住宅入口、店铺后门、收货位置与垃圾收集点，部分与行人共用 |
| 台阶与步道 | 提供跨高差的直接或安静步行路线，与缓坡道路互补 |

道路宽窄、铺装、路缘、照明与入口共同表达身份。N主路不承担穿越城区的快速交通，台阶不承担主要补货，后巷保留通道而非堆满装饰货箱

### 弯折与坡度

主要转弯分别对应坡面方向、既有地块、较平整的平台或老路遗留。小店前的缓弯来自旧路绕过高差后的平缓地段，停步、进店与侧巷连接在此形成邻里节点

窄街段、普通门前与少量停留节点交替出现，不在每个地点前扩成广场

空间尺度以站前至小店约 300 米、增加 12 米高程为设计起点；小店至摘星台按约 1 公里、增加 60 米高程安排渐进登高，回程采用较短支路。导览图以固定正交斜俯视镜头表达地形、建筑与道路关系，地面高程、建筑高度和坡面控制点仍属设计假设；具体距离、局部坡度与标高在后续空间制作中校核

核对局部陡段、转弯、平台和入口衔接，普通店铺与核心公共设施提供不依赖楼梯的到达方案。山顶步道单独设计，一条名为缓坡的路线不能代替全程无障碍核对

### 站前与过街

公交停靠、接送与自行车停放位于广场边缘，车站出口到商店街的主要步行线保持连续。向河边的路线在联络路设置明确过街节点，避免连续经过多个大型车行路口

车站形制需随交通方案落实。若采用地面入口、地下轨道，应同时安排通风、维护、排水与出入口防护空间

## 补货、服务与雨水

### 小店补货

城市配送 → 街坊道路装卸位置 → 小型车辆或推车 → 背侧服务巷 → 货运侧院 → 店内储物与陈列区

大型货车止于合适的装卸位置，收货侧院经独立服务门连接储物区，与顾客入口、公共台阶分开，也不承担必须经过的公共捷径。食品店、饭馆与小店错开配送状态，分别呈现收货、经营和整理

小店全天营业，夜间状态使用整理与交接；其他商铺根据各自作息收店。部分后巷在非配送时段可放邻里座椅或小展示桌，活动家具保持所需通道

垃圾与回收物设固定收集位置，避开食品出入口、窗下休息处和主要观景点。电表、设备箱、维修门和通风设施依建筑用途安排，设施密度来自实际需要

### 排水与公共设施

坡上来水沿道路边缘、截水设施和排水系统逐级收集，门前平台、挡墙和庭院各有排水出口，避免店侧台阶把水集中引向正门。花池承担局部调蓄，生活污水接入城市系统

框架按以下分区组织汇水与收集方向，作为道路、平台和挡墙接合的共同条件。管径、沟底坡度、设计暴雨、泵排与防洪能力由后续工程专项确定

| 分区 | 收集位置 | 去向与场地接合 |
| --- | --- | --- |
| 山脚与上街住宅 | 山侧道路边缘、住宅台地上缘分段截收 | 顺道路纵坡接街坊雨水支线，再汇入城市联络路系统；坡面来水在进入住宅院落前截收 |
| 小店与采购街 | 小店门前横向路缘、背侧检修带与货运侧院集水点 | 接服务巷和采购街雨水支线；台阶上口先横向截流，门前平台保持独立排水出口 |
| 校园与东侧住宅 | 29 m 上街、18 m 校园台地及东侧住宅台地分别收集 | 上街沿校外路排走，校园和住宅各接低街支线；11 m 高差边缘设独立收集与检修位置 |
| 影院屋顶与外部平台 | 屋面低点、平台边沟、电梯落脚平台分别收集 | 屋面经建筑雨水立管接地面系统，外部平台经自身落水路径接低街；上街来水在接平台前截收 |
| 滨水两层空间 | 6 m 上层通道与低层亲水支路各设集水位置 | 上层接城市岸线排水系统，低层由滨水专项确定受水位影响的排放方式；高水位关闭边界与通行绕行同步设置 |

雨后差异来自雨棚滴水、沟渠流水、接缝积水、湿树叶与水位变化，地面材质和积水依具体位置表现

公共厕所结合站前或滨水服务设施，饮水、垃圾收集与维护设施随使用空间设置。自行车停放靠近站前、公共设施与主要入口，避开窄巷、台阶落脚处与连续步行线

这些关系需要在场景里成立，物流、垃圾处理与城市交通不要求完整模拟

## 河岸与跨河联系

### 两层通行

较高的沿河通道承担日常连续通行，局部低层平台、台阶与候船空间由主通道分出。下层不成为回家的唯一路径，高水位或维护关闭时，在开放范围内沿较高路线绕行

台阶、护栏、关门位置、水位标记与绕行指示说明边界。较高通道的存在不代表应对所有洪水，极端天气下的关闭范围与替代路线需要与具体标高、防护能力共同确定

### 沿岸段落

| 岸段 | 主要体验与联系 |
| --- | --- |
| 河岸小广场 | 联系站前和商店街，供会合与短暂停留 |
| 渡口 | 候船、检修与上下船边界清楚，旧候船设施可遮雨、展示交通信息和旧照片 |
| 长椅段 | 稍离主要会合人流，供看水、聊天和独处 |
| 小摊段 | 联系东侧住宅与公园，经营空间从连续步道旁展开 |
| 桥下通过段 | 以桥梁结构、声音与光线变化表现通过体验，另保留安静休息岸段 |

用铺装、树荫、岸线、声音和使用者形成差异，旧候船设施保持生活尺度。临时展示与邻里摊集沿小广场边缘展开，活动后恢复普通通行

### 渡口与桥梁

渡口提供步行跨岸的便利与观看城市的方式，与轨道和桥梁互补。适应水位变化的码头形式另行确定，滨水主通道保持与局部登船设施的区别

桥梁引道沿城市道路组织，与小店门前的生活主路分开。桥面与岸边步道分层，桥下检查净空、照明、雨后通行和高水位替代路线。每处图面交叉明确实际连接层级及上下桥位置

## 尺度与取景

可压缩重复街段与缺少内容的距离，门、楼梯、学校和车辆保留协调尺度。大型设施可展示入口与部分院区，其余体量延伸到不可进入的背景

分别标明世界存在范围、玩家可达室外与可进入室内。核心街区尽量保持连续室外行走，远端城区通过交通与场景转换联系，大河和对岸不按概念图宽度直接换算真实尺度

记录小店、观河转角、河岸和摘星台的实际取景方向，逐项检查建筑、树木与高差是否允许视线成立。两面夜景在同一场景和同一时刻核对，具体尺寸通过灰盒验证

## 平面与剖面核对

- 商店街形成连续街面与后院，站前、东西街坊及图外道路相连，设施服务范围可理解
- N主路主要弯折有地形或地块依据，高差、距离、局部坡度与入口衔接一起记录
- 回家线与采购短环成立，远距离绕行保留为可选路线
- 装卸位、服务巷、公共台阶、顾客入口与私人入口各自明确
- 滨水主通道与低层支路分层，过街、桥下通过和水位变化时的替代路线成立
- 门前平台、挡墙、庭院和台阶有排水去向，公共设施与建筑用途相符
- 地图编号与正式地点 ID 分开维护，地点、地块与道路使用同一份主数据
