## 扩容设计基线

街区采用轻近未来生活背景，站前科技与兴趣中心、滨水—东侧文娱中心由商住街、采购街和住宅相连。设计范围为 10—14 个街坊、220—350 个本岸建筑体量、70—100 处特色场所；对岸背景单独统计

影院与城市会客厅承接公共展示功能，学校为普通星见学园，屋顶公园与地面城市花园分别承担高处休息与地面活动，公共球场保留独立到达

建筑按有边界的独立体量计数，楼层、房间与内部商户归属其所在建筑。场所按可独立辨认的目的地计数；影院会客厅共用一份档案，校内多栋建筑归属同一校园，内部功能不重复累加为目的地。货运侧院与公共台阶保留空间身份，与特色场所数量分别记录

具体数量与尺度通过地块、建筑容量和路线的共同校核确定。规划容量、已经绘制的体量与重点空间深化程度分别记录

## 城市框架交付深度

城市框架维护可从街道和总图读出的空间：街坊、建筑外形、道路、地形、室外公共空间及相互到达。重点是完整街面、清楚的城市尺度与连续通路

| 对象 | 框架所需信息 |
| --- | --- |
| 建筑 | 地块、外轮廓、基底高程、楼高或层数、主要用途、街面朝向、入口和必要的院落后场 |
| 道路 | 等级、实际宽度、连接节点、高程、坡道或台阶、公共与服务边界及图外城市联系 |
| 立体空间 | 上下街、建筑入口层、屋顶、平台、桥梁和公共垂直交通的归属与连接 |
| 公共空间 | 学校建筑组与操场、公园、广场、河岸和山脚的范围、主路径、出入口、绿地及停留位置 |
| 地形与街景 | 连续坡面、水平建筑台地、必要挡墙、河岸层次，以及道路转折、树木与主要视线的关系 |

道路骨架、实际路宽和关键标高随每个街坊的建筑布局同步确定，收口阶段复核局部交叉、入口与高差。每个街坊同时展开沿街建筑、普通住宅、内部开放空间和服务到达

框架平面表达建筑轮廓与室外布局，楼层用途只细化到辨认建筑功能和入口层所需程度。剖面优先处理高差、建筑高度和平台接续，沿街立面用于核对体量、入口、遮蔽与街面差异

室内房间、内门、家具陈列、内部设备和施工级工程不属于城市框架。已有室内参考独立于框架验收，后续按可进入的游戏场所选择细化

交付包括无编号城市总平面、道路与公共到达图，以及小店坡地、影院屋顶、校园边界、桥梁和滨水的关键剖面。进度按街坊覆盖、建筑信息、道路入口连通及空间节点核对分别记录

框架完成时，隐藏编号仍能读懂主要街坊；公共目的地能沿室外道路抵达；建筑落地、道路交叉、校园边界和上下层关系在总图与必要剖面中一致。普通建筑按街段和住宅组展开，规划容量随实际布局校准

## 空间目标

第一次到达能找到回家的路，多走几次能选择更顺路、更安静或更好看的走法；长期重访能够认出谁在哪里活动、门后的空间属于谁，以及事件留下的变化

小店是玩家的生活中心，车站、中学、公共设施、其他商铺与住户也有独立的服务范围和活动。远处的大河、桥梁与对岸表现都市规模，近处的店面、院落、台阶与公共空间表现日常生活

丰富程度来自同一地点在不同方向、时段与关系中的体验。街区扩容与已有地点的深化一起推进，保留普通、安静和允许不发生事件的空间

## 普通生活与异常边界

初秋是局部季节状态，日期、年龄、天气和生活事件仍然推进。道路、补货、排水、公共服务与维护以正常城市关系成立，需要异常的部分另列可观察范围和影响边界

梦境错位建立在玩家已经认识的正常路线、声音和物件上。现实街区保留充足的正常生活，使异常改变了什么能够被察觉；具体事件使用叙事档案记录，不由场景概念自动生成正式委托

摘星台保留同地、同夜转向可见的两面夜景。画面要求与成因分开，普通山体遮挡不作为已经确认的完整解释。新增机制在确认前不进入玩家世界规则

## 美术与声音

站前通过交通标识、较完整的建筑界面、出入口与稳定人流建立识别；兴趣店铺通过设备、作品与制作活动形成差异。采购街保留连续橱窗、雨棚、手写菜单和经营动作，西侧住区以院门、维修物件和较近的生活声呈现日常

小店以自家招牌、橱窗、台阶、树下座位和熟悉灯光辨认。东侧中学、影院会客厅、音乐场所与公园各有入口和公共停留位置，河岸以水面、桥梁、候船设施和远处城市展开；向山侧行走时，住宅逐渐退去，树木、天空与视野成为主要内容

招牌从真实来路可辨，转角用侧向标识，深处店铺可在巷口提示。大图形、局部高饱和色与夸张商品装置集中于少量关键店面，住宅、诊所、中学和安静街巷有各自密度。小店白天与夜晚都保持识别点

声音从站前交通、人流与饭馆经营，过渡到修理铺试机、洗衣店设备，向上逐渐减弱，近岸转为水、船与桥梁的层次。音乐活动与邻近住宅分别组织声环境，重要入口、危险与交互同时提供视觉信息

风貌与道路结构使用同一份地点、道路、建筑及地块数据。屋顶、墙面、道路和平台分别投影，标签始终朝向屏幕；小店附近支持隐藏地名核对空间关系。取景与缩放不改变道路尺度，高度配色用于表达道路结构中的高差

## 交付核对

街区结构先通过总图与剖面核对道路、入口、高差和公共边界，场所再通过平面与日常状态核对用途、人物和后勤。实际镜头检验主要取景方向、昼夜辨识与视觉提示，声音与视觉互相补充

摘星台始终区分已定画面、候选机制与待定成因。地图与 Wiki 通过同一份主数据呈现地点关系，阶段记录保留实际产物和验证范围
