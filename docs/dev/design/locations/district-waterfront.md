# 影院与滨水建筑

影院街、音乐街和滨水花园组成第二活动中心。建筑沿公共道路形成街面，屋顶、会合前场、装卸后场和两层河岸各有明确范围与到达方向；普通商住与工作建筑连接主要目的地

图纸沿用[城市总图](district-plan.md)的轮廓、入口、道路宽度和相对高程。建筑楼层表达主要用途及外部连接，平面重点是街坊与室外空间

## 影院街与公共屋顶

影院基底为 +17 m，餐饮联系层为 +21 m，公共屋顶为 +29 m。屋面边界内是建筑的屋顶花园，边界外的平台单独支承公共通路，转折后接到上街。地面入口、公共电梯和上街入口共同组织高低到达

沿街普通建筑承接生活商业、工作与住宅，入口面向公共街道；影院外围保留低街通行，屋顶花园形成独立的高处停留选择。屋面、平台和上街关系采用同一组标高，结构与开放管理由后续专项确定

## 音乐街与后台到达

演出建筑位于音乐街南侧，北侧以普通混合楼和音乐服务建筑形成连续街面。观众从公共道路进入会合前场，再到场馆门口；器材和维护通过装卸位置到后门，室外等候保留连续通过的道路

音乐街与城市联络路相接，夜食和普通生活商业沿路展开。演出前场、街道与花园分别承接排队会合、经过与停留，建筑之间保留可辨认的公共巷口和后勤边界

## 花园、岸线与桥梁

城市花园的活动区域由周边建筑和公共路径界定，园路接到滨水上层通道。低层渡口和亲水平台从主通道分出，上层岸线保留连续通行；岸边服务建筑让街坊与水面之间有生活界面

桥梁引道沿城市道路接桥面，音乐街保持地面联系。桥面与桥下通道采用不同节点和高程，平面交叉分别落在对应层级；关键剖面同时表达桥上、桥下与河岸的关系

## 类型与依据

| 类型 | 城市框架中的作用 | 依据与项目取舍 |
| --- | --- | --- |
| 影院社交综合体 | 低街入口、主要用途层、公共屋顶与上街形成立体联系 | [城市空间研究](world-research.md) R2—R4；将观影、会合与公共花园组织在同一建筑，标高采用本项目设计值 |
| 音乐目的地建筑 | 观众前场、后勤入口和邻接街道形成两侧到达 | R7；将设备服务需求落实到装卸和外部通道 |
| 普通混合楼 | 连续街面、住宅与工作场所补足两中心之间的城市密度 | R5、R12；沿街用途与上层居住或办公组合，建筑高度随街段组织 |
| 滨水服务建筑 | 为花园、渡口和岸线提供日常服务及维护入口 | R1、R4；公共停留与连续通行分别留出范围 |

楼高、占地和公共平台标高均为设计假设。框架核对建筑落地、道路与门口连通、屋顶归属和高低路线接续，结构、荷载、水位及运行管理按专项推进
