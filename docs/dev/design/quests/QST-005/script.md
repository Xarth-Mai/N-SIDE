# 第四章 · 初秋以外：完整制作脚本

[故事正文](../../../../player/story/main/beyond-autumn.md) · [共用写法](../script-format.md) · [正式台词](dialogue.csv)

阅读顺序：S001 搬苗 → S002 环境边界 → S003 试验准备 → S004 梦中循环 → S005 双端反效果与撤回 → S006 迁移和处置范围 → S007 协调解除 → S008 空架与分路回家；S009 是实际进度重访。八个主场对应[分场纲](../campaign-sequences.md#第四章-初秋以外)，整章设计预算 90–120 分钟，不把等待天气、植物生长或自然日转场计为额外游玩量

主要演员：曜 CHR-001、玲 CHR-002、巧克力 CHR-003、艾玛 CHR-019、陈知夏 CHR-020、邱立 CHR-028、罗宾 CHR-033、塞拉 CHR-037、诺拉 CHR-025、苗盘认领者 CHR-056。潜梦由曜承担、玲清醒接应；不同现实观察位有明确负责人，角色不通过切镜同时站在几个地点

前提：第三章已经建立跨点观察工作，AFTER 9 旧声响与学校旧输出仍保持隔离。本章开场前苗损已经发生，临时试验可撤回但不能让已死苗木复活。只解除已经核验的一组新增交叉联系，保留局部初秋活动、正常日期与其他待测范围

<a id="qst-005-s001"></a>

## QST-005-S001 · 牌子先别搬

入口：白天的四季温室，原拍摄架旁有一块卷起的背景纸。曜从公共到达侧进入，玲夹着图样袋，艾玛在受损苗盘前蹲着，手掌托叶背而不拔根；邱立把空架挪到搬运路径外，陈知夏拿着原定取苗联系表。认领牌仍插在各自盘内，损失和未受损苗没有混装

<a id="qst-005-s001-k01"></a>

### QST-005-S001-K01 · 这张照片先不拍

触发：首次进入温室，玩家靠近苗架

玩家镜头，当前操作曜。艾玛抬头要说话，先用另一只手指住一盘仍挺立的苗，等曜看清再放下已经枯软的叶片；玲原想放下图样袋取背景纸，看见叶片垂落，改把袋子挂到干燥挂钩

**QST-005-L001｜艾玛**：先帮我搬这一盘。底下托住，别抓叶子
**QST-005-L002｜月城曜**：搬去哪儿？
**QST-005-L003｜艾玛**：门边确认过的空架，先离开这段地面

玩家实际靠近指定盘，双手托底抬起，镜头仍可看前路；到达空架后将盘底放平再松手。路径由邱立让开，搬运不要求穿过异常作用区或等多次无信息动画

<a id="qst-005-s001-k02"></a>

### QST-005-S001-K02 · 留在受损的那一格

触发：第一盘已放稳，玩家查看受损盘与认领牌

短表演镜从苗架外侧中景接管，禁移动与拿取，可暂停或跳过到认领牌仍留原盘。玲用两指捏起歪倒的牌，准备插到旁边还有绿叶的一盘；艾玛抬手挡在两盘之间，没有抓玲的手，眼睛一直看着牌尖

**QST-005-L004｜艾玛**：先记下是哪一格，别把还活着的也数进去

玲手停在盘上方，将牌尖沿原孔插回，扶直后才松开。镜头随她的手退回曜的玩家视角，牌面可读

**QST-005-L005｜屏幕文字**：认领用途：社区育苗活动／本轮已约取苗／本盘现况：受损，交付待重新答复

牌未被转给未受损盘，玩家查看只取得事实，不等于代认领人接受补种

<a id="qst-005-s001-k03"></a>

### QST-005-S001-K03 · 当天就要答复的人

触发：可保留苗盘已移至确认的临时位置，玩家核对现存与受损位置

玩家镜头，曜把原架的空位置留在现场记录中，玲用小纸签在图上分别标“已移走”“原盘受损”，不以绿色总面积替代清点。陈知夏站在门边逐个发出联系说明，艾玛点查每条发出记录，自己承担交付改变

**QST-005-L006｜陈知夏**：原来的拍摄时段，我先用来通知取苗的人
**QST-005-L007｜艾玛**：写这盘今天交不了。别写成过两天一定有
**QST-005-L008｜屏幕文字**：取苗改约通知｜本轮认领盘受损，今天无法按原约交付；请先不要按原安排来搬运，新的数量与照料安排会再联系本人确认

出口：可保留盘在门边空架，受损盘与牌仍在原架，通知已经发出；认领者稍后到场是核对与答复，不被写成未收到通知的突发责难。离开后从尚未搬完的盘或未核对记录续接，不重复制造苗损、收回已发通知或把临时安置当最终种植交付

<a id="qst-005-s002"></a>

## QST-005-S002 · 雨停了，接缝还湿着

入口：温室外允许观察的公共地面，罗宾在记录板旁，邱立持排水维护照片。曜操作，玲负责将来源分别夹好；花草店、屋顶、城市花园和林缘的同轮记录已经按来源进入工作资料，不要求为看同一结论强制跑遍每处

<a id="qst-005-s002-k01"></a>

### QST-005-S002-K01 · 同一批，两个地方

触发：玩家查看花草店送来的同日养护记录与温室受损位置图

玩家镜头局部查看。玲把两个苗盘的来源签对齐，手指在同批标记间来回，不把长得好的照片当成本地恢复图。罗宾用可移标贴圈出温室越过旧养护范围的受损位置

**QST-005-L009｜屏幕文字**：花草店同日记录｜同一批苗在店内养护处仍正常生长；记录只覆盖店内这批，不代表温室条件
**QST-005-L010｜屏幕文字**：温室位置记录｜受损位置跨过旧养护图边界；边界外仍有当前变化，范围待现场比较
**QST-005-L011｜罗宾**：同一批不等于同一块地。先看今天哪儿干、哪儿还湿

先看过花草店实物的玩家直接使用自己的现场记录，不重复领取同一份“新证据”；没去过者使用有来源的送达记录，主线仍有后续现场独立核验

<a id="qst-005-s002-k02"></a>

### QST-005-S002-K02 · 脚边的两条边

触发：玩家沿温室外允许通行的一侧查看当前干湿边界

玩家镜头，曜蹲到地面标志外，先看干燥铺面的颜色，再以记录工具指向仍暗湿的接缝；不让裸手伸进未经核验的材料缝隙。镜头可自选近看，玲站在他身后半步，避免影子遮住标记。玩家沿接缝标出实际湿润延伸，到干燥处停笔

**QST-005-L012｜邱立**：排水通了，这里却一直没干。填进去的这一层，比旧照片更贴着构件

邱立将维护前后两张照片递到曜视线高度，照片中的填充边缘变化可见；玩家把今天标出的湿边叠上去，重合区域被留下，其余仍是未测

**QST-005-L013｜屏幕文字**：维护记录｜先前排水改善已完成；填充层与旧构件接触位置改变／当前雨后观察：接缝持续潮湿／与异常活动是否相连：待试验

<a id="qst-005-s002-k03"></a>

### QST-005-S002-K03 · 相邻还不足以画实线

触发：玩家比较现场边界、维护记录和相邻位置的资料

玩家镜头，工作板上有可以拖入“待验证”栏的候选联系，不存在只靠地理距离就自动通过的答案。若玩家将仅相邻的一段标为已证实，罗宾不替其悄悄修正，把对照点的空记录放在旁边

**QST-005-L014｜罗宾**：这一段只有位置近，还没有同步变化。先放待测

玩家将该线移回候选区；如果一开始就留在候选区，则播放下一句，承认有效判断

**QST-005-L015｜罗宾**：这里先空着是对的。等有两边的记录，再决定连不连

出口：当前干湿边界、维护后的接触变化和有来源的跨处记录可供试验；尚未得到相互作用结论。玩家可以先看城市花园、屋顶或林缘已送达记录，新增的是各自实际范围，不在未到现场处虚构自己的亲历；必需的现场核验集中在本章受控点

<a id="qst-005-s003"></a>

## QST-005-S003 · 开始以前就知道怎样停

入口：温室外已核验的工作台，曜的设备位在可安全退出的位置；玲面对监测屏，罗宾在第一个观察位，邱立前往第二个观察位，塞拉核对人员与撤回职责。艾玛已将剩余盘准备在可转出区域，未投入新的苗做破坏性试验。对照点与两个作用观察位分开标记

<a id="qst-005-s003-k01"></a>

### QST-005-S003-K01 · 一张表上看见三处

触发：玩家在试验台核对梦内试验点与现实观察位

玩家镜头，曜把梦内预期接触位置放到试验图中央，玲依次点亮两个现实通道与独立对照点。每个通道先收到来自本人当前检查的回应才显示可用，旧照片不能点亮当前确认

**QST-005-L016｜罗宾**：温室这端在位，当前范围已标
**QST-005-L017｜邱立**：另一端在位，撤回路径空着
**QST-005-L018｜月城玲**：对照点也有连续记录。我看三处，不只看温室

玩家核对人员、通道和撤回位置；未完成项保留显眼空格，开始连接不能越过准备

<a id="qst-005-s003-k02"></a>

### QST-005-S003-K02 · 停止条件就是本轮约定

触发：三个观察渠道均已确认，玩家查看并确认试验卡

玩家镜头，塞拉用笔尖分别指过屏幕上预先标定的范围边线，再沿设备线检查接应位到安全出口是否无遮挡。量值留给后续原型核验，本稿不编造仪器精度或安全数值；玩家能看见曲线是否跨越已经标记的本轮范围

**QST-005-L019｜屏幕文字**：本轮试验｜只对已标记联系做一次临时调整；任一观察点越过标定范围、现实通道失联或接入不稳，立即停止；曜放开梦内操作，现实端收回临时调整，玲组织退出；保留全段记录
**QST-005-L020｜塞拉**：只试这个位置。哪边先越线，哪边就报停，不等另一个人看懂
**QST-005-L021｜月城曜**：我听到停就收手。没看见另一边，也照停

<a id="qst-005-s003-k03"></a>

### QST-005-S003-K03 · 这轮以前，和这轮以后

触发：试验准备齐全，开始按钮与继续准备同时可用

玩家镜头。玲将自己的接应时段夹在图板边，不挡三处观察；她用手指在本轮结束的位置画一条线，曜看见后把设备包移出她的取稿路径

**QST-005-L022｜月城玲**：我能接完这轮。后面我还要改稿
**QST-005-L023｜月城曜**：这一轮，先把这一轮弄清
**QST-005-L024｜屏幕文字**：开始本轮受控连接
**QST-005-L025｜屏幕文字**：暂不开始，继续核对准备

选择暂不开始时，曜盖回接口防尘片，不触发苗损或异常升级；玲把笔放在图板旁，允许玩家自由核对已有记录

**QST-005-L026｜月城玲**：那先别接。我把记录留着

再次选择开始时从当前准备状态进入 S004，不重新搬苗或重发通知。试验未开始时可离开，人员安排随重新预约检查，不以现实等待强迫用户留下

<a id="qst-005-s004"></a>

## QST-005-S004 · 庭院在另一边相遇

入口：曜在现实坐稳并确认连接，玲留在监测位。梦内为熟悉园艺空间的错接庭院，候秋者沿固定次序照料；路径在梦中随着动作接通，现实街道不改形。巧克力随曜进入，在安全入口旁形成支援形体

<a id="qst-005-s004-k01"></a>

### QST-005-S004-K01 · 看完一轮再伸手

触发：本轮连接成立

短入场镜从曜松开现实设备扶手切到梦内相同放手动作，他站在干燥台沿外侧；禁移动到双脚站稳，可暂停或跳过至入口观察位。候秋者从遮阴架下经过，先抬起浇水容器，再转身整理另一段花木，道路随最后一个固定动作接上，旧路又在其身后断开

**QST-005-L027｜月城曜**：它走完这一段，那条路才接过来
**QST-005-L028｜月城玲**：现实路没动。我这边记的是接缝和输出

立即还控。玩家沿安全边沿观察，完整看见一次“照料、切换、路径相遇”，或者先到下一观察位交叉核对；记录根据实际看见的环节填入

<a id="qst-005-s004-k02"></a>

### QST-005-S004-K02 · 留住能返回的那一侧

触发：玩家发现区域切换时才出现的通路

玩家镜头。曜在不会随候秋者动作消失的入口台沿放标记，再在路径相遇处观察两块分离的材料边；巧克力只在已出现的通路上试探，不跨空处侦查未连接地点。玩家可等待候秋者下一次动作或利用已观察到的绕行空当接近试验点，不需要重复战斗清场

**QST-005-L029｜月城曜**：这里原来分着。它转过去的时候，两边才挨上
**QST-005-L030｜月城玲**：对应的是我们标出的这组。旁边没测过，别一起算进去

玩家查看标记确认具体作用点，只有这一点进入本轮可操作范围；梦内看似连通的整个庭院不被算作单一接点

<a id="qst-005-s004-k03"></a>

### QST-005-S004-K03 · 动作从这里开始

触发：玩家到达已核对的试验点并主动执行临时调整

玩家镜头，曜一手扶稳不动的外缘，另一手按准备方案将可活动的接触片移离原对接位置；这是当轮临时操作，松开可按原路退回。巧克力站在返回侧以标记示意撤回位置，不替玩家完成调整。对应屏幕通道显示当前动作开始，而非预播成功词

**QST-005-L031｜月城曜**：开始调整，这一处已经离开原位置
**QST-005-L032｜月城玲**：收到。温室这端在下降，另一边还在报

出口：曜的临时操作已发生，持续看得到自己的撤回路径；S005 从双端反馈继续。跳过任何已触发的入场表演都只到安全观察位，绝不自动执行本镜或让试验被视为已经取得结论

<a id="qst-005-s005"></a>

## QST-005-S005 · 另一边先越线

入口：承接临时调整的同一轮，曜梦内维持操作，玲现实观察三通道，罗宾与邱立仍在各自位置。开始前受损苗的数量与位置不因试验而改变；越界发生时人员立即按预案停止，不让玩家以故意拖延换取新剧情伤亡

<a id="qst-005-s005-k01"></a>

### QST-005-S005-K01 · 半句话还没说完

触发：温室通道下降、第二通道越过本轮已标范围

短现实插入镜在玲刚要指给曜看温室曲线时接管，机位是她肩后近景，两个观察位和对照点同时可见；禁梦内继续施力，允许暂停或跳过到停试指令已发出。玲先指温室通道，另一边的指示沿相反方向越线，她马上收回手指，按下停止通话键

**QST-005-L033｜邱立**：这端越线了，停
**QST-005-L034｜月城玲**：停手，另一边在增强

镜头立即回梦内曜当前站位并交还控制，给“松开并退回”操作；若玩家无输入，安全撤回仍由既定保护与接应立即执行，不允许为了等待操作而持续扩大影响。自主操作与保护撤回均完整记录真实发生的动作

<a id="qst-005-s005-k02"></a>

### QST-005-S005-K02 · 看不见也必须先停

触发：收到停止指令，玩家主动撤回或保护已启动

玩家镜头或相同保护动作镜：曜先停止施力，沿刚才的轨迹将接触片退回临时调整前的位置，再松开手退至标记侧；巧克力绕到他身后撤出通路，不留在切换区域。现实罗宾与邱立分别收回本端临时操作，不把任何一边擅自固定在看似较好的读数

**QST-005-L035｜月城玲**：你能看见那一边吗？
**QST-005-L036｜月城曜**：看不见。我已经退回了
**QST-005-L037｜罗宾**：温室这端回到试验前范围
**QST-005-L038｜邱立**：我这边也往回退。对照点没有跟着变

两端曲线沿相反方向返回原范围，第三条对照线保持自己的记录。恢复标记不是“全区正常”，只表示临时改变已撤回

<a id="qst-005-s005-k03"></a>

### QST-005-S005-K03 · 这一次带回失败记录
