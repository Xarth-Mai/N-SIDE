# 名字写回去以后：完整制作脚本

[故事正文](../../../../player/story/world/names-returned.md) · [共用写法](../script-format.md) · [正式台词](dialogue.csv)

本任务主动游玩预算为 35–55 分钟，转场不以现实等待计时。以下镜头使用相对地标锁定构图与切换条件；自由操作段保留玩家机位，短接管仅完成已触发的表演，未操作的证据、选择和交付不会因跳过得到完成。台词阅读呈现由同目录 CSV 回填

## 阅读顺序与出演索引

- S001 → S002／S003／S004 的资料核对可按获得顺序访问
- 有限授权和必要材料齐备后完成 S004 校读 → S005 实際交付
- S006：结项后的道路与展屋重访

稳定角色身份：`CHR-001`、`CHR-002`、`CHR-004`、`CHR-005`、`CHR-018`、`CHR-020`、`CHR-023`、`CHR-029`、`CHR-035`、`CHR-054`；台词表使用这些身份，SYSTEM 仅为屏幕或纸件文字

## QST-024-S001 · 最好看的开头

入口：第三章公开照片与顾文珍的交接已经核对。旧帆展屋正常开放，陈知夏在临窗工作桌试排一张新展签，玲操作，曜站在不挡来访通道的桌侧，老钟整理旧票夹。桌上有未发布试排稿、带旧称的票据复制件和注明 Null 的可公开记录；知夏已知道城市旧称与来源栏含义不同，不再把它当作首次知识揭晓

<a id="qst-024-s001-k01"></a>

### QST-024-S001-K01 · 遮住小字以后

玩家镜头。先检查试排稿可以直接看到标题；先看票据或来源记录也保留已观察事实。知夏用笔杆把纸推到有自然光的位置，指尖顺着标题走过，故意不指下面较小的说明

**QST-024-L001｜屏幕文字**：没有名字的城市

**QST-024-L002｜陈知夏**：底下会解释。先让路过的人停下来，总得有一句让人想看的。

玩家比较标题和材料后触发老钟遮字的短表演：镜头在纸面外侧近景，老钟从票夹里抽出一张无字衬纸，仅盖住正文，露出大标题；转中景看他把纸举到普通来访者视线高度

**QST-024-L003｜老钟**：只看见这一行的人呢？

**QST-024-L004｜陈知夏**：我知道这两件事不同。可这个标题……比我前几个都好。

跳过表演落在标题与被遮的正文仍可检查的台面，不能直接订正展签。归还玲原站位控制

<a id="qst-024-s001-k02"></a>

### QST-024-S001-K02 · 找一张支持它的票

玩家镜头逐件对照。票面旧称按既有复制件保留，不另取新的城市旧名字；日期、盖章和文书字段是可观察的原物部分，未确认字迹不能补出新的人名或具体年份。玩家将“城市曾使用旧称”和“异常来源未明”分别放入说明草稿，不能把两个标签合并

**QST-024-L005｜屏幕文字**：这张旧票使用当年的城市称谓。另一份记录中的 Null 位于来源栏，表示这条来源未能归属。两个位置记的是不同的事。

**QST-024-L006｜玲**：按你那个标题找一张。哪件材料说这座城当时没有名字？

知夏把笔移向小字字号，又收回，改用衬纸盖住大标题，保留下面已核实的内容

**QST-024-L007｜陈知夏**：没有。先把这一行空着，我再找一句。

出口：试排稿留在知夏工作夹，尚无新展签公开。玩家可先去 FLASHBACK、家庭核对或服务中心；未取得的信息保持空白，汇合到 S004 时逐项显示已核实材料

<a id="qst-024-s002"></a>

## QST-024-S002 · 镜头只到这里

入口：FLASHBACK 允许查看的工作桌。郑文良站在底片灯旁，玲和知夏在桌前，曜从侧面帮助压住复制纸。灯面只放经授权的完整底片，原件由郑文良保管。已经在第三章看过同一完整底片时，直接从边缘送货箱与时间出处继续，不再次假装发现被裁掉的换班者

<a id="qst-024-s002-k01"></a>

### QST-024-S002-K01 · 姓名栏先别填

玩家镜头。调整底片查看范围可以看到普通送货箱、临时牌及仍辨不清的人脸；不能放大出原影像没有的细节。知夏将空白姓名栏排在草稿边缘，笔尖对准第一行

**QST-024-L008｜陈知夏**：这里这个人，还能认出来吗？这一列总空着，看起来像没做完。

**QST-024-L009｜郑文良**：你认得他，还是觉得填上去会更完整？我能证明拍摄的日期和方向，脸看不清。

玲把盖在箱子边缘的姓名纸往旁边挪，保留照片完整边界。玩家确认“仍未确认”后，知夏划掉假定人名的位置，改成记录状态

**QST-024-L010｜屏幕文字**：画面边缘：送货箱与临时通行牌可辨。此处人物身份：尚未确认。照片以外的活动：本张照片不能证明。

<a id="qst-024-s002-k02"></a>

### QST-024-S002-K02 · 交给你的是复制件

郑文良逐张确认本次可用复制件，将授权范围写在纸背，递给玲。玩家接取后才获得可供展签使用的材料；原底片仍留在灯面或收回原套

**QST-024-L011｜郑文良**：这张完整复制件可以用，别再裁掉边缘。拍摄方向也照原记录写，镜头外的别替我作证。

**QST-024-L012｜玲**：箱子也留着。不认识的人，就先不写名字。

出口：带走的是获准复制件和出处说明；离开后不丢失已核对记录，未授权影像不能随剧情自动出现在展屋。换拍照任务的私人肖像无论是否完成，都不进入本展签

<a id="qst-024-s003"></a>

## QST-024-S003 · 那天的货，不是整夜的故事

入口：按父母确认的会面时间回月台杂货，桌面已让出可摊资料的位置，不临时中断父母自己的外出安排。月城修拿原进货本，陈美惠拿当时留下的通路说明复制件；玲操作，曜坐桌边，知夏等家人先确认能讲哪些内容，再展开自己的展签纸

<a id="qst-024-s003-k01"></a>

### QST-024-S003-K01 · 怕走的那一段

玩家镜头。此前第五章家庭饭局尚未核过本组材料时，比较照片货箱标记、进货记录和临时通路说明，父母只说自己经历的工作。此前已经核过时，直接使用后两句承认已知，玩家只核对本次可公开范围，不重做童年真相揭晓

**QST-024-L013｜玲**：我记得那条路不让我们自己去。我一直以为，里面还有什么没处理完。

**QST-024-L014｜陈美惠**：那阵子有人交班、有人运东西。不是你们能自己钻过去找人的地方。你当时怕，也不是装出来的。

**QST-024-L015｜曜**：这些我们上次饭桌上看过。今天是问，哪部分能放进那张说明。

**QST-024-L016｜月城修**：用途可以核。公开怎么写，再给我看一遍。

<a id="qst-024-s003-k02"></a>

### QST-024-S003-K02 · 圈出来的是称呼

玩家完成材料对照后，知夏将试写的小标签放到箱子旁。短接管机位从纸面近景抬到月城修半身；他读完，没有马上把纸推走，先圈住标签中的称呼

**QST-024-L017｜屏幕文字**：月城修——守住通路的人

**QST-024-L018｜月城修**：我送过这一批。旁边还有谁在忙，我没看全。

**QST-024-L019｜陈知夏**：可我刚查到是谁做的，又要把名字拿掉？

月城修把记着货物、时段和用途的复制资料留在桌子中央，将写有人名与英雄称呼的标签推回知夏手边。他没有抽回所有材料

**QST-024-L020｜月城修**：这几项你可以用。名字我不想放，这个称呼也不是我做的事。

**QST-024-L021｜陈知夏**：好。那我得把做过的事写清，不能只剩一个箱子。

跳过只落到标签收回、有限授权材料仍在；玩家仍须确认引用范围，不能把“不同意署名”自动解释成全部不可用或已可公开姓名

<a id="qst-024-s003-k03"></a>

### QST-024-S003-K03 · 这次同意用的

玩家在供展签使用的副本上核对范围后由父亲确认。原本不带走，复制页与允许内容同时保存，未答复的其他提供者不被写成同意

**QST-024-L022｜屏幕文字**：本次可用：已核实的进货记录摘要、与临时通路有关的用途。以匿名材料说明引用。不同意：公开提供者姓名、英雄称呼、推断整晚在场。

**QST-024-L023｜陈美惠**：本子放家里。这张带去吧，背面的别忘了看。

出口：父母按原安排离场或继续生活，知夏带走获准范围。中断前尚未确认则不产生授权；确认后的拒绝和许可均保存，换个入口也不能再次诱导具名

<a id="qst-024-s004"></a>

## QST-024-S004 · 留给未知的地方

入口：Null Site 服务中心公开资料区，叶真在资料台，只提供可公开的沿革。玲操作，知夏拿当前工作稿，曜帮助将不同来源分开放在台上。这里没有新的潜梦、秘密档案访问或主线必需权限

<a id="qst-024-s004-k01"></a>

### QST-024-S004-K01 · 不是把所有空格填满

玩家查看叶真提供的沿革摘录，比较“未知來源”“已找到某条来源”和今天的城市称呼。叶真用指尖停在记录字段，不指向票面的城市旧称

**QST-024-L024｜屏幕文字**：记录沿革摘录：部分早期异常条目因来源未能归属而记为 Null。后续证据可订正具体条目；缺少充分证据的来源仍记未知。该词后来进入公共语言，成为城市通行名称。

**QST-024-L025｜叶真**：补出这张票的来历，不等于补出了所有异常的来源。今天大家怎么称呼这里，也不会因此撤掉。

<a id="qst-024-s004-k02"></a>

### QST-024-S004-K02 · 普通标题放在最上面

玩家将已经获准的照片、家庭用途摘要与票据事实排成可读顺序。知夏对着匿名署记发愁，把写有漂亮标题的未发布旧稿露出一角，又压回文件夹

**QST-024-L026｜陈知夏**：不写名字，它又像背景了。那现在叫什么？总不能把核对过程全抄上去吧。

叶真把纸转向箱子的图像，留知夏自己看；镜头仍是可自由退出的桌面查看，不强制切到反应特写。知夏先轻声试读，划掉句首多余的修饰，把纸推远到路过能看到的位置

**QST-024-L027｜陈知夏**：有人在送货。……就写这句吧。

**QST-024-L028｜玲**：这一句后面，接着写送的是什么、当时为什么走那里。

<a id="qst-024-s004-k03"></a>

### QST-024-S004-K03 · 展签完整原文

玩家阅读待印全稿，逐项检查来源和授权；以下正文可在书面界面完整查看。来源标注采用已获准匿名家庭摘要、郑文良授权照片和公开沿革；其他未答复的私人资料不列入

**QST-024-L029｜屏幕文字**：有人在送货 这张照片的边缘有送货箱和临时通行牌。完整影像、当次进货记录与通路说明相互对应：那里曾用于工作人员交接和运送物件。照片只证明拍到的范围，不能说明某个人整晚都在场。 旧票保留当时的城市旧称；早期异常记录中的 Null 则标记未能归属的来源，两者分开说明。仍不能确认的人物与异常来源保持未知。 材料：郑文良授权的完整照片复制件；经同意匿名引用的家庭进货记录摘要；可公开的临时通路说明与记录沿革。

本篇的必要有限材料已经在 S002、S003 与本场分别取得：郑文良同意使用完整复制件，父亲同意匿名用途摘要，叶真提供公开沿革，旧票在展屋既有可展示范围内。必要内容尚未实际取得时，校读保持未提交，回对应交付镜续接，不自动补授权。其他后来联系、尚未答复的提供者属于附加资料，只留工作夹；上列完整定稿不依赖它们，也不含其姓名或私人物件，不要求等待全城身份齐全

出口：陈知夏和材料提供者已确认本次文字范围后，玩家提交这一版交付旧帆展屋。跳过对话不替代校读与提交。更改未确认稿不会撤回早已公开的正确订正

<a id="qst-024-s005"></a>

## QST-024-S005 · 箱子露出来

入口：旧帆展屋开放时段，当前已公开旧版还在展台，知夏带确认稿，老钟取出票夹预备留出展签位置。玲操作；展屋来访者 CHR-054 从正常入口进入，不是任务召唤的见证人

<a id="qst-024-s005-k01"></a>

### QST-024-S005-K01 · 把改过的留下

玩家实际将新签放入展台卡槽，旧公开版本取下收进有订正记录的档案页。未发布的“没有名字的城市”试排稿仍留知夏工作夹，不把它假写成曾面向公众发布的错误

**QST-024-L030｜屏幕文字**：本次订正：分开城市旧称、材料提供者与未明异常来源；恢复完整图像中的运输用途。原公开版本留存于订正记录，未确认部分仍保留未知。

老钟习惯性把票夹往照片前一放，遮住箱子；他看一眼新标题，拿起票夹，换到侧边留出的托架。短近景只在玩家安装结束后强调箱子重新露出的动作，可跳过，不自动安装

**QST-024-L031｜老钟**：票在这边也看得清。箱子这次别又挡了。

<a id="qst-024-s005-k02"></a>

### QST-024-S005-K02 · 路人问的是路

来访者停在不挡出口的展台前，手指停在图中的临时通路标记外，不触碰原件。知夏从侧袋取出已确认用途的小图，与当前通行信息分开摆

**QST-024-L032｜展屋来访者**：临时通路是在这里吗？我今天好像从旁边走过。

**QST-024-L033｜陈知夏**：这张讲当时运货和交班的用途。今天走哪边看开放牌，不能拿旧图当通行证。

**QST-024-L034｜展屋来访者**：明白了。原来照片边上那一堆也是在做事。

出口：展签交付与来源授权完成即结项，不等待找到照片里每个人。人物不因完成任务自动同意今后所有用途；返回展屋仍显示已交版本，不能再领取同一资料或反复安装

<a id="qst-024-s006"></a>

## QST-024-S006 · 今天也有人搬箱子

入口：后来普通开放时段，兄妹走到以前绕开的公共路段；保持当前开放道路，不闯临时作业区。阿东正在完成今天的正常交接，货物与历史照片中的箱子不是同一件遗物。玲携小册草图，曜走在她旁边

<a id="qst-024-s006-k01"></a>

### QST-024-S006-K01 · 留一笔今天的

玩家镜头可停留观看阿东抱箱、确认落点、双手撤回，再返车取下一件。玲只有在玩家观察完成后才在草图边缘补一只正被托住的箱子，画中路径对应现实开放空间

**QST-024-L035｜玲**：小时候我只看见路被拦着。今天这只箱子，至少看见它从哪里交到哪里了。

**QST-024-L036｜曜**：那就画今天这一趟。别替他把剩下的一天也画完。

<a id="qst-024-s006-k02"></a>

### QST-024-S006-K02 · 新来的仍要核对

再次到展屋时，老钟把一张后来收到的普通票据放在工作桌，不覆盖已交展签。知夏取新的核对纸，旧授权材料保持原范围

**QST-024-L037｜老钟**：又有人送来一张票。日期能看见，来历还没问全，先放这边。

**QST-024-L038｜陈知夏**：标题先不急。这回先问它能说明哪一趟。

跳过或离开保留新票“待核对”的现实状态，不自动追加一个必须完成的新任务，也不把已经结束的本任务重新打开
