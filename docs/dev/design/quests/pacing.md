# 首发任务体量与长度

## 参照范围

完整版采用原神 1.0 首发阶段的任务分层作体量参照：主线由多个可结束的小任务组成，人物故事有自己的起承转合，世界任务有长有短，探索让这些内容在空间里相遇。N:SIDE 保留当前十章完整结局、十二条街坊故事和五条世界任务，先做好一个城市故事包；不将每条小委托扩大成数小时篇章

这取代此前讨论的 40–60 小时硬目标。现有 91 个场所是世界空间，不是 91 个同等长度的委托；地图面积、地点数量与任务时长分别管理。Demo 仍使用[原范围](../../direction/demo-scope.md)，不因完整版预算变化扩充

以上核对了文本、当年发布信息和视频说明中的分段时间戳，没有将录像逐帧重新计时。样本录像不等于平均玩家耗时，剪辑、熟练度、旅行路线和阅读方式都不同；下面的分钟数是据这些层次为 N:SIDE 制定的设计预算，不是原神官方时长或本作实测结果

## 计时口径

计入第一次正常阅读、必要步行、观察比较、选择、梦内行动与现实后续；不重复计入同一场对话在主线和支线的交叉出现。不把刷取、强制等真实日期、无新变化的来回跑路、读档重试或自由停留列为剧情产能

单个操作与对话片段通常组织为 3–10 分钟单元；较长调查／梦内序列分成 10–20 分钟的可保存段落。它们组合成下表任务，表中“段”表示目标或处境发生变化，不是每段都换地图或多接一个委托

正文标题不等于独立计时单元，同一现场的几个段落可以连续完成。跨章互引与后来的重访按实际进度出现，不作为当次必经回放；做饭、等雨、到场与次日归还使用正常转场，末尾列出的关联场所也不是必须全部打卡的路线

## 主线逐项预算

| 任务 | 目标分钟 | 单元组织 | 最需要保住的长度 |
| --- | --- | --- | --- |
| QST-001 门还开着 | 30–45 | 店务、一次街区走访与晚饭，短动作可在同一场自然串联 | 完成卡与实物的差别、伙伴日常和米娜请求 |
| QST-002 最后的玩具 | 75–105 | 现实基准、初探、现实复核、二次处置、整理与离城；沿用原十六 Beat | 看见归还、自己选观察路线、完成双侧处置，完整篇章送行另于 Demo |
| QST-003 多出来的掌声 | 75–105 | 排练冲突、声源排查、厅堂规则、隔离、澄清和新安排 | 调查能推翻旧音轨归因，安可实际承担回应 |
| QST-004 没有放学的那一天 | 75–105 | 当下出入、底片与交接、重画选择、两段离场、展览与主动调查 | 证据改变画法与行动，不能只听顾文珍讲完 |
| QST-005 初秋以外 | 90–120 | 搬苗、环境比较、受控试验、停止与调整、协调处置、余波 | 双点反馈与安全停止，保留合理方案之间的取舍 |
| QST-006 仍在一起 | 60–90 | 工作相识、范围比较、授权会面、日常家务、下一现场与家庭谈话 | 旧图比较和两人的今天；已有家庭资料只补新的回应 |
| QST-007 河没有倒流 | 90–120 | 旧提示、现场调查、候船规则、新联系判断、停用与承诺冲突 | 区分旧输出与新路径，损失落到已认识的人身上 |
| QST-008 把今天带回来 | 45–75 | 核心讨论、有限并行准备、各自决定、连接检查和演练 | 改变分工和验证方案，不逐个拜访所有居民集齐信任 |
| QST-009 回声之后 | 90–120 | 原十四 Beat 分为进入、组合行为、现实窗口、核验提交与退出 | 新组合、双确认和可中止，不以重复刷相同形体撑长度 |
| QST-010 明天照常营业 | 30–45 | 交付与演出、按真实进度的重访、家庭晚饭和回家 | 兑现已建立的关系，允许未做支线留待之后 |

主线合计 **660–930 分钟，即 11–15.5 小时**。这是十章内容的目标总额；每章内部的场景与信息展开见[分场纲](campaign-sequences.md)，超预算先合并重复到访或删掉没有变化的对话

十二条合计 **226–370 分钟，约 3.8–6.2 小时**，其中轻相处与较完整人物线有明确长短，不让所有故事平均占满一小时

## 世界任务逐项预算

| 任务 | 目标分钟 | 有意义的阶段 | 结项后不占用任务时长的变化 |
| --- | --- | --- | --- |
| QST-023 雨棚下的第二条路 | 30–45 | 当事人决定、接手与费用、现行路线、实际交付 | 顾客以后选择谁维修，阿东自己的晚间安排 |
| QST-024 名字写回去以后 | 35–55 | 原物比较、不同证据、家庭旧路、署名与展签 | 新收到的票据、街坊继续经过旧路 |
| QST-025 空着的一格 | 25–40 | 失株与承诺、两种使用需要、有限分配、首批补种 | 几天至数周后的实际生长，下一轮照料 |
| QST-026 不是备用的那一天 | 25–40 | 不同意见、具体编辑、选择参与形式、交稿 | 下一版折页和两人自己的日程 |
| QST-027 寄往新地址 | 25–40 | 今日需要、物件或资料、家人代班、使用回应 | 后来的新朋友、未公开照片与下一次通信 |

五条合计 **140–220 分钟，约 2.3–3.7 小时**。按正常转场结束等待；已做主线中的相同交接在支线里承认结果，不能为了领另一份进度再次演完

## 总量与收缩方式

二十七条全部完成的主动任务预算为 **1026–1520 分钟，约 17.1–25.3 小时**，即主线加全部可选任务；它不是“首次主线加部分支线”的保底时长，也不是原神 1.0 总游戏时间的等量证明。自由探索、可选阅读与不同分支可延长停留，具体多长仍未知

参照的实质是首发层次：一组能到结局的主线、数条人物故事、短而具体的生活请求、少量多地点世界链。世界密度依靠人物在不同剧情时段继续使用同一空间、伏笔逐次改变意义和事件后的新状态；不要求首发再增加第二个城市、全地图独立任务或数值养成来填足旧目标

若原型低于下限，先判断互动是否被省成一句话、现场是否缺少可见线索，真实内容不足才补必要动作；若高于上限，先删重复路程、重复说明与无新信息的等待。依据完整路线实际计时调整，不通过放慢行走和强制等待达标

验收记录分别保留首次通关、提前发现、轻量跳过对白和完成相关支线后的路线。时长、理解和情感投入分别观察；这轮只有文档与资料核对，原神完整录像重测、本作运行计时和真实玩家反馈均为 NOT RUN
