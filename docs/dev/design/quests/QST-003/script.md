# 第二章 · 多出来的掌声：完整制作脚本

[故事正文](../../../../player/story/main/extra-applause.md) · [共用写法](../script-format.md) · [正式台词](dialogue.csv)

完整中文制作稿，覆盖原八分场及条件续接、重访。设计预算 75–105 分钟，主要由现场比较、厅堂观察与实际处置构成；对白与镜头依动作完成切换，不用重复听录音或跑图凑时长。全部音频仍待录制，实际机位、动画和玩家时长待场景验证

参与：月城曜、月城玲、巧克力、安可、悠真、贺佳、阿杰、塞拉；乔伊和唐惠通过电话参与已约定工作。BC-002 为没有观众的掌声，曜潜梦、玲全程清醒接应，玲在接入后不离开曜的身体与设备，现实隔离由塞拉在授权作业位执行。引座员只执行循环，没有新配音人格

入口：新歌有可排练稿；QST-020 已有效选定副歌时继承原版本，否则保留未定，宣传用途按当前用途核对，小册首轮校样已约；今天是序章登记的后来那个校样日，并非开店介绍当天。出口：旧声源隔离且同条件复核、场地按许可恢复、公开误解订正、餐食结算完成；新歌继续创作，玲失去的首轮校样不自动找回，河岸首演仅成为新的工作意向

阅读顺序：S001 排练交付 → S002 空场停机与失去的校样 → S003 停用和现成承诺 → S004 来源比较与现实连接 → S005 厅堂观察 → S006 当轮通路和隔离 → S007 退出复核 → S008 公开说明与回店（K01–K05 → K08 河岸意向 → K06 或 K07 结束工作 → K09 回店，保留镜号）→ S009 中断/延后/重访。现实证据可依不同顺序查看，已观察项目不要求补做误判；S005/006 保留提前看懂直接通过与先误走舞台再退回两条路径

控制与恢复：现实调查以玲操作为主，曜进入后镜头归曜；现实端插镜只给玩家已经取得的现场信息。短演出接管均允许暂停与跳过，跳过不能替玩家观察、判断、选择、调整通路或维持窗口。递物和隔离开始后的恢复续在已发生的动作位置，不复制物件、不重开已隔离接触、不撤销已经完成的退款与结算；未完成的独立复核保留到复核镜

## QST-003-S002 · 空下来以后仍有掌声

<a id="qst-003-s002-k01"></a>

### QST-003-S002-K01 · 先停哪一部分

玩家镜头。玲将记录设备放到贺佳能看到的台面，手指停在录制按钮外；她先指调音台，再指空观众席与后排旧构件，请求的范围只覆盖本次场地

**QST-003-L015｜月城玲**：能先停播放，再录这间空场吗？工程文件只看今天这份。

**QST-003-L016｜贺佳**：可以。相关人员先到门外，其他客户的东西别动。

**QST-003-L017｜悠真**：今天的工程在这里。先把它停住，再听屋里。

玩家实际点击停止播放、看见播放头停止并确认输出状态，然后启动独立记录。两项动作顺序可纠正但不能只看对白就算做过

**QST-003-L018｜阿杰**：这里还有。不是从我们的工程里放出来的。

悠真把备份握在胸前，听完一次没有立即说话，又将独立录音拖回同一段听第二次，手指才慢慢松开袋边

**QST-003-L019｜悠真**：这份保留。别再拿工程里的猜测当说明。
