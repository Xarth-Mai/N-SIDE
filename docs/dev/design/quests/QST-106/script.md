# 一本书的几种读法：完整制作脚本

[故事正文](../../../../player/story/daily/ways-to-read.md) · [共用写法](../script-format.md) · [正式台词](dialogue.csv)

本篇主动游玩预算 20–35 分钟，沿用既有任务范围；下述场面是中文制作交付稿，预算、镜头与动作尚未经过实机或演员验证。远途移动、日历转场和已经完成的交接不重复计时，支线结果分别读取实际记录

## 阅读顺序与连续性

S001 两张书签 → S002 核对两版 → S003 预约编辑与原句许可 → S004 平台阅读角 → S005 页面交付及书籍归还 → S006 续接与重访。两个版本可反序核对，私人书签退回后不再成为玩家库存或后续任务自动取得物

演员：兄妹、小满、诺拉、顾文珍、通过约定辅助通道参与的遥，旧版读者 CHR-044、修订版读者 CHR-045、小满的荐书朋友 CHR-046。遥只处理这页约定的编辑工作，不因此提供私人历史或扩大接入范围。所有读者只代表自己的阅读经历

F27 由 S001-K02 两段相斥文字、S002-K02 版次补证、S003-K03 原句与授权、S005-K01 实际页面闭合；F12 在 S003-K04 保留口语批注，F14 在 S004-K01 按 QST-101 的实际进度使用尺寸草图或试版样片。先做 QST-026 时可读已获准折页，不能预设两位都署名

<a id="qst-106-s001"></a>

## QST-106-S001 · 同一页码的两张纸

入口：白页书店临窗阅读桌，接近小满答应整理完推荐页的时段。两位读者各坐桌的一侧，手边是自己写的书签，各人的袋中还带着今天正在读的其他书，没有带齐当时借过的《沿河慢车》版本；小满站在桌头，推荐页留出两个漂亮封面的位置。顾文珍在靠壶的一侧，诺拉带着空白排版纸来到桌边。兄妹从书架通道进入，只知道有人意见不同，尚未取得版本证据

<a id="qst-106-s001-k01"></a>

### QST-106-S001-K01 · 先别把两句放在一起

玩家镜头，小满弯腰把桌头那本小说的封面摆正，旧版读者伸指压住自己的书签，不让她把两张收成一摞

**QST-106-L001｜小满**：我本来想让大家各写一句，沿路找本书坐一会儿。现在连她最后有没有买票，都得重新吵。
**QST-106-L002｜修订版读者**：她走到售票口了。最后几页，你是不是没看完？
**QST-106-L003｜旧版读者**：票在抽屉里。那几页我看过不止一次。

小满将已拿起的胶点放回垫纸，手没有碰任一书签文字

**QST-106-L004｜小满**：也许就是开放结局，各有各的——
**QST-106-L005｜顾文珍**：他说书里没有，那可不只是喜不喜欢。

顾文珍把茶杯放到自己一侧，杯底一声轻响结束抢话。玩家获得查看两张原纸的目标，而不是选谁说得对

<a id="qst-106-s001-k02"></a>

### QST-106-S001-K02 · 两张实际写了什么

玩家镜头局部查看，两张可反序阅读，纸张一直由各自读者压住一角；查看只记录文字，不转移持有权

**QST-106-L006｜屏幕文字**：《沿河慢车》：她把票留在抽屉里。她不出门，也不欠谁一趟旅行
**QST-106-L007｜屏幕文字**：《沿河慢车》：她终于去买票了。前面走得这么慢，末尾这一小步才让我想再读

诺拉将原先为拍封面留出的空位腾给两张说明纸，小满把“当天交页”的便签挪到自己面前

**QST-106-L008｜诺拉**：别先把谁那张压到下面。去找他们实际借的那两本。
**QST-106-L009｜月城玲**：先看借到的是哪一版，再比那几行。
**QST-106-L010｜月城曜**：封面看着一样，也先别拿今天这本替他们读过的作证。

最后两句按是否已察觉版本问题互斥。玩家可退出，原书签分别留在读者手边；小满保留已读文字，重来不要求再挑谁可信。出口：小满带可公开的借阅版本记录，兄妹随她去旧书交换屋 S002

<a id="qst-106-s002"></a>

## QST-106-S002 · 纸张颜色不同的地方

入口：旧书交换屋核对桌。小满按两位读者自己同意查看的书目记录取出两本《沿河慢车》，旧版放桌左，修订版放桌右，封面朝上。两位读者跟来，只核对自己的借阅；顾文珍与诺拉一同走到桌边，顾文珍坐靠旧版的一侧，诺拉把从公共茶台取来的两杯茶放在身后边柜。其他人的记录不出现在镜头里。曜站桌外，玲能从桌短边同时够到两本书

<a id="qst-106-s002-k01"></a>

### QST-106-S002-K01 · 相似封面不是完整来源

玩家镜头，操作“查看版次页”翻到两本书各自的说明位置。可先左后右或反向；只翻封面没有核实结尾。纸页有翻动声，颜色差异可见但不作为超自然提示

**QST-106-L011｜屏幕文字**：《沿河慢车》·旧版。以下末章保留本版文字
**QST-106-L012｜屏幕文字**：《沿河慢车》·修订版。末章离开前的行动已修订，请按本版正文阅读
**QST-106-L013｜小满**：你先找到这里了。把另一版也翻开，我不再让他们凭封面重讲一次。

如玩家尚未自行发现，小满只指书脊内侧给出观察方向，不报答案。两本版次取得后仍需实际翻至末章，进入 K02

<a id="qst-106-s002-k02"></a>

### QST-106-S002-K02 · 不是同一段话

玩家在两本末章放可移除对照条，玲手掌压住书页下角，不盖住文字。镜头可局部查看并退出至原站位，必须各自读到一段才建立两版差异

**QST-106-L014｜屏幕文字**：她将车票放进抽屉，把没吃完的早餐推回桌边。窗外又一班慢车经过，她没有起身
**QST-106-L015｜屏幕文字**：她擦净桌边的面包屑，走到售票口。轮到她时，她把要去的地方说了一遍，接过新买的票
**QST-106-L016｜修订版读者**：你那本真是这样。刚才说你没看完，我收回。

修订版读者先将自己的书向中间推，推到一半又扶住，不把道歉变成赠书；旧版读者看一眼对照条，才松开一直按住书页的指尖

<a id="qst-106-s002-k03"></a>

### QST-106-S002-K03 · 解释之后仍然不喜欢

玩家镜头，从桌短边同时看见两本。修订版读者把手指移到“新买的票”，说话重新快起来

**QST-106-L017｜修订版读者**：那作者后来也觉得她该走。总不能一直停在那儿吧。
**QST-106-L018｜旧版读者**：他改他的。我没欠她一趟旅行。
**QST-106-L019｜顾文珍**：我还是喜欢这一版。作者后来不喜欢，也不能替我不喜欢。

小满已经从口袋拿出准备写“误会解决”的笔，停在纸上方，最后只写下版本对应。诺拉把茶放在两本书中间，杯柄朝外，两位读者暂时都没伸手。沉默持续到小满把笔帽合上，不额外拉长等待

**QST-106-L020｜小满**：那我不能只写“大家终于读懂了”。先把哪一版放清，再留各自愿意说的话。

出口：两本依借用登记带往 MONO 的约定桌面，书签各归原作者，小满携版本对照记录。已核对结果永久保留，后续不会把评价争执再误认成记忆异常

<a id="qst-106-s003"></a>

## QST-106-S003 · 编辑不能替读者答应

入口：MONO 预约工作桌。诺拉已在约定时段开启辅助通道，遥的工作回应从通道传来，现实不出现她走进店里的镜头。小满坐在屏幕正前，兄妹在侧边，读者可看到送审的实际文字；两本小说、版本对照和两张书签分开摆。遥只获准看到这一页与提供的段落

<a id="qst-106-s003-k01"></a>

### QST-106-S003-K01 · 把说明放到会被读的地方

玩家镜头，诺拉调好阅读方向，按下发送当前页后移开手。声音位置来自桌面终端，环境音乐放低到能听清，但旁人的翻书仍可闻

**QST-106-L021｜诺拉**：这一页到了。两版对应放在旁边，你只看这页就好。
**QST-106-L022｜遥**：版次写在最下面，读到那里以前，他们已经替两位读者吵完一轮了。
**QST-106-L023｜小满**：挪上来就得撤一块封面。我答应朋友这次把那本放进去。
**QST-106-L024｜遥**：那是另一件要答复的事。这里要只剩一张书签，谁愿意让它代表自己？

玩家执行将两段版本说明移到对应书签上方，移动只改排版未获授权正文，不替读者作公开决定。版次位置可来回比较，确认后保留一个采用稿

<a id="qst-106-s003-k02"></a>

### QST-106-S003-K02 · 抽回来的纸

短镜在玩家把原句放入样张时触发，机位为桌角中近景，保留小满的编辑笔和旧版读者的手；禁移动和翻书，暂停、跳过可用。小满划掉“也不欠谁一趟旅行”，把纸递过去，旧版读者读到划痕，用两指抽回，纸边从她掌心退出

**QST-106-L025｜旧版读者**：我写的不是这一句。
**QST-106-L026｜小满**：是我删了。原句给你留着，愿不愿意放出去，你再定。

小满把笔横放在自己一侧，双手离开纸。镜头回玩家原位，跳过也只到书签已回本人、授权未定；不能因跳过判定同意

<a id="qst-106-s003-k03"></a>

### QST-106-S003-K03 · 原句和原纸分别归谁

玩家镜头，可执行“请本人确认原句”或“先归还私人书签”，这只是询问与归还，不是替本人选择同意。询问发生时旧版读者实际看完无删节呈现，按其最后决定进入允许或拒绝路径

**QST-106-L027｜屏幕文字**：请本人确认原句／先归还私人书签
**QST-106-L028｜旧版读者**：那就整句留着。纸给我，页上可以用这句。
**QST-106-L029｜旧版读者**：我这张放回书里。你们写版本说明就够了。
**QST-106-L030｜小满**：纸还是你的。我只留这句已经给你看过的字。
**QST-106-L031｜小满**：好，这格不替你补感想。

允许路线由小满当面复制原句、递出确认，原书签仍被读者夹回自己袋中另带的阅读本；拒绝路线没有复制授权正文，页面清除该意见，只保存版本事实与“本次未刊”工作结果。修订版读者把自己的纸推到样张旁，看见原句未改才点头

**QST-106-L032｜修订版读者**：我的可以放，别替我加“终于成熟”那种话。

两路线都到 K04。后续 QST-026 能取得版本说明及真实获准文字，绝不再从私人书里取回被拒书签

<a id="qst-106-s003-k04"></a>

### QST-106-S003-K04 · 少放一本自己喜欢的书

玩家镜头，执行“撤下本期封面位”后，小满将朋友荐书的小封面从版上揭起，撕到最后一角放慢，免得折坏；她把它放进随身工作夹的透明内袋，用空出来的位置排版次。拨通朋友的联系，镜头仍留在她和那一小块封面上

**QST-106-L033｜小满**：你那本这期放不下了。是我没先算清，想移到后续页；你不同意继续用封面，我就还你。
**QST-106-L034｜小满的荐书朋友**：那就下次吧。你把这次定好的先发来，我不想又等一张空页。

小满没有等到夸奖，手仍压着工作夹边，回一声后把夹子合上。遥在获准原句边留下两条实际批注，第二条指向保留的口语，拒绝旧版时则指向修订版的“走得这么慢”

**QST-106-L035｜屏幕文字**：两处情节分别注明版次；读者口语保留，不替他说成编辑腔
**QST-106-L036｜诺拉**：这句真不再润一下？
**QST-106-L037｜遥**：这是他写给一本书的话。他又没来应聘编辑。
**QST-106-L038｜小满**：我的那句也留着。我还是想推荐它，只是不能拿谁的话盖住谁。

出口：诺拉发回实际定稿范围，遥结束这次工作联系，终端不保持无限候问。样张由小满持有，私有书签归各自读者，两本流通书依登记仍待送回，转 S004

<a id="qst-106-s004"></a>

## QST-106-S004 · 下车以后吃什么

入口：平台阅读角，一段可以坐下翻页的普通休息。顾文珍坐在靠阴的一端，旧版读者和修订版读者各有自己的座位与书，彼此未换口味。玲整理包内纸张，诺拉把茶放到不碰书的位置；曜在栏边等她拿好东西

<a id="qst-106-s004-k01"></a>

### QST-106-S004-K01 · 不是小说里的票

玩家操作“递出空白纸”时，玲从包里抽出薄纸，刚要当书签递给顾文珍，纸边票夹示意露出来。QST-101 已试版时使用留下的样片；未开始或未到试版时只使用母亲交来的尺寸草图，不能凭本任务制造完成版型

**QST-106-L039｜屏幕文字**：口袋尺寸草图：票夹开口需露出便于取用的一段；待本人试穿确认
**QST-106-L040｜屏幕文字**：口袋试版样片：票夹露出长度按本人伸手取票确认；此片不作裁衣成品
**QST-106-L041｜月城玲**：拿错了。妈妈给我的尺寸草图，她还得自己试。
**QST-106-L042｜月城玲**：这是剩下的样片。她为拿票不卡手，换着动作试了好几回。

玲把纸转到图案朝上，顾文珍看完便递回，纸回玲包内不变成公用借阅书签。不同选口袋版本继承 QST-101，不在此镜重选

<a id="qst-106-s004-k02"></a>

### QST-106-S004-K02 · 不替结局再盖一次章

玩家镜头，顾文珍用自己的书签夹回旧版。玲坐到她旁边，先看一眼小说开头的早餐段落，再问，语气像随口聊天而非结题

**QST-106-L043｜月城玲**：要是接着写，你还想知道她什么事？
**QST-106-L044｜顾文珍**：她下车以后吃什么。前面写了那么多早餐，最后一页忽然不饿了。
**QST-106-L045｜修订版读者**：我觉得停在那里刚好。下车以后我自己想。
**QST-106-L046｜旧版读者**：我还想留在那张桌子边坐一会儿。

三人各翻自己那一页，没有轮流点头成为共识。茶声与远处脚步填在翻页间，不以煽情音乐替代各自仍在看的书

<a id="qst-106-s004-k03"></a>

### QST-106-S004-K03 · 记录理由或仅用原话

玩家镜头，沿用正文两种工作方式。选择写理由时，兄妹把当事人当面确认的理由另记在推荐卡，不替被拒公开的私人书签转述；选择原话时只留下 S003 已授权的文字

**QST-106-L047｜屏幕文字**：帮写各自愿意推荐的理由／只用本人已允许的原话
**QST-106-L048｜小满**：那每写完一句给本人看。说给我们听的，不自动就是要印的。
**QST-106-L049｜小满**：就用确认过的几行，私人那张别再追着要。
**QST-106-L050｜修订版读者**：可以写“我喜欢她把想去的地方真的说出口”。这句是我的。
**QST-106-L051｜旧版读者**：我的写“留在原处也还有下一天”。别接一句说我终于理解另一版了。
**QST-106-L052｜旧版读者**：我不用再写一条。这本让我带着读完就行。

追加必须由本人确认才入公开卡；此前拒绝者不会被“理由”选项绕过。两路在 S005 汇合。小满提出下一本的薄书，顾文珍还看手中旧版，修订版读者另取一本，两人没有定成统一书单

<a id="qst-106-s005"></a>

## QST-106-S005 · 页真的放上书架

入口：白页书店交页桌。小满手边有带版本说明的实际采用样张、已确认的意见及自己那一句短评；被拒书签不在桌上，诺拉跟来取已获准的版次说明副本。两本用于核对的流通书放在待还区，个人书由本人带走，不混为玩家拿走的两件库存

<a id="qst-106-s005-k01"></a>

### QST-106-S005-K01 · 哪一句印出来

玩家镜头，在最终样张核对版本标题与实际许可。共同版次说明与小满短评显示在页首与页尾；中间采用以下四个实印段落之一，依S003许可和S004记录方式互斥，制作组合规则不印到读者页面。小满把先前收进随身工作夹的荐书小封面放回白页书店自己的抽屉，供后续页使用
