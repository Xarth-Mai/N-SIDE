# 橱窗还差一点：完整制作脚本

[故事正文](../../../../player/story/daily/unfinished-window.md) · [共用写法](../script-format.md) · [正式台词](dialogue.csv)

预算沿用 35–55 分钟，来自实际试玩、比较反馈、完成一轮有信息变化的删改与真实展示；不靠反复失败、连续熬夜或等展期计时。默认操作玲，主角可亲自尝试原型；试玩者表演与主角操作分别记录，不强迫已经看懂的玩家先等风。原型操作以“放线准备—松开放飞—转向—收线落下”的动作意图描述，按键与实机演出尚待接入验证

| 顺序 | 场景 | 条件与结果 |
| --- | --- | --- |
| 1 | QST-103-S001 风没有等来 | 阿杰与首轮受邀试玩者独立停在起点 |
| 2 | QST-103-S002 真的按一次 | 玩家先懂或等待均成立；说明遮挡与反馈缺口分开确认 |
| 3 | QST-103-S003 那片最漂亮的屋顶 | 展期与劳动边界明确；苏弥选本轮可交付范围 |
| 4 | QST-103-S004 实际动手改 | 小关卡路线拆模型裁海报；制作展路线标范围撤邀请 |
| 5 | QST-103-S005 本轮展示 | 两路均实际交付；延期路线首展预约观众离开 |
| 6 | QST-103-S006 独自落下来 | 修订版陌生试玩者完成短版；延期路线在后来约定的试玩中完成 |
| 7 | QST-103-S007 橱窗再看一次 | 中断续接、两种成本、先后支线回应及小夹去向 |

角色为玲、苏弥、凯文、阿杰、安可、乔伊，以及互不代替的 CHR-047 首轮受邀试玩者、CHR-048 首展预约观众、CHR-049 修订版陌生试玩者。米娜不回城充当试用者。QST-002、QST-020、QST-027 均非必需前置；只在确实发生时触发相应回扣

<a id="qst-103-s001"></a>

## QST-103-S001 · 风一直没有来

入口：PLAYROOM 试玩桌，苏弥将当轮原型摆在显示屏前，阿杰坐操作器正中，首轮受邀试玩者站在门侧等下一轮；玲从入口来，安可靠桌另一侧看自己获准拍的演示片，凯文把屋顶模型放在屏幕侧边。苏弥知道起飞操作，阿杰与首轮受邀者都没看过操作示范；演示片从放飞以后才开始。模型挡住玲早先画的一部分起飞箭头

<a id="qst-103-s001-k01"></a>

### QST-103-S001-K01 · 先看见了宣传片

玩家镜头，靠近桌端可先看演示片或先看实际屏幕。选择片段时只播放被允许展示的短段：风筝沿玲画的长线越过凯文最费工的转角；视频结束在未完成的远屋顶，没有展示抵达操作。安可把进度条拖回开头一下，苏弥目光跟着她手指走

**QST-103-L001｜安可**：开头这一下一定有人愿意点开。
**QST-103-L002｜苏弥**：真的？我还留着后面那段。

不看视频的玩家直接观察 K02，之后可在 S003 看苏弥暂停的同一片段，不强制补看才理解问题

<a id="qst-103-s001-k02"></a>

### QST-103-S001-K02 · 第一双没动的手

玩家镜头，阿杰拇指停在操作器旁，画面角色攥着线，风的背景声持续、衣角在动，起飞状态却没有清楚变化。苏弥站在他斜后，不遮挡屏幕；她看他手，再看角色，忍住一次后开口

**QST-103-L003｜苏弥**：怎么还不走？
**QST-103-L004｜阿杰**：在等风。
**QST-103-L005｜苏弥**：风不是一直在吹吗？
**QST-103-L006｜阿杰**：那他怎么还攥着？

短接管从玩家面向屏幕的实际位置触发，只呈现角色攥线与阿杰静止拇指的对照近景，不将玩家角色移到椅子上。苏弥伸手想拿操作器，玲扶住椅背而不抢机器，她的目光转向正在等待的另一位受邀者

**QST-103-L007｜月城玲**：先让下一位自己试完。你刚才还没示范给他看。

交还控制时阿杰放下操作器起身，第二位受邀者从门侧走来就座；跳过只结束对照与换座，不写入主角已经操作或读懂

<a id="qst-103-s001-k03"></a>

### QST-103-S001-K03 · 第二个人停在同一处

玩家镜头，首轮受邀试玩者双手接操作器。阿杰站后方不解释，安可暂停手机视频，避免演示泄露操作。试玩者先左右看屏幕，轻动方向发现角色只偏身，随后放回拇指等风

**QST-103-L008｜首轮受邀试玩者**：是还没轮到我动吗？
**QST-103-L009｜苏弥**：现在就能。……先记这一下。

玲可“记下停顿位置”，实际写的是角色仍握线、输入后缺少可辨响应，不评价试玩者笨。首轮试玩者完成这一轮后把操作器平放桌上，向苏弥点头，从侧边空位退开，不再被改称“完全陌生的人”参与修订验收

**QST-103-L010｜屏幕文字**：首轮观察：两人都在起飞处等待；可操作状态与演出状态外观接近；未提供操作示范

出口：原型保持未修改，记录纸留玲手边。玩家可进入 S002 亲自试，也可先查看被模型遮住的图；不因旁观两个停顿就自动判定主角也曾等风

<a id="qst-103-s002"></a>

## QST-103-S002 · 不是把风筝画大一点

入口：同一试玩桌，操作器空出，玲站在椅后，苏弥在侧面留空间；阿杰站近门侧，首轮受邀者结束后已离开试玩位。凯文仍守着模型，安可将视频保持暂停。纸上箭头可能已被玩家注意到，但模型尚未挪开

<a id="qst-103-s002-k01"></a>

### QST-103-S002-K01 · 玩家真的尝试

玩家选择“坐下试玩”，玲拉开椅子、坐稳、双手接操作器，镜头以实际屏幕为主要观察面，保留退出交互。此处将输入交给原型：放线准备会轻动角色的手，松开完成放飞，转向让风筝越过近处转角，收线可落回已完成的落点；旧版对准备、可放手和成功落下缺少清楚的持续反馈，远屋顶还不能到达。屏幕不先用制作提示解释答案

若玩家已读懂并实际完成放飞，执行以下两句，不故意吞输入或强制停住

**QST-103-L011｜月城玲**：我看到手松了一下，就试着放开了。可是刚才那个变化太像一段动作播完。
**QST-103-L012｜苏弥**：你看的是手。他们看的是风。都记上。

若玩家只完成准备动作、尚未松手放飞便结束观察，执行下句，不播放 L011 的松手陈述

**QST-103-L079｜月城玲**：我看到他把线拉紧了，不过还不知道什么时候该松。

苏弥将这个位置记在准备之后，保持玩家真实输入结果，随后汇入 K02

若玩家主动停止尝试并选择“我在这里不知道该做什么”，记录其实际停止点，执行以下两句；不设必须等待多久才能过关

**QST-103-L013｜屏幕文字**：我在这里不知道该做什么
**QST-103-L014｜月城玲**：我以为还在播，手一直没敢松。
**QST-103-L015｜苏弥**：那就先记在起飞前，不替你算玩过了。

已放飞但在转向或落下停止时使用下句替代 L014，不能把其进度退回起飞处

**QST-103-L016｜月城玲**：我已经放起来了，这里却看不出刚才那一下有没有做成。

三路汇入 K02，保留尝试过程；不要求完成原型才允许提出修改意见

<a id="qst-103-s002-k02"></a>

### QST-103-S002-K02 · 把纸从模型后面拿出来

玩家镜头，退出试玩后玲将操作器放回桌面才起身。选择“查看起飞图”，可从桌侧看见被屋顶遮住的箭头尾部；已提前看见者直接接下面的处理，不重复惊讶。凯文取一只普通小夹，将说明卡固定到桌沿外侧，卡不再被模型挡住

**QST-103-L017｜凯文**：这张先离开屋顶。模型不能替你给人指按钮。
**QST-103-L018｜屏幕文字**：起飞：准备放线，再松手放飞；转弯后收线，在本轮落点结束
**QST-103-L019｜安可**：把这几步放进片头，会不会清楚一点？
**QST-103-L020｜苏弥**：片子能说清楚，可按下去那一下还是看不出来。

玩家执行“按说明再看一次反馈”，仅复查刚才有疑问的一个动作；已经确认缺口的玩家可直接对照原记录，不重复玩整关。输入发生，动作改变，但现有声画没有清楚表示成功；玲将“说明位置”与“操作反馈”写两行

**QST-103-L021｜屏幕文字**：图被挡：已移到桌沿；输入后反馈：仍不清楚，需要改原型

<a id="qst-103-s002-k03"></a>

### QST-103-S002-K03 · 他喜欢的那一次转弯

说明卡移出后，阿杰向苏弥示意再试，接过桌上操作器坐回椅子；这次按读到的说明放飞，先把风筝转过近角，在不清楚落点处停下回到起点；第二次他提前收线，落得太靠近起飞处；第三次绕过近角再收线，仍拿不准是否算结束。他每次都实际放下手再重新输入，玲可以在旁检查模型与记录，不被要求陪同重玩三遍。阿杰将操作器放回桌面，起身退回近门侧，苏弥这才接过

苏弥从桌面接过操作器，坐到阿杰先前的椅子上，在他停止的位置把手放下，不立刻飞到自己熟悉的终点。玩家镜头保持两人侧面，阿杰回到屏幕另一侧指近处转角

**QST-103-L022｜阿杰**：那边转弯我其实喜欢。我试了三次，就想知道后面有没有地方落下。
**QST-103-L023｜苏弥**：我还以为你要说没关系。
**QST-103-L024｜阿杰**：有关系。我还想再玩，得知道这一回到哪儿算结束。

出口：桌沿小夹继续夹说明，原型只完成问题定位，未凭谈话修好。乔伊从入口带着展览排期来，声音从实际门口进入，转入 S003；玩家离开时记录纸归苏弥保管，回来不重新安排两位已看过的试玩者装作第一次

<a id="qst-103-s003"></a>

## QST-103-S003 · 最漂亮的那片屋顶

入口：同桌稍后，乔伊站在桌端，把已有展期单展开，苏弥坐屏幕前，凯文站模型旁，安可与玲在另一侧。大家知道本轮反馈需改，苏弥还要做兼职，不能用不睡觉填平工时。展位属于已经约好的这轮安排，并非无限空置的私人房间

<a id="qst-103-s003-k01"></a>

### QST-103-S003-K01 · 日期先落在桌上

玩家镜头，可查看排期单与当前能抵达的模型范围。乔伊把纸压在未放食物的空处，食指落在本轮展示段，随后移到展后归还项

**QST-103-L025｜屏幕文字**：本轮展示：按原约布展与撤展；可玩内容需标明可完成范围；制作过程展示需清楚注明非完整试玩；另约试玩另排时段
**QST-103-L026｜乔伊**：场地这一轮已经排了。你要交哪一种，我现在就得按哪一种写。
**QST-103-L027｜苏弥**：我那天之前还有班。全部屋顶赶不完。

苏弥拖动视频停在最喜欢、却尚不能实际抵达的远转角，屏幕照亮她手背；玩家可看同一镜头与模型，桌边暂时只有原型风声，随后她自己按停声音，不以强制长沉默拖时长

<a id="qst-103-s003-k02"></a>

### QST-103-S003-K02 · 凯文没有马上动手

玩家触发“比较能交付的两种安排”后短接管，机位在模型侧中景，能见两人手和接缝。苏弥沿模型指到最后一片屋顶，凯文把底座稍转给她看连接位置，双手仍托住，不拆

**QST-103-L028｜苏弥**：这片能不能暂时卸下来？
**QST-103-L029｜凯文**：能。上星期你说的是，大家一定要走到这里。
**QST-103-L030｜苏弥**：以后还会用。
**QST-103-L031｜凯文**：这次展完，是不是又要我赶着装回去？
**QST-103-L032｜苏弥**：我不是说你白做了。
**QST-103-L033｜凯文**：我知道。你告诉我这次拆到哪儿。

苏弥拿笔圈出近处可完成的转角，把最费工的屋顶留在圈外。短接管到铅笔落纸即结束，回到玲桌边，跳过不能选择范围或拆模型

<a id="qst-103-s003-k03"></a>

### QST-103-S003-K03 · 两个都少了东西的交付

玩家将下面两份安排分别展开给苏弥比较，选择是提出本轮帮忙安排，最终由苏弥明确承担版本决定；界面不承诺某条路线能保住所有内容

**QST-103-L034｜屏幕文字**：建议按期交一个完整小关卡：删后半段，修清起飞、转向与落下
**QST-103-L035｜屏幕文字**：建议本轮做制作展示：撤下试玩邀请，另外约修订试玩
**QST-103-L036｜苏弥**：那这一轮到近处落点。我把后面拿掉，修好能真正玩完的这一段。
**QST-103-L037｜苏弥**：这轮先把制作过程交出去。我自己撤试玩邀请，改好以后另约，来不了的人也算这次没来。
**QST-103-L038｜乔伊**：我按你选的这一份排。这回之后的档期另说。

出口：确认前玩家可离开，苏弥仍面对未定的本轮安排，未裁海报、未撤邀请；确认后保存一个实际方案进入 S004，不通过后来重访反复切换来消除损失

<a id="qst-103-s004"></a>

## QST-103-S004 · 自己拆开的那一段

入口：FRAME 工作桌，展件从 PLAYROOM 由凯文与苏弥沿普通通道搬来，模型底座平放软垫。玲带原海报与修改纸，苏弥的制作电脑与操作器放在不接触模型的另一端，安可保管演示片，乔伊已按选定方案安排展位。玩家不携整座易损模型跑图；进场时看见两人把实物落稳，知道搬运怎样完成

<a id="qst-103-s004-k01"></a>

### QST-103-S004-K01 · 按期小关卡：把屋顶装进盒子

条件：选小关卡。玩家镜头，苏弥请凯文指认接件；凯文只示范解开第一处，并托住底座，把工具柄朝她交出。苏弥接稳后自己沿标记拆剩余接点，另一手托住卸下片，不让它从半空折落

**QST-103-L039｜苏弥**：接件怎么拆你告诉我，剩下的我来。展后这一片先收着，不再算你的加班。
**QST-103-L040｜凯文**：先托底，再松这边。卸下的面朝上，别压那个角。

玩家选择“帮忙固定底座”后才触发拆件短接管，以工作桌同侧近景拍接点松开、片体受托、放入有衬垫的盒子三个连续动作；允许暂停或跳过至已安全收盒，不替玩家裁海报或修改原型。交回玲原站位，苏弥把接件装小袋放同盒，凯文写好盒签

**QST-103-L041｜屏幕文字**：本轮未展屋顶与接件；苏弥保管；未承诺重新装回日期

<a id="qst-103-s004-k02"></a>

### QST-103-S004-K02 · 按期小关卡：改画真正到得了的终点

玩家镜头，玲将原海报长风筝线描在透明对照纸上，操作“把本轮终点改在近处”，线到近处落点便收尾；裁下最漂亮的远端图放进工作夹，不揉掉。安可把长版视频从本轮宣传清单移除，保留原文件

**QST-103-L042｜月城玲**：你还想留这段吗？
**QST-103-L043｜苏弥**：想。……但这次先别拿它当结尾。

玲完成实际改图后，盒中屋顶不再出现在本轮可玩范围与宣传结尾；苏弥把本轮范围纸摆到制作电脑旁，继续 K04 的实际修订与验证，再进入 S005-K01

<a id="qst-103-s004-k03"></a>

### QST-103-S004-K03 · 制作展示：保留模型也要标边界

条件：选制作展示。玩家镜头，苏弥不拆整件模型，亲自沿已经可玩的近段摆上范围条，把远端标为未来设想；凯文递已量好的纸条，不承诺追加制作。玲保留原图，但分别写明可玩草稿与未完成设想，不用漂亮远景伪装正式结尾

**QST-103-L044｜苏弥**：模型照现在这件展。你的制作到这里交完，下一次改不算进这次。
**QST-103-L045｜凯文**：好。标签别压住接缝，让人看得出它怎么做。
**QST-103-L046｜屏幕文字**：制作过程展示：近段为操作草稿，反馈仍在修订；远端屋顶为未完成设想；本轮不提供完整试玩
