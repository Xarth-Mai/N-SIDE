# 空着的一格：完整制作脚本

[故事正文](../../../../player/story/world/empty-planter.md) · [共用写法](../script-format.md) · [正式台词](dialogue.csv)

本任务主动游玩预算为 25–40 分钟，转场不以现实等待计时。以下镜头使用相对地标锁定构图与切换条件；自由操作段保留玩家机位，短接管仅完成已触发的表演，未操作的证据、选择和交付不会因跳过得到完成。台词阅读呈现由同目录 CSV 回填

## 阅读顺序与出演索引

- 初轮：S001-K01、K02 → S002 → S003 选择已可行安排 → S004 实际安置补种
- 较晚接取且初轮已由照料者完成：S001-K03 → S004 当前新一轮补种，不重做旧分配
- S005：后续剧情时段的实际生长重访

稳定角色身份：`CHR-001`、`CHR-002`、`CHR-019`、`CHR-024`、`CHR-030`、`CHR-033`、`CHR-056`；台词表使用这些身份，SYSTEM 仅为屏幕或纸件文字

| 场次 | 阅读位置与出演 |
| --- | --- |
| `QST-025-S001` 这格今天就是空的 | 曜、玲、艾玛、乔伊 |

| `QST-025-S005` 再来时才知道 | 玲、艾玛；乔伊、顾文珍在各自地点 |


<a id="qst-025-s001"></a>

## QST-025-S001 · 这格今天就是空的

入口：第四章局部输出已处理，损失早已发生，上次取消领取的通知也已送达。四季温室可用工作区，玲操作，曜在工具架旁，艾玛清洗空盘，乔伊按改约时间到场。初轮本场摆放六盘确认可安置的现存苗：三盘属于同一连续观察小组，另三盘可单独用于入口布置；受损空盘与本轮六盘分区，不用后来长出的苗冒充原株。较晚接取而初轮已分配者使用 K03，不将苗搬回温室重演

<a id="qst-025-s001-k01"></a>

### QST-025-S001-K01 · 没看漏的空盘

玩家镜头，自由查看苗、旧牌与清洗区。玲打开颜料盒，先在纸上描一整排叶片轮廓，目光停在架尾空格；艾玛双手托着刚洗好的空盘，甩去外侧水珠，放到原空位，再将盘底轻推到齐线处

**QST-025-L001｜玲**：这一格还等哪一盘？我先把轮廓留出来。

**QST-025-L002｜艾玛**：这格今天就是空的，你没看漏。

玩家逐盘将现存标签与实物对照。缺少实物的旧牌移到“上一轮”夹板，不换贴到相似的新苗上；艾玛在旁重新擦已经擦净的盆，直到玲把不对应的牌放到她面前才停手

**QST-025-L003｜屏幕文字**：上一轮领取：已通知取消。本轮现存苗重新确认去向。空盘保留原记录，不记作已恢复。

<a id="qst-025-s001-k02"></a>

### QST-025-S001-K02 · 车不是又白来一趟

乔伊将空推车停在不挡浇水通道的位置，先看艾玛留下的改约通知，再看待确认的六盘。玩家将三盘观察组与另三盘分开，乔伊伸手去托一盘，看到还没有接手标签便将手放回车把

**QST-025-L004｜乔伊**：上次取消的通知我收到了。今天这一轮能拿多少，我得告诉他们，别又空出一个下午。

**QST-025-L005｜艾玛**：我列出来。能交的、要补种的，还有这一轮不再约领取的，都分开说。

玩家读完本轮盘数与用途后，可随乔伊去屋顶，或先查看顾文珍带来的观察本；两处信息均需实际比较才形成分配，跑到屋顶本身不算取得照料条件

<a id="qst-025-s001-k03"></a>

### QST-025-S001-K03 · 来晚了，先看已经做过的

仅初轮安置已由照料者完成时，温室玩家镜头显示真实空架与已签接手记录；乔伊不再带空车索要已交苗，六盘中的原去向不改变。艾玛拿来下一轮确有需要的补种盘和种子，邀请玩家参与当前这批

**QST-025-L006｜艾玛**：前一批已经送到各自接手的人那里了。这次要补的是这盘，先看新的记录。

**QST-025-L007｜玲**：那旧图不重画成起点。我把已经安置的留下，再补今天这一栏。

此路线保留阅读已确认照料条件的入口，跳过 S002、S003 的首次争执与重新选分配，进入 S004 的当前补种和记录；若玩家只是中途离开后回来，则从自己未完成的原操作续接，不误判为另一期

<a id="qst-025-s002"></a>

## QST-025-S002 · 两种不能互换的需要

入口：屋顶公园公共种植区，乔伊指入口侧已规划但尚未恢复的小片区域，不占通道；顾文珍带观察本在边上等共同核对，罗宾带当前环境记录，兄妹从正常公共路线到场。之后到林缘自然观察庭比较旧观察组的位置和取水路线，不新增临时建筑

<a id="qst-025-s002-k01"></a>

### QST-025-S002-K01 · 入口原来画满了一片

玩家镜头，玲将乔伊原布置图与眼前容器逐一对照。图上六个苗位连成一片，现场可先恢复其中三个；玩家可走过旁边通道，看见少放植物不会挡住通行，也不会让原先布置自动补齐

**QST-025-L008｜乔伊**：我可以缩小，但不能再挂一个没有日期的“即将恢复”。已经留时间来照料的人，还得知道这次做哪一片。

**QST-025-L009｜屏幕文字**：入口本轮布置：待确认数量。照料者只承接已经写入本轮表的范围，未安排部分不另贴恢复承诺。

<a id="qst-025-s002-k02"></a>

### QST-025-S002-K02 · 同样大小不是同一组

玩家打开顾文珍的观察本，三盘的叶缘形状与旧图对应，每盘原牌留有各自记号。玲从屋顶布置纸上剪出六个小格，想左右各放一些；玩家试把观察组三格拆开时，记录仍显示“同组连续对照被拆分”，不把平均数量判断为正确答案

**QST-025-L010｜顾文珍**：他们下一次来，是接着看这几株。换三盆差不多的，前面的图就不能当作同一组往下接。

**QST-025-L011｜玲**：我刚才只数了几盘，没看哪几盘。

<a id="qst-025-s002-k03"></a>

### QST-025-S002-K03 · 表上空的一格没有人

玩家镜头沿两处现有取水、遮挡和交班位置观察。罗宾将当下光照、风雨与用水记录摆在每处查看点；只排除不适宜的放置位，不宣称一定发芽。乔伊与顾文珍分别在自己的时段栏确认接手，艾玛想把空时段写成自己补位

**QST-025-L012｜罗宾**：这里能放、那里要避开直吹。记录能说明这些，不能替你们变出一个浇水的人。

**QST-025-L013｜艾玛**：那就先从我的这边减。我早一点过来，也许能顾到——

**QST-025-L014｜乔伊**：哪一天？你把温室那一栏也放旁边看。

玩家对照后，艾玛收回准备加班的笔，把已有温室职责保持原位。顾文珍将观察数量缩为本轮连续组，不要求把所有旧植物恢复

**QST-025-L015｜顾文珍**：我挑需要连续留下的这一组。剩下的，你别替我们都许了。

出口：两处空间条件、照料可用时间与连续观察用途均已实际查看后进入 S003。任何时候可离开，已读记录保留；未获得的记录可在原查看点续看，角色不会因玩家步行慢而让植物死亡

<a id="qst-025-s003"></a>

## QST-025-S003 · 推车这次装哪几盘

入口：回到温室分配台，六盘仍在原安全位置，桌上有屋顶图、观察本和已确认时段。玲操作，艾玛站在苗架一端，乔伊扶车，顾文珍留出可以接观察组的箱托。玩家提交可行安排，由实际照料者共同确认；没有单纯“全分两半所以都满意”的第三条路

<a id="qst-025-s003-k01"></a>

### QST-025-S003-K01 · 两张实际装车单

玩家可以切换两张已经满足照料条件的去向单，场景预览只显示将移哪些盘，不先搬动。每张单都清楚写下不保留的部分；未选择时仍可离开

**QST-025-L016｜屏幕文字**：保留连续观察组：三盘原观察苗送林缘，另三盘恢复屋顶较小范围。屋顶原六盘布置缩减，空出的范围本轮不补满。

**QST-025-L017｜屏幕文字**：优先屋顶本轮：六盘由已确认的屋顶照料者接手。林缘停止这一组原株的连续对照，保留旧页并新开补种记录。

玩家确认其中一张后，玲将对应苗牌夹到推车与箱托上，等艾玛、乔伊和顾文珍看清才锁定本轮搬运；选择不修改此前损失，方案确认之后只搬尚未搬的盘

<a id="qst-025-s003-k02"></a>

### QST-025-S003-K02 · 少掉的不会因为点头消失

方案一，短表演中景以乔伊原布置图为前景、她未装满的车为后景。乔伊沿旧图的外框看一遍，把多出的那半折到背后，用笔划出今天实际恢复的范围

**QST-025-L018｜乔伊**：入口就先到这条线。我去和约好来的人说，剩下那片这轮不排了。

**QST-025-L019｜顾文珍**：这三盘接着看。其他原定的观察，我也得跟他们说少了。

方案二，机位转到观察本近景，顾文珍在原组最后一页写去向，将新页翻到空白处；乔伊伸手准备拿盘，先等笔尖离纸才接

**QST-025-L020｜屏幕文字**：本组原株已转入屋顶照料，本处连续观察在此停止。后续补种另开新页，不与原株记录连算。

**QST-025-L021｜顾文珍**：以后再来看它们长成什么样，是另一份记录。这一本从这里换页。

**QST-025-L022｜乔伊**：我接这六盘。入口按这一轮做，后面的养护照刚才那张表。

共用出口：镜头回玲原站位。跳过仅收束当事人已经确认的回应，不替玩家移动苗盘、播种或完成通知。实际搬运进入 S004，已选择方案保存，读档不重新征求相反选项

<a id="qst-025-s004"></a>

## QST-025-S004 · 先种今天这一批

入口：已确认的交接位置，苗盘按选定路线逐批运送。玲操作，曜负责双手搬运较重托盘，接手者在各自位置。尚未运送的盘留温室，已安置的盘不回车；较晚接取者只展示这些既有位置，直接参与当前确需补种的空盘

<a id="qst-025-s004-k01"></a>

### QST-025-S004-K01 · 把盘放在有人照顾的位置

玩家在目的地对照苗牌与接手名单，先清出与方案相符的位置，再让曜把托盘落在稳固面上。玲托住盆侧，接手者扶另一侧，二人确认盆底完整承重才依次松手。方案一各送三盘；方案二六盘均到屋顶，林缘只接后续新播种记录，不生成一份原观察组副本

**QST-025-L023｜玲**：牌子这一面朝外。下次来的人先看见接手的是哪一批。

**QST-025-L024｜乔伊**：屋顶这一批收到了，照料表也在这里。不是等你们再来才浇水。

**QST-025-L025｜顾文珍**：这几株还是原来的。下一次的图从上一页继续。

签收按各目的地分别保存。中断在放置中间时，盘回到本次双方尚持有的安全承重点，不掉落损失；已完成的放置保留，只续未完成盘。任务不能靠离开制造新失株

<a id="qst-025-s004-k02"></a>

### QST-025-S004-K02 · 没有叶子的那一步

温室可用操作台的玩家镜头，艾玛把已洗空盘、土、种子和旧牌分开摆好。玩家按艾玛示范松土、落种、覆上薄层并浇本次所需的水；只有实际完成的盘写播种记录。新种子不是原株复活，原损失牌仍在旧夹板

**QST-025-L026｜艾玛**：这里先别加叶子，我还不知道会不会出。先把今天做的记下。

**QST-025-L027｜屏幕文字**：本轮补种已播下；日期随本次记录保存。原株损失保留。照料按本轮交接表继续，是否出苗下次实际观察再记。

日期显示使用本次剧情日的实际记录，不伪造现实系统日期或让跳过变成几周生长。艾玛将写好的牌插到本盘边缘，字面朝外，旧领取日期留在上一轮夹板

<a id="qst-025-s004-k03"></a>

### QST-025-S004-K03 · 把承诺逐条答完

玩家镜头。艾玛向本轮涉及的接手者分别确认：已交现存苗、已开始补种、这轮不再安排的领取。乔伊和顾文珍当面回复；受损苗盘认领者 CHR-056 已收过取消通知，本次通过正常电话确认新的范围，不再被告知一次仿佛刚发生的损失

**QST-025-L028｜艾玛**：原来那批没有了，上次已跟你说过。这一轮我先做了补种，现在没有一盘能按原来的样子给你。我不把出苗日期先许下来。

**QST-025-L029｜受损苗盘认领者**：我知道。我这次那块位置先另作安排，你有实际长出来的再联系，不用替我一直空着。

**QST-025-L030｜艾玛**：好，这轮领取先取消。下一次要不要，再按那时的情况问你。

所有答复均从实际交接记录产生，已回复项重入只查看记录，不再打同一通电话。跳过电话表演不自动安置和播种；只在玩家已核对并实际发起本次答复后记录这一条

<a id="qst-025-s004-k04"></a>

### QST-025-S004-K04 · 刮掉那排整齐的绿

玲可自由查看当前盘数后修改苗牌画。玩家将已画却无对应实物的叶片擦去，纸面露出擦改后的底色；笔尖经过空位时不自动补植物。短近景从纸边向空盘轻移，空盘与留白同时在画面内，完成动作后立刻回玩家机位

**QST-025-L031｜顾文珍**：下回来，再画那时候的。今天这一页已经写了不少。

**QST-025-L032｜玲**：这一格就这样留着。至少不是我先替它长好了。

出口：实际安置、首批补种、承诺答复和照料交接均已完成后结项。未做照片任务时不出现共同拍摄物；已获许可的照片只用于对应日期记录，不能把事前完整苗架照当作今天结果。未完成其中一步可自由离开，其余成果保存

<a id="qst-025-s005"></a>

## QST-025-S005 · 再来时才知道

入口：经过明确的后续剧情时段，非反复进出温室刷生长。玲自由来访，艾玛进行实际照料，场景读取当时新叶、未出苗和轮值情况。稳定初秋照常存在，日子和记录仍向前

<a id="qst-025-s005-k01"></a>

### QST-025-S005-K01 · 尚未出苗

尚未出苗分支，玩家查看原播种牌和当前空盘。艾玛移开挡住日期的小水壶，让玲看到是同一盘，再将壶放回取水处；不把土刨开强迫呈现种子变化

**QST-025-L033｜艾玛**：还没有。日期在这里，今天就记“未出苗”。我再按这一轮的安排看，不重种一遍给你看结果。

**QST-025-L034｜玲**：那这一格今天还是空的。我把日期往下接。

<a id="qst-025-s005-k02"></a>

### QST-025-S005-K02 · 新叶旁边仍空着

已经出苗分支，玩家观察新叶，艾玛用指背停在叶片外侧，不碰新芽，再转向仍未出苗的另一格

**QST-025-L035｜艾玛**：先看这里，新出来了。旁边还没动静，别一起画满。

**QST-025-L036｜玲**：一格一格画。这次多的，是今天真的看见的。

<a id="qst-025-s005-k03"></a>

### QST-025-S005-K03 · 各自继续

屋顶重访按方案一保留较小恢复范围，按方案二保留六盘实际接手范围；后来数量改变也使用真实照料记录，不机械展示六盘永不变化。林缘方案一续接原组观察，方案二从新播种页开始。玩家自由经过，路过的人仍能只坐一会儿而不被要求领任务

**QST-025-L037｜乔伊**：这一片就照我们确认的范围养。空着的那边有空着的用法，别又临时给我画上六盆新的。

**QST-025-L038｜顾文珍**：本子在这里。旧的到哪里、新的从哪里开始，都留得住。

离开与重复来访不重复奖励、不重做损失、不取消已交接照料；后续是否调整种植属于新的普通生活决定，本任务保持结束
