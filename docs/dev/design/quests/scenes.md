# 回声之后：人物场景样稿

完整故事与关系以[百科](../../../player/story/index.md)为准，场景中的「曜」「玲」分别指月城曜与月城玲。以下对白沿用正式角色命名，不补造法定姓名

以下十一段是场景剧本，覆盖每章的关键人物行动，并保留一段可选海报故事。分场中的操作与信息用于制作拆解，故事事实由相应百科正文维护；正式台词 ID、配音时长、镜头与交互位置在接入时确定

## 场景一：名字的位置

归属：QST-019／月台杂货橱窗；海报版本和报酬交谈

橱窗边。安可把海报举到脸旁，往后退了两步

安可： 这样呢？远一点是不是就看不清名字了？

玲： 看得清

安可： 那……记不记得住？

玲： 你已经问第三遍了，我肯定记得住

安可把海报放低一点，露出眼睛

安可： 我是说没见过我的人

玲接过海报，指了指边上的新歌名

玲： 那你希望他先记住你，还是先知道你这次唱什么？

安可张了张嘴，又看了一会儿

安可： 可以两个都要吗？

玲： 可以做两张。第二张另算

安可： ……你平时看起来没这么会做生意

## 场景二：照片外的人

顾文珍把完整底片翻到桌面，手指停在画面边缘

顾文珍： 这里这个人，是来换我的班

玲： 我以为您一直留到了最后

顾文珍： 我也待了很久。只是没那么久

她没有继续解释，先把快凉的茶递给陈知夏

陈知夏： 那后来呢？

顾文珍： 后来我回家。第二天再来

玲： 那这一页……

顾文珍： 你别急着划掉。我做过的那些事，也没有变成假的

玲把画往自己这边挪了挪，在旁边另放一张纸

玲： 我知道。我想给接班的人也留个位置

维恩： 原来那样找起来更方便

## 场景五：这一次不省略

悠真： 好听。那段有点长

## 场景七：下一趟

归属：QST-001／月台杂货工作台与货运侧院；先完成固定件核对，再处理配送小票

阿东在服务门边抬起一只空箱。曜夹着电话，腾出手将陈列架转向玲

曜： 差不多了，你先拿过去

巧克力把旧完成卡转向她。玲握住架子一侧，另一侧仍松着；她把架子放回工作台，让曜看见空出的固定孔

玲： 这个也算差不多吗？

曜按住电话，先接住架子

曜： 这边还没装。我来——

阿东指向旁边那箱约好取走的维修件。曜展开它们各自的检查单，又划出一件尚未完成的物件，留在工作台上

阿东： 我下一站要接唐惠的货。这一件是现在带走，还是下一趟？

玩家把卡与陈列架对应后，可以先协助装固定件，也可以将架子留在工作台；维修件依各自检查结果另行交接，不能靠一句“好了”同时勾掉店内陈列与对外配送

玲把旧卡移开，在新卡上留下已完成与待完成的两行。巧克力将阿东的小票放到旁边，没有跟着把待交付一栏划掉

曜： 下一趟。我确认完给你消息

阿东收回空箱，在自己的表上改了一行

阿东： 那我先走。台阶那边你们抄近路，我这车可过不去

离场：陈列架处理与配送预约分别留存；阿东照常出发，不因为玩家先逛街停在门口等整个序章

## 场景八：箱子还没有封

归属：QST-002／米娜房间；位于完整篇章的现实清点之后，不进入精简 Demo

已经隔离的柜背不再带动物件。玲拿着封箱带，看着米娜把一件旧玩具从箱里拿出来，又将另一件放回去

玲： 要不要给这一箱都拍一张？

米娜： 可以。但照片不用跟箱子一起走

曜看了一眼留在桌上的那件

曜： 这个带走？

米娜： 嗯。别的先放好。我新房间究竟能放多少东西，还不知道

玩家依她已作出的选择完成随身物与收纳物的清点；可先看照片或物件痕迹，不通过“留下越少越成长”的评分替她作决定

巧克力经已建立的联系显示待确认的寄送事项。玲要抄旧地址，米娜伸手压住纸角

米娜： 新的我安顿好再发你。现在寄，会比我先到，还不知道谁收

玲撕下尚未使用的地址纸，改把照片交给她挑

玲： 那等你的消息

离场：已带走、已收纳与尚未寄送分别成立；离城后由米娜主动提供今日需要与新收件方式，后续任务不能自动生成已经确认的地址

## 场景九：先别开录

归属：QST-003／AFTER 9；同一场内有调查段与核验后的澄清段，两段之间保留正文的潜梦及现实处置

安可站在空台前。还没唱，掌声已经从后排响起。悠真把手从调音台上拿开

悠真： 先别开录

安可： 我们先拍没有声音的那段？

悠真： 那段拍完，别人还是会以为这场录好了

玲没有接过安可的手机，先向贺佳确认停机与现场记录范围。玩家停止播放，对照本轮独立录音与构件振动；掌声在设备停止后仍出现，阿杰将工程问题的猜测留为已排查项

阿杰： 这里还有。不是从我们的工程里放出来的

贺佳： 这个空间先停用。下一场怎么安排，我们再谈

镜头转入调查与处理。旧声源隔离并完成场地核验后，安可重新拿起手机；预设动态还留着原来的标题

安可： 我写“设备出了点状况”，行吗？

悠真： 刚才有人已经记住是我放错了

安可删掉第一行，自己重新录一段

安可： 今天的试听改期。之前对录音的猜测不对，声音不是悠真混进工程的

她录完，没有让玲立刻换上“全新现场”的海报，先联系已订的餐食，说明到场人数与已备餐费用

离场：原因澄清、场地恢复、餐食结算与新歌完成分别处理；听见真实掌声也不能提前交付尚未录完的作品

## 场景十：另一头也在响

归属：QST-005／四季温室安全工作区与梦内庭院交替；本轮试验前已取得授权并约定停止条件

艾玛将受损的苗盘往内挪，玲伸手想把空架旁的旧苗牌拔掉

艾玛： 先留着。我还得知道哪一盘没救下来

玲将牌扶正。玩家先协助安置可保留的苗盘，再查看试验中的两个观察位置；选择不开始时保留调查，不触发偷偷运行的试验

曜入梦后按既定步骤暂时减弱一处活动。梦内温度的偏移缓下来，现实第一处读数也回落；另一观察点传来新的变化

罗宾： 另一边上去了。先停在这一步

曜： 这边已经降了。我再看一下返回的位置——

玲： 你能看见那一边吗？

曜抬头，庭院的墙挡住另一段通路。他停下，没有继续尝试第二个操作

曜： 看不见。按说好的停

塞拉确认现实端撤回临时操作，玲持续接应曜退出。试验前后记录并列留着，没有把受损苗木与另一点变化从结果中删掉

曜： 刚才我想把这里做完，就当这一片都好了

罗宾： 现在知道两头得一起看。下一次先把范围定出来

艾玛： 你们定范围。我先定这几盘今晚放哪儿

离场：单点下降不能推出全区改善；既有苗损仍在，新的照料安排由艾玛决定，[后续补种](../../../player/story/world/empty-planter.md)不会把损失倒写成试验前已经消失

## 场景十一：空着的第二格

归属：QST-009／合流场、月台杂货后场与渡口安全作业位交替；具体进入、阶段提交与中止以[十四个 Beat](QST-009/development.md)为准

入场：玲已打开梦内窗口；现实人员正在完成支撑与固定，尚未取得本阶段的两项独立确认

梦内。引座员转过身，候船队列暂时让开出口。熟悉的声音从通路后方传来

旧回放： 固定好了，回来吧

玲朝出口挪了一步，停下来核对本轮已收到的信息

玲： 第二项呢？

后场。巧克力把记录转给曜，只显示本轮已收到的构件位置确认，固定情况仍空着

巧克力屏幕： 还没有收到

曜抬手停在接应台上，没有取下妹妹的设备

曜： 收到，继续保持。现场完成后再发

玩家继续观察返回路径并维持可操作窗口；这里允许回避、重新调整站位或按预案中止，不能以按一次“相信哥哥”代替操作和核验

渡口。塞拉把第一项现场记录传回，固定检查由负责该项的专业人员独立完成。第二项检查完成、与本轮行动对应后，她才发送新的结果

塞拉： 第二项确认，固定完成。本轮记录一起发回

梦内。玲看见第二条返回路径已经停止把物件送回起点，继续保持通路，将当前观察报告给曜

玲： 这边没有再送回去，窗口还在

后场。曜核对接收路径、当轮标记、两项现场结果与玲刚报告的窗口，提交这一个处置阶段

曜： 这一处确认了。接着处理剩下的联系，最后再撤出

玲确认返回路径持续没有回送，再退离这一处，走向仍相连的通路；画面在这里不切到庆功，也不把出口出现当整场胜利

只有余下新增联系解除、现场复验与最终确认全部完成，才接正文的退出与喝水场景。若窗口或连接失效，切到预案中止，保留已完成阶段和未完成工作，稍后按恢复规格继续

## 接入与失败处理

- 对话进入前从所属任务读取当前事实与参与者状态；退出或跳过后把必需判断放回可查看的资料或交互，不依赖听完一句台词才能继续
- 照片、海报、工作表、书架、实物与完成卡、收纳箱、现场录音、苗牌和当轮确认是场景的具体操作对象。默认焦点、注视、可取消动作、键鼠／手柄返回按 UI 规格接入，具体镜头与时长待场景小样确认
- 两场涉及作品或照片的选择保留当事人的决定：选择海报不扩大无限修改范围；私人照片不能自动变成宣传图
- 联合梦境家务不改变遥的现实照护安排。巧克力为游戏内家庭角色，不调用真实外部 Agent
- 场景可跳过与重访后不得重复计算报酬、创建另一份作品或倒退交付；演出声画、字幕和保存恢复需另行实测
