# 晚场以后：完整制作脚本

[故事正文](../../../../player/story/daily/after-the-late-show.md) · [共用写法](../script-format.md) · [正式台词](dialogue.csv)

本篇主动游玩预算 10–20 分钟，沿用既有任务范围；下述场面是中文制作交付稿，预算、镜头与动作尚未经过实机或演员验证。远途移动、日历转场和已经完成的交接不重复计时，支线结果分别读取实际记录

## 阅读顺序与条件

进入条件：QST-003 的相关场地已经核验恢复，此处发生的是后来的普通晚场；错过时预约另一场已恢复的演出，不重演异常当晚。S001 散场 → S002 请求与借还选择 → S003 当夜归还或封存 → S004 确认到达 → S005 实际相聚 → S006 续接重访。获准次日归还者在相聚后回 S003-K05 完成真实归还；晚饭另约则按实际先后排序，借还与相聚都完成才结项

演员：兄妹、悠真、贺佳、唐惠、阿东、音频店接收员 CHR-061、悠真的晚场朋友 CHR-062。朋友与悠真有自己的聚餐和音乐话题；玩家可以不陪席。本轮耳机与 QST-020 的另一次借约分开，持有人、袋内转接线、封存和接收不因换任务而重置

F15 在 S001-K02 的“顺便”、S002-K02 具体请求与 S005 真正坐下回收；F23 经左右声道检查、明确接手和 S003 实际交还闭合，续借获准不是归还完成

## QST-107-S001 · 没扣上的箱子

入口：AFTER 9 普通晚场散后。贺佳在观众门内把场次牌翻到结束面，悠真站在后台器材桌旁绕线，冷饭盒放在箱子右侧，与线缆隔开；自用器材的箱盖未扣，借来的监听耳机与原袋放在桌左，转接线仍插着。朋友在门边向车站方向看，兄妹从已经散空的观众门返回，不假装在这一镜又听完整场演出

<a id="qst-107-s001-k01"></a>

### QST-107-S001-K01 · 他的话比肚子早一点

玩家镜头，能先看饭盒或耳机。查看饭盒时，玲拿手背靠近盒盖感温而不打开食物；悠真在收线时腾出拇指指饭盒，眼睛仍盯线圈

**QST-107-L001｜月城玲**：这盒你不是开场前买的吗？
**QST-107-L002｜悠真**：刚才不饿，收完再——

他的肚子响一声，手中线圈松出半圈。他低头重新绕回去，玲没有接一句责备，目光转向箱盖和耳机袋

<a id="qst-107-s001-k02"></a>

### QST-107-S001-K02 · 今天不是想独处

玩家镜头，朋友在门边把包背带拉到肩上，手仍扶着门，先开口而不自动留下等候

**QST-107-L003｜悠真的晚场朋友**：我们往车站走了，你来不来？
**QST-107-L004｜悠真**：你们先，我顺便把这个收了。

朋友点一下头，退到门外，脚步真往车站走；悠真等声音远了一点才抬头。贺佳把自用器材箱向库房方向转正，再把耳机袋放在另一边，没有将两件事一并塞给兄妹

**QST-107-L005｜贺佳**：你的箱子进库房。耳机借到今晚，店里还等着收。是两件事。
**QST-107-L006｜月城玲**：我以为你喜欢收完以后一个人坐一会儿。
**QST-107-L007｜悠真**：有时候是。今天不是。

他说完把线头扣入束带，终于把脸转向门口。出口：尚未有人接手耳机，玩家可继续检查 S002 或离开；离开不制造自动归还记录

**QST-107-L017｜悠真**：好。你们去，我到店后发消息。

**QST-107-L019｜悠真**：好，我先去还。饭要是赶不上，我自己改约。
**QST-107-L020｜贺佳**：我守场地收尾，你回来取自己的箱子。借的那一件先交清。

悠真把冷饭盒盖紧，放进自己的随身袋，再将耳机袋单独握在另一手，提袋离开；不把食品放进借用耳机袋。兄妹可跟去看交接或自行办事；无人接单不产生惩罚台词，后续从 S003-K02 读取悠真实际完成的一次归还，绝不再让兄妹重复归还

**QST-107-L022｜音频店接收员**：可以。今晚封好别再用，明天开门后交到柜台，仍算悠真这张借约。
