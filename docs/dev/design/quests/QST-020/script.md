# 还没写完的第二首：完整制作脚本

[故事正文](../../../../player/story/daily/unfinished-second-song.md) · [统一写法](../script-format.md) · [正式台词](dialogue.csv)

设计预算：30–45 分钟；动作、试听、路程与转场均包含在原预算内，实际时长待灰盒验证

出场：玲（当前操作）、曜、安可、悠真、苏弥、音频店接收员 CHR-061

场次阅读顺序：S001 受邀到场 → S002 两版盲听 → S003 站起来唱 → S004 废样上定工作 → S005 公开范围 → S006 归还、离场与重访

第五章后的预约试听。首演前讨论当前可交付版本，首演后讨论下一轮修订，已完成演出不倒退。Q019 的同一废样、Q103 的实际交付、Q107 的本次另借分别核对；未做支线有独立入口。《晚点见》两版共享主歌和收尾，只替换副歌；末次表演使用当次由安可与团队确认的版本，暂缓不等于自动选择第二版

控制通则：未明确标为短接管的镜头均由玩家控制，可暂停、查看与离开；近看文字后回到原站位。短接管只在对应交互已经发生后播放，暂停与跳过可用，期间停用移动、切人及其他交互；跳过仅落定该次已经触发的表演，保留未做的观察、选择、交接与操作。所有镜头以可见动作或对白结束为切换点，建议节拍不作为已测时间
