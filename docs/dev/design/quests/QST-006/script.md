# 第五章 · 仍在一起：完整制作脚本

[故事正文](../../../../player/story/main/still-together.md) · [共用写法](../script-format.md) · [正式台词](dialogue.csv)

阅读顺序：S001 MONO 编辑工作 → S002 预约与授权 → S003 历史范围比较 → S004 纠正摘要 → S005 受邀家务 → S006 结束访问 → S007 家庭饭桌 → S008 当前问题；S009 为条件重访。对应[分场纲](../campaign-sequences.md#第五章-仍在一起)八场，整章设计预算 60–90 分钟，以调查比较和短生活动作推进，不把纸面字数折算为通关实测

主要演员：玲 CHR-002、曜 CHR-001、安可 CHR-036、诺拉 CHR-025、维恩 CHR-006、遥 CHR-007、月城修 CHR-004、陈美惠 CHR-005。只有 S005 的授权住家访问由玲潜梦，曜留在现实；维恩作为原有联合梦境参与者另行接入。遥的现实照护始终在街区外，MONO 与共享工作室不是她的病房或无人监护的替代设施

前提：第四章相互影响结果已取得，用于旧方法范围比较；原始源头已终止、遥真实参与已有独立验证，均不是本章等待揭晓的反转。QST-106 阅读支线和 QST-024 家庭史可先完成，也可未做；相应镜头只引用实际已授权和已发生的内容。拒绝额外私人材料不降低主线成功条件

<a id="qst-006-s001"></a>

## QST-006-S001 · 这句话是谁说的

入口：已约的白天创作时段，MONO 的公共工作桌，玲坐靠窗一端摊小册稿，安可坐其旁却把自己的歌词页横放，诺拉在远程交流设备侧。遥通过获准的辅助远程通道参与，画面只显示本次交流界面与她同意的呈现，不窥看街区外照护环境。曜稍后带技术资料到共享工作室，不因人物齐全而硬塞进此场

<a id="qst-006-s001-k01"></a>

### QST-006-S001-K01 · 先处理眼前的词

触发：玩家把本次小册稿放到共同查看区

玩家镜头，操作玲。她将边角卷起的页压平，安可先把歌词纸向自己拉一点，留出给小册的区域。遥的标记落在原文一处，玩家选择查看后呈现原句和编辑替换，镜头不强制切成历史说明片

**QST-006-L001｜屏幕文字**：小册原稿：旧日不再的温柔角落／遥的改稿：每天有人用它等朋友
**QST-006-L002｜遥**：这个角落现在谁还在用？你画的椅子上，不是坐着人吗？
**QST-006-L003｜月城玲**：我再把今天在这里做什么写清楚

玲把原句划一条线而非擦到不留痕，在边上补记当前用途；没有完成编辑就不能把页面显示为遥已认可

<a id="qst-006-s001-k02"></a>

### QST-006-S001-K02 · 留下她写自己的那一句

触发：安可将新歌介绍推入本次讨论范围

玩家镜头局部查看，安可用掌缘挡住仍在改的副歌页，只公开这两句介绍。遥的光标停在第一句后，安可先把椅子向桌前挪半步，手指压住歌词页角

**QST-006-L004｜屏幕文字**：介绍候选｜安可终于成为真正的自己；悠真也终于不再怀念从前的她
**QST-006-L005｜遥**：“终于成为真正的自己”，是谁说的？
**QST-006-L006｜安可**：我自己写的
**QST-006-L007｜遥**：以前唱那些歌的人算谁？
**QST-006-L008｜安可**：以前也是我。这次就是想这么唱

遥的标记在第一句旁留下一个问号，光标向下移动；玲原本抬起的笔停在空白边，没有替安可删第一句

<a id="qst-006-s001-k03"></a>

### QST-006-S001-K03 · 划去的只有代别人说的话

触发：本次讨论移到介绍第二句

短演出接管，桌面斜近景保留安可握笔和玲空着的批注栏；禁移动与改写他人稿，允许暂停或跳过至第二句被安可划去、第一句及问号仍在

**QST-006-L009｜遥**：下一句，悠真这样说过吗？
**QST-006-L010｜安可**：没有。这句是我替他写的，删这句

安可从“悠真”起划到句尾，笔尖越过纸边才抬起；她把剩下的第一句转回自己面前，折起遮住副歌的另一张纸。玲将自己的笔放下，望了遥的光标一眼，见它已移向新的错字，才继续记自己的修改

**QST-006-L011｜月城玲**：那这一句先按你自己的介绍留着
**QST-006-L012｜安可**：嗯。等唱出来你再说喜不喜欢

镜头回玲原座位，玩家可读编辑后版本；跳过不自动选择副歌、确定新歌版本或批准过期宣传

<a id="qst-006-s001-k04"></a>

### QST-006-S001-K04 · 批注也有熟悉与初见

触发：本次稿件意见已保存，按 QST-106 是否实际完成读取互斥台词

玩家镜头。已完成阅读支线且保有授权样张时，玲把自己确实获准保留的那份版次说明放在本次稿旁，不重新取回被读者拒绝公开的书签

**QST-006-L013｜月城玲**：上次读书那页也是这样。一处要写具体，一处您又让原话留着
**QST-006-L014｜遥**：因为那是他说的话。这句是不是你写的，得先分清

未完成 QST-106 时，玲只看自己本次页上的两种批注，不伪称参加过阅读会

**QST-006-L015｜月城玲**：这里您让我改得具体，这里又留下原来的语气
**QST-006-L016｜遥**：该说明白的说明白。人说话也不必都长得一样

两路汇入本场出口：诺拉收起公共交流界面，玲保管自己的改稿，安可带走介绍与歌词。历史会谈另按 S002 准备，安可不因为参与创作讨论自动获悉遥全部病程

<a id="qst-006-s002"></a>

## QST-006-S002 · 能谈的桌面，和关着的抽屉

入口：约定的共享工作室，维恩从入口带来授权资料袋，曜在桌外侧放下第四章记录，玲将小册夹放到自己椅边，诺拉核对会谈安排。社区诊所协助的本地现实沟通与正规转介已经体现在确认材料中，不安排角色去诊所寻找遥本人

<a id="qst-006-s002-k01"></a>

### QST-006-S002-K01 · 把问题放在前面

触发：玩家将本次问题与获准资料对照

玩家镜头，操作玲。维恩把封口朝自己的私人材料袋留在腿边，只抽出已授权的工作图、摘要与历史简报；曜将温室双端记录放在桌面另一半。诺拉指向一张已答复的会面卡，玩家实际查看本次范围

**QST-006-L017｜屏幕文字**：本次会谈｜可比较：公开历史结论、获准工作图、验证与终止摘要、当前观察；不包含：全部私人交流、病程细节、未授权第三方记录／住家访问另需双方确认和当次连接核验
**QST-006-L018｜维恩**：这些能给你们比较。其他署名人的材料，我不能因为认得他们就一并交出来
**QST-006-L019｜月城曜**：今天主要问，这条旧边界到哪里为止

<a id="qst-006-s002-k02"></a>

### QST-006-S002-K02 · 不从私人生活里凑答案

触发：玩家查看资料范围中的未授权部分

玩家镜头，未授权材料只显示类别与未开放状态，没有“说服到同意”的隐藏任务。玲的手停在桌面边缘，收回后把问号写到今日现场图上；维恩没有把私人袋递出

**QST-006-L020｜月城玲**：这部分不看。今天能在现场重新量的，我们回现场取
**QST-006-L021｜维恩**：好。已提供的足够比较旧方法，不足以替你们画出今天的整张图

本镜是明确拒绝追加私人内容的既有边界，读到或不点开类别都可继续；不扣资料收集完成度，不生成关系惩罚

<a id="qst-006-s002-k03"></a>

### QST-006-S002-K03 · 来访也可以改约

触发：当次资料会谈已准备，尚未启动住家连接

玩家镜头，诺拉把两个时段区分在同一日程页，不能选择“直接入梦”绕开当事人答复。正常继续者先进入 S003 资料工作；玩家离开或选择延期访问时可见明确选项

**QST-006-L022｜屏幕文字**：先完成本次资料比较，住家访问另约
**QST-006-L023｜屏幕文字**：按已确认安排继续，访问前再核对连接

选择延期时，玲将私人访问提醒从当前格移到待双方确认栏，不改遥其他已约稿件

**QST-006-L024｜月城玲**：家里的来访另约。我先把这几份资料对完
**QST-006-L025｜遥**：可以。下一次时间定下来再来，别把我的晚饭先划掉

遥通过已建立的本次交流通道答复后结束该段辅助交流；后续访问用新的双方确认启动，不靠现实倒计时等待，也不撤销已完成的资料比较。任一路都需 S003、S004 完成当前判断才进入 S005

出口：公开与授权材料在工作台，本人未开放部分仍由维恩带回；住家预约状态与资料进度分开。中断会谈保留已经对照的记录，回到桌边从尚未核实的页继续，不重问遥是否真实

<a id="qst-006-s003"></a>

## QST-006-S003 · 旧图没有画到这里

入口：同一次共享工作室资料会谈，桌上三类材料分开，维恩坐授权图纸侧，曜在当前测量侧，玲居中操作透明复制件；遥按约远程参与后续自己记录的比较，不能在这里以本人知识覆盖全城未知区域

<a id="qst-006-s003-k01"></a>

### QST-006-S003-K01 · 三个完成标记不能叠成一个

触发：玩家查看历史资料并排列先后

玩家镜头局部查看，三份文件各有事件名称与已有相对时间依据，不补造未设定的公历日期。玩家依据资料将停止扩张、独立验证、实际终止分别放到时间线上；错误把前两项合并时，盖章文本仍分属于不同记录，玩家可重新展开，不播放无依据的专家总结

**QST-006-L026｜屏幕文字**：公开历史简报｜大规模连接达到新的稳定边界后停止向外扩张；停止扩张不是源头终止，局部救助与隔离另行进行
**QST-006-L027｜屏幕文字**：独立验证摘要｜维恩与既有共享环境无法提前接触的新信息由独立渠道提供；遥在随后交互中主动使用，记录与重复核对确认真实共梦
**QST-006-L028｜屏幕文字**：源头终止记录｜独立验证完成之后，旧日回放的维持结构与正常共同生活分开，原始梦魇被实际终止；获得本地条件的城市局部另行处理

已在第二章看过简报者不重新走“发现源头已终止”的演出，曜直接把那份记录归入已知栏

**QST-006-L029｜月城曜**：终止这件事我们已经看过。今天查它当时处理到哪儿

首次完整核验历史次序者在排好后由玲说下一句，不使用惊吓反转镜头

**QST-006-L030｜月城玲**：先停止扩张，再验证，后来才终止源头。是三段工作

<a id="qst-006-s003-k02"></a>

### QST-006-S003-K02 · 完成的是这一组

触发：历史先后已经核验，玩家打开终止前后观测与工作图

玩家镜头。曜沿盖有完成记录的旧图追一条线，食指移到纸边时继续朝温室图靠近，途中却隔着未覆盖的空白。维恩从下面抽出更早工作图，按住测量真正停止的位置，玲将两份图角对齐

**QST-006-L031｜维恩**：那次解决的是这一组，不是往后所有地方
**QST-006-L032｜月城玲**：中间这块，当时测过吗？
**QST-006-L033｜维恩**：这份工作图没有走到那里。我不能拿后来的空白替当年作答

玩家分别查看“处理前有原输出”“处理后该范围未再出现原输出”的观测，才将已完成标记限定在该组；不能将盖章文件整体缩放成城市永久安全地图

<a id="qst-006-s003-k03"></a>

### QST-006-S003-K03 · 今天的线从纸外露出来

触发：旧图有效范围已确认，玩家叠加第四章当前测量

玩家镜头局部操作。玲将透明复制件覆盖到旧图，先按实际共有地标对齐，再向旁边错开，让新增联系露在旧测量边缘之外。玩家可以先检查今日范围再回看旧图，不强制隐藏已经看懂的交叉部分

**QST-006-L034｜月城玲**：今天这一段在旧边界外。不能因为旧图没有，就当它现在也没有
**QST-006-L035｜月城曜**：能找谁补？

维恩翻到获准来源页，沿署名逐项核对，再把不在自己授权内的部分合回封套

**QST-006-L036｜维恩**：我能比较我做过的这些。有些人调走、退休了，有些材料不在我的范围里。现在的岸线，你们要找现在维护它的人

<a id="qst-006-s003-k04"></a>

### QST-006-S003-K04 · 把空白交回现场

触发：玩家整理旧方法可用部分与今日缺项

玩家镜头，曜在当前问题卡上写下渡运、地形与材料接触，玲将旧图复制件收入“方法参照”夹，原件交回维恩。已经对齐的观察留在本次工作台副本，不占用对方全部私人资料

**QST-006-L037｜屏幕文字**：下一步比较｜沿用：选择性分离已确认关系的方法；需重建：当前渡运、水位、岸线材料接触与有效路径；旧图空白不等于无活动

出口：旧范围与当前缺项已经由玩家实际比较，维恩没有给出一键解决图。缺项带向第六章，接着 S004 核对摘要中与遥生活有关的一处错误归类；未读取的私人材料不作为该核对前提

## QST-006-S004 · 那天有一份新稿

入口：共享工作室同一桌，遥在获准远程界面中查看属于自己的摘要，维恩把授权验证材料放在可比较位置，玲操作两份复制件；曜将当前城市输出记录保持在桌角，不自动将正常生活对应到有害输出

<a id="qst-006-s004-k01"></a>

### QST-006-S004-K01 · 不是再问一次真假

触发：玩家翻到整理摘要中被归入早年回放的一段生活记录

玩家镜头，摘要上能看到整理者的分类和原记录相对验证事件的时间位置。遥的标记先圈住分类，不圈自己的名字；她停到玲把原始记录调出来才继续

**QST-006-L038｜屏幕文字**：后编摘要条目｜分类：早年回放／附注原始记录：发生于独立验证完成之后，含当次新稿修改往来／分类与原始时间及交互待核对
**QST-006-L039｜遥**：这段为什么放进回放？那天我刚退了一份新稿，前一次根本没有这几页
**QST-006-L040｜月城玲**：我把原始时间和测试摘要并排

<a id="qst-006-s004-k02"></a>

### QST-006-S004-K02 · 新内容有自己的来源

触发：玩家对照授权原记录、独立验证材料及遥指出的改稿节点

玩家镜头局部查看。玲按顺序打开来源页，维恩只在自己做过的记录旁停手；当前材料显示验证条件与新交互足以更正摘要，没有要求玩家再“测试”遥回答一个秘密问题

**QST-006-L041｜屏幕文字**：授权比较摘录｜该条晚于独立验证；当次收到新稿并作新批注，往来可与原始交互记录对应／应改列为后续真实共同生活；原摘要分类保留为已更正历史
**QST-006-L042｜维恩**：原始记录在这里。是整理时沿用了旧类别，不是验证被推翻了
**QST-006-L043｜遥**：把那份稿还给它自己的那一天就行。别再从我第一次看书讲起

玩家确认更正，摘要原分类用删线保留，更正理由与来源并列；只读遥的一句说明不足以自动通过三份来源比较

<a id="qst-006-s004-k03"></a>

### QST-006-S004-K03 · 城里那张表要另外读

触发：摘要更正与当前输出记录均已查看

玩家镜头。曜把城市输出图从私人生活复制件下抽出来，两张纸不再相压；玲指向当前有害输出的本地路径，手指停在未测处，没有画线连向遥的住家

**QST-006-L044｜月城曜**：当前有害活动没有从你们的共同生活传来。要补的是这些本地结构之间的路
**QST-006-L045｜维恩**：就按当前观察继续。我们的家不是替所有空白预留的答案

出口：本章得到授权且足够的活动比较特征，错误摘要已更正，真实共梦的既有事实保持。随后 S005 进入已单独确认的普通来访；延期者可在双方新的可用时段续接，不重复更正摘要或索取更多私人对话
