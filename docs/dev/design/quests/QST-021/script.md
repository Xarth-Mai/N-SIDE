# 借你一把伞：完整制作脚本

[故事正文](../../../../player/story/daily/lend-you-an-umbrella.md) · [统一写法](../script-format.md) · [正式台词](dialogue.csv)

设计预算：8–15 分钟；动作、试听、路程与转场均包含在原预算内，实际时长待灰盒验证

出场：玲（当前操作）、曜、塞拉、巧克力；电话中的值班同事 CHR-060

场次阅读顺序：S001 伞架 → S002 试开与交接 → S003 借伞同行／等雨 → S004 吃到的点心 → S005 归还与普通重访

第四章后一次正常雨天，塞拉已经下班。若当前正有不可离开的紧急工作，改约下一次普通雨天，不把散步插入处置窗口。Q101 已改外套才谈实际取票经验；Q008 已完成才回顾那次分工。借伞与等雨是互斥事实，只有借伞路径出现借出与归还

控制通则：未明确标为短接管的镜头均由玩家控制，可暂停、查看与离开；近看文字后回到原站位。短接管只在对应交互已经发生后播放，暂停与跳过可用，期间停用移动、切人及其他交互；跳过仅落定该次已经触发的表演，保留未做的观察、选择、交接与操作。所有镜头以可见动作或对白结束为切换点，建议节拍不作为已测时间

## QST-021-S001 · 雨还差半条街

入口：月台杂货傍晚，塞拉在门内伞架侧，手机在外套口袋；玲在结账台外侧，曜在后侧工作桌收一件今天无人等着交付的小工具，巧克力在门与借伞架之间。新伞有零售价签，借用伞另有借还牌；门外已有细雨，店门保持可通行

<a id="qst-021-s001-k01"></a>

### QST-021-S001-K01 · 价格和路程

玩家镜头。塞拉拿起新伞，看价签，再透过门看向 N站方向，拇指沿伞柄转半圈后挂回去。她让过进门顾客，仍没有离开；玲问话时离她一个伞架，不从背后突然拍肩

**QST-021-L001｜玲**：你很急吗？

**QST-021-L002｜塞拉**：不算。走到车站前应该会更大。家里又没地方放了。

**QST-021-L003｜曜**：借店里的吧。等我拿一下。

<a id="qst-021-s001-k02"></a>

### QST-021-S001-K02 · 借还牌上的旧线

玩家镜头。曜把伞柄朝塞拉递出，但手仍托着收束带，等她接稳才放；塞拉没有直接带走，沿伞骨看见一处异色补线，将伞身转给玲。玩家可先看借还牌、先看补线或先看雨，已先发现线迹就直接问，不要求角色再“才发现”一次

**QST-021-L004｜屏幕文字**：店用借伞：先试开合；当面登记借用；晾干后按约送回。若有磨损，请交还时指出。

**QST-021-L005｜塞拉**：这个修得很明显。

**QST-021-L006｜曜**：因为后来换了线。不是后来没下雨。

出口：借伞仍属店用，未登记、未离店；塞拉持柄，曜托收束带的手已放开。她走到店外不挡门的雨棚边试开，玲随行到边侧，进 S002；中断时伞搁在借用架试用位，不会产生借出记录

<a id="qst-021-s002"></a>

## QST-021-S002 · 那道线只负责这一处

入口：月台杂货门外雨棚边，塞拉站远离门扇的一侧，伞尖向下且不朝行人；曜面对补线侧，玲在两人侧后，巧克力留门内。雨棚只是当前普通店前遮雨处，不拿终章已拆的河岸檐段当作完整旧物

<a id="qst-021-s002-k01"></a>

### QST-021-S002-K01 · 看清好不好用

玩家镜头。目标是观察一次开合与补线受力。塞拉确认周围没人，推开伞；曜只在伞已撑开后按住修补接点外侧，请她轻向外撑。玩家近看补线没有松，却能见另一侧水滴顺伞沿落到曜袖口；她先转伞遮住他，等他收手后才合，避免夹住手指

**QST-021-L007｜曜**：这里撑一下，别猛拉。

**QST-021-L008｜塞拉**：线没松。另一边倒是先给你试了雨。

**QST-021-L009｜玲**：要不换把看着整齐一点的？

**QST-021-L010｜塞拉**：这把现在好用吗？好用就先看它，不用替我把旧的藏起来。

<a id="qst-021-s002-k02"></a>

### QST-021-S002-K02 · 外套的事说到做过的地方

玩家镜头。玲把新伞推回零售架，没有把借伞当维修未验收就默认合格。Q101 完成时回忆实际选型，不说两种版型同时存在；未做时只谈待试穿

**QST-021-L011｜玲**：妈妈那件外套也是。最后得让她自己拿出票夹，再决定留哪一边。

**QST-021-L012｜玲**：妈妈有件外套要改口袋，我还得让她试穿。现在看着顺，不知道拿票顺不顺。

**QST-021-L013｜塞拉**：一个管拿票，一个管挡这阵雨。都先试过，挺好。

<a id="qst-021-s002-k03"></a>

### QST-021-S002-K03 · 电话那端接上了

玩家镜头，不锁进长对话镜。塞拉手机响，先将合拢的伞靠稳借伞架，空手接电话；曜与玲后退半步留说话空间。她把手机贴耳，不开免提给全店听；玩家听见为叙事呈现的电话音，角色仍按私人通话表演

**QST-021-L014｜值班同事**：那份普通巡看记录放哪儿了？我接着记今天这一页。

**QST-021-L015｜塞拉**：值班台左侧文件槽，日期标签朝外。后面的空页是今天的。

**QST-021-L016｜值班同事**：找到了，我来接着记。

**QST-021-L017｜塞拉**：好，有新问题按值班安排找当班的人。

塞拉拇指停在屏幕边，像要重新点开；雨忽然密起来，她把手机塞回口袋，再从架上拿起刚试过的伞，左手握柄、右手收好带子，不从手机移出任何未交接的秘密任务

<a id="qst-021-s002-k04"></a>

### QST-021-S002-K04 · 你那一下有多长

玩家镜头，曜已经回到桌旁想把刚才工具合好，又摸到未装接件。玩家触发“把不急的工具留到明天”后短接管：机位在工作桌朝店门的中景，能同时看见曜悬着的手、未装接件与门外雨。塞拉站门边发话，曜先看窗外，再笑着把接件放进单独格，扣盖贴待续纸，不伪称已经修完

**QST-021-L018｜曜**：我再收一下就过来。

**QST-021-L019｜塞拉**：你那一下有多长？我的雨已经到了。

**QST-021-L020｜曜**：这件明天再装。今天没有人等它交付。

**QST-021-L021｜屏幕文字**：待续：接件未装；明日从此处继续。今日无交付约定。

曜的双手离开盒盖后交还桌侧玩家控制；跳过仅完成已经决定的收纳，不结束明天的修理。出口：值班同事已接普通记录，工具保持未完，塞拉才开始自己的安排，进 S003

<a id="qst-021-s003"></a>

## QST-021-S003 · 现在走还是等一阵

入口：月台杂货雨棚与借伞台，塞拉持尚未登记的合伞，玲在借还册边，曜刚扣好工具盒来到门旁。雨已变密，去街口与等雨各有实际时间后果，不能两条都赶回同一盘甜点

<a id="qst-021-s003-k01"></a>

### QST-021-S003-K01 · 明确本次安排

玩家镜头。两项原文显示在当次相处选择上；玩家选择向塞拉提出安排，她看门外后答。离开而未选时她不被永久留在门口，改为下一次雨天续约，不凭空建立借还

**QST-021-L022｜屏幕文字**：按约借出这把伞，一起走到街口

**QST-021-L023｜屏幕文字**：不借伞，在不挡门的地方一起等雨

**QST-021-L024｜塞拉**：那我借这把，晾干后按约拿回来。我们到街口看看还有什么吃的。

**QST-021-L025｜玲**：我记本次借出，回来时一起看看这道线。

**QST-021-L026｜屏幕文字**：本次借出：店用补线伞。借用人：塞拉。归还：晾干后正常来访时当面交还。

**QST-021-L027｜塞拉**：那我等一阵。伞放回去，别记成我借走了。

**QST-021-L028｜曜**：坐里面一点。门口给大家留着。

等雨选择落定后，塞拉把试过的合伞放回借伞架，转正伞柄挂牢，确认不会滑落才松手；玲合上未新增记录的借还册，再去墙边坐下

<a id="qst-021-s003-k02"></a>

### QST-021-S003-K02 · 伞下的街口

玩家镜头。塞拉出门前完全撑开伞，等伞骨锁住才踏下门槛；曜从门内自用挂钩取自己的雨伞，玲取挂在相邻钩的雨衣，分别撑开与扣好；两件是兄妹自用物，不写入塞拉的借还册。曜撑自己的伞，玲穿雨衣，三人各有实际雨具，不挤入一把伞而凭空人人不湿。玩家沿正常路线走到街口，途中可停，但不增加追逐或异常。塞拉看甜品柜，原想选的位置只剩空托盘；店面售卖信息可读，不新增有戏份的店员

**QST-021-L029｜屏幕文字**：今日现货：柜内剩余点心；空盘品项已售完，不再加做。

**QST-021-L030｜塞拉**：这个也行，一份。

玩家看见塞拉付款、实际取到一份第二选择甜点；曜与玲各指向仍有库存的普通点心，自己付款并取到各自一份，三份分别装进本人手中才离柜；不靠店员为主角额外加做消除损失。接 S004-K01

<a id="qst-021-s003-k03"></a>

### QST-021-S003-K03 · 雨小下来的时候

玩家镜头。塞拉坐墙边，先看手机上店方公开库存页，显示售完；她用拇指停住刷新动作，把手机朝下放膝上。以店内短相处和明确天气转场表现雨减弱，不强制玩家现实计时等待；选择离开可先做别事，回来按本次等待事实续接。未借的伞仍在架上

**QST-021-L031｜屏幕文字**：今日甜点已售完。下一营业日照常供应。

**QST-021-L032｜塞拉**：来不及了。你们这里那包点心还有吗？

**QST-021-L033｜玲**：有，就在下层。你自己挑。

玩家让开货架前空间，塞拉自己蹲一点取包，查看价签后正常付款，巧克力完成基础结账没有被征用散步。曜与玲随后各从同一货架取一份自己要吃的普通点心，照店内自用记账规则登记并付入货款，分别拆自己的包装，没有挪用塞拉那份。她拿的是本店普通包装点心，接 S004-K02；雨较小时才走，已经晚些到家

<a id="qst-021-s004"></a>

## QST-021-S004 · 没有追回来的几分钟

入口：借伞路线在街口公共遮雨位置吃到第二选择甜点，伞合拢靠在塞拉腿侧；等雨路线在月台杂货靠墙凳边吃普通点心。两处都不挡通行，包装由塞拉自己打开，曜与玲拿各自实际买到的点心，不从她一份里凭空复制

<a id="qst-021-s004-k01"></a>

### QST-021-S004-K01 · 第二选择

玩家镜头。塞拉撕开包装一角，咬下一口，先把纸边折齐再承认原计划；曜翻出已湿的袖口，玲站到包装不会淋雨的一侧。没有强制近景吞咽特写

**QST-021-L034｜塞拉**：我本来想赶最后一盘。刚才在伞架前算来算去，还是慢了。

**QST-021-L035｜玲**：怎么不早说？

**QST-021-L036｜塞拉**：说了好像就非买到不可。

**QST-021-L037｜曜**：那我这样是不是白淋了？

**QST-021-L038｜塞拉**：你不是也吃着？

共用相处后的回顾去 K03，不传送回店继续吃另一份同剧情点心

<a id="qst-021-s004-k02"></a>

### QST-021-S004-K02 · 普通的一包

玩家镜头。塞拉顺包装缺口撕开，包装比甜点盒响，几个人同时低头看一眼，她停一下才笑。曜把椅脚移回墙边，雨声渐弱

**QST-021-L039｜塞拉**：我本来想赶最后一盘。现在连第二种也没了。

**QST-021-L040｜玲**：怎么不早说？

**QST-021-L041｜塞拉**：说了好像就非买到不可。

**QST-021-L042｜曜**：我那一下也够长的。

**QST-021-L043｜塞拉**：这包也得吃完。我们别再把回家说成顺便。

<a id="qst-021-s004-k03"></a>

### QST-021-S004-K03 · 提到真实做过的事

玩家镜头。Q008 已完成才谈具体分工，否则谈今天眼前这件；塞拉说话时把包装空处折起，准备按自己路线离开，不进入楼上私人住家

**QST-021-L044｜曜**：那次你们各自把确认做完，我才能守住家里这边。今天也听见有人把记录接过去了。

**QST-021-L045｜塞拉**：接过去的人得真接住。也不是我挂了电话，事情就自动做完。

**QST-021-L046｜曜**：电话那头说找到，我才知道你真能走了。

**QST-021-L047｜塞拉**：今天的值班有人接着。我现在先回家。

出口：借伞路径塞拉带登记过的伞离开，兄妹先把自用伞与雨衣带回店门内滴水位，伞合拢、雨衣脱下晾好后可继续玩家路线；等雨路径她雨小后空手离开、借伞仍在店。垃圾投入现有收集点，工具盒未完便签保留。普通相处与交接完成，不增加城市处置资格；借伞后续归还接 S005-K01，等雨直接 K02

## QST-021-S005 · 下次普通来访

入口：之后正常营业时段的月台杂货门口，玲在借伞架附近，曜在工作台。只有借伞且尚未归还时塞拉带晾干的那把来；等雨路线她不携该伞，没有借还待办

<a id="qst-021-s005-k01"></a>

### QST-021-S005-K01 · 把磨损指出来

玩家镜头。塞拉把伞柄递曜，先用另一手拉出已干伞布的磨边给他看；曜托接点，塞拉等接稳松手。玩家查看旧补线与另一处新磨损后，才在借还册记收回。若先观察磨损，直接承认观察，不要求先漏看

**QST-021-L048｜塞拉**：晾干了。旧补线没松，这边倒开始磨了，你下次用之前看看。

**QST-021-L049｜曜**：看到了。今天先不放回可借那一格。

**QST-021-L050｜屏幕文字**：本次伞已当面收回；另一侧边缘磨损，放待维护位，检查后再借。

曜把伞放到明确的待维护位，旧线未消失，新磨损未被口头修好。该归还只执行一次，后续进 K03

<a id="qst-021-s005-k02"></a>

### QST-021-S005-K02 · 没有一笔借还

玩家镜头。塞拉经过门口看伞架，手里是自己的普通随身包；玲没有打开借还册。那把试过的伞仍属店内物，若已另作维护按正常店务位置显示，不冒充她归还

**QST-021-L051｜塞拉**：上次雨停才走，甜点早没了。今天我先走到街口看看。

**QST-021-L052｜玲**：那把没记你借。你要是今天借，今天再试。

<a id="qst-021-s005-k03"></a>

### QST-021-S005-K03 · 不用先问案子

玩家镜头。塞拉只在门外向工作台看，不上楼；兄妹忙时她收回将要迈进的脚，让出门口。闲时她可以停下谈天气，不要求新异常

**QST-021-L053｜塞拉**：今天只是路过。点心还有没有上次那包？

**QST-021-L054｜玲**：有。我们这会儿在交件，你先看货架。

**QST-021-L055｜塞拉**：那我自己选。你们忙，我买完就走。

<a id="qst-021-s005-k04"></a>

### QST-021-S005-K04 · 中断回来

玩家镜头。尚未选择时新一次正常雨天从有效试用状态续接，前次没有登记的借还仍为空；已借未还时不把她传送回来归还，只保留下一次正常来访

**QST-021-L056｜玲**：上次只试开了，没登记借走。这次还要借，就再看一下现在的伞面。

**QST-021-L057｜曜**：伞还在塞拉那里，约好晾干后带回。不用现在追到车站去。

结项与后续：本次普通咨询确实交接、工具未完状态明确、所选点心与到家延后保留；借伞只在实际收回时关闭借还记录，等雨从头到尾无虚构借还。后续天气、磨损与个人日程继续存在，楼上私人空间不因关系亲近开放
