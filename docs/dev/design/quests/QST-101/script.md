# 旧外套的新口袋：完整制作脚本

[故事正文](../../../../player/story/daily/new-pocket.md) · [共用写法](../script-format.md) · [正式台词](dialogue.csv)

预算沿用 30–45 分钟，来自取物比较、实际试样和成衣复核，改衣及旅行的日历间隔不计入主动游玩。默认操作玲；曜只在带回采购与交付时到场，不为递一件道具安排额外跑腿。角色为玲、曜、陈美惠、凯文、梁素；母亲定版，玩家执行她确认的改法，不能以玲的审美覆盖本人试穿意见

| 顺序 | 场景 | 进入与结果 |
| --- | --- | --- |
| 1 | QST-101-S001 月台柜台 | 发现旧袋口不合票夹；接下试样工作 |
| 2 | QST-101-S002 材料桌 | 纸样先试进出；携两种方案去修改店 |
| 3 | QST-101-S003 一只手提着东西 | 两种动作实际比较；第一版退回修改 |
| 4 | QST-101-S004 母亲定版 | 保留绣线偏袋或拆绣扩袋；按决定下工单 |
| 5 | QST-101-S005 成衣交付 | 站、坐、提物复核；衣服与票夹交回本人 |
| 6 | QST-101-S006 后来来访 | 未交付续约或已交付旅行回应；不复原已拆绣片 |

完成 QST-002、QST-027 或尾声均不是本篇前置。相关回扣只读实际经历。自由操作镜可随时离开；短接管一律允许暂停与跳过已触发演出，未执行的剪裁、缝制确认、本人选择和成衣试穿不由跳过补齐

<a id="qst-101-s001"></a>

## QST-101-S001 · 票夹露在外面

入口：白天的月台杂货柜台。陈美惠为出门准备来找女儿改衣，站在柜台顾客侧，旧外套叠在新商品旁；票夹在她左手，资料只露封面，不展示私人行程。玲在柜内面对母亲，针线盒收在侧架，柜台暂未接别的顾客。玲认得旧绣线，不知道母亲带的新票夹尺寸与实际取用方式

<a id="qst-101-s001-k01"></a>

### QST-101-S001-K01 · 先去拿了相配的线

玩家镜头，靠近外套时开放“看旧口袋”和“看票夹”，顺序自由。查看口袋，玲食指沿绣线绕过磨损处，停在自己小时候常摸的转角；抬手拿出相近色线轴，先放在外套旁。母亲正把票夹往旧袋口送，硬角卡住；她不硬推，换手转半个角，仍有一截露在外面

**QST-101-L001｜月城玲**：以前不是放得下吗？
**QST-101-L002｜陈美惠**：以前我没带这个。你先别给我加花。

若玩家先看票夹，玲先接住它，手伸向侧架又收回，没有取出线轴，也不重演一次明知卡住的尝试；两条观察顺序均在看清袋口与票夹后汇入 K02

<a id="qst-101-s001-k02"></a>

### QST-101-S001-K02 · 把要做的事记对

玩家选择“用票夹量旧袋口”，玲将票夹平放在干净纸上描出外缘，再把旧袋口压在轮廓旁比照，笔尖在欠出的宽度处停住。母亲把外套朝自己拉回一小段，指向自己平时伸手的位置

**QST-101-L003｜陈美惠**：里面放的是出门要用的。拿的时候，我另一只手未必空着。
**QST-101-L004｜月城玲**：我先做能试的，别一下把这块拆了。
**QST-101-L005｜陈美惠**：先试。最后怎么改，我穿上再说。
**QST-101-L006｜屏幕文字**：试样：票夹能放入，也要能单手取出；定版前不剪旧外套

出口：玩家亲手将外套与封好的票夹放入布袋，纸样夹放外层。母亲约在梁素店里试穿，先回去处理自己的事；她从门口离开，不一直站在柜台等玩家跑完街区。玲携实物前往 S002，未接下试样前可以离开，物件仍归母亲保管

<a id="qst-101-s002"></a>

## QST-101-S002 · 纸袋也要让手进去

入口：手作材料店的公用试料桌，靠店内一侧，通道空着。凯文正在看样料，受玲当面邀请帮折样，不因此承诺代做整件外套。玲把布袋放桌下靠自己一侧，旧外套留袋内，只取纸样和票夹；原绣线配色来自她携来的局部比色纸。两人都知道母亲还未定版

<a id="qst-101-s002-k01"></a>

### QST-101-S002-K01 · 很适合正面看的一版

玩家镜头，可比较两块现成里布样料，不以材料颜色增加结果分支。玲取与旧绣线相近的一片压在纸样下；操作“折出袋深”后凯文沿玲画的线折起三边，以可拆纸夹固定，留下袋口。玲将票夹放进去，正面平整

**QST-101-L007｜月城玲**：这样看，旧线正好还在边上。
**QST-101-L008｜凯文**：放进去之后呢？

玩家选择“试着取出”，玲用一手扶模拟衣面、一手抽票夹，纸袋随手上提。凯文将自己的手也伸入空袋比照，袋口歪向一边；近景短接管只覆盖纸折线张开这一动作，取物已由玩家触发，暂停或跳过均落在歪纸袋留桌、手退出后的原站位

**QST-101-L009｜凯文**：这一版很适合拿来展示。你妈妈的手大概没办法只从正面看。

<a id="qst-101-s002-k02"></a>

### QST-101-S002-K02 · 两种代价写在旁边

玩家镜头，凯文展开另一张纸，在旧绣片轮廓外留出新袋口；不替梁素确定缝法。玲将两张样片分别夹好，实际可读说明跟着样片走

**QST-101-L010｜屏幕文字**：样片甲：保留原绣线，改另一侧袋位与开口；需试新的取物位置
**QST-101-L011｜屏幕文字**：样片乙：拆下绣片，直接扩袋；原处会留下新缝线
**QST-101-L012｜凯文**：纸上折得开，衣服还得让梁素看。我跟你们把样片带过去。

出口：玲带外套和票夹，凯文带样片，两人按普通街道去修改店；途经共享木作工坊只作为连通路径，不强制进店领物。可在路上暂离，凯文把样片交玲带走，约在修改店会合，不以跟随 NPC 丢失惩罚玩家；S003 入场时他从店门带自己的工具小包进入，不凭空出现在试衣镜前

<a id="qst-101-s003"></a>

## QST-101-S003 · 另一只手还提着东西

入口：衣物修改店试衣镜前。陈美惠已按约到店，面向镜子；梁素站在侧面工作桌旁，剪刀收在桌里，针插与计数盘置于手边。玲从门口带来外套和票夹，凯文在桌另一端放好样片。曜在本场 K03 才带普通采购进门，此前不占镜中位置

<a id="qst-101-s003-k01"></a>

### QST-101-S003-K01 · 漂亮没有直接过关

玩家镜头，操作“把两张样片摊开”，玲先将甲样转向母亲，乙样平放一旁，不藏在甲样下面。梁素不拿剪刀，先沿甲样建议位置用临时大针脚缝一段试袋；每次落针远离母亲身体，外套平摊在工作桌完成后才递给母亲

**QST-101-L013｜陈美惠**：这样也好看。
**QST-101-L014｜梁素**：好看先记着。穿上，手自己去找口袋。

接管由母亲接过衣服触发，镜头从工作桌侧中景跟到镜侧，展示穿衣和临时袋位置；不播放缝制全程。可暂停或跳过到母亲穿好、票夹仍由玲持有的玩家机位，未替玩家把票夹塞入或完成取物试验

<a id="qst-101-s003-k02"></a>

### QST-101-S003-K02 · 空手时看起来行

玩家触发“递票夹”，玲托底递给母亲，母亲握住才松手。她将票夹放入试袋，换成惯用手取一次；袋口拉住袖侧，她转肩才取出，抬眼看玲后才笑

**QST-101-L015｜陈美惠**：站着拿，倒也拿得出来。
**QST-101-L016｜月城玲**：你刚才肩膀也跟着转了。

已先注意到牵扯的玩家可以直接检查袋口张力，不强迫玲说“完全没问题”。凯文把甲样原先画的直线转向自己，看见纸上没有肩部动作，沉默地在边缘画了弯记号

<a id="qst-101-s003-k03"></a>

### QST-101-S003-K03 · 不是每一站都有女儿

曜从门口进来，购物袋握在右手，见桌面已满便停在门旁；母亲伸手接过袋子，再将票夹放回试袋。玩家选择“请她提袋再取”，母亲手肘被新袋口牵住，票夹只出来一半。她停一下，把购物袋缓慢放到脚边，准备空出手继续

**QST-101-L017｜月城曜**：采购在这儿。要试提东西？
**QST-101-L018｜月城玲**：我帮你拿着。

短接管从镜侧中近景保持提带、票夹与玲的手同框。梁素把放下的袋子轻推回母亲能自行提起的位置，抬眼等玲看见，不握住或阻挡玲的手

**QST-101-L019｜梁素**：她出门的时候，你也每一站跟着？

陈美惠笑出一口气，手仍扶住卡着的票夹；玲把伸出的手收回，先看母亲，再看自己拿来的甲样。接管结束回到玲镜侧位置；跳过落定收手，不自动选乙样或拆线

<a id="qst-101-s003-k04"></a>

### QST-101-S003-K04 · 自己把那几针拆开

玩家选择“退回临时样片”，母亲先脱下外套放平，梁素确认所有试针都已取下并放进计数盘，再递拆线器。玲压住布边，挑断临时线，每挑一段就把线头收入小碟，不割原绣线；凯文将第二张样片摊到空出来的位置

**QST-101-L020｜月城玲**：先别照这个缝。另一张也试一下。
**QST-101-L021｜梁素**：这几针拆了，后面得重新排时间。今天先把位置试准。
**QST-101-L022｜陈美惠**：我不是不喜欢它了。
**QST-101-L023｜月城玲**：我知道。你再伸一次手。

<a id="qst-101-s003-k05"></a>

### QST-101-S003-K05 · 两种改法都用同一只手试

玩家镜头，原衣仍完整，甲样留下失败折痕，临时袋已拆。梁素确认试针已全部入盘，撑起衣领递给母亲；母亲先放下采购袋，重新将双臂穿入未裁的原衣，理平下摆，再提起袋子。操作“试调整后的偏袋”时，梁素把不带针的甲样板靠在外套另一侧，沿母亲自然伸手的位置向下移，玲扶住板外沿；母亲用另一手提同一采购袋，将票夹送入、抽到完全离开袋口，再松下肩膀。新位置不再牵起袖侧，正面两袋却明显不对称；玩家可绕至镜前同时看两侧

操作“试直接扩袋”时，母亲把票夹取出，玲撤开甲板后才换乙板，梁素用手撑住拟扩的袋口轮廓，不在衣上开剪；母亲保持同一提袋姿势，沿熟悉的一侧放入、抽出票夹，手臂直起不用转肩。玲把原绣片轮廓叠到乙板上，扩出的开口穿过旧片所在位置，不能以一张图同时承诺完整保留旧片

每次都由母亲实际把票夹取到板外才完成观察，不用两个确认按钮替代表演。顺序可交换，换板前先收回票夹、放下采购袋，板就位后本人再提起袋；两个动作都看过才进入 S004，母亲不会仅因哪版先展示就选它。出口时两板回桌、票夹归母亲，衣服脱下平放且未裁剪

<a id="qst-101-s004"></a>

## QST-101-S004 · 由穿衣的人选

入口：仍在修改店，母亲把同一购物袋放回椅脚旁，合上票夹放在桌边；未裁的外套平摊在工作桌，两版改过的纸样并排。梁素把裁剪工具留在关闭状态，等陈美惠的决定；玲拿记录笔站在母亲对面。此处保存的是陈美惠试穿后的决定，玩家操作是接过她选中的样片和记录，不显示玲替她投票的菜单

<a id="qst-101-s004-k01"></a>

### QST-101-S004-K01 · 保留绣线的决定

条件：陈美惠本次选择保留绣线、调整另一侧口袋。镜头由玩家视角在她抬起甲样时短接管至工作桌上方中景，母亲用一手取起甲样，另一手先指刚才实际试过的新袋位，再移向平摊外套上的旧绣片；她已看过 S003-K05 的完整试取，此处只作决定，不再重复穿衣试验；说完将甲样转给玲

**QST-101-L024｜陈美惠**：这块我还想留着。口袋挪到刚才那个位置，我拿得顺。
**QST-101-L025｜梁素**：两边会不一样。穿上以后也一直是这样。
**QST-101-L026｜陈美惠**：嗯，就这样。别为了对称又挪回去。

交还原站位，玩家选择“记录母亲选定的偏袋”，玲接样片并在工单画出定位。跳过只结束母亲的表态，不代写工单。玩家尚未记录可退出，样片归母亲手边保管；记录完成后汇合 K03

**QST-101-L027｜屏幕文字**：已定：保留原绣线；按试穿定位改另一侧袋位与开口；正面不对称；成衣再试提袋取物

<a id="qst-101-s004-k02"></a>

### QST-101-S004-K02 · 拆下绣片的决定

条件：陈美惠本次选择拆绣扩袋。镜头同样只在母亲举起乙样时短接管，她用空着的手沿乙样袋口画出刚才试过的伸手方向，再点平摊衣服上的旧绣片，明确它会被拆下；票夹与采购袋留在刚才放好的地方，不重复穿衣试验

**QST-101-L028｜陈美惠**：还是这一边顺手。把它拆下来，袋口照这张开吧。
**QST-101-L029｜月城玲**：我拍一张这段线，可以吗？只留细节。
**QST-101-L030｜陈美惠**：可以。里面那张行程纸别拍进去。

交还玲桌边原位，玩家选择“拍获准的绣线细节”，取景限定衣面，无行程文字和其他顾客信息。完成拍摄后选择“记录母亲选定的扩袋”，玲重画袋口，梁素把乙样别在工单上；剪裁由确认之后的专业缝制完成，跳过不能提前拆掉绣片

**QST-101-L031｜屏幕文字**：已定：拆下绣片，按试穿定位扩袋；原处保留新缝线；局部照片仅自留；成衣再试提袋取物

若母亲已经主动说明要留绣片，执行下句并把拆下片装入标有她名字的纸袋，成衣交付时一并归还；没有提出留存时执行随后一句，普通余料由梁素收置，不另弹“纪念品命运”菜单

**QST-101-L032｜陈美惠**：那片先和衣服装在一起，我自己带走。
**QST-101-L033｜陈美惠**：碎布照平时收就好，照片留着了。

两种留片处理互斥，均汇合 K03，不改变已经同意拆绣的结果

<a id="qst-101-s004-k03"></a>

### QST-101-S004-K03 · 把重来的工夫算进去

玩家镜头，梁素从工单夹取出可预约的交付单，填写自己确认的下一次成衣交付，不用连续缝制过场消耗玩家时间。玲把失败甲样与最终样片分开夹入工作夹，没有把旧样丢掉；曜拎起购物袋，等母亲取回自己的票夹

**QST-101-L034｜梁素**：我缝好后放到包装修补那边交。赶不上共用院那一趟，就回店里约，别赶着来。
**QST-101-L035｜月城玲**：这张也留着。下回我先问你另一只手在做什么。
**QST-101-L036｜陈美惠**：下回也先让我穿上。
**QST-101-L037｜屏幕文字**：外套留店改制；票夹已交陈美惠带走；按本人已定版型制作；成衣到后约试穿

出口：外套归梁素保管，票夹归母亲，采购归曜，样片归玲。母亲与曜从店门离开，玲可自由继续别的事。正常日程转场到预约交付；若跨章后再来，按这张工单继续，不重新试两种版型，不把已剪绣片补回

<a id="qst-101-s005"></a>

## QST-101-S005 · 衣服交回来以后

入口：交付日，包装修补工作室的交付台。梁素已按工单完成成衣并包装，她自己把包交给玲，不增加无名交付人员。陈美惠在共用院等试穿，她带来自己的当日日用袋，先放椅脚外侧不挡人的位置，袋中是她这次实际要提的物品；凯文带改过的样片到院；若错过共用院预约，改为修改店同一张干净桌，母亲已同意新的见面时间，以下动作原样执行

<a id="qst-101-s005-k01"></a>

### QST-101-S005-K01 · 先核对包里的那件

玩家镜头，选择“核对交付工单”，玲将包口展开，依工单查看实际袋位、原绣片或新缝线；保留路线原绣片在衣上，拆绣路线该处只见新缝线，主动留片才有小纸袋。无误后玲双手托包带去共用院，梁素收好工单、锁好本轮交付柜后从门口跟上，与玲一同步行到院；步行由玩家控制，不自动跨地图移交

**QST-101-L038｜梁素**：别先替她说好了。票夹得放进去再拿出来。

<a id="qst-101-s005-k02"></a>
