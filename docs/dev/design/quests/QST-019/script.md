# 把我的名字写大一点：完整制作脚本

[故事正文](../../../../player/story/daily/make-my-name-bigger.md) · [统一写法](../script-format.md) · [正式台词](dialogue.csv)

设计预算：15–25 分钟；动作、试听、路程与转场均包含在原预算内，实际时长待灰盒验证

出场：玲（当前操作）、曜、巧克力、安可、悠真、贺佳；三位路人 CHR-050/051/052

场次阅读顺序：S001 橱窗提案 → S002 实地试读 → S003 用途与报价 → S004 实际交付 → S005 张贴、重访与续接

进入使用当前有效的普通演出或后续张贴安排；已取消场次、已撤回动态与过期日期不重新启用。与 QST-020 的废样笔迹按实际顺序保留，小卡印量在下单后固定，本次选择不会重新收费已经交付的旧版本

控制通则：未明确标为短接管的镜头均由玩家控制，可暂停、查看与离开；近看文字后回到原站位。短接管只在对应交互已经发生后播放，暂停与跳过可用，期间停用移动、切人及其他交互；跳过仅落定该次已经触发的表演，保留未做的观察、选择、交接与操作。所有镜头以可见动作或对白结束为切换点，建议节拍不作为已测时间

## QST-019-S001 · 先记住什么

入口：月台杂货正常营业时段，玲在靠橱窗桌内侧，安可站桌外侧，手里三张试样边缘对齐；曜在通往店门的一侧整理夹具，巧克力停在商品架与门之间。双方知道这是海报委托，安可尚未决定主次

<a id="qst-019-s001-k01"></a>

### QST-019-S001-K01 · 三张都好看

玩家镜头。目标是查看安可递来的三张试样。安可把人像版举到自己脸旁，第二张用手肘夹住，第三张险些滑下；玲托住下沿，接过后依次放在空桌面，不盖商品。可任意顺序放大脸、姓名、歌名、日期与合作署名；读完一版只记录该版

**QST-019-L001｜安可**：这张很好看。这张也是。这个名字……还能再大一点吗？

**QST-019-L002｜玲**：你刚才还说脸要大，新歌名也要大。先选一个最想让人看见的。

**QST-019-L003｜屏幕文字**：试样 A：人像优先／试样 B：文字并列／试样 C：姓名与演出信息优先

<a id="qst-019-s001-k02"></a>

### QST-019-S001-K02 · 门口没有空出来

玩家镜头跟随安可退到门边。她先把纸贴近身前，又向后退一步，鞋跟靠近门扇回转范围。巧克力朝来客方向亮箭头；安可收拢纸张，侧身让出整个门口后才继续说话。路人照常通行

**QST-019-L004｜巧克力**：请让出入口

**QST-019-L005｜安可**：这样呢？远一点是不是就看不清名字了？

**QST-019-L006｜玲**：看得清。

**QST-019-L007｜安可**：那……记不记得住？

**QST-019-L008｜玲**：你已经问第三遍了，我肯定记得住。

**QST-019-L009｜安可**：我是说没见过我的人。

<a id="qst-019-s001-k03"></a>

### QST-019-S001-K03 · 先按住名字

短接管由玩家选择“问她希望路人先看见什么”触发。机位在门内靠橱窗一侧，中近景同时看见她的食指与玲手里的另两张纸，只随纸轻下移。安可张嘴要回答歌名，手指先压住自己的名字；玲沿指尖看过去

**QST-019-L010｜安可**：可以三个都要吗？

**QST-019-L011｜玲**：可以先告诉我，他第一眼只看一个的时候，你舍得哪两个等一会儿。

**QST-019-L012｜安可**：名字。先是我的名字。可我也想让他们知道我不是只唱以前那首。

安可收回手，玲把试样摞好。纸由安可松手、玲接稳后交还门内原位控制。跳过不自动获得张贴许可或路人意见

<a id="qst-019-s001-k04"></a>

### QST-019-S001-K04 · 可以再约

玩家镜头。继续时安可接过两枚夹具；延后时玲把纸夹回文件袋，试读保持未完成

**QST-019-L013｜屏幕文字**：去实际张贴位置试读

**QST-019-L014｜屏幕文字**：先保留试样，晚些再试

**QST-019-L015｜安可**：好，我先不拿这张去印。你回来我们再到门外看。

出口：继续时兄妹携三张试样，安可拿夹具，从正门步行前往获许可的展示框；延后时纸留在玲文件袋、夹具回桌，不挂正式宣传。两路均在 S002-K01 接上，不重演提案

## QST-019-S002 · 经过的人看见什么

入口：月台杂货外授权展示框与 AFTER 9 入口告示位，同次试读行程。玲携文件袋，曜拿可移除夹具，安可走靠墙侧；悠真在 AFTER 9 核对本场演出信息。两处已获本次临时试挂许可，路面通道保持畅通

<a id="qst-019-s002-k01"></a>

### QST-019-S002-K01 · 真的高度

玩家镜头。目标是把试样依次夹到同一高度，退到实际走路位置看。曜托下沿，玲扣夹具后松手检查未遮营业文字；每换一版先取下上一版入袋。先去 AFTER 9 或先看橱窗均可，第一地点的观察带到第二地点，不要求已经看懂者补犯一次错

**QST-019-L016｜玲**：先别贴牢。我们从会走过去的地方看，不从你举着它的位置看。

**QST-019-L017｜安可**：近看这张最好……歌名怎么没了？

**QST-019-L018｜曜**：还在你刚才坚持不动的那一行。

<a id="qst-019-s002-k02"></a>

### QST-019-S002-K02 · 不是每个人都停下来

玩家镜头，三种回应次序自由，各一次。老歌路人停在不挡门处，点节拍后指人像；乐队路人先看署名栏，再向悠真点头；赶路的人不被交互锁住，回答后继续走。玩家不追问私人行程

**QST-019-L019｜玲**：不好意思，这张你第一眼记住了什么？

**QST-019-L020｜老歌路人**：是你啊，我会唱你以前那首。新歌叫什么？刚才没看见。

**QST-019-L021｜乐队路人**：我先看见日期。走近才发现悠真他们也在，这一行太低了。

**QST-019-L022｜赶路的人**：我赶时间，没看。你们忙。

**QST-019-L023｜安可**：……谢谢。

<a id="qst-019-s002-k03"></a>

### QST-019-S002-K03 · 空白里站着谁

玩家镜头，可提前指出署名过小，不必等悠真先抱怨。安可将合作署名条移到页脚，用指甲划出想留下的空白。悠真从门边过来，只接纸，不接笔；二人隔一张展开海报

**QST-019-L024｜玲**：姓名是看清了。走过去的人还看得见下面是谁吗？

**QST-019-L025｜安可**：人得先认出我，才会停下来看你们。

**QST-019-L026｜悠真**：这次介绍的是你的独唱录音，还是我们一起做的现场？

玩家触发“把署名区展开给安可”后短接管。机位贴玲身侧桌面高度，中景看见悠真把纸放回与安可抬到一半又落下的笑。无人接她备好的笑话；她遮住人像旁最喜欢的留白，把署名条移上去，折痕与缩小的空白都在画内。此镜不批准印刷

**QST-019-L027｜安可**：现场。那这些名字不能让人猜。你看看，这样齐了吗？

**QST-019-L028｜悠真**：齐了。我还是喜欢另一张的排法，这张的信息能用。

**QST-019-L029｜安可**：我留这张。你不用也喜欢它。

悠真把署名条还给玲后交还原位控制。跳过保留偏好不同、署名核对完成的结果；另一地点未试读仍需实际查看。出口：两处试挂纸全收回文件袋，悠真回到自己的工作，兄妹与安可返回 S003；未确认日期留在校样栏，不作为已定场次张贴

## QST-019-S003 · 另算的一张

入口：月台杂货原桌，主海报排样在中间，独照在右侧，报价在两纸之间。曜坐门侧收夹具，巧克力靠商品架。安可已承认署名位置，仍想得到独照成品

<a id="qst-019-s003-k01"></a>

### QST-019-S003-K01 · 另一个用途

玩家镜头。玲把三份旧试样摊开，依序推出主海报与独照。安可笑着把独照推向主海报，玲不接笔，只把报价转正

**QST-019-L030｜玲**：主海报按这张。独照可以做小卡，是另一个用途。

**QST-019-L031｜安可**：朋友再改一次，不算什么吧？

**QST-019-L032｜玲**：主海报的三版已经在这里。小卡要重新排版和印，哪一项你希望我不算？

**QST-019-L033｜安可**：我就是还想留这张照片。小卡另付。让我看看印多少。

**QST-019-L034｜屏幕文字**：主海报含已约定排样与本次校色；独照小卡另项计费。缩小本批印量：随主海报交付。移到下一批：本次仅交主海报。追加修改另行确认。

<a id="qst-019-s003-k02"></a>

### QST-019-S003-K02 · 两种拿不到全部的办法

玩家镜头。两项印制安排显示为订单选项，实际费用按印量确认；本稿小批分支固定六张，其中五张已预留给本场合作人员，一张先由安可自留，延期分支本次零张。这是安可确认用途与预算，玲只在她核对后下单；玩家可递选项供她签认，不把投票当作者的内心决定

**QST-019-L035｜屏幕文字**：本批小卡印六张，另付制作费用

**QST-019-L036｜屏幕文字**：小卡移到下一批，本次只印主海报

**QST-019-L037｜安可**：六张。预留五张，我留一张，剩下的不再补进这一批。

**QST-019-L038｜玲**：主海报和这一小批一起取。我按你确认的量下单。

**QST-019-L039｜安可**：这回先没有小卡。下一批的钱另留，照片样子先别扔。

**QST-019-L040｜玲**：本次只交主海报。小卡等下一批确认后再交，不写成已经印好。

**QST-019-L070｜屏幕文字**：本批小卡：六张；五张按合作人员预留名单交付，一张由安可自留。延期分支本次小卡：零张，成品另在后续批次交付。

两路汇入 K03。下单后选择固定；未下单离开时安可保管独照、玲留报价，回来只确认未决定项，不重新做全部试读

<a id="qst-019-s003-k03"></a>

### QST-019-S003-K03 · 废样正面停用

玩家镜头。安可抽出单面废样，指正面将计划写成已完成的宣传。时间分支只播放适用组，不叠播

**QST-019-L041｜屏幕文字**：旧试样，停止张贴：新歌录制与场次说明须按实际完成情况重核。

**QST-019-L042｜安可**：这句我已经发过，又撤掉了。不能换张纸再说一遍。

**QST-019-L043｜玲**：这次先核对真能交的歌和真能用的场地，再写正式日期。

**QST-019-L044｜玲**：这一行现在只是计划。你先圈出来，别让它看起来已经录完。

**QST-019-L045｜安可**：那就先不写“已经”。我还没唱完呢。

**QST-019-L046｜安可**：那场已经唱完了。这是下一次的纸，旧日期不拿来凑。

<a id="qst-019-s003-k04"></a>

### QST-019-S003-K04 · 绕开已有的字

玩家镜头近看纸背。Q020 先发生时安可从歌词夹展开同一废样，手指绕过两栏副歌批注，在折痕旁找空白；未发生时背面留出两栏，供后来同一物件进入 Q020，不伪称已听过歌。玲实际写下决定，不擦旧笔迹

**QST-019-L047｜安可**：这里已经记过试听了。你从折痕旁边写，别把那句盖住。

**QST-019-L048｜安可**：背面还空着。先记今天定下的，歌的事以后写这里。

**QST-019-L049｜屏幕文字**：主海报：姓名先读到；歌名、时间地点、合作署名可读。独照小卡：另项付费，按已确认批次交付。正式张贴前重核场次。

出口：玲带订单与主海报文件去印制工作室，安可保管废样及独照；安可按项目付费。预约完成以明确转场呈现，玩家可做其他事，不原地等时长；交付通知到达后进 S004

## QST-019-S005 · 名字旁边与商品旁边
