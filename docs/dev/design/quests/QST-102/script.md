# 一桌不同的晚饭：完整制作脚本

[故事正文](../../../../player/story/daily/different-dinners.md) · [共用写法](../script-format.md) · [正式台词](dialogue.csv)

预算沿用 10–20 分钟。联系集中在一张桌前；取餐、布桌、后半顿为既有参与路径，不把餐饮关联场所全部串成邀请清单。场内给出的早席 18:20–18:55、晚席 19:10–19:40 是这次各人确认的约定，错过整晚后另约时重新确认并换当次纸张；两席间用正常生活转场，不计入现实等待

| 顺序 | 场景 | 条件与结果 |
| --- | --- | --- |
| 1 | QST-102-S001 饭盒和日程 | 同桌确认可留时间；选择参加取餐、布桌或后半顿 |
| 2 | QST-102-S002 各自的一份 | 采购与分份、布桌；后半顿路线由当事人按约准备 |
| 3 | QST-102-S003 早席 | 邵敏吃完先走；玩家可以先走或继续留下 |
| 4 | QST-102-S004 晚席 | 阿东实际收取所留餐食；第二张照片与收桌交接 |
| 5 | QST-102-S005 事后的桌子 | 缺席者收到真实回复；结束确认与重访 |

角色为玲、曜、唐惠、宋美香、悠真、邵敏、阿东、安可。默认玲为操作角色，曜按实际参与时段同行；玩家未到场的饭席不播放成玲的亲历，后续用有发送者的消息说明已发生的结果。邵敏在阿东到店前离场，任何路线不合成全员同场照片。短接管可暂停或跳过到当前席间原位，不替玩家同意照片留存或完成未触发的取餐、留份交接

## QST-102-S001 · 这次我今天有空

入口：晚班汤饭店准备开晚班的空桌，唐惠站桌内侧擦饭盒，悠真坐门侧，玲与曜在邻侧。唐惠手机放桌面，群内消息可按本人展示范围阅读；最早的约饭消息提到已经不在菜单上的点心。邵敏、阿东、安可此时不在店里，他们只通过自己实际回复参与约定

<a id="qst-102-s001-k01"></a>

### QST-102-S001-K01 · 总能再等一等

玩家镜头，操作“看这次各人的时间”才展开唐惠已允许查看的约饭消息，不打开其他私聊。唐惠先将空饭盒推给悠真，手指擦一下盖上洇开的旧取餐纸；悠真翻过盒盖，认出自己的名字

**QST-102-L001｜屏幕文字**：上次约饭：等大家都有空，再一起尝新点心
**QST-102-L002｜唐惠**：都不难，再等等，总能凑齐。
**QST-102-L003｜唐惠**：那一回你也说下次坐着吃。
**QST-102-L004｜悠真**：这次我今天有空。
**QST-102-L005｜月城玲**：那就先来的先吃？
**QST-102-L006｜唐惠**：那跟你们平时各自来取饭有什么两样？我都快只会问邵敏加不加葱了。

悠真把饭盒重新摆正，不接“下次”。镜头保持玩家视角，唐惠看他一眼，放下抹布，拿起手机发起当晚可留时段的确认；不自动播出一个全员同意的蒙太奇

<a id="qst-102-s001-k02"></a>

### QST-102-S001-K02 · 把不能到的那段也留下

玩家触发“把回复排到纸上”，玲从桌边取空白纸，唐惠逐条念自己收到的本次回复；文本也以消息原文显示。邵敏与阿东的两段在纸上不相接，玲的笔停在中间空白，不画箭头把他们拉到一起

**QST-102-L007｜邵敏**：我今天 18:20 到，18:55 前得走。能吃前一段，不等我延长
**QST-102-L008｜阿东**：配送完 19:10 才到，19:40 走，牌友已经约好了。别把我算在前一桌
**QST-102-L009｜安可**：我前后都能坐一会儿。先声明，不许吃一半才想起来叫我拍照
**QST-102-L010｜唐惠**：这中间还空着。邵敏一走，阿东才来。
**QST-102-L011｜悠真**：我们先把这两段吃上。

QST-107 已完成时追加下句，未完成直接进入参与选择，不宣称悠真已有那次散场交接经历

**QST-102-L012｜悠真**：上回器材交到人手里，我才真坐下。这回我把时间先空出来。

玩家所见选择为已有三种参与方式；每项选后只播放对应回应，再汇入 S002

**QST-102-L013｜屏幕文字**：我去取这次要用的餐食
**QST-102-L014｜屏幕文字**：我来摆桌，吃前一段
**QST-102-L015｜屏幕文字**：我后半顿来
**QST-102-L016｜唐惠**：就带单上这一轮的，后面的留我和店里安排。
**QST-102-L017｜唐惠**：桌布在靠门的柜里。别把厨房里的东西一起搬出来。
**QST-102-L018｜唐惠**：好，19:10。前面不用赶回来，坐下以后再点你的。

出口：选择晚席者可离店，S002 和 S003 的未参与事件由已答应的人完成，回店从 S004 开始；取餐或布桌者继续 S002。若尚未接参与安排便离开，饭局未冻结等待主角，之后在当事人仍可用的时段再确认一次，不把过期纸张当今天的新约定

<a id="qst-102-s002"></a>

## QST-102-S002 · 后来的不是冷掉的剩饭

入口：取餐路线在生鲜小超市同一轮采购开始，唐惠与玲对照清单；布桌路线在汤饭店客区开始，唐惠完成这轮采购后刚提袋回店，先把采购交店内安排，再指给玲桌布位置；玲不被要求再走同一遍。宋美香通过本次联系送来可留份的旧款与少量试做新品，后半顿才本人到店；阿东不承担额外取餐，配送表上的休息空隙仍属于他

<a id="qst-102-s002-k01"></a>

### QST-102-S002-K01 · 放回那一份

条件：取餐路线。玩家镜头，玲按唐惠已写明的两轮份量拿材料，在准备把同一份量再加一份时唐惠将其中一包平稳放回货架，保留价签原位

**QST-102-L019｜唐惠**：这一轮吃多少拿多少。阿东那碗得等他来再做。
**QST-102-L020｜月城玲**：我想让他也吃到这一份。
**QST-102-L021｜唐惠**：要同样再做一份，就按加做的价和我能排的时间来。他说换现做的也行。
**QST-102-L022｜月城曜**：要是每次都给两拨多备一份，你得提前多久起床？
**QST-102-L023｜唐惠**：得再早半小时。……这回按刚才商量的。
**QST-102-L024｜阿东**：不用替我追早上那道菜。给我留一份旧款面包，到了点热的，钱照常算

玩家按实际清单核对并领取已备餐食，不设额外搜店环节；易冷餐食由店方正常保管到相应时段，兄妹只带当轮允许带走的部分。采购结束回汤饭店门口汇入 K03

<a id="qst-102-s002-k02"></a>

### QST-102-S002-K02 · 空位也是布桌的一部分

条件：布桌路线。玩家镜头，操作“铺桌、放本轮餐具”，玲先擦干桌面，铺好桌布，再放邵敏、悠真、安可及实际到场兄妹的餐具；晚席的干净碗另放客区柜，没有用空碗假装阿东已到。曜将不需用的椅子移到不挡服务通路的位置

**QST-102-L025｜悠真**：这只先别放。他到了还要点。
**QST-102-L026｜月城玲**：早走的那边，待会儿也不用谁补上。

玩家摆完本轮所需物件即可结束，不要求精确对齐重复摆设。唐惠从已放好的采购中核对本轮份量，汇入 K03

<a id="qst-102-s002-k03"></a>

### QST-102-S002-K03 · 阿东的空隙没有再添一站

公共结果：当轮采购已交店方，餐具已由承诺布桌的人摆好，哪项不是玩家做的，就由唐惠或悠真在现场接好，不显示主角已完成该操作。唐惠把阿东发来的当日配送时间夹在取餐袋旁，圈的是 19:10–19:40，不加“顺便去拿”

**QST-102-L027｜屏幕文字**：早席 18:20–18:55：到场再上热食；晚席 19:10–19:40：面包留阿东一份，热食本人到后现做；取餐由早到者承担
**QST-102-L028｜唐惠**：他这段空出来是来吃饭的。取餐别再绕到他那边。

若 QST-023 已完成，配送表只采用改约后的现行路线，执行下句；未完成不提前划掉渡口旧路，也不回忆改约结果

**QST-102-L029｜唐惠**：改道后的这张他已经确认过，备料就跟这张走。

出口：早席参加者按约坐下进入 S003；晚席路线直接在 S004 从门外进入，只能看见该时段真实剩下的物件。日程转换明确，剧情不要求玩家站在饭馆等钟表走完空隙

## QST-102-S003 · 第一张照片

入口：早席，邵敏工作包放椅侧，悠真坐靠墙处，安可在桌端摆手机，兄妹仅在选择取餐或布桌并实际留下时入席。唐惠往桌边送汤仍照看店面；阿东正在配送，不在背景凑人数。汤匙、筷子与菜各归本席，晚份留在经营者安排的保管处

<a id="qst-102-s003-k01"></a>

### QST-102-S003-K01 · 还要再等谁

玩家镜头，坐下吃第一口触发短接管，机位在手机侧后方中景，能看见门边空椅。安可调整手机，让邵敏偏外的椅子进画面，再看门口；邵敏看一眼时间，把汤匙放回碗边

**QST-102-L030｜安可**：阿东还没来。要不再等——
**QST-102-L031｜悠真**：他来了还要再点。你可以拍第二张。

安可瞥他一眼，按下快门：悠真低头，邵敏包未卸，唐惠站桌侧，阿东的空椅仍空。手机没有发出发送声。接管结束回到玲的座位视角，可暂停或跳过至照片已拍但尚未确认留存的阶段

**QST-102-L032｜安可**：拍到了。先别骂，我没发。各自看一下，能不能留这张？
**QST-102-L033｜邵敏**：只留我们自己看，别带到工作那边。
**QST-102-L034｜悠真**：能留，别等我嚼完再拍一轮。

若曜实际在早席且入镜，他接过手机看一眼自己的位置，点头后播放 L075；不在场时不播放。唐惠将手擦干，接着看清自己所在的一侧，把手机退回安可手边后播放 L076

**QST-102-L075｜月城曜**：只在这桌留，我同意。

**QST-102-L076｜唐惠**：自己人留着看吧，外面别发。

玩家只决定自己在照片中的留存，不代表其他人授权

**QST-102-L035｜屏幕文字**：这张留给在场朋友看就好
**QST-102-L036｜屏幕文字**：这张别留我
**QST-102-L037｜安可**：好，只在答应的人之间留。外面不发。
**QST-102-L038｜安可**：行，我把这一张删掉。剩下的人愿意的话，再拍他们那一边。

拒绝后可取其他已同意者局部照片，玲与不同意者不在画面，也不为补拍延长邵敏停留；物件中“第一张照片”指实际获准保留的那张，不保留原拒绝画面。两路汇回席间玩家控制，可吃饭或起身

<a id="qst-102-s003-k02"></a>

### QST-102-S003-K02 · 出去的门没有被挡住

在邵敏本次确认的结束节点，镜头保持玩家自由视角，邵敏喝完碗里最后一口汤，拿起桌边的纸笔写下 L041，把笔放回纸边才拿手机起身；她把椅子收回桌下，工作包却仍留椅侧。唐惠看见包，先俯身抓住提带拿起，再追到门边，嘴张开后改成举起忘拿的包

**QST-102-L039｜唐惠**：你的包。
**QST-102-L040｜邵敏**：差点又只顾着看时间。阿东那张便条在桌上，帮我留给他。
**QST-102-L041｜屏幕文字**：阿东，今天那道辣的好吃。下回你别只点清淡的。——邵敏

玩家选择“把便条留给晚席”，玲把纸移到干净边盘旁，不压在湿碗下。即使玩家先走，唐惠也按邵敏当面托付收好这张纸，不能标成玲留的。邵敏一旦离开，本次晚席不再返回

**QST-102-L043｜屏幕文字**：我再坐一段

## QST-102-S004 · 第二张照片少了另一个人

入口：晚席，早席餐具已清出可用桌面。邵敏不在；阿东从门口提配送包进来，先把包放到不挡通路的位置。宋美香本人随后到店，从唐惠按本次食品条件保管的位置取出 S002 已送达的那两袋试做新品与旧款，分袋放桌端；没有再送第二份。晚席路线的玲从门口进入；已留下路线的玲保持原座位。唐惠把获准留存的早席照片与邵敏便条放桌侧，未同意的照片没有出现

<a id="qst-102-s004-k01"></a>

### QST-102-S004-K01 · 留的那份交到本人

玩家镜头，唐惠将留给阿东的旧款面包单独放在干净盘上，再等他点现做热食。玩家参与“把便条递给阿东”时，玲从干净盘边拿纸递出；不在场路线由唐惠递纸，只有实际执行者作动作

**QST-102-L046｜阿东**：她每次都推荐我吃不了的辣味。
**QST-102-L047｜唐惠**：那你回她一句。
**QST-102-L048｜屏幕文字**：下次你当面尝给我看。——阿东
**QST-102-L049｜阿东**：面包收到了。热的现在点，今天不用抢谁剩下的一口。

留份只有本人接到才记为交付，单放桌上不算。现做食物按普通出餐节拍切入，兄妹不进厨房搬锅；本席不重新演采购。阿东将邵敏的便条放回桌边，吃一口后才翻手机看牌局地点

<a id="qst-102-s004-k02"></a>

### QST-102-S004-K02 · 不拿包来顶人

短接管触发：晚席已实际坐定，安可再次拿手机，机位仍从手机侧后看桌面。她下意识抓住邵敏早先坐过的椅背，看向空座，松开手，没有把谁的包摆上去；新照片保留另一边的空位

**QST-102-L050｜安可**：第二张。人还是没齐，这回少的是另一边。
**QST-102-L051｜阿东**：我能留。别给我画一个邵敏在旁边，我看了还得给她让座。

安可将本次照片给宋美香看，并指明只在答应的人之间留；宋美香看完整张后面向安可点头。曜实际在晚席且入镜时，重新看这张照片再播放 L077，不沿用早席同意；不在场时不播放。唐惠亲自看本次画面，把手机交回后播放 L078

**QST-102-L077｜月城曜**：这张也只给答应的人看。

**QST-102-L078｜唐惠**：这张也是，别拼前面的。

玲首次参加本席或本席再次被拍时，需要本席自己的同意，不能借早席的许可覆盖新照片。晚席保留/拒绝使用以下独立选项与响应，完成后汇入 K03

**QST-102-L052｜屏幕文字**：这张也只留给答应的人
**QST-102-L053｜屏幕文字**：这张别留我
**QST-102-L054｜安可**：记住了，两张各管各的，不拼一张。
**QST-102-L055｜安可**：删这张。你继续吃，我拍桌子和愿意入镜的人。

交还控制在玲原座位。跳过只结束拍摄动作，不默认照片许可；缺席者既不会被拍进来，也没有代表别人作答的选项

<a id="qst-102-s004-k03"></a>

### QST-102-S004-K03 · 新面包没有赢过旧款

玩家镜头，宋美香看见新品袋比旧款袋鼓。安可手在新品上方略停，转向旧款，试着从袋后侧拿；宋美香直接把旧款袋向她推近，另一手把新品袋口折小

**QST-102-L056｜宋美香**：行，我明天少做一盘。你倒不用偷偷吃。
**QST-102-L057｜安可**：我本来想晚一点再拿。
**QST-102-L058｜宋美香**：晚一点你也还是拿这个。趁现在还好吃。

不弹“夸新品”讨好选项。桌面清楚保留真实偏好与剩余量，新品不会因一句鼓励突然全部售罄

<a id="qst-102-s004-k04"></a>
