# 寄往新地址：完整制作脚本

[故事正文](../../../../player/story/world/new-address.md) · [共用写法](../script-format.md) · [正式台词](dialogue.csv)

本任务主动游玩预算为 25–40 分钟，转场不以现实等待计时。以下镜头使用相对地标锁定构图与切换条件；自由操作段保留玩家机位，短接管仅完成已触发的表演，未操作的证据、选择和交付不会因跳过得到完成。台词阅读呈现由同目录 CSV 回填

## 阅读顺序与出演索引

- S001 取得本人当前需求和方式 → S002／S003 依正常公共路线比较小物与关系
- S004：寄物走 K02，资料走 K03，K01／K04 为共用家庭交接
- S005 已收到但未使用 → 后续剧情时段 S006 实际使用回应；公开照片和迟来试玩均可选

稳定角色身份：`CHR-001`、`CHR-002`、`CHR-003`、`CHR-009`、`CHR-010`、`CHR-013`、`CHR-035`、`CHR-055`；台词表使用这些身份，SYSTEM 仅为屏幕或纸件文字

## QST-027-S001 · 照片还没放进箱里

入口：米娜已真正离城，主动给兄妹发来近况；她不为补支线搬回旧家。月台杂货后场工作桌，玲操作，曜在另一侧整理普通店务，巧克力停在显示消息的位置。玲桌上有自己的旧合照、未制作的底座图样和空包装样盒；样品盒里有月台杂货自有的两款小夹，一款底座六厘米见方、一款较宽，本次仅试用，未选样品会放回库存；第一章各玩具仍按原决定带走、寄售或留存，不从旧箱里重新取一套赠品。较晚开始时读米娜本次更新的小需求，不倒回搬家第一天

<a id="qst-027-s001-k01"></a>

### QST-027-S001-K01 · 下一句才是她要的

玩家镜头打开米娜主动发来的文字，消息不以米娜在场说话的声音播放。玲看见第一段，已经把旧合照移到盒边；玩家继续阅读到末句，她的手停在照片短边，随后把照片移回自己一侧

**QST-027-L001｜米娜**：我的桌子比想象中窄。能放夹纸小物的这一角，我量了一下，最多留六厘米见方；再大就占写字的位置。想请你们帮我找个能夹零散纸张的小东西。

**QST-027-L002｜米娜**：别装满一整箱。我现在真的没有那么大的地方。

**QST-027-L003｜曜**：这张照片也包进去？

**QST-027-L004｜玲**：先等等。她要的是夹纸的这一小块。

<a id="qst-027-s001-k02"></a>

### QST-027-S001-K02 · 好看的一圈挤到了纸上

玩家将原底座草图放在米娜给出的可用方框上比较，图样越出方框会盖住写字区；可缩放一次纸样看清图案挤在一起，不能以画得更漂亮跳过尺寸。玲沿缩小后糊成一团的线描一笔，停下来，松开按纸角的手

QST-101 已完成且口袋样片仍在本人允许的使用范围时，玲从工作夹取出自留尺寸样片作比较；未完成时仅使用眼前米娜给的六厘米方框，不产生母亲已经改好口袋的回忆

**QST-027-L005｜玲**：上回口袋也是先看手怎么进去。这次先看纸往哪里放，图样留在我这儿也可以。

**QST-027-L006｜玲**：缩小以后看不清，放大又占她写字的位置。这张先留着。

玩家确认当前需要后，玲将自店两款小夹扣回随身样品盒，带去对照用途；巧克力只调出原打包去向和空着的新订单栏。不能凭旧寄存信息、朋友照片或上一封信自动填地址

**QST-027-L007｜巧克力**：原打包记录已确认。本次需求：夹纸小物。收件方式未定，新收件地址未取得。

<a id="qst-027-s001-k03"></a>

### QST-027-S001-K03 · 先问寄什么方式

玩家实际发送询问当前取得方式的消息，玲先把可做的六厘米以内底座画成两种简图，附上只取得尺寸说明也可行的安排。寄送和资料两路来自米娜确认，不通过玩家替她选择礼物大小；尚未答复可结束查看并去做其他事

**QST-027-L008｜玲**：我们先按这个尺寸试。你想收一个做好的，还是只要尺寸和做法，在那边找合适的？照片和其他东西先不一起放。

**QST-027-L009｜米娜**：寄一个做好的吧。我确认好这次能收件的地方，再单独发给你。

**QST-027-L010｜米娜**：给我尺寸和做法就好。我可以在附近买一个，或者自己做，不用寄。

出口：保存本人确认的方式，未确认时可先到 PLAYROOM 比较实物与做法，但不能发运。之后改方式只在交运或资料发送前按米娜明确的新答复处理；交运后不无说明地把包裹改成数据

<a id="qst-027-s002"></a>

## QST-027-S002 · 她不在，今天也试一局

入口：PLAYROOM 正常创作时段，苏弥正在自己的工作台改短游戏，屏幕一侧开着尚未发送的留言。兄妹来比较说明卡的小夹，玲操作，曜在旁边等腾出试用位置。这里不是要求米娜远程立即接入的测试活动

<a id="qst-027-s002-k01"></a>

### QST-027-S002-K01 · 没发出的半句

玩家镜头，只有苏弥主动把留言窗口转给玲看后才读到未发送文字，不翻别人私人历史。苏弥将演示倒回自己刚改好的一处，嘴角抬了一下，又被未发的留言拉住目光

**QST-027-L011｜屏幕文字**：未发送：你什么时候回来帮我试玩？走了就不管这边啦。

**QST-027-L012｜苏弥**：我知道她忙。就是这个地方改好了，原来最想先给她看。

**QST-027-L013｜玲**：先留你今天最想让人试的那一小段。她什么时候有空，我们还不知道。

玩家帮苏弥定位这一段可开始与可结束的位置，她把催回来的话全部选中删除，再写邀请。短特写只从她确认替换文字到发送前停顿；跳过不把未发草稿当成已发

**QST-027-L014｜苏弥**：这里改了一小段。有空再看，不用特地回来，也不用今天答我。你看到的还是这份版本。

苏弥确认后自己发送，手悬在键上片刻才松开，随后转向站在旁边的曜

**QST-027-L015｜苏弥**：你先来。今天这一轮别也放进等回信里面。

<a id="qst-027-s002-k02"></a>

### QST-027-S002-K02 · 说明卡真的挡住了吗

玩家镜头。苏弥拿起桌上固定说明卡的小夹，先把卡松开，再让玲按六厘米方框比较底座和夹口；小夹仍是现场用品，不未经允许直接装进包裹。QST-103 已做时它承接已实际使用的经验；未做时只就眼前夹纸行为展开

**QST-027-L016｜玲**：那次它让被挡住的说明露出来。这回先试她这一叠，不能只记得我们用着方便。

**QST-027-L017｜玲**：夹住一张试试，再加到她平时那样一小叠。底座不能压进写字的地方。

玩家将自店两款样品与苏弥的说明夹并排，取一张纸、再一小叠纸分别放入夹口，观察是否遮住需要读的一面；底座若超出方框，只保留“不合适”的比较记录，不强迫赠送。玲把自店六厘米样品的用途与尺寸记下，将较宽样品扣回盒内待归库存，向苏弥归还工作台原夹，桌面说明卡重新夹稳

**QST-027-L018｜苏弥**：这个留给我固定说明。你们拿尺寸，别把我的下一轮也一起寄走。

<a id="qst-027-s002-k03"></a>

### QST-027-S002-K03 · 本地这一轮有个结果

曜在苏弥已经指定的短片段里实际操作，玲可继续自由观察，游戏屏幕仅使用当前原型已有操作，不为本故事新增战斗或规则。苏弥在他卡住的位置作标记，等片段正常结束才接回控制器

**QST-027-L019｜曜**：这里我没看见下一步。你刚才说的，我听见了，屏幕上还没找到。

**QST-027-L020｜苏弥**：记这儿。那就先改这一处，她晚一点看也不用等着我什么都不做。

出口：只取得本次合适尺寸与做法，不带走苏弥原夹；邀约和本地试玩分别保存。离开前未发送者草稿仍未发，已发者不重发，未试完者可继续同一短片段，不能自动填写米娜反馈

## QST-027-S003 · 那个位置今天有人

入口：桌游卡牌店一局普通活动开始前，周然在桌边分牌，桌游新来者 CHR-055 已坐在米娜过去常坐的位置。玲操作，曜在她后面留出通道。此处借用小样片说明夹纸用途，活动不因米娜离城暂停；新来者不是她的替身，也不突然拥有她的私人回忆

<a id="qst-027-s003-k01"></a>

### QST-027-S003-K01 · 收回来的手

玩家镜头进入桌边后，玲下意识把自己带的小样往旧位置伸，新来者正将自己的东西收拢到桌角。玲停住，把小样收回胸前；周然数到自己面前时发现少放一份，把牌重新收齐，再按当下人数铺开

**QST-027-L021｜周然**：她回来可以一起玩。今天这一局，先让今天的人坐下。

**QST-027-L022｜桌游新来者**：这一张是给谁的？我是不是多拿了？

玲顺周然留出的位子坐到自己这一侧，手掌向上接住那张牌，目光仍短暂经过对面的旧席

**QST-027-L023｜玲**：给我的。刚才是我站错地方了。

短接管从伸手停住到坐到本人位置结束，机位在桌边中景同时保留两人不同位置；可跳过到玲已坐定，但不替玩家完成之后的样片试用或任何正式游戏胜负。玩家可正常起身退出

<a id="qst-027-s003-k02"></a>

### QST-027-S003-K02 · 同一行又漏了

玩家在桌边参与一次原有桌游的简短轮次或直接查看当局说明卡，不新增强制赢牌条件。新来者按现有规则漏看卡上说明的下一行，周然把手指移到那一行；玲准备提醒的手停住，先让对方自己再读

**QST-027-L024｜桌游新来者**：原来下面还有一句。我只看到上面就动了。

**QST-027-L025｜玲**：她以前也会漏这里。……我自己也漏过。

**QST-027-L026｜周然**：那就把要读的留在看得见的地方。这张小样能借，原局用的卡留在桌上。

玩家接取借用样片，周然另折一张新规则卡供米娜本人决定是否需要，写下实际可读的小邀请；这张是可选附物，不提前塞进样盒

**QST-027-L027｜屏幕文字**：给新的一桌：先把说明放到大家都看得到的位置。有人没记住，就停一下再读。留一句给一起玩的人：下次也给我留个位子。

<a id="qst-027-s003-k03"></a>

### QST-027-S003-K03 · 只要普通的那个

玩家在可拍照的工作小桌拍下合适小物、可选照片和新规则卡，画面不带其他客人的脸。玲把选物图发给米娜；她的决定沿本次通信返回，未答复部分继续不包入

**QST-027-L028｜玲**：这个底座在你量的六厘米范围里。旁边的照片和规则卡都是可选，你想要哪样就说；只留夹纸的也可以。

**QST-027-L029｜米娜**：就那个最普通的夹子，别加底座花纹。照片先留你那里，规则卡我这次也不用。

**QST-027-L030｜米娜**：夹子的做法加上规则卡的文字发我就行，不用寄实物。照片先别打包。

若本人已确认要附照片或实物规则卡，使用下句替换实物“只要夹子”的回复，不强制她选择该版本

**QST-027-L031｜米娜**：夹子之外，再放那张我刚确认的小照片和规则卡，其他就不用了。

本人只需要一项附物时分别使用以下回复，不能把它们合并成默认两件都寄

**QST-027-L061｜米娜**：夹子和刚才那张小照片就好，规则卡这次不用。

**QST-027-L062｜米娜**：夹子旁边放那张规则卡就行。照片留你那里。

玩家核对本人确认的清单后将未选样品归还周然，借的原样片无论哪条路线都在离店前还回；月台杂货自有的候选小物由兄妹带回工作台，未选较宽样品归库存，未使用的大底座图始终在玲的工作夹里

出口：本次方式与内容确认保存；未回复可带着自己的记录回店，候选物暂不发运。若实物选项变更发生在交运前，以米娜最后明确回复核对一次，不重播整个牌局

<a id="qst-027-s004"></a>

## QST-027-S004 · 今天有人替它接这一段

入口：月台杂货交接工作台，玲操作，曜在包装一側。巧克力原本约好参加一段家庭活动，日程图标已亮；具体活动仍沿已确认安排，本篇不替用户选择新活动。消息、物品清单、可用尺寸和待交接文件分开放置。寄物路线准备一件确认的小物与获准附物；资料路线没有邮包、地址表和邮费支付

<a id="qst-027-s004-k01"></a>

### QST-027-S004-K01 · 图标放到它自己的那一格

玩家镜头。巧克力先抬夹持臂准备接扫描表，视线又转向自己日程。QST-022 已做时沿用那次本人选过的观众图标；未做时显示本次自己的参与标记，不预先回忆小屋檐

**QST-027-L032｜巧克力**：今天这一段，我要参加。

**QST-027-L033｜玲**：清单我对。寄东西的话，封箱也我来；只发资料就由我看一遍能不能打开。

**QST-027-L034｜曜**：地址和费用我按米娜这次的答复核，交到人手里也我来。发资料就只核那份内容，不填地址。

巧克力将表交到玲手里，等她握住后松开；屏幕参与图标移到当前时段，沿正常路线离开工作台去参加原活动。短接管只用于物件交接，可跳至表已交与它离开，不代办资料检查或发运

<a id="qst-027-s004-k02"></a>

### QST-027-S004-K02 · 寄物：空栏等本人填

仅实物路线，玩家镜头。新地址尚未收到时，曜把标签收在包裹旁，不打印猜出的地址；有回复后只在个人核对界面显示实际所需信息，镜头不必把完整私人地址拍给无关人物。以下消息属于米娜主动发送，不据照片定位

**QST-027-L035｜米娜**：这个是我这次能收件的地址，按这条写。只用于寄这份东西，店里的照片别带上这一页。

玩家对照本人清单放入唯一小物与实际选中的附物，玲托住箱底，曜把防碰材料放在空隙，不拿未选照片填空。玩家核对实际寄件费用并按双方确认安排支付，未确定费用前可收好暂存，不凭一句“尽快”自动发运

**QST-027-L036｜屏幕文字**：本次收件方式：寄送实物。内容按米娜最后确认的清单；地址仅供本次寄送。费用确认后交正常配送。

**QST-027-L037｜曜**：物件、这一回的地址、费用都对上了。封好以后就按这份交，不再往里加东西。

玩家执行封箱，玲压齐盒盖再贴封条，曜沿盒边确认无松口，把面单贴在平整面；只有实际交给正常承运并获得接收记录才记“已交运”，封好仍放店里时不记送达。阿东若承担本次正常揽件，按他的真实班次来，不要求他额外加班

**QST-027-L038｜阿东**：这份我接了，按面单上的这次交。后面有回执再看，不是我拿出门就算她收到了。

<a id="qst-027-s004-k03"></a>

### QST-027-S004-K03 · 资料：先在这里打开一次

仅资料路径，玩家镜头。玲把尺寸图、文字做法和米娜实际需要的可选规则卡内容排成可直接读取的页面，曜在另一个普通阅读界面打开同一份检查；不生成地址、物流单或邮费步骤，桌面样盒保持空着并收回
