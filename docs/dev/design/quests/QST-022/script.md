# 巧克力今天不值班：完整制作脚本

[故事正文](../../../../player/story/daily/chocolate-off-duty.md) · [统一写法](../script-format.md) · [正式台词](dialogue.csv)

设计预算：15–25 分钟；动作、试听、路程与转场均包含在原预算内，实际时长待灰盒验证

出场：巧克力（实体店员机体参加）、玲（前半程操作）、曜（完成交班后后半程操作）、凯文、安可

场次阅读顺序：S001 报名意图 → S002 实际轮班 → S003 玲陪前半场 → S004 曜接后半场 → S005 本人图注与照片 → S006 回店安置与重访

普通共用院小型手作活动；邀请错过便约真实的下一场，不倒退结束的展出。巧克力统一身份与并行能力不变，这次选择不兼做普通接待。Q027 若已交付，实体寄件与数字资料分别回顾；未做不生成回忆。Q103 的拆改展示只在该次实际发生后引用。家庭合照可私留或在各参与者同意后用于本次展示

控制通则：未明确标为短接管的镜头均由玩家控制，可暂停、查看与离开；近看文字后回到原站位。短接管只在对应交互已经发生后播放，暂停与跳过可用，期间停用移动、切人及其他交互；跳过仅落定该次已经触发的表演，保留未做的观察、选择、交接与操作。所有镜头以可见动作或对白结束为切换点，建议节拍不作为已测时间

## QST-022-S001 · 图标放回来了

入口：月台杂货报名桌，玲面对活动报名界面，曜在另一侧看店务日程，巧克力实体机体在两人间偏外、能触到屏幕的位置。活动邀请写明一个完整参加时段，与一段基础接待重合；报名尚未提交，谁也没替它确认服务岗位

<a id="qst-022-s001-k01"></a>

### QST-022-S001-K01 · 错了一栏

玩家镜头。巧克力先替已同意的人整理报名，最后把自己的名字与小椅子图标放到参加栏，指尖停在名字后。玲看见有一项未归接待，顺手拖到协助栏，话说完才看巧克力；它低头看被移动图标，再将其拖回观众栏

**QST-022-L001｜屏幕文字**：共用院手作小展示：参加／协助接待。填写本人意愿后确认报名。

**QST-022-L002｜玲**：连自己都没忘。接待这边是不是还少一个？

**QST-022-L003｜曜**：刚才点错了？

<a id="qst-022-s001-k02"></a>

### QST-022-S001-K02 · 椅子和作品一起放大

短接管。机位在报名屏侧、略低于成人视线，中近景同时看到曜伸到一半的手、巧克力屏幕与小椅子。它将自己的名字、小椅子和作品图形放大，身体向参与栏靠一点；曜的手停住，随后落到自己那边桌沿，不再替它拖动

**QST-022-L004｜巧克力**：参加

**QST-022-L005｜玲**：你想坐在那里做，不是去帮别人登记。

巧克力发短促肯定拟声，屏幕笑脸亮起又收回参与图标；不新增人类口语。它把“接待”和“参加”并排，先同时点亮展示能力没有失去，再只留参加。镜头在玲手离开报名控件后交还桌前控制，跳过保留意愿已看见，不自动完成轮班或报名

**QST-022-L006｜巧克力**：这次：参加

<a id="qst-022-s001-k03"></a>

### QST-022-S001-K03 · 先看谁真的在店里

玩家镜头。目标是查看兄妹已答应的日程及活动邀请。可以先看日程发现重合，玲直接承认，不再让她误读一次。两人把各自待办展开，巧克力不自动填补没人负责的空档

**QST-022-L007｜曜**：活动的这段，我前半能留店。后半要先看你什么时候接得上。

**QST-022-L008｜玲**：我先陪它过去，再回来接你。普通整理挪到之后，别也塞进这段里。

**QST-022-L009｜屏幕文字**：拟安排：前半段曜接待，玲陪同；玲返店交班完成后，曜去共用院。普通整理留到活动之后。

出口：巧克力意愿保留，但报名未提交。日程与普通店务单由兄妹自己拿到接待台，进入 S002，不能在他们口头说好后就让无人看店的空档消失

<a id="qst-022-s002"></a>

## QST-022-S002 · 接住留下的事

入口：月台杂货接待台，曜站收货架前，玲在记录本侧，巧克力实体机体面向他们逐项展示取货位置。已确认订单在对应架格，尚未确认的普通查询留空；没有新的紧急事务，也不展示无关顾客隐私

<a id="qst-022-s002-k01"></a>

### QST-022-S002-K01 · 能接续才确认

玩家镜头。玩家核对两个已可用时段，普通整理明确挪到之后，选择“确认本次轮班”进入 K02；若当次已有不可挪的承诺挡住接续，显示下一项并使用延期回应。延期只约下一场真实存在的小活动，不开强制现实等待计时

**QST-022-L010｜屏幕文字**：确认本次轮班，让巧克力完整参加

**QST-022-L011｜屏幕文字**：这次无人接续，预约下一场小活动

**QST-022-L012｜玲**：这次后半接不上。我们不能先送你过去，再一直叫你回来。下一场我先把自己的时间留好。

**QST-022-L013｜曜**：把下一场邀请留着，到那天按能交接的安排走。今天不算已经放假。

**QST-022-L014｜巧克力**：下次：参加

延期路线退出本次活动，下一次有效邀请从本场 K01 重核真实时段，先前意愿与已留记录仍在，不播放已经做过屋檐的虚构片段。若玩家只是暂时离开核对界面，保留拟排班未确认状态，回来可继续

<a id="qst-022-s002-k02"></a>

### QST-022-S002-K02 · 取货架先认一遍

玩家镜头。目标是曜实际查看取货架、交接本与待确认查询三个位置。巧克力指向每个实物位置，曜走过去找到对应格，玲核对记录后勾已接手；空白查询只写待问，不用巧克力猜客户意愿补全。三处可任意先后，已经确认的保持勾选

**QST-022-L015｜屏幕文字**：取货：按已确认记录核对架格。未确认订单：留空，先问当事人。普通查询：记录后由当班者处理。

**QST-022-L016｜巧克力**：已确认：取货架；待确认：留空

**QST-022-L017｜曜**：架子我找到了。这个没有确认，我先记着问。

**QST-022-L018｜玲**：我回店以后接后半，不从院子里再叫它查。

<a id="qst-022-s002-k03"></a>

### QST-022-S002-K03 · 又想添的一件

玩家镜头。曜指向一项不急查询，话头已出，玲把刚写的轮班页推到他手下，指他自己名字对应时段。曜看巧克力已选的椅子图标，把查询挪到自己的纸角，写下要问的问题；巧克力没有从活动中远程补做

**QST-022-L019｜曜**：这项你到那边还可以顺便……

**QST-022-L020｜玲**：这一格是谁接的？

**QST-022-L021｜曜**：我。好，我自己记，问清楚再填。

**QST-022-L022｜屏幕文字**：待问：对方要的是当前现货，还是下一批到货？普通查询由曜接手。

<a id="qst-022-s002-k04"></a>

### QST-022-S002-K04 · 曾经接下过哪一种

玩家镜头。若 Q027 已交付，玲翻到那次真实完成记录，物理包裹和数字资料只用各自一句；若未做不翻不存在记录，直接确认本次。巧克力只看已知资料，不凭云端能力造地址

**QST-022-L023｜玲**：米娜那次寄物，我们自己核地址、装包和交配送。今天这张也能自己接。

**QST-022-L024｜玲**：米娜那次只要资料，我们自己核对能不能打开。没寄东西，也没有去填地址。

**QST-022-L025｜玲**：今天就从这张单开始。你回来我给你看做完了什么。

**QST-022-L026｜巧克力**：参加时段已确认

出口：玩家实际确认报名，巧克力实体机体随玲从正门去共用院，曜留店前半段；普通查询在曜纸上，整理留到之后。店务通信不向院子推送普通问题，紧急事务仍按正常安排处理，不因本支线杜撰险情。玲为当前可操作角色进入 S003

<a id="qst-022-s003"></a>

## QST-022-S003 · 先让我放这块

入口：共用院低手作台，凯文在材料侧，玲带巧克力到桌前。纸材与小零件由凯文放低到机体能抓握的位置，左右留出转身空间；曜明确留店，没有同时在院内。巧克力决定做一小段屋檐，玲的任务是陪同和递它请求的材料

<a id="qst-022-s003-k01"></a>

### QST-022-S003-K01 · 够得着的位置

玩家镜头。凯文先把高处材料箱移到低台，从箱里逐件放下硬底片、屋顶纸和小夹子；巧克力伸出夹持端试抓最外一块，凯文见它碰到箱边便把箱再转开。玩家可以先绕台检查空间，提前发现碰边可立即调整

**QST-022-L027｜凯文**：这里抓得到吗？先试，不够我再往这边放。

**QST-022-L028｜巧克力**：这里

**QST-022-L029｜玲**：今天我负责递，不替你选。

<a id="qst-022-s003-k02"></a>

### QST-022-S003-K02 · 颜色不配也要

玩家镜头。巧克力取两块颜色不相配的纸，一块平放做底座、一块举成坡面；玲下意识抽出更协调的纸，递到夹持端前。它没有接，将自己原选那块转一方向，把边缘对到想要的位置；玲持新纸悬一拍，慢慢放回箱内，原选颜色不被交换。巧克力从同色边角里取一小条，折成低矮的支撑片，试放在底座与屋顶接触处；原屋顶纸搭在这块试折片上，支撑还未稳定

**QST-022-L030｜玲**：这块配起来会不会……好，你先放。

**QST-022-L031｜巧克力**：这块

**QST-022-L032｜凯文**：等它摆完再看，先别替它把图改了。

<a id="qst-022-s003-k03"></a>

### QST-022-S003-K03 · 玲先留下一张草图注

玩家镜头。玲帮把散落边角放到小托盘，不碰已摆好的作品；她顺手在临时图注纸写下拟稿，纸留桌侧并明确未获巧克力确认。玩家可以查看此稿，为后半场具体修改留下实物起点

**QST-022-L033｜屏幕文字**：临时图注，待确认：大家一起完成的小屋檐。

**QST-022-L034｜玲**：我先写个位置，你做完再改。到交班了，我回店接曜。

**QST-022-L035｜巧克力**：继续做

<a id="qst-022-s003-k04"></a>

### QST-022-S003-K04 · 交班这段真的发生

玩家镜头随玲实际离开手作台、沿普通路回店，巧克力留在凯文主持的活动场内继续自己的制作，不跟回店接待。到接待台玲接过曜记录本，逐项对当天已处理与尚未处理的内容，未确认项仍有标记。此时才允许把操作交到曜；不是隔空把两位主角互换位置

**QST-022-L036｜曜**：前半段交付已记在这里。这项查询我问了，还在等对方确认，没替他下单。

**QST-022-L037｜玲**：看到了。后半我在店里，普通整理还是留到后面。你去看它做的那块。

**QST-022-L038｜屏幕文字**：前半段由曜完成；后半段玲已当面接手。未确认查询保留待复；普通整理未做。

出口：玲站上真实接待位置，曜合上自己的工具盒，将空手腾出后从正门步行去院子；镜头在玩家主动确认“交班完成，随曜去院子”后切到店门口曜的跟随位，玲仍在店内，暂停和离开不让店无人。恢复后从实际交班阶段续接，巧克力没有被普通询问中断。S004 由曜操作

<a id="qst-022-s004"></a>

## QST-022-S004 · 它自己重摆

入口：共用院同一低台，凯文仍在材料侧，巧克力已把屋顶暂搭在底座，临时图注在桌角；曜从院门走近，安可带手机到展示边，玲在店后半段接待。颜色与前半段一致，材料没有因为换主角自动升级成完成品

<a id="qst-022-s004-k01"></a>

### QST-022-S004-K01 · 先挡住那只手

玩家镜头。曜看屋顶歪，伸手想扶正；巧克力先把夹持端挡在他手前，另一端护底座，屏幕亮很有把握的笑脸。曜停下，手摊开放到桌边。屋顶在笑脸尚未收回时沿原接触面滑下，落到托盘里，没有伤人和异常

**QST-022-L039｜曜**：这边是不是该……好，你来。

短接管从玩家实际收手触发。机位在低台侧面近景，完整看到曜退手、屋顶滑落和巧克力低头的视线方向；给它看自己失败的一个完整停顿，不立刻用台词盖过去。凯文嘴角动一下，抿住笑，屋顶停止滑动即还控制，不自动替它搭好

<a id="qst-022-s004-k02"></a>

### QST-022-S004-K02 · 只夹底座

玩家镜头。巧克力把落片推到曜手边，先显示夹子，再点底座边；曜拿夹子给它看，只有玩家执行“夹住底座”才把夹口张开、扣在底板边且避开夹持端，松手确认夹牢。巧克力先从底座取下刚才过低的试折支撑片，放进旁边托盘；再从同色边角另取一条，折出更高的支撑。它取回托盘里的原屋顶纸，换方向搭上新支撑，压住接触边后才放手；凯文将第二只夹子放在旁边而不代夹

**QST-022-L040｜巧克力**：夹子：底座

**QST-022-L041｜曜**：只夹这里。屋顶你自己放。

**QST-022-L042｜凯文**：另一只在旁边。要用再拿。

若玩家伸手扶屋顶，巧克力仍护原位置，曜收手重新给夹子；这是纠正误操作而不是强制失败奖励。跳过不会在尚未执行夹底座时生成夹具。操作结束屋顶以巧克力重摆的位置留住，颜色仍不协调，玲未出现在台边

<a id="qst-022-s004-k03"></a>

### QST-022-S004-K03 · 手机先放低

玩家镜头。安可抬手机寻找自己脸的角度，巧克力没有抬头配合，指最后一块，再把观众图标移到朝安可的屏幕位置；安可看见后将手机降到膝旁，坐到空椅子，不把未完成手作摆成已完成合照

**QST-022-L043｜安可**：现在拍？我站这边光好。

**QST-022-L044｜巧克力**：先放完

**QST-022-L045｜曜**：玲平时也得等你选完照片。

**QST-022-L046｜安可**：我又没说不等。

<a id="qst-022-s004-k04"></a>

### QST-022-S004-K04 · 声音也让它选

玩家镜头。巧克力从活动台已有的演示声里选一段轻短提示音，按播放后看安可；具体音色留给音频制作，本文不交音频资产。安可这次等完整提示结束才举手机，曜不代替挑“更像屋檐”的声音

**QST-022-L047｜巧克力**：展示声音：这一段

**QST-022-L048｜安可**：我听完了。现在轮到问你能不能拍。

出口：屋檐实际完成，底座夹子仍在，原屋顶纸已回成品，拆下的旧试折支撑片与余料留在托盘，临时图注仍写“大家一起完成”。曜与巧克力进入 S005 处理署名和照片，不把拍照许可当已获得

<a id="qst-022-s005"></a>

## QST-022-S005 · 谁的作品

入口：同一低台，成品在巧克力前，曜站侧面拿临时图注，安可坐空椅，凯文保管材料箱。玲只在字条上留下初稿并在店里值班，照片不得把她凭空合成为现场在场者

<a id="qst-022-s005-k01"></a>

### QST-022-S005-K01 · 把名字挪回去

玩家镜头。曜拿起玲的初稿，让巧克力看全，再把纸放它可操作处；它将自己的图标移到作品前，把兄妹名字移到材料和帮助栏。曜指底座夹子，巧克力看一眼，给曜名下补夹子图标，再将作品朝自己转半圈，等待用正确署名拍照

**QST-022-L049｜曜**：玲刚才写“大家一起完成”。你要不要改？

**QST-022-L050｜巧克力**：作品：巧克力

**QST-022-L051｜曜**：那我这只夹子放哪儿？

**QST-022-L052｜巧克力**：帮助：曜夹底座；玲递材料；凯文提供材料与场地

**QST-022-L053｜屏幕文字**：小屋檐｜制作：巧克力｜材料与场地支持：凯文｜递材料：玲｜底座夹持帮助：曜｜保留拆改小块与制作过程

<a id="qst-022-s005-k02"></a>

### QST-022-S005-K02 · 旁边留下失败的那块

玩家镜头。凯文用托盘把此前实际从底座拆下的旧试折支撑片留在成品旁，二者之间留清楚间距，不混成新成品组成部分。Q103 已发生则提实际制作展示；未发生只谈本次实物，不声称苏弥游戏已完成
