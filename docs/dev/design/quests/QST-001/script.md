# 序章 · 门还开着：完整制作脚本

[故事正文](../../../../player/story/main/prologue.md) · [共用写法](../script-format.md) · [正式台词](dialogue.csv)

完整中文制作稿，覆盖分场纲七场和结项重访。预算沿用 30–45 分钟；移动、观察、店务操作占用同一轮生活时间，镜头以动作与对白完成切换，不强制用慢动作、等候或重复跑图填满预算。台词以 CSV 为源，音频尚未录制，实际镜头和时长待场景验证

参与：月城曜、月城玲、巧克力、阿东、乔伊、安可、米娜；顺路取物与采购可见陆成、唐惠。没有 Black Case，不发生潜梦。入口为共同经营小店的普通一日；出口为陈列实际状态、本趟配送一次性交付、小册校样与海报咨询留档、米娜次日上门约定

阅读顺序：S001 工作台 → S002 本趟配送 → S003 真实路线 → S004 陈列 → S005 小册 → S006 海报咨询与顺路外出 → S007 米娜及晚饭 → S008 条件重访。S001/004 的未完成店务不扣住配送与来访，S006 顺路取物/采购先后任选；在场来访发生一次，重进不复制订单

镜内原子动作约定：递物前可中断并保留原持有者，实际接触到接稳期间的暂停恢复在同一动作点；跳过只落定已触发的这次交接。装配中断不复制零件，恢复已开始动作后仍要玩家亲自做独立复核；所有离开续接均保持已经实际完成的物件状态

<a id="qst-001-s001"></a>

## QST-001-S001 · 工作台交接

入口：同一轮白天店务，月台杂货工作台靠服务门的一侧。玲为当前操作角色，站在架子的取货端；曜在工具端，一手接电话、一手扶着未装的支架，另有备用螺帽靠在唇间。电话对方只作听不清内容的声底，不增加有文本的陌生说话者。巧克力停在两人之间偏外的位置，旧完成卡夹在它的卡夹上；陈列架的末端固定孔空着，对应支架、螺丝和手工具都在工作台上，地面没有散落件。侧院可听到推车声，阿东尚未进入本场交接

已知：兄妹都知道这件是店用陈列架，玲尚不知道最后一个固定件未安装；旧卡来自上一轮工序，其字样不能代替本轮检查。此时不解释任何异常或终章

<a id="qst-001-s001-k01"></a>

### QST-001-S001-K01 · 从正在做的事开始

玩家镜头，自由移动与观察。工作台的空孔、工具端和卡夹位于可绕行的同一观察范围，玩家可先看卡或先看空孔，不强推机位。靠近取货端时曜听电话，视线跟着螺孔走，没有抬头确认玲拿的是哪一侧；他伸出小指朝架子点一下，肩膀仍夹着电话

**QST-001-L001｜月城曜**：差不多了，架子先拿过去。

曜说完把支架略微抬起，给玲留下一个看似可以提走的空隙。玩家尝试“拿起架子”时，玲仅提起靠自己的一端，架框轻晃，未连接的支架留在台面；她立即把重量落回台面，不允许抱着松散架子离开。若先观察空孔，直接显示同一实体细节，省去试提动作，没有角色要求补犯一次错

<a id="qst-001-s001-k02"></a>

### QST-001-S001-K02 · 卡和孔不是同一个答案

玩家镜头进入局部查看，可旋转观察架末端和旧卡，退出查看即恢复原位。看卡时呈现正面原文；看孔时能看见完整孔缘、没有穿过的螺丝和一旁相匹配的支架，不用任务提示提前写结论

**QST-001-L002｜屏幕文字**：已完成

完成卡和缺孔两项中的任意一项后可把另一项拿到视野里对照；仅看到卡不会登记“架子已固定”。实际对照后玩家触发“叫曜看固定孔”，玲左掌仍压住架脚，右手从卡片移到空孔上方，没有把手指伸进孔内

**QST-001-L003｜月城玲**：我拿过去以后，还差什么？

此句可由查看先后任一路触发一次；两项都检查过才进入 K03

<a id="qst-001-s001-k03"></a>

### QST-001-S001-K03 · 把省略的半句补回来

接管触发：玩家完成对照并叫曜查看。镜头由玲肩后缓推至工作台中景，保留两人的手、架脚与空孔在同一画面；暂禁移动、取物与换人，允许暂停和跳过本段。曜用拇指结束通话，把手机屏幕朝下放到工具盒外沿，再把唇间螺帽取下放进零件碟。他先看玲的手停在哪里，随后把支架抬到空孔前，却发现玲仍不抬架子

**QST-001-L004｜月城曜**：支架。最后这个还没装。先放回来，我这就弄。

玲按着架脚，确认台面已完全承重后，手掌慢慢离开；她不拔高声音，先看支架，再看曜

**QST-001-L005｜月城玲**：你刚才说的是架子，还是这一整件事？

曜本来准备把支架装上，听完停住。巧克力低头看卡夹，屏幕的完成勾缩小，伸出夹持臂，将卡片翻到空白背面，推到玲手边。切回玲原站位的玩家镜头，给予“写清当前完成度”交互。跳过只落到卡已翻面、零件已放妥的此处，不代写新卡，也不安装支架

<a id="qst-001-s001-k04"></a>

### QST-001-S001-K04 · 写在这一面

玩家镜头，可先查看架体或已翻面的卡。确认更正后，玲用空着的手取笔，把纸压在工作台平面，在卡背逐字写下新说明；巧克力扶住卡边，待笔尖离纸才夹起，屏幕短亮一个小勾

**QST-001-L006｜屏幕文字**：架子已好，固定件未装

曜将支架放回对应缺口旁，视线从旧卡边缘移到新说明

**QST-001-L007｜月城曜**：架子。……那张卡是上一轮的。

更正交互结束即保持玲原地控制；新卡记录已经完成，未装固定件仍真实留在原处，卡不能改变它的位置

<a id="qst-001-s001-k05"></a>

### QST-001-S001-K05 · 把最后的活做完

玩家镜头。操作“扶住架框”后玲将两手分别放在稳固的立杆和底脚外侧，曜把支架抵到孔位，先用手旋入螺丝，确认能保持位置后向工具碟伸手。玩家触发递工具，玲保持一手扶稳，另一手取工具，转成手柄朝曜递出

**QST-001-L008｜月城玲**：先扶住，我把工具给你。

短动作镜只在工具接触曜手掌时接管，以工具端侧面近景看见他握紧、玲松手、螺丝逐步锁入；暂禁移动与其他交互，可暂停或跳过到本次装配动作完成。没有递出工具则不播放完成结果。曜收回工具放进工具碟，指腹轻触支架外侧确认没有悬空，再将托底的手退到架脚旁

**QST-001-L009｜月城曜**：可以松了。现在试一下。

镜头退回玲原来的玩家机位。固定件已装而“玩家复核”仍未完成，跳过不可越过下一镜的实际检查

<a id="qst-001-s001-k06"></a>

### QST-001-S001-K06 · 现在可以交接

玩家镜头，目标为查看固定孔并轻试架框。操作后玲先俯身看螺丝确实穿过对应位置，再沿架框施加轻微来回力量；固定件与架体一起停稳，没有先前的分离晃动。曜不抢答，待玲将两手完全松开后才伸手扶住搬运侧

**QST-001-L010｜月城玲**：这回是整件。

玲在新卡下面补记结果，巧克力把卡夹到架框不会被商品遮住的一侧

**QST-001-L011｜屏幕文字**：架体、固定件已核对，可移至陈列位

出口：架子留在工作台，允许玩家随后移到 S004 陈列位；本场不自动搬进橱窗。工具已回碟、手机在工具盒外沿、零件碟只留下备用件。曜抬眼看服务门外的阿东，侧院推车声把注意力引向 S002；玲保留当前站位和全部操作权。若暂不布置陈列，可先交接配送，阿东不被店用架子扣住

<a id="qst-001-s001-k07"></a>

### QST-001-S001-K07 · 更正后离开，再回工作台

条件：新卡已写，固定件未装。玩家镜头，曜指向支架，没有把它悄悄装上；玲可自由离开，只有再次选择“继续固定”才把手放回架框

**QST-001-L012｜月城曜**：架子还在台上。卡改了，固定件还没装。

**QST-001-L013｜月城玲**：好，我先扶稳。

汇入 K05 扶住架框，不重听电话或重复填卡。若只观察过而尚未更正，保留已观察项，从 K02 的未完成对照继续，旧卡仍在夹上

<a id="qst-001-s001-k08"></a>

### QST-001-S001-K08 · 装好了，还没有确认

条件：已装固定件、未做复核。玩家镜头，曜把工具碟推离架脚，给玲留出检查位置，不代替玩家搬走架子

**QST-001-L014｜月城曜**：固定好了，就差你最后看一遍。

汇入 K06；不重复装配，不生成第二个固定件

<a id="qst-001-s001-k09"></a>

### QST-001-S001-K09 · 同一件架子的重访

条件：已完成复核、尚未移往陈列位。玩家镜头，曜把夹在侧面的新卡稍微转向玲，随后继续整理工具；旧卡正面仍能翻看，但不重新变成当前完成状态

**QST-001-L015｜月城曜**：卡和架子都在这儿。已经核过了。

可继续 S002 或搬运到 S004；搬运后的工作台只留工具与普通维修件，不能再次取走同一架子

<a id="qst-001-s002"></a>

## QST-001-S002 · 本趟能带走什么

入口：同一轮店务，服务门外侧院。阿东将停稳的配送车靠在装货区，手握配送表，笔夹在表顶；另一箱普通维修件已在工作台待核对，与 S001 店用陈列架分开放置。曜到服务门与他交接，玲为操作角色；即使架子还未完成，也能开始本场。阿东知道下一程要接唐惠备料，兄妹尚未逐件确认当趟出货

<a id="qst-001-s002-k01"></a>

### QST-001-S002-K01 · 留在这一趟的时间

玩家镜头。阿东从车旁走到门槛外，等玲为箱子腾出可落放的位置，才把配送表压到箱盖上，笔尖停在“取件”栏而不落勾。曜把普通维修箱提到门内的工作台边；玲可以走近核对，也可留在前场，阿东此时只整理本来要送来的货

**QST-001-L016｜阿东**：约好的维修件，这趟能一起带走吗？我后面还要接唐惠的备料。

**QST-001-L017｜月城曜**：等我把最后那件再看一眼。

阿东把视线从曜移到表的后半页，将已圈好的收工时间转给他看，不加催促音效。玩家打开配送表，看到完整本轮条目

**QST-001-L018｜屏幕文字**：本趟：取月台杂货已确认维修件 → 接唐惠备料 → 渡口换线；未确认件留店，下趟重新核对；收工后不加单

<a id="qst-001-s002-k02"></a>

### QST-001-S002-K02 · 把未完成的一件留下

玩家镜头切局部物件查看，随时可退出。箱内各件有自己的原维修标签，玩家逐件将实物与“复核完成”位置对齐；最后一件的待检签仍挂着，曜重新试过一次后将它放到工作台的留店托盘。操作目标是把这件的配送状态改为下趟，不允许点“全部已取”掩盖差异

**QST-001-L019｜月城曜**：这件还没过复核，今天留我这里。其余这些已经核过。

**QST-001-L020｜阿东**：下一趟可以，现在别写已取走。

玩家确认留店后，玲在该件行写下新内容；原行不擦掉，未完成的物件仍在镜头内

**QST-001-L021｜屏幕文字**：留店：复核未完成；本趟未取；下一趟取件前再次确认

已确认的物件依次回箱，玲合上箱盖、扣好扣件；一次性交付只在 K03 双方实际接物后成立

<a id="qst-001-s002-k03"></a>

### QST-001-S002-K03 · 签收和手中的重量

接管由玩家选择“交给阿东”触发，服务门内侧中景保留两双手与箱底。曜托住箱底一端，阿东双手接住另一端并先试承重；曜感到重量已经转移才松开。阿东将箱落到车面，玲在“本趟已取”栏只勾已交付条目。暂禁其他交互，可暂停或跳过至箱已在车上且对应行完成，此跳过不含留店件

**QST-001-L022｜阿东**：这些我带走。留店那件，下次来再对。

镜头回到玲服务门内原位置，恢复全部控制。下一场先走真实路线，阿东还没有被传送到街口；他仅整理已接的箱子。若玩家离开，交付记录和车上箱不退回工作台

<a id="qst-001-s002-k04"></a>

### QST-001-S002-K04 · 中断的交接

玩家镜头，互斥条件。尚未确认的箱仍开着，阿东指向未落勾的行

**QST-001-L023｜阿东**：这一行还空着。你核完再叫我，我先理车上的货。

汇入 K02 剩余物件，不重查已确认项。已交付后返回时，阿东拍拍绑带而不再次接箱

**QST-001-L024｜阿东**：这箱已经在车上了。台上那件没带。

出口：配送表归阿东，店内保留对应留店记录；箱在车上，未完成件在留店托盘，店用陈列架另算。转 S003

<a id="qst-001-s003"></a>

## QST-001-S003 · 人和车走不同的路

入口：服务门、货运侧院、门前公共道路及店侧公共台阶构成同一次步行观察。阿东扶车把，曜留在服务门门边收掉脚下包装；玲站在车侧，不占车头。只画现有地图支持的方向关系，不假定坡道与私人内梯连成新运输捷径

<a id="qst-001-s003-k01"></a>

### QST-001-S003-K01 · 那边看起来更近

玩家镜头，玲可望向店侧上坡台阶，再查看车轮和货箱。点“询问台阶路线”后，她抬手沿台阶向上比划，目光从上方平台回到阿东

**QST-001-L025｜月城玲**：雨天从上坡台阶走，会不会近一点？

阿东没有抬起满载的车试爬阶，先踩稳地面，用鞋尖轻碰前轮外侧，再将掌心平放在箱顶让玲看重量的位置

**QST-001-L026｜阿东**：人能上去，它不行。车要沿公共路绕，最后从服务门交。

玩家需实际查看台阶、车轮和服务门三项；查看顺序自由，听完台词不自动完成观察。三项都已见过时可直接在 K02 标路，不强制再绕一轮

<a id="qst-001-s003-k02"></a>

### QST-001-S003-K02 · 走到转角再画

玩家镜头保持自由步行，阿东沿已经可供车通过的公共路径缓推，玲可在前后侧观察转角，人物与货车都不穿私人内梯。到拐角后阿东停轮，等待玲从墙边让出可过的位置，再缓转车头。玩家在随身纸上分别标记步行台阶与配送方向

**QST-001-L027｜屏幕文字**：步行：公共台阶 → 住宅巷；推车：公共道路 → 货运侧院 → 服务门；回家：店内后场 → 私人内梯

如果只查看了门尚未看到车过转角，纸上配送转角仍保持未标，目标仍是实际观察。停止跟随不会倒计时失败，阿东停在可停靠处整理下一件货，不让人或车封住通道

<a id="qst-001-s003-k03"></a>

### QST-001-S003-K03 · 收工的圈没有擦掉

在真实转角完成观察后触发短中景，镜头位于服务门外斜侧，留得见阿东的车与曜手中另一件未列单物品。阿东重新压住表，把手指落在收工圈上。曜走到门边本想举起物品，视线碰到圈后，慢慢把它收回胸前

**QST-001-L028｜阿东**：接完备料就去换线。今天到这儿。

**QST-001-L029｜月城曜**：这件我留下一趟。路上慢点。

阿东抬手示意，重新握好车把沿公共道路离开。接管期间只禁移动与取物，允许暂停/跳过到曜已将追加件留店、车驶出本场视线；没有新签收。镜头回玲在转角旁的实际位置，由玩家走回店里或继续街区走访

<a id="qst-001-s003-k04"></a>

### QST-001-S003-K04 · 门的用途仍然不同

玩家回到服务门、台阶或私人内梯时保留已画路线。调查服务门显示店内路线纸的同份结果，不新增谜题；若在 K02 中途离开，阿东仍在最近的公共停靠点等待确认路线，触发一次回应

**QST-001-L030｜阿东**：转弯这边还没看完。等你站开，我再推过去。

人物让开后继续 K02 未完成观察。出口：路线纸归玲，阿东已经离开则不因重访被召回。S004、S005 在同一店务内继续，公共台阶始终可供行人通行
