## QST-026-S001 · 到这里就结束的一格

入口：第五章正式会谈已结束，两人提供的历史资料不再通过本任务追加。白页书店工作桌，小满整理一张普通阅读折页，诺拉带着尚未发布的活动草案。玲操作，曜陪同取样张。遥与维恩通过已经约定、本人同意的辅助通信参与稿件工作；遥的现实照护仍在城外，屏幕不显示照护空间。本次可供观看的是获准工作内容，不是随时打开的私人生活窗口

<a id="qst-026-s001-k01"></a>

### QST-026-S001-K01 · 纸边不是备用

玩家镜头可先看折页和页边日程，再接通本次工作通信。纸边用原约结束时刻对应的短标记划出终点，不新增城市统一钟点设定；看到标记不会自动承诺延期。小满将一张便签移到待办最上方

**QST-026-L001｜屏幕文字**：本次只编辑这一张折页。到原约结束时交回确认稿；额外改动另约下一版。之后的时段已有私人约定。

**QST-026-L002｜小满**：这一格她特地写出来了。稿子交回去以后，他们各选的一首歌都得听完，不能中间换。

<a id="qst-026-s001-k02"></a>

### QST-026-S001-K02 · 还没发出去的标题

玩家查看诺拉的活动草案后，诺拉把其中“历史问答”半页移到遥可见的工作镜头范围。接管仅从诺拉递页到收回这半页：书店侧中景包含未发布草案和通话屏，屏上维恩视线向稿边倾，准备翻自己的资料

**QST-026-L003｜屏幕文字**：追加提议：早期共梦经历短问答。尚未确认，不公开发布。

**QST-026-L004｜遥**：书还没说完，就轮到我讲事故了吗？

**QST-026-L005｜诺拉**：我原来只备了几道短的问题。那块位置也留了，想让来的人多一点。

**QST-026-L006｜维恩**：有几项我可以——

**QST-026-L007｜遥**：短到什么程度，才不算把今天改掉？

维恩收回翻资料的手，将视线转回眼前书稿。诺拉把问答页对折，收进自己的未发布工作夹，不贴到活动栏，不让别的角色替两人同意

**QST-026-L008｜诺拉**：那就照普通读书交流安排。空出来的留给这次愿意来的读者。

跳过只收束这次已触发的拒绝与收稿，不替玩家阅读折页。控制回玲书店桌前，下一段可到 MONO 逐页比较；未接通信就离开时，保留未确认草案而不先宣传

## QST-026-S002 · 同一版也不同意

入口：MONO 已允许使用的普通桌位，小满把样张按阅读顺序排在桌面，玲操作；曜将两杯饮品放到纸张外侧，避免遮住文字。遥的逐条批注和维恩自愿提交的读后感已经送到，不新增远程身体出现在咖啡馆。玩家可自由离桌，别人不会因为玩家查看慢就自动发布

<a id="qst-026-s002-k01"></a>

### QST-026-S002-K01 · 把形容词后面的事写出来

玩家从开页顺读，先看到小满原本的短推荐，再翻到遥的批注。小满用手盖住只有形容词的一行，露出空着的情节说明位

**QST-026-L009｜屏幕文字**：店员初稿：这是一本温柔而疗愈的书，值得在安静的时候慢慢读。

**QST-026-L010｜屏幕文字**：遥的批注：写一件书里实际发生的事，再留一句你不喜欢的。不要替所有读者先喜欢上它。

**QST-026-L011｜小满**：我想让别人愿意拿起来，结果连讲什么都没留。那句不喜欢的，我本来删了。

玩家核对本篇实际引用的短段落，原文作为本次折页的可读节选，不延长为必须读完整本书。该段只属于本篇样书，不替换 QST-106 车票故事的两种版次

**QST-026-L012｜屏幕文字**：本篇样书节选：她把没有寄出的信留在抽屉里，开门时没有带走。天亮以后，她回来取了钥匙；信还在那里。

<a id="qst-026-s002-k02"></a>

### QST-026-S002-K02 · 被合成一句的话

玩家翻到维恩和遥的两段原意见，玲先把它们排入窄版折页，发现与自己的整齐构图冲突。她拟出合并句，只有在玩家把两段对照过后才显示该句为待审稿，不能直接作为他们已同意的话

**QST-026-L013｜屏幕文字**：维恩：结尾交代她回来取钥匙，让我知道她还会处理留下的事情。我喜欢这个明确的回返；中间的停顿若更短，关系会更清楚。

**QST-026-L014｜屏幕文字**：遥：我更喜欢门开以后那一下没有答复的停顿。回返写得太清楚，反倒替我把还想留一会儿的感觉收了起来。

**QST-026-L015｜屏幕文字**：待审合并句：不同理解中，仍有共同的温柔。

工作通信中，遥划过合并句，维恩把被省掉的反对部分贴回原位置。镜头只对获准稿页做局部查看，人物声音可来自已接通工作通道

**QST-026-L016｜维恩**：这回不同意，不是资料还没补齐。

**QST-026-L017｜遥**：也不是谁漏做了一次验证。

**QST-026-L018｜玲**：两段都放，会不会像在吵架？

**QST-026-L019｜遥**：这次吵的是一本书，它受得住。

<a id="qst-026-s002-k03"></a>

### QST-026-S002-K03 · 版次能查，喜欢不能代查

玩家打开样书版本页核对两份引用。QST-106 已做时，小满只取该次允许留存的版次记录；旧版或修订版读者已经取回的书签不在桌上，获准留存的书签也仅在其原许可范围内参考。未做时直接比较当前两份样书，不突然出现陌生人的书签

**QST-026-L020｜小满**：那次的版次记录还在。书签只看本人同意留的，收回去的就不用了。

**QST-026-L021｜小满**：先看这两份眼前的样书。引用同一段，再听他们各自喜欢哪里。

**QST-026-L022｜屏幕文字**：本次核对：两份引用来自同一版、同一段。引文一致，读后判断不同。

<a id="qst-026-s002-k04"></a>

### QST-026-S002-K04 · 让一页装得下两个声音

玩家把被删改的意见退回作者，分别确认本次公开范围。两个观点都获准时，维恩删短论证而保留“不喜欢停顿”的判断，遥保留反对结尾的意见；小满缩掉自己的推荐，不替两人合并。只有一方同意公开时，另一方意见留在私人工作稿，不显示其内容、姓名或“不愿公开”标签

**QST-026-L023｜维恩**：我的这一段可以用。删短可以，别删掉我不同意的地方。

**QST-026-L024｜遥**：我的也放进去，各自在自己的名字下面。

**QST-026-L025｜遥**：这一版只用维恩那段。我这段留在工作稿，下次再说。

**QST-026-L026｜维恩**：这次先用遥的。我这一段不放，不用替我留一个空名额。

三条是原作者实际许可的既有范围，玩家只按许可排列，不以选择菜单替别人决定。仅维恩公开时用 K02 的 QST-026-L013 原意见；仅遥公开时用 K02 的 QST-026-L014 原意见；双方公开时两段各用本场已展开的原意见，不复制台词。每条都接下列同一版公共店员推荐

**QST-026-L027｜屏幕文字**：小满推荐：一封没有寄出的信，留在一个后来还会打开的抽屉里。我喜欢她开门时没把答案一起带走；结尾又有一点太齐整。这里刊登的读后感保留各自的判断，请先读那段，再决定自己的。

出口：保存实际校读、版次与许可。公开版由推荐与获准原意见构成，私稿不进入读者可取折页。中断后保留已确认部分，未答复者不默认为同意；不把更多署名数当完成条件

## QST-026-S003 · 今天结束以后还有两首歌

入口：诺拉通过原渠道确认收尾方式：书面交付或共享工作室的一小段远程交流。兄妹只安排两人各自愿意参加的部分；遥仍不亲自出现在本地，双方可一人参加、一人只交文字，也可只交文字。公共活动不直播私人相处

<a id="qst-026-s003-k01"></a>

### QST-026-S003-K01 · 确认方式，照样交稿

玩家镜头在书店工作台，诺拉把两种安排写在本次约定栏。玩家查看后将各作者真实答复记到名字旁；已明确不参与者没有空座强等，不以共同上线作为结项要求

**QST-026-L028｜屏幕文字**：书面交付：确认稿交白页书店，本次工作结束。短交流：仅在本人确认的时段连接本人愿意公开的内容，到点结束，其余讨论留在现场。

**QST-026-L029｜诺拉**：谁能来哪一段，就写哪一段。只交文字也照样算交到，不挂一个让人等的头像。

<a id="qst-026-s003-k02"></a>

### QST-026-S003-K02 · 已经打开的另一份材料

获准工作通道仍开着的末段，维恩收到普通研究咨询。画面只显示他本人允许的工作视窗，不展示未授权咨询内容。接管从他打开新窗口到关闭为止：中景保留他放在桌边的两曲播放清单，他把新资料窗口拉大，清单被压到下层

**QST-026-L030｜维恩**：这个我先回一条……

他停下，沿窗口边看见歌单的第二行，退回原日程，把咨询另约回复发出，再关闭资料

**QST-026-L031｜维恩**：这份另约。我把可答复的时段给过去了，今天不在这页后面接着做。

跳过只结束此私人物品被遮又恢复的表演，不替玩家确认折页或收稿。回到工作稿查看状态

<a id="qst-026-s003-k03"></a>

### QST-026-S003-K03 · 她也有想多改的一句

遥在本次约定修改已经完成后，圈出一句可留到下一版的措辞。小满看到新圈，手又摸到延后印制的纸条；玩家可查看圈注，它与必须修正的事实错误已分开，不能用“按时交付”跳过真正的必改问题

**QST-026-L032｜小满**：这一处要再等一个版本吗？

**QST-026-L033｜维恩**：你是不是还要听歌？

**QST-026-L034｜遥**：要。这一句留下一版，答应改的这一张已经交完了。

**QST-026-L035｜屏幕文字**：本轮确认稿已交。额外措辞建议留待下一版；新增急改不纳入今天的约定。

出口：两路都先进入 S004-K01 实际交付确认稿和公开成品；书面路径随后结束公共工作，交流路径再按原预约进入 S004-K02。此前已完成公共交流的晚接玩家阅读已公开稿并参与下一次普通校读，不撤回旧版、不重开已结束的历史问答

## QST-026-S004 · 到点把连接交回来

入口：书面路径在白页书店，小满接稿；交流路径按本人确认时段在共享工作室开放的桌区，诺拉主持，小满负责阅读页，兄妹以普通参与者在场。镜头始终避开任何未获授权的私人材料

<a id="qst-026-s004-k01"></a>

### QST-026-S004-K01 · 纸真的到了书架

两路共用的玩家镜头，玲将确认稿交小满，玩家核对印出样页与许可后把可取折页放上指定书架。不能只谈完就让架上出现成品；必要的正常印制时间用明确转场“确认稿送印后，回到取稿时段”推进，不强制现实等待

**QST-026-L036｜小满**：这一版我收下。下一版的圈注留在工作夹里，这次架上只放确认的这些。

仅书面交付后使用下句，交流路径留到 K02 正常结束

**QST-026-L037｜诺拉**：今天就到交稿。有人想聊，我和小满在这里，不再往他们那边加一题。

交付完成后，书面路径播放诺拉的 QST-026-L037 并汇入 S005；交流路径不播这句书面结束对白，随后沿正常公共路线去共享工作室，按 S004-K02 继续。私下约定在本次公共工作结束后发生，不要求玩家留在书架边见证；未实际交付者不进入私人短镜

<a id="qst-026-s004-k02"></a>

### QST-026-S004-K02 · 留下来的是现场的人

交流路径玩家镜头。实际确认参加的作者才进入原授权通道，另一位若只交文字，由小满展示其获准文本而不播放伪装直播。玩家可打开本篇样书节选和公开折页比较，诺拉将讨论限定在同一段内容；并未新增玩家表达选项

**QST-026-L038｜诺拉**：我们只谈这张上面实际印出的意见。没有参加的人交的是文字，今天不替他追加回答。

**QST-026-L039｜遥**：不喜欢也可以。别把找到了同一版，当作读到了同一种结尾。

仅维恩本人的意见实际获准并印入本版时使用下句；本人只参加而不公开自己稿件时，使用后面的 QST-026-L052

**QST-026-L040｜维恩**：我的判断印在这里。它解释得更清楚，但这不是替其他人下结论。

**QST-026-L052｜维恩**：这张放的是已经确认的文字。我今天可以听大家谈这一段，自己的稿子不在这一版里。

原约结束时诺拉先抬手示意现场暂停，给实际在线者明确结束回应，然后结束公共连接。短接管只从结束手势到屏幕回到普通活动页，允许跳过，不替尚未阅读的玩家补齐观点核对

**QST-026-L041｜诺拉**：到约好的时间了，谢谢。还有想聊的，我们留在现场接着说。

**QST-026-L042｜遥**：好，下次的新稿再见。

**QST-026-L043｜维恩**：今天这一段交完了。再见。

两人都只交文字时不进入本镜，直接 K01。公开连接断开后才进入 S005 的私人时间；玩家控制交还共享工作室原站位，可以与诺拉、小满继续普通交流或正常离开

<a id="qst-026-s005"></a>

## QST-026-S005 · 两首都听到最后

本场是公共工作结束后的平行叙事短镜，表现两人已经存在的私人通信。遥的手、杯与桌面均属于已有真实联合梦境住家中的梦内形体，维恩这一晚在现实自己的私人桌边，沿原有已获授权的辅助通道与她共同听歌；两端控制只响应原来可共享的音频安排，镜头不得把遥拍成城内现实健康到场，也不新增现实身体活动能力。此处不是对活动听众的直播，不增加兄妹的知情范围、访问许可或新的潜梦入口。玩家可跳过叙事镜，双方实际听完的生活事实仍发生；不要求玩家强制坐满两首歌的播放时长，时间省略必须发生在同一首仍连续播放的过程中，不用切歌伪造完成

<a id="qst-026-s005-k01"></a>

### QST-026-S005-K01 · 伸到一半的手

机位在遥的梦中住家播放控制与维恩现实私人桌边的近景交替，以两处各自既有空间轮廓区分世界；只见手和桌面，不展示遥现实照护细节。遥先开始自己选的歌，维恩把另一份工作资料扣下。音乐经过开头进入一段较长过渡，维恩手指向跳过键移动；遥没有停曲，只在私人通道说一句

**QST-026-L044｜遥**：这一段也算。

**QST-026-L045｜维恩**：我没按。

### QST-026-S005-K02 · 听完再说不喜欢
