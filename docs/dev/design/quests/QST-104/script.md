# 雨停之后取衣服：完整制作脚本

[故事正文](../../../../player/story/daily/collect-after-rain.md) · [共用写法](../script-format.md) · [正式台词](dialogue.csv)

预算沿用 8–15 分钟，只做一次普通误会、两样读牌、本人领取与邻里出门。何芸主动显示获准联系的这一单，不开放其他顾客袋、号码或留言。默认操作玲，曜同行；何芸、梁素、CHR-039 取衣顾客、CHR-040 取衣牌试读熟客各自承担不同角色，不让当事顾客冒充不知前情的试读者

| 顺序 | 场景 | 进入与结果 |
| --- | --- | --- |
| 1 | QST-104-S001 最后一袋 | 旧牌与电话里的两个误会；本次领取时间实际确认 |
| 2 | QST-104-S002 两张取件牌 | 陌生于本单前情的熟客试读；何芸选清楚的版本 |
| 3 | QST-104-S003 这次真的取走 | 本人核验衣物、收牌、何芸终于出门 |
| 4 | QST-104-S004 下一个普通雨天 | 未领取改约续接或已领取重访；不把袋子挂回 |

本轮演示使用双方当面确认的今天 18:10–18:30 人工交付段，与自助营业分开。跨日继续时只在新的联系确认后换当次安排，不拿已失效的“今天”当通行凭证。联系、设计与等候在同一店内完成；梁素顺路带来已有合适牌架，不为它新增去服务中心开证明或全街采购的任务

<a id="qst-104-s001"></a>

## QST-104-S001 · 最后一袋还挂着

入口：傍晚小雨的自助洗衣店，机器将结束一轮。何芸在柜台内侧，旧外套搭椅背、钥匙握在手里，取件袋挂在柜内她能取到的位置，袋上夹着仅用于这单核验和领取后收起的小取件牌；柜台面对顾客另有一只公共说明牌架，里面的大字“周五后可取”是日程说明纸，两者不是同一物；门侧湿伞挡住从顾客位置看袋架的一角。玲与曜从街道进门，尚不知道这一单取件纠纷。梁素在茶桌庭等何芸，取衣顾客正在换班间隙，均未到店

<a id="qst-104-s001-k01"></a>

### QST-104-S001-K01 · 钥匙已经拿好了

玩家镜头，从门边看到湿伞、椅背外套与钥匙，视线可自由转向取件牌；不以查看无关洗衣内容作线索。何芸先将湿伞从挡住袋架视线的位置移到门边临时托盘，袋架与通路露出；伞尖留在托盘里，暂未收进最终的伞架滴水位，她把钥匙换到另一手，回头看机器剩余转动

**QST-104-L001｜何芸**：早处理好了，他说周五来。再等十分钟吧，反正我也得看机器。
**QST-104-L002｜月城玲**：你外套都拿出来了。本来要去哪儿？
**QST-104-L003｜何芸**：茶桌庭。梁素给我留了座，应该还没散。

若玩家先看取件牌，直接进入 K02 的实物观察，再回到本段未听过的问答；外套与钥匙始终在原处，不要求重复进门

<a id="qst-104-s001-k02"></a>

### QST-104-S001-K02 · 被夹掉的两个字

玩家选择“从顾客一侧看牌”，镜头仍由玩家控制，牌架正面“周五”占很大位置，后边“后可取”被窄边夹住，只露半字。可侧移看见纸张边缘，不直接拔出店内物件。曜站在玲旁边稍侧位置，俯身沿顾客读字高度看牌

**QST-104-L004｜屏幕文字**：周五后可取
**QST-104-L005｜月城曜**：从外面看，后面那截被夹住了。
**QST-104-L006｜何芸**：我天天都看，知道上面写了什么。

玩家看清夹边即可指出，不必先误答“只能周五”。何芸从工作夹只取这一单允许联系的记录，其他资料仍合着

<a id="qst-104-s001-k03"></a>

### QST-104-S001-K03 · 两个人记得的不是同一句

玩家触发“请何芸核对本单留言”，何芸亲自打开本单获准联系的信息，屏幕只呈现取件安排；拨号由何芸完成，不把顾客私人号码加入兄妹联系人。声音电话使用真实取衣顾客 CHR-039，何芸按本人已允许的取件协助范围让兄妹听清安排

**QST-104-L007｜屏幕文字**：本单取件留言：周五来取；允许店方就本单领取安排联系
**QST-104-L008｜取衣顾客**：我后来改班了，不是提过以后得晚些来吗？
**QST-104-L009｜何芸**：我记得你说的是，下次来再告诉我。衣服周五之后就能领，不是只有周五。
**QST-104-L010｜取衣顾客**：牌上我就看见周五。错过了，我还以为得等下一周。
**QST-104-L011｜月城玲**：你从我现在这边看一下。

短接管从柜台外侧中景开始，何芸把手机放在仍能听清的柜台边，走出工作侧，弯腰看牌；镜头跟她视线降到夹边，不越到无关袋后。她看清后笑出短短一声，伸手扶一下歪牌

**QST-104-L012｜何芸**：这上面倒像是我不许人周六来了。

接管结束回到玲原站位，电话继续；暂停或跳过只完成换位看牌，不替双方确认新的领取时间

<a id="qst-104-s001-k04"></a>

### QST-104-S001-K04 · 今天能交的那一段

玩家镜头，何芸回到柜台，把手机握回手里。顾客先说白跑，何芸的手指在钥匙圈上收紧；两句话相碰后留一个自然停顿，不立刻化成互相夸奖

**QST-104-L013｜取衣顾客**：可我确实白跑过一趟。那会儿没人。
**QST-104-L014｜何芸**：我也多等了两晚。今天我能交到 18:30，18:10 起在这里。你赶不赶得上？
**QST-104-L015｜取衣顾客**：赶得上。今天 18:10 到 18:30，我来取这单。临时换班我先留话。
**QST-104-L016｜何芸**：我回了你，再按新时间来。没回之前别猜你该不该跑。

玩家操作“把确认内容写清”，玲在何芸指给她的本单记录纸上写下公开需要的时段，何芸核对后将记录收回自己工作夹

**QST-104-L017｜屏幕文字**：本次已约：今天 18:10–18:30，物主到店核对后交件；若换班，先留话并等店方确认新时段
**QST-104-L018｜何芸**：我跟梁素说晚一点。不是再让她替我留十分钟。
**QST-104-L019｜何芸**：今天这单约到 18:30。我交完出门，再告诉你是不是还赶得上

出口：衣物仍在原袋挂架，尚未交出；本单新时间已确认。何芸没有因为电话讲通便换衣离店，梁素随后带牌架进门进入 S002。玩家可暂时离开；若跨过本轮人工交付段，按 S004-K01 重新联系，不把时间到了自动算领取

<a id="qst-104-s002"></a>

## QST-104-S002 · 漂亮的那张反而没读懂

入口：同店柜台客侧空面，梁素从门口进来，手提从居家用品店带来的普通牌架，尚未见两张新纸样。何芸取出旧纸，玲拿空白纸与笔，曜把临时托盘靠门侧放稳，湿伞仍未收进固定伞架。CHR-040 是来店里的普通熟客，不知道本单争论，没有听刚才电话；他不是取衣顾客

<a id="qst-104-s002-k01"></a>

### QST-104-S002-K01 · 两张都要让人真的读

玩家镜头，操作“重排两张纸样”，玲先画大字日期与花边，再做一张朴素版本，将起取日、交付时段与变更联系放在同一阅读区。两张正文都写完整，不用抽象“较好版”标签替代可读物

**QST-104-L020｜屏幕文字**：周五／后可取；今天人工交付 18:10–18:30；变更请联系
**QST-104-L021｜屏幕文字**：本轮周五起可取／今天人工交付 18:10–18:30／换班请先留话，收到确认再按新时间来
**QST-104-L022｜梁素**：牌架是这只。先看字进去以后，边上还剩多少。

玩家分别把两张纸插进同一牌架，从顾客站位看，明确甲的花边挤压说明、乙的正文不被夹口吃掉。已提前识别乙更清楚的玩家可直接保持自己的判断，仍让未获提示的熟客完成独立试读，不被要求故意选错

<a id="qst-104-s002-k02"></a>

### QST-104-S002-K02 · 不教答案的一次试读

何芸请熟客先读甲，玲没有在旁边解释。短接管只在熟客低头看牌时固定为柜台外侧双人中景，能见牌面与他视线方向；甲读完取出，再放乙，不能把甲已解释过的答案提示给他

**QST-104-L023｜何芸**：只看这个，你觉得什么时候来？
**QST-104-L024｜取衣牌试读熟客**：周五。
**QST-104-L025｜何芸**：再看这张。
**QST-104-L026｜取衣牌试读熟客**：周六我有空，来之前留话，等你回了再来就行？
**QST-104-L027｜何芸**：对，按我确认的那次时段。就这张。

短接管结束交还玲柜台外原位，可跳过到两张试读已完成而新牌尚未正式写好的位置，不替玩家写当次日期。熟客结束协助后回到自己的普通店务，不冒领那只取件袋

<a id="qst-104-s002-k03"></a>

### QST-104-S002-K03 · 花边退到字后面

玩家“按乙版写正式牌”，玲把原想保留的大花边缩到不挡字的位置，写入本次起取日及确认时段；写完把牌架翻面看背面，旧牌边压在桌边。完成 QST-001 时有以下一句回扣；尚未经历则只做当前日期检查，不凭空讲旧完成卡

**QST-104-L028｜月城玲**：店里那张也是上一轮的。这个换了日程，也得换当次的纸。
**QST-104-L029｜屏幕文字**：本次已更新：起取日、人工交付时段、变更联系；已洗好不等于已交出

玩家触发“请何芸核对新牌”，何芸从顾客站位读一遍，把今天的联系记录与牌并在一起核对，确认后才立牌。没有该动作就保持草稿，不能按一次跳过自动贴出未经核对的日期

**QST-104-L030｜何芸**：这回从外头也能看完整了。旧的先放这儿。

出口：新的公共说明纸在顾客能读到的牌架中，旧公共说明纸在柜台内侧，袋上本单小取件牌仍附着、取件袋仍未交；梁素将带牌架的空提袋折好放进自己的包，告别何芸后从店门先回茶桌庭，新牌架留店使用。玩家可自由离开或按当次约定继续 S003；约定前的时间使用明确生活转场，不要求原地看机器转完多轮

<a id="qst-104-s003"></a>

## QST-104-S003 · 这次真的取走

入口：本次确认的人工交付时段，店外仍小雨。取衣顾客 CHR-039 从门口进来，收起雨具，把自己的本单领取凭据递给何芸；玲与曜在客侧让出通路。何芸先核对，不因有人报“那件衣服”就把袋子交给围观者

<a id="qst-104-s003-k01"></a>

### QST-104-S003-K01 · 手交到手

玩家镜头，何芸核对顾客本人持有的本单信息，镜头避开号码等私人字段，只见她拿出对应袋，与凭据并排。她从挂架取下袋子放交付台，请物主查看；玩家不能代替本人点确认，也不能查看其他订单

**QST-104-L031｜何芸**：是你这单。你自己看一下，确认了我再收牌。
**QST-104-L032｜取衣顾客**：对，是这件。已经好了这么多天。

只有本人核验后，玩家才可参与“把对应取件牌递给何芸”。玲只从何芸指定的本单袋上取下小取件牌，不动柜台公共说明牌，交给她，何芸收进已交件夹；顾客接住袋底与提带，何芸确认重量由他接住才松手

**QST-104-L033｜取衣顾客**：我还以为，你是不是不想做我这单生意了。
**QST-104-L034｜何芸**：我以为你不急着穿。

没有拥抱或立刻道歉大团圆。镜头保持两人间柜台的实际距离，让误会解除而已花掉的时间仍在

<a id="qst-104-s003-k02"></a>

### QST-104-S003-K02 · 把旧纸翻过去

短接管触发于顾客看向新牌，柜台外侧中近景同时保留新牌、旧纸与何芸手部。顾客读完新牌，稍微侧头指向清楚的交付时段

**QST-104-L035｜取衣顾客**：这张终于看得懂了。

何芸吸气像要辩一句，指尖碰到旧纸；她把纸翻成空白背面，没有再竖起来证明旧句语法没错。随后视线从旧纸移到顾客带来的雨具

**QST-104-L036｜何芸**：雨衣罩得住袋子吗？
**QST-104-L037｜取衣顾客**：够。我赶下一班车，先走了。

顾客从门口离开，走过外沿雨棚进入实际街路，不继续站旁边给结案作证。交还玲客侧原位；暂停或跳过只落定此次已核验后的交付和顾客离场，不重播核验、不生成第二只袋

<a id="qst-104-s003-k03"></a>

### QST-104-S003-K03 · 今天晚到，但已经出门

玩家镜头，何芸目送顾客离开，转身看见自己外套还在椅背，先愣一瞬，随后抖开外套穿入双臂，将钥匙放进自己的口袋。她给梁素发出已经动身的消息，而非继续许诺“再等十分钟”

**QST-104-L038｜何芸**：今天晚些到，但这一次已经出门了
**QST-104-L039｜梁素**：茶还在。到了自己找座，别又站着替人收杯子

玩家“把临时托盘里的湿伞收进伞架滴水位”，玲先握住伞柄、另一手托住伞尖收水处，把整伞从托盘抬起；曜扶稳伞架，玲将伞尖落入底部滴水盘，伞柄收在架内不伸出通路，确认立稳后松手；不接触顾客已带走的雨具。何芸看见门口空出，从柜台取个人包，对兄妹挥一下手

**QST-104-L040｜何芸**：剩下的照平时自助。你们也去忙，别在这儿替我守着。

出口：何芸从门口实际走向茶桌庭，柜内本单挂位空出，取件牌已收，旧纸翻面，新牌保留当次人工时段并按营业变化更新。完成条件是本人领取与收牌，何芸动身构成可见后果；玩家保留原地控制，可继续普通街区活动，不因她离开便把自助店锁成无人可用

<a id="qst-104-s004"></a>

## QST-104-S004 · 下一个普通雨天

<a id="qst-104-s004-k01"></a>

### QST-104-S004-K01 · 没赶上约定时段

条件：S001 已确认且该单实际尚未领取，取衣顾客在当次交付段未到；玩家跨日续接也须先核对仍未领取。衣袋仍属该单，何芸遵守自己出门安排，不被任务永久锁在柜台；本单有顾客主动留下的改班消息，回店时由何芸核对并回复，兄妹只看到同一获准范围

**QST-104-L041｜取衣顾客**：临时又换班，今天那一段赶不上。我先留话，等你确认再来
**QST-104-L042｜何芸**：收到。下一次我在店里能交件时再约，不沿用今天这张牌

玩家再次到人工服务时段“请何芸确认新安排”，何芸与顾客电话确认下一次同样明确的 18:10–18:30 段，日期为这次新约定的游戏日，牌上日期与联系记录一起更新

**QST-104-L043｜何芸**：这次约好那天，18:10 到 18:30。你换班的话还是先留话。
**QST-104-L044｜取衣顾客**：这回这个时间我能到。照你确认的来，不猜了。

汇入 S003-K01，物主核验与实际交件仍须发生。若只是玩家不在而物主已按约实际领走，进入 K02 读真实结果，不将袋子重新挂回供玩家补做；何芸本人按原职责完成核验与收牌，不把这一操作归功于玩家

<a id="qst-104-s004-k02"></a>

### QST-104-S004-K02 · 不在场的那次交付

条件：玩家离开期间，已约顾客确实完成领取。再见何芸时，玩家镜头中原挂位已空，已交件夹关闭；她只示意本单已交，不再打开顾客资料供重温

**QST-104-L045｜何芸**：那件他已经拿走了，牌也收了。你们上回改的字，他这回看懂了。
**QST-104-L046｜月城玲**：那你那晚后来去成了吗？
**QST-104-L047｜何芸**：晚了点，去了。茶没赶上最热的那一壶。

该路线与现场见证交付拥有同一物件结果，主角记录标明听到本人说明而非亲手递牌。若顾客尚未取走则此镜不播放

<a id="qst-104-s004-k03"></a>

### QST-104-S004-K03 · 普通雨天的湿伞

条件：已交付后再访，何芸已经从茶桌庭回来，旧外套挂回个人柜内而非一直搭着椅背，门口只有普通营业新来的湿伞。玩家镜头，她从店门走进，将自己的伞收好，再指门边一把挡路的伞

**QST-104-L048｜何芸**：帮我挪一下就好，别挡人进门。今天没有谁得陪我多等两晚。
**QST-104-L049｜月城玲**：牌上今天的时间已经换过了。
