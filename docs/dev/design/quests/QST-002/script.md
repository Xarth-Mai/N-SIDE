## QST-002-S001 · 今天想请你们帮忙

对应 B001；营业时段，月台杂货。玲在靠窗陈列桌旁，曜在柜台内整理工具，巧克力店员机体停在客用通道外。米娜背着日常小包进门，打包照片在自己的手机里，未授权公开。窗台上一张小卡的上角卷起，旁边现成卡托空着；本场只交接这件日常陈列，不新增取货支线

<a id="qst-002-s001-k01"></a>

### QST-002-S001-K01 · 扶住那一角

玩家镜头，柜台向橱窗的斜向中景。米娜进门时先用两指压住被门风掀起的小卡，等玲靠近；交互“把小卡放入卡托”后玲拿起卡托，米娜抬起压角的手，玲将小卡下缘插入、扶正并松手。巧克力贴近一点，屏幕眼睛先看歪着的上沿，卡片稳定后眨一下，不替玩家完成陈列

**QST-002-L001｜米娜**：这边又翘了。我压着，你把底下那个套上

陈列动作结束立即交还控制，小卡仍在窗台。若玩家离开去做别事，米娜把卡平放在原托盘等待；回来再次交互从实际放置状态开始，不伪造完成

<a id="qst-002-s001-k02"></a>

### QST-002-S001-K02 · 请求的两种入口

触发与米娜交谈后才接短中近景；镜头从柜台外侧看三人，不越过私人手机。已完成序章时，米娜先把手机屏幕朝自己唤醒，再转向玲，续接之前约好的请求

**QST-002-L002｜米娜**：我把昨天说的照片带来了。它今天早上又不在那一格

未做序章的独立入口使用下一行替代 L002，米娜先把包带从肩上滑到前臂，腾出手取手机，不说“昨天你们见过”

**QST-002-L003｜米娜**：我快要走了，准备带走的玩具却老换地方。能请你们来看看吗？

两入口汇合：曜停止整理工具，转身朝她，但仍在柜台内，不先伸手拿手机。玲把米娜手机屏幕保持朝两人之间，不面向街上的顾客

**QST-002-L004｜曜**：有人动过箱子，还是你看见它自己移动？

**QST-002-L005｜米娜**：我没看见怎么动的。我拍过放好的位置，后来那里空了。大家已经替我解释过好多遍为什么舍不得

她拇指沿手机壳边缘搓一下，停住，把照片调到日期那一栏，不继续替自己的离城决定辩解

**QST-002-L006｜玲**：我们先看你拍到的。你愿意让我们检查哪些地方？

**QST-002-L007｜米娜**：房间里的旧柜、箱子和清单都可以。带什么走，最后还是我自己选

**QST-002-L008｜玲**：好。先把东西找明白，箱子等你来分

本镜跳过后保留已经听取的请求记录，手机归米娜，小卡在卡托；调查授权只覆盖本次说明的范围，未看照片的细部仍需住宅焦点交互

<a id="qst-002-s001-k03"></a>

### QST-002-S001-K03 · 把工具拿上

恢复玩家镜头。玩家选择同行交互时曜将工具按原槽放好、扣上包，绕柜台走到门边等玲，不从柜台穿模。米娜收手机，推门后侧身留出通道；巧克力留在店内，屏幕出现柜台图标，之后通过接入协作

**QST-002-L009｜曜**：工具我带。店里先交给巧克力，我们到你那里对着原位置看

若玩家先离开、稍后回来接受，米娜将手机拿在掌中，直接给出续接行，不重复求助长段

**QST-002-L010｜米娜**：我还没重新收那副柜子。你们准备好了，我们再过去

出口：玩家亲自离店前往受邀住宅，米娜带手机与清单；接受请求后未到住宅不自动取得基准。迟到没有真实日历倒计时，也不会以玩具消失惩罚；米娜保留自己的出发行程，调查转场按剧情时段安排

## QST-002-S002 · 先把空格留下

对应 B002，住宅调查共同入口；白天，米娜邀请兄妹进入坡上住宅自己的房间。玲主控；曜站在柜门外侧，不挡柜门扫过的区域，手里是合着的工具包。米娜在桌与柜之间，清单压在两张不同日期的照片下，已封的行李箱放在远离柜脚的墙边。旧柜的低位周转箱仍在原位置；谁都还没看见内部。房间其余私人物品不开放交互

<a id="qst-002-s002-k01"></a>

### QST-002-S002-K01 · 两个日期

玩家镜头，入口侧中景；进门后可自由看桌面与柜体，不自动把视角扳向米娜。交互“查看打包记录”时，米娜先把杯子挪开，拿照片的两角将它们推到桌沿，手指分别压住日期，留出中间的柜层区域给玲看。玲走到桌边站定，俯身但不拿走照片；曜把工具包放在脚边，伸出的手在碰到柜门前停住

**QST-002-L011｜曜**：我先看看柜子有没有松——

**QST-002-L012｜米娜**：等一下。这个是前一天，这个是后一天。柜子我收过了，东西也放回去过

米娜把后一天的照片往前再推一点，空着的格子与前一天有玩具的格子并排。曜收回手，蹲到照片所在的桌角下方看柜脚，不抢走照片

**QST-002-L013｜玲**：好，先照这两张找。哪一件你最确定放过？

**QST-002-L014｜米娜**：这个，底下磨白了一块的。我还拍到那块白印了

玩家放大照片里的磨痕，照片焦点确认后返回原视角；对话可跳过，照片仍可再次查看，跳过不自动完成照片观察。照片离手后仍留在桌上，不进入玩家背包

<a id="qst-002-s002-k02"></a>

### QST-002-S002-K02 · 清单、箱封与柜脚

自由调查镜，三个观察点可任意先后。看清单时，玲用笔尾沿纸面逐行移动，不勾掉尚未见到的物件；看箱封时只转身低头，米娜将箱角稍稍转向光，不让玩家拆开已完好的箱封；看柜脚时玲蹲下，掌心撑在膝上，把手电沿既有磨痕平移到柜背接缝，光束停在暗处，不伸手盲掏。曜退到玲后侧给光路让位。三个焦点的字幕独立出现、独立回看，不以对白结束代替观察

**QST-002-L015｜屏幕文字**：打包清单｜A 旧小车一件：底座磨白，原在柜子下层，现位置待核对；B 小陀螺一件：贴纸缺角，原在同层，现位置待核对；C 布偶一件：蓝线补缝，现桌角；D 较新同款小车一件：底座无磨白，据原照片放进墙边封箱，内部未开核；共四件，去向由米娜确认后填写

**QST-002-L016｜屏幕文字**：箱封记录｜封口仍连着；贴签日期早于这次移位照片；尚未开箱核对内部

**QST-002-L017｜屏幕文字**：柜脚记录｜新磨痕沿柜内接缝延伸，终点被低位周转箱挡住

完成任一焦点只记录该项，其他焦点继续保留。三项全部看过后，玲把清单放回两张照片旁，用铅笔在“现位置”后留下一条空线

**QST-002-L018｜曜**：封口没动过。先别把整柜拆了，这条新痕还得留着看

**QST-002-L019｜米娜**：那空格先别划掉。我想知道它到底去哪儿了

<a id="qst-002-s002-k03"></a>

### QST-002-S002-K03 · 两种调查顺序

玩家镜头，玲站在桌角，可见柜脚与准备用来休息的椅子。焦点完成后在现场提供原 C001 的两项操作入口；两项不是对米娜感情的判断。米娜把自己的椅子从柜门前移到桌边，曜把设备包放到椅子旁，均未开始接入

**QST-002-L020｜屏幕文字**：先检查周转箱与柜底夹层

**QST-002-L021｜屏幕文字**：保留标记，先准备潜梦

选择第一项时米娜把清单转向自己，拿起笔，为将找出的原物预留清点位置；不自动出现玩具，转 QST-002-S006-K01

**QST-002-L022｜米娜**：可以。找出来的先放这块空桌面，我来认

选择第二项时玲把手电放在柜旁矮凳上，曜拿纸条在磨痕旁作位置标记，纸条不遮住痕迹；未看的箱和夹层保持原样。米娜看一眼仍为空白的位置栏，把笔横放在纸上

**QST-002-L023｜玲**：东西先不挪。我进去看看，出来再对这几处位置

**QST-002-L024｜曜**：标记留好了。我守在这边，你准备好再接入

第二项在完整版先进入 S008 的入梦前核对，之后汇合 QST-002-S007-K01；Demo 直接到 S007-K01；跳过本镜只跳过已经选定后的表演，不代选 C001。离开房间暂停调查，回来仍站在门口，已看过的焦点保留记录，米娜将清单指给玩家，不重复初次质问

**QST-002-L025｜米娜**：清单还在桌上，刚才看的那几处我没有动

场景出口：照片和清单在桌上，已封行李在墙边，周转箱只在玩家实际选择并执行检查后移动。C001 尚未选时不推进 B004；无论哪条路线，旧柜当前活动尚未停止

## QST-002-S006 · 原来就在下面

对应 B003，C001 的 inspect 路线；接 S002-K03，仍在同一房间。玲从柜脚侧蹲下，米娜守在清点桌边，曜在柜门外侧将工具包朝墙推半掌，腾出取箱的位置。所有实物沿既有柜内缝隙与低位容器移动，不出现穿墙、复制或“领取”第二件玩具

<a id="qst-002-s006-k01"></a>

### QST-002-S006-K01 · 拉到能看清的位置

自由操作镜；交互“查看低位周转箱”后只接管手部取物动作，镜头从玲肩侧贴近箱沿，不切到封闭柜背透视。玲一手托住箱前缘、一手握把，将箱子沿地面缓慢拉至柜外；遇阻先停，曜扶稳柜门，玲换成双手平拉，箱底越过原磨痕后停下。输入只在双手实际抬拉的短段屏蔽，暂停可用；跳过落在箱已拉开、双手离把的位置，但不替玩家观察箱内

箱内物件显露后立即交还观察控制，提示与实物并存。玩家将视线落到带白色磨痕的底座，确认观察后玲才伸手，掌心托住底部、另一手挡住可活动的小部件，取出原物并回身走到空桌面放下。取出前退出不会取得物件

**QST-002-L026｜玲**：底下这块白的，是照片里那一块吗？

**QST-002-L027｜米娜**：是它。别拧那边，那里以前松过

玲松开准备抓侧边的指尖，改托底座。米娜接触玩具时不马上夺走，先翻到磨白的一面，让原照片与原物的痕迹同向

<a id="qst-002-s006-k02"></a>

### QST-002-S006-K02 · 找到不等于停住

玩家镜头，桌角近景。玩家交互“对照照片与原物”后米娜将旧玩具放在照片旁，用铅笔在清单空线写“周转箱”，不改物件总数，不创建副本奖励。玲指回周转箱原先挡住的方向；柜底另一个可见夹层仍有未核对的位置，剩余空格继续保留

**QST-002-L028｜屏幕文字**：清点补记｜A 磨白底座旧小车已在低位周转箱找到，现放清点桌；仅登记原物一次；B 小陀螺仍待找，D 封箱内部仍待核；四件总数尚未核全

**QST-002-L029｜米娜**：找到了。谢谢。可我前天也是把它放回去，然后它又不在那儿了

她拇指压在磨白处，另一只手抵住桌边，没有开始装箱。玲放下笔，手离开玩具，把清单上的“找到”与空着的“停止移位”两栏分开给她看

**QST-002-L030｜玲**：你先拿好。柜子为什么会把它带走，我们还没查完

**QST-002-L031｜曜**：先让它留在桌上。柜子里还有什么在动，我继续看

<a id="qst-002-s006-k03"></a>

### QST-002-S006-K03 · 夹层的边界

自由观察镜，焦点回到箱后接缝。玲沿磨痕照过去，只从现有开口看见夹层内轮廓，不拆柜、不盲伸手；玩家可核对照片上对应空格，当前看不清的细部照实保留。曜拿记号纸贴在不接触活动部分的柜脚外缘，然后把取出的周转箱放到桌旁，原位置地面的压痕保持可见

**QST-002-L032｜曜**：这里还有一段被导轨挡住。先别伸进去，我把能看见的位置记下

**QST-002-L033｜玲**：这一件没有消失。剩下的还要找，移动也还没停

出口：已找回的原物留在清点桌，米娜写下唯一位置；不把物件塞回异常柜体来重复表演失踪。完整版先到 S008 核对，Demo 直接到 QST-002-S007-K01，准备潜梦时使用“提前找到”回应。若此时离场，物件、照片、清单和已拉出的箱子保持各自位置；返回不再次生成找回演出，米娜先看桌面，再指向柜脚

**QST-002-L034｜米娜**：那件还在这里。柜子的问题，我们接着看
