# 回声之后：终章行动与恢复规格

## 输入与范围

对应 QST-009、BC-006 与 BC-007，故事正文见[第八章](../../../../player/story/main/after-echoes.md)，长期因果见[跨章契约](../../story-continuity.md)。本页固定人物、行为与状态责任，尚无运行时、手感或实际设备验证

玲全程潜梦，曜全程清醒接应并守在她的身体和设备旁；巧克力沿人类的当下有效连接进入与撤出。塞拉协调现实现场，邱立与专业人员分别负责构件位置和固定情况检查，兄妹不代替专业人员实施物理作业

第七章已经完成后场接入的建立、当前路径验证、监测与联合演练。正式 B 方案以这些结果为前提，A 方案承担安全回退，不新增善恶分支或第二套结局

## 处理目标与物理边界

合流场由当下有效通路连接持久结构，不是复活的原始源头或新的人格化总敌人。战斗用于打断、牵引、回避与接近联系部位，目标是改变新增联系及其输出条件

西环渡口的浮动候船设施在允许范围内随水位运动，导向构件和连接件支持正常定位。新增局部输出造成反复小幅运动，使进入维护位置后的固定不能完成。公众区域先关闭，专业人员从安全位置支撑与锁定；梦内操作提供不再持续受扰的窗口，不会自动修好现实构件

第六章已调查材料更换、雨后接触、水位和输出，处理旧提示并临时压制新扰动；第七章明确需要改变的构件接触与停止条件。本章相互加强再次触及待处置的新联系，已隔离的广播和旧输出不重新开启

构件的具体几何、允许运动范围、水位工作区间、固定方式、窗口时长与工具能力仍需灰盒及场景规格验证，不在本页虚构数值。不能仅用“设备安全”四字替代后续设计

## 当下确认怎样成立

1. 开始本轮行动时建立新的行动标记，将待处理联系、当前通路与责任人对应；它是识别本轮报告的标识，不是魔法暗号或自动证明完成的钥匙
2. 梦内窗口必须有可观察反馈：已打开通路保持有效，第二条返回路径停止把物件送回起点；巧克力护线有限，关键目标仍由玲判断
3. 现实端分别检查构件已经到达允许的处置位置、固定操作已经完成。两项报告保留各自观察结果与本轮标记，由塞拉协调发送，不合并为一句无来源的“好了”
4. 报告通过第七章实际建立并持续监测的当前接入与联络通路传入；曜核对本轮标记、两项现实结果、自身连接监测与玲提供的窗口状态。任一缺项、失效或彼此冲突都暂停提交
5. 曜在上述条件满足后发出本阶段确认，完成该处一次性提交。全部新增联系解除并经现场复验后，才生成整场完成确认；阶段确认不能提前打开“委托已完成”状态

已观察到的结构能重放已有声音与模式，无预知能力。它不能在真实检查发生以前提供与这些条件相符的当前事实；但若本轮真实报告已经产生，它也可能复制已知内容，因此声线、新鲜词句或单独一个标记都不是证明。判断仍依赖生成条件、独立现场结果和连接监测，重复听到真实报告不撤销已完成操作

联络链的数据载体、界面具体布局、监测失效判据及可用性预算留待工程验证。叙事不许在这些前提未知时直接宣称“实时通信绝对可信”

## 中止、检查点与保存

| 情况 | 当次尝试如何结束 | 持久状态与恢复 |
| --- | --- | --- |
| 必需观察错过／对白跳过 | 在原观察点重看，记录页保留已经取得的事实 | 不撤回玩家提前识别的知识，不强迫先被旧语音欺骗 |
| 工具受扰或护线失效 | 回安全观察位，收回未完成的临时动作 | 恢复本次工具与支援尝试，不重复消耗唯一剧情物品 |
| 窗口丢失、现实确认冲突 | 停止当前物理步骤，先保护人员与构件 | 未满足的提交保持未完成；按确认仍有效的安全状态重新准备 |
| 当前接入失效／主动紧急退出 | 巧克力随连接撤出，现实端执行既定停止及保守隔离，必要时回退 A | 不将撤出算成功，也不让角色无连接继续行动；后续从明确检查点恢复 |
| 梦内已到位、现实第二确认未到 | 允许继续保持窗口、观察变化或安全中止 | 不能按出口已开、熟悉语音或进度条提交 |
| 一处双侧确认已完成 | 记录该处实际隔离与现实处置结果 | 一次性提交后重访不能无条件复活；后续尝试继承真实完成部分 |
| 所有联系已处理、复验未完成 | 保持调查／复验状态，按安全安排退出或继续 | 不提前开启最终完成与尾声；可恢复到未完成的复验 |
| 最终确认与正常退出完成 | 玲与巧克力退出，曜完成设备交接、余波说明 | 保存最终处置、角色接应和现实修缮状态；物品、报酬与消息不重复发放 |

检查点是本次游戏尝试的恢复边界，不在世界史中倒流现实时间。实现前必须确定快照包含哪些暂态、哪一处现实提交已持久化；已发生的维修、损失、停用和改期由真实节点承接，不能靠重试抹除

## 接入验收场景

- 已提前识别旧提示和首次发现提示两条路线都能完成，不由脚本强制角色误判
- 保持窗口时分别注入缺失第二确认、错误轮次、失效通路和相互矛盾的现场结果，均不得提交成功
- 当前检查真实完成后再次收到相同报告，不重复提交、不回滚结果，也不将复制本身误判为现实未完成
- 依次在工具未落定、阶段提交前、阶段提交后、最终复验前和完成后测试退出与读档，检查一次性结果与暂态恢复
- 无可选支线资料仍可完成所有必需观察；保留私人记录不降低成功率
- 实际查看窗口、第二条返回路径和现实结果的反馈是否能辨认；静态表格与构建成功不能代替体验验证

这些场景留给相应原型任务执行，本次文档整合仅检查因果和状态契约。现有 Viewer 无上述玩法，不为这份规格伪造执行证据
