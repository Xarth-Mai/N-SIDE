# 回声之后 · 完整制作脚本

[故事正文](../../../../player/story/main/after-echoes.md) · [动作与恢复规格](development.md) · [台词表](dialogue.csv) · [脚本约定](../script-format.md)

主动任务预算 90–120 分钟，九场覆盖 T01—T14。玲全程潜梦，曜全程清醒并守在玲身体和设备旁；巧克力随当前有效的人类连接进出。现实拆改由邱立与专业人员实施，固定核验员独立给出固定结果，塞拉协调各现场，罗宾比较联合输出；主角不越过专业职责亲自修现实构件

出场：月城玲、月城曜、巧克力、塞拉、邱立、固定核验员、罗宾、邵敏、艾玛、月城修、陆成。点名者、引座员、候秋者与候船队列沿用已观察的局部固定行为，不增设最终人格化敌人，米娜个案不并入此次合流

镜头设计以舞台、长椅、侧门、檐口和安全观察位为相对参照，不给未经灰盒验证的距离或窗口秒数。自由操作镜可移动、观察、暂停并发起安全中止；工具必须保持的镜头另限实际移动范围。短接管镜支持暂停、字幕推进和跳过，跳过只压缩已触发演出，不替玩家观察、安放工具、作出取舍或补齐当前确认

本轮标记是与真实报告对应的识别物，不是魔法通行证。报告必须来自实际检查，经当前有效联络送到，并与两侧观察和监测相符；旧声线、复制真报告或单一标记都不能独立证明未发生的动作已经完成

## QST-009-S001 · 今天这一轮

入口：紧接第七章正式进入。现实玲坐在小店后场，曜在她身侧的接应椅，停止页和设备位均已检查，前场有限帮班正在进行。梦内玲站在混合等候空间的安全位，长椅扶手有旧磨痕，远处厅堂亮起，侧门却接向不属于这里的檐下。工具放在随身袋中，巧克力沿当前连接到她侧后

<a id="qst-009-s001-k01"></a>

### QST-009-S001-K01 · 两端都报自己的位置

短接管从现实曜的手移到监测页，再切玲梦内肩后中景。曜不是全城俯瞰观察者，画面只显示本次已收到的现场；玲取出工具，将本轮标记扣在工具可见侧，翻转确认仍可读，再把它握稳。跳过停在梦内安全位，不越过入口验证

**QST-009-L001｜月城曜**：本轮连接有效，我在你身边。各处仍守着已确认的范围，先看入口。
**QST-009-L002｜月城玲**：标记装好，长椅在我左边，侧门通向檐下。我先留返回位置。
**QST-009-L003｜屏幕文字**：跟随当前连接

<a id="qst-009-s001-k02"></a>

### QST-009-S001-K02 · 不从最亮的地方走

玩家镜头可观察厅堂、等候庭与候船口，最亮舞台在另一侧，侧门后的队伍是真正尚待理解的路径。玩家选择观察入口边缘的标记和可往返位置，沿一段当前开放路径前进再退回长椅参照；若先靠近舞台亮处，队列合拢的可见动作使玲留在外侧，不强制进入陷阱、扣掉已有认知或被旁白嘲笑

**QST-009-L004｜月城玲**：侧门这段能走回长椅。舞台亮着，不等于出口在那里。
**QST-009-L005｜月城曜**：返回位置记下了。你看到的才算梦内这一端，我继续核对现实。

<a id="qst-009-s001-k03"></a>

### QST-009-S001-K03 · 把范围放在手边

玩家在长椅侧安全位打开记录，旧声源隔离、现实当前待处置段与梦内已见路线分栏。工具重新入袋，方便接下来观察。巧克力在侧门外示意退路，玲看向它再看回队列，准备比较完整一轮；不抢先写出拆后重叠结论

**QST-009-L006｜屏幕文字**：本轮开始：原有输出隔离保持；新增联系待逐处处理；退路已验证；现实位置与固定各待现场确认

出口：本轮入口与退路建立，玩家可先观察或直接利用已经看懂的规律。安全中止则随连接退出，未处置段不记成功；重新进入建立新轮标记但保留已完成现实工作

<a id="qst-009-s002"></a>

## QST-009-S002 · 提前响起的结果

入口：玲在长椅靠侧门处，巧克力在身后退路侧，工具在袋中。放行口与原长椅均处于可观察范围。空厅尚无这轮离场完成的队伍，却先有旧掌声传出，候船放行声随后响起

<a id="qst-009-s002-k01"></a>

### QST-009-S002-K01 · 声音先到

玩家先在长椅旁选定这一轮随队列运送的箱子：玲取出同组的另一枚本轮标记，等箱子停在扶手旁，左手按住箱沿，右手将标记扣在带浅缺口的外角，压紧后松手，退到椅外。工具上原标记仍留在工具侧，不被移走。玩家读回箱角缺口、扣上位置与当前箱位，再连续看它随队列行进；标记用于对应本轮观察，不单靠字样证明箱子未回送。随后玩家自由镜跟看当前队尾；声音响时队尾仍在入口，带本轮标记的观察箱尚未越过出口。玲扶着椅背，不随掌声迈步。玩家可查看标记位置或声音记录，先取得实际位置即可直接指认声音不能作完成证据，不强制被欺骗一次

**QST-009-L007｜月城玲**：声音已经到结尾，队尾还在这里。我们这一轮还没走完。
**QST-009-L008｜屏幕文字**：声音已响／当轮位置未变

<a id="qst-009-s002-k02"></a>

### QST-009-S002-K02 · 看过就不用再装不知道

若玩家已在入口看懂，沿侧门外缘直接前进至 S003；未比较清楚可在安全位回看完整一轮，声音轨只显示实录顺序，不把未观察路径自动揭示。玲取出工具后暂握身侧，主手不持续施力，目光沿引座员转身和队列返回分别移动

**QST-009-L009｜月城曜**：现实结果还没产生。先用你看到的队伍和位置判断，不等一个熟悉声音替我们宣布。

出口：旧声响抢先的规律已成为判断工具，不是终章全部难题。玩家离开或重接保留这项认识，复制已有声音不使旧声源现实隔离失效，转 S003

<a id="qst-009-s003"></a>

## QST-009-S003 · 两条路挤到同一处

入口：长椅外缘向侧门的观察位；玲握工具但未安放，巧克力站在退路。引座员走向空座时横过候船队列，点名返回又穿过庭院路径。三种动作能从同一安全观察位分次比较，现实街区没有移动

<a id="qst-009-s003-k01"></a>

### QST-009-S003-K01 · 先让一支真正离开

玩家镜头以椅背为固定参照，看引座员转身拦住候船队尾，再看点名者返回堵住侧门。玲抬工具准备接近时停住，把一条经过自己的队伍完整让过，不站到双方交叉点。玩家标出两个阻塞来源，先看哪一个都可；只看一个时另一项仍未知

**QST-009-L010｜月城玲**：他一转身，候船这队就被拦住。点名的又从侧门回来了。要把两次离开分开。

<a id="qst-009-s003-k02"></a>

### QST-009-S003-K02 · 入座空当

玩家等待引座员领前排入座形成的外侧空当，沿座椅背后绕至侧向联系。玲先收紧工具贴身，侧肩通过，不从座位或人影身体穿过去；到位后用工具改变这一轮侧向路径，让第一支候船队列完整离开。回看时队尾确实越过第一阻塞，不因播放一句台词就算完成

**QST-009-L011｜月城玲**：这一支先走。巧克力，把点名的返回位置留给我看。
**QST-009-L012｜屏幕文字**：返回位置：侧门内侧

<a id="qst-009-s003-k03"></a>

### QST-009-S003-K03 · 给第二支自己的路

保持玩家镜头，玲确认第一支尾端已过后，退出旧施力位置，沿空出的侧后方到第二落点；工具先离开旧点、收入身侧，再伸向新点，不能同时维持两个离手效果。第二队沿新的侧向通路离开，不再横穿前队；若错过时机则回观察位等待下一轮，已识别规律保留，不重复教学台词

**QST-009-L013｜月城玲**：前一队已经过了。我把第二队放到侧面，不从它们中间穿。
**QST-009-L014｜月城曜**：现场看到对应间隙了，范围仍是第一段。等你接近联系部位。

出口：侧向通路开放，临时工具操作不等于永久隔离。玲把工具收回并沿已可通行的侧后路线接近具体联系，巧克力跟在退路，转 S004。窗口受扰时恢复到安全观察位，不倒退旧案隔离

<a id="qst-009-s004"></a>

## QST-009-S004 · 一次护线

入口：已打开的侧向通路尽头是第一段新增联系，玲能看见工具落点，干扰形体仍会掠过。巧克力只可提供一次覆盖本轮操作的护线，不能同时护住整个复合空间。曜在现实核对现场可操作许可

<a id="qst-009-s004-k01"></a>

### QST-009-S004-K01 · 目标由玲指给它

玩家镜头在落点外观察，识别的是与当前接触图对应的一段，不以消灭形体数量选目标。玲先抬手指向联系部位，目光确认巧克力看向同一处，才请求护线。巧克力移至受扰方向抬起手臂，退路仍留在另一侧

**QST-009-L015｜月城玲**：护住我到这个落点的一轮。另一边先留着，我不会同时追过去。
**QST-009-L016｜屏幕文字**：这一轮，守住这里

<a id="qst-009-s004-k02"></a>

### QST-009-S004-K02 · 手放上去之后

玩家在护线开始后沿通路接近，玲低身避开掠过的干扰，左手扶稳工具柄，右手将工具端与联系方向校准，接触后缓慢加力至通路不再回送；辅助手移到能安全支撑身体的位置，主手保持。没有安放便撤回时不触发现场施工；受扰丢失落点则双手收回工具，沿原路退回，支援恢复为本次未完成尝试，不永久耗掉唯一剧情工具

**QST-009-L017｜月城玲**：工具到位，庭院这一侧不再把队尾送回。现实第一段可以继续。

<a id="qst-009-s004-k03"></a>

### QST-009-S004-K03 · 现场也要做完

短接管现实场面仅在梦内窗口成立且现场许可后插入，邱立与专业人员按已核验工序改变第一段接触，核验员另行核对本轮结果；曜从自己监测位接收，始终不离开玲身体旁。隔离完成后切回玲工具位，交还玩家镜头，让她收回已可撤的临时工具，再退到长椅参照；现实已完成一段不会随工具撤回重开

**QST-009-L018｜邱立**：第一段新增接触已经隔离，现场位置与固定记录齐全。我把两份本轮结果都送过去。
**QST-009-L019｜月城曜**：当前窗口、标记、连接与两份结果相符，第一段记录完成。剩下的还要复测。

出口：第一段永久处置保存，玲已收工具回到观察位。旧提示与学校等已隔离输出不重新开启；当前余下联系尚待检查。阶段提交后中止，恢复不重发首段完成或消耗相同工具

<a id="qst-009-s005"></a>

## QST-009-S005 · 回来的同一箱

入口：玲在长椅侧面，工具已收回右手，巧克力位于退路。前段现实拆开之后，原来错开的两轮归返开始重叠；第一次从长椅看到标记箱回来是这次新条件的证据，不是第七章已经预演过的固定台词

<a id="qst-009-s005-k01"></a>

### QST-009-S005-K01 · 比刚才早了一步

玩家镜头保持长椅、返回侧门与檐下之间的可视关系。掌声响，队列未出；引座员尚在转身，候船者已经返回；带本轮标记的箱子出现在同一扶手边。玩家查看箱子标记与两次转身，记录同一轮的前后关系，箱子不当作新奖励或可无限复制道具

**QST-009-L020｜月城玲**：这一次重在一起了。刚才给前队留的空当，正好让另一队回檐下。
**QST-009-L021｜月城曜**：现场也出现新间隔。先留在长椅旁，别追那只箱子。

<a id="qst-009-s005-k02"></a>

### QST-009-S005-K02 · 已完成的仍在那里

玩家在安全位对照当前接触图，首段隔离仍标为已实际完成；邱立在现实指向没有重新接回的前段，再由维护人员观察剩余共同接触。玲左手打开记录页，右手工具收进袋内才能翻动完整图；巧克力不替她点出答案，只保留两次返回位置供比较

**QST-009-L022｜邱立**：外围拆开的仍然分离。现在集中响应的是原拟保留的檐段连件，导向部位又在固定前往回动。
**QST-009-L023｜月城玲**：两次返回都经过这里。只把先前那一轮再做一遍，还是会挤回来。

<a id="qst-009-s005-k03"></a>

### QST-009-S005-K03 · 先把下一步停住

短接管现实接应台近景，曜将位置和固定栏并列，固定未完成，没有代填；塞拉让现场暂停下一段，专业人员转回保护构件的位置。玲在梦中将图收入袋中，再从工具袋取出工具握在右手，仍留安全位，不迈向正在重叠的队列

**QST-009-L024｜塞拉**：下一段暂停。保守隔离仍然就绪，必要时按 A 撤出；已经拆过的照实际位置保护。
**QST-009-L025｜月城曜**：我们没有丢掉刚才完成的。现在缺的是这一处的新窗口和现场固定。

<a id="qst-009-s005-k04"></a>

### QST-009-S005-K04 · 纸上的完整轮廓

玩家自由镜看向檐口缺角，玲手指在侧袋草图边缘摸了一下，没有马上抽出，因为右手仍拿着工具。玩家可回看第六、七章取得的支承与可拆范围；从未做过可选支线也具备全部必要事实。完成当前两路比较后转 S006；未观察全可在 K01 等下一轮，旧掌声可关闭重复播放但不能替代观察

出口：已识别剩余共同接触，具体处置仍待现场重新许可。工具在右手、旧侧路窗口已经失去，绝无离手自行维持的操作；中止可退 A，真实首段拆改保持

<a id="qst-009-s006"></a>

## QST-009-S006 · 檐线与第二格

入口：紧接 S005，梦中外围联系已隔离，两轮返回现在重叠；玲在长椅靠侧门的安全观察位，面向缺角檐口，旧侧路在回送出现后已失去窗口，玲已把工具从旧落点收回握在右手，不存在离手后自行维持的旧操作；巧克力留在她退回侧门的路线上。现实中邱立位于围挡外观察位，维修组已对构件做保护性支撑，尚未抽出最后的承重附属连件；曜坐在玲身体旁，当前连接监测、位置与固定两份报告并排显示，手没有离开接应台。老钟与公众在作业区外，无人站在檐下

<a id="qst-009-s006-k01"></a>

### QST-009-S006-K01 · 旧声音和仍然回来的标记

玩家镜头，从长椅侧后方可同时看见候船口和檐下返回口；前景扶手提供不随队列移动的参照。玩家能转身、观察、暂停和发起安全中止，不能越过正在回送的队列。旧掌声从空厅传来，随后旧放行声响起；带本轮标记的箱子越过放行口，绕到檐下，又滑回原长椅。玲的右手随箱子前移半步便停在扶手外，没有追入人群。玩家分别检查标记、第二条返回口和现场接触图；取得过的比较保留，提前看明白可直接指认最后仍相连的檐段，无须再听完整一轮。以下 L061 与 L062 只在本轮两路回送均已实际观察后出现；只查声源仅出现 L063

**QST-009-L061｜月城玲**：标记又回来了。掌声已经响过，两条路都还在送回这里。
