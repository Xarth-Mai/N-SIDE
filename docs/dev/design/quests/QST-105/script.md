# 球场边的一张椅子：完整制作脚本

[故事正文](../../../../player/story/daily/courtside-chair.md) · [共用写法](../script-format.md) · [正式台词](dialogue.csv)

本篇主动游玩预算 15–25 分钟，沿用既有任务范围；下述场面是中文制作交付稿，预算、镜头与动作尚未经过实机或演员验证。远途移动、日历转场和已经完成的交接不重复计时，支线结果分别读取实际记录

## 阅读顺序与连续性

S001 用品店的同长时间表 → S002 找椅子位置 → S003 选一轮排法并实际交接 → S004 人像或空椅 → S005 收场交还 → S006 续接与重访。S003 两种排法共用交接，S004 照片许可不由兄妹替别人选择

本篇演员为曜、玲、魏航、叶真、陈知夏、球场等候者 CHR-041、常客 CHR-042、初学者 CHR-043；等候者的朋友及经过的小车使用者只演动作，不新增声音身份。公共规则允许不参加本轮者另约，任务不收走其使用资格

F26 落于 S002-K02 的第一次堵路、S003-K04 魏航放下自己的球、S004-K03／K04 的两种授权照片和 S005-K02 实际收椅；F06 只在已核对第三章照片时由 S004-K02 回扣，未经历者从当前等候者获得同样完整的一场故事

## QST-105-S001 · 他还没穿上的鞋

入口：约定活动开始前，体育用品店门口。魏航坐在矮凳侧沿，两膝夹球，打气针插在球嘴；他自己的旧鞋在凳下，待售鞋在店内架上。常客倚在门框外侧看轮用纸，初学者站在靠路边的一端，两人没有挡住店门。兄妹从公共人行道靠近，玲手里没有活动表，曜也未答应组织这场球

<a id="qst-105-s001-k01"></a>

### QST-105-S001-K01 · 两双鞋

玩家镜头，能绕到矮凳旁看球、鞋和纸。靠近时魏航压完最后一下打气筒，拔针，指腹压住球嘴听漏气声，再把球在膝上转半圈。玩家可先看鞋；玲的视线从鞋底旧磨痕转到他脚上的便鞋

**QST-105-L001｜月城玲**：这双不是拿来卖的吧？
**QST-105-L002｜魏航**：我的。今天带来了，总该穿得上。

未看鞋则魏航把球抱起露出凳下，执行共同邀请；先看过鞋不重复笑话

**QST-105-L003｜魏航**：你们帮我看看？我照每个人一样长排的，纸还没贴上，就已经有人想走了。
**QST-105-L004｜屏幕文字**：看看这轮怎么排／我晚些再来
**QST-105-L005｜月城曜**：我们先办自己的事。这张先别算已经问过我们。
**QST-105-L006｜魏航**：行。我再问问到场的人，下一场也能接着试。

延后保留表由魏航持有，兄妹可离开；晚到不回滚活动，按 S006-K01 续接。选择查看后魏航把气筒靠回凳腿，双手展开纸给玩家，进入 K02

<a id="qst-105-s001-k02"></a>

### QST-105-S001-K02 · 一样长不等于都能来

玩家镜头局部查看，纸由魏航扶着下边，玩家可先点常客划出的下班位置或初学者的连续练习段。两项都允许反序查看；第二项读完才开放比较，不要求回到默认顺序

**QST-105-L007｜屏幕文字**：本轮草排：各组轮用同样长；到场后再分组。等候位置未定。尚未确认
**QST-105-L008｜球场常客**：这一格我还没下班。你分给我，和没分差不多。
**QST-105-L009｜球场初学者**：我刚摸到一点感觉就得让出去。下次来，又从捡球开始。

常客指尖停在自己的那格，初学者没有碰纸，只把鞋袋往肩上提。魏航用拇指抹平纸边，话说得比动作快

**QST-105-L010｜魏航**：那你们说个都行的。

他说完看见两人各退开半步，把纸折到只露空白背面，没有逼两人当场给答案。玲将手指从“同样长”移到“等候位置未定”

**QST-105-L011｜月城玲**：先别给所有人填格子。我们跟他们走一遍，好不好？

出口：魏航锁好气针，把自己的鞋袋提在左手，球夹右臂，四人步行到球场；没有人被送上场。纸仍在魏航口袋里，进入 S002

<a id="qst-105-s002"></a>

## QST-105-S002 · 看球最好的位置

入口：同一轮场前，球场外缘。叶真从服务点带来已获准借用的折椅，收拢放在公告栏旁；等候者靠近通往等候庭的路口，目光一直越过球场看出口。球门旁既是人行通路也是物件出入处；包和球收在边缘，不占门缝

<a id="qst-105-s002-k01"></a>

### QST-105-S002-K01 · 先问要去哪里

玩家镜头，可依次或反序查看球场、校外等候庭和亲子活动室的使用说明，只比较眼前需要，不让玩家跑遍全部关联地点。叶真拿出已有位置简图指点，身体侧向当事人，让他们先回答

**QST-105-L012｜叶真**：这里等放学方便，室内那边下雨能用。今天想在外面打球的人，不能都往里塞。
**QST-105-L013｜球场初学者**：我想在这个场练。换到屋里坐着，时间再长也不是这个事。
**QST-105-L014｜球场等候者**：我等朋友从那边出来。能看见出口就好，不占你们的场。

玩家若早已看到出口，可直接提出靠出口的位置，叶真点头，将确认点留到 K03；不强制先犯堵路错误。未早发现则曜接过椅子，进入 K02

<a id="qst-105-s002-k02"></a>

### QST-105-S002-K02 · 椅背挡住门缝

玩家操作“试放椅子”后，曜双手握住椅背侧杆，张开椅脚确认落平，放在看篮框最清楚的一点；玩家仍可旋转镜头。小车使用者走到门边停下，前轮正对被椅脚缩窄的通路，双手没有松开把手，也没有硬撞。轮轴轻响后停止，玲先看车轮，再碰一下曜的袖口

**QST-105-L015｜月城玲**：椅子先抬一下，门边有人等着。

玩家执行挪开时曜从空侧提起椅子，玲退到墙边给车让路。车完整通过才亮出可继续试位的边缘，不因跳过演出记录“通路已试用”；没有操作就只保持等候，不消耗虚构倒计时

<a id="qst-105-s002-k03"></a>

### QST-105-S002-K03 · 请要坐的人试

玩家镜头，操作把椅子放到出口可见且不挡门的边缘；早发现路线从 K01 直接来此，玩家仍实际摆椅并让来车通过。叶真一脚踩住椅脚旁地面确认没有高差，用手示意等候者。等候者先绕椅后看一眼出口，再坐下，把袋子收进双膝之间而不是横放过道

**QST-105-L016｜球场等候者**：这里就行。坐正中间看球，我反而得一直回头。
**QST-105-L017｜月城曜**：我刚才给你找的，是我想坐的位置。
**QST-105-L018｜月城曜**：那就留这里。车过得去，你也看得见。

上面两句按是否误放互斥。陈知夏走到球场边，相机停在胸前，拇指离开快门，先记下椅子位置

**QST-105-L019｜陈知夏**：我先不拍。这个角度刚才差一点只剩球了。

出口：椅子在边缘，等候者留坐，叶真把借用条夹到公告栏背侧；兄妹保留原位操作，去魏航处比较当轮排法 S003。中途离开椅子不自动归还，实际位置与通过结果保留

<a id="qst-105-s003"></a>

## QST-105-S003 · 魏航让出去的一段

入口：场边公告栏，魏航把原表翻面，两组使用者各站一侧，玲站在其间靠外，不挡开门；曜在球袋旁，鞋与球仍属于魏航。每个人只知道已听到的需要，两个试排都还没成为既定规则

<a id="qst-105-s003-k01"></a>

### QST-105-S003-K01 · 让两张纸说清代价

玩家镜头，在两张试排纸上比较，先读任一张均可。没有读过的一张不会自动算“大家讨论过”，选择前展示受影响人的一句回复

**QST-105-L020｜屏幕文字**：先新手后常规：新手连练一段；常规组后进场。本轮方便时段缩短，魏航少打一部分
**QST-105-L021｜屏幕文字**：错开交接：常规组先开一段；到提醒即交场给新手连续练习；常规组另接一段。整理交接占用本轮时间
**QST-105-L022｜球场初学者**：前面这一段不截开，我愿意早点来。
**QST-105-L023｜球场常客**：我下班赶得上后面。有人不愿少打，就另约一天，别在表上替他点头。
**QST-105-L024｜球场常客**：中间真停下来？那我把这回合打短一点。拖到提醒以后就算我占了。
**QST-105-L025｜球场初学者**：我能等前面，但轮到以后别再让我每个回合都让。

<a id="qst-105-s003-k02"></a>

### QST-105-S003-K02 · 选本轮能试的

玩家执行选择，纸张上出现所选安排，其余纸折进魏航口袋，不销毁以后调整可能

**QST-105-L026｜屏幕文字**：试“先新手后常规”／试“错开交接”
**QST-105-L027｜魏航**：这回先给新手连着来。我的那段往后挪，别给我偷偷补回去。
**QST-105-L028｜魏航**：那就照提醒停，谁都一样。我少一段收东西的工夫，得先找个人接手。

同一常客把包挪进界线，指向公告栏下一张空预约纸

**QST-105-L029｜球场常客**：我试这一轮。刚走的那位说不好用，他下回另约，这句也记着。

玲把未到场者的意见记在另约栏，不编成多数同意；两种选择在 K03 汇合。任务没有“全员满意”条件

<a id="qst-105-s003-k03"></a>

### QST-105-S003-K03 · 提醒响时球还没落下

玩家镜头。先新手路线：正式新手段尚未开始，常客只在场内投热身的一球；玩家提醒立即按刚确认的安排结束热身，将第一段完整交给新手，随后才到常规组和魏航的本轮场段。错开路线：常规组先实际使用确认的第一段，玩家到约定点提醒，交给新手完整一段，然后常规组使用表上已经留出的后一段，魏航在后一段上场。两路线均在 K04 交给新手；A 不增加第二轮新手或额外常规时间，B 的两段始终来自所选表内。球声与鞋底摩擦声保持现场距离，不加胜利音乐

**QST-105-L030｜屏幕文字**：提醒交接

魏航拿起哨子吹一次，常客球还在手里。他张口想加一句，眼睛先看篮框，再看场边已经扎好鞋带的初学者；他把自己抱着的备用球放回袋口，退过边线

<a id="qst-105-s003-k04"></a>

### QST-105-S003-K04 · 先交出自己那只球

短镜接管只在玩家提醒已发出后触发，从公告栏一侧中景看魏航放球的手和边线；暂禁移动、投球和接另一请求，暂停、跳过可用。跳过仅完成本次放球与场边就位，不替玩家下一镜收物件

**QST-105-L031｜魏航**：照说好的，交场。这球留下一段。
**QST-105-L032｜球场常客**：你不是也想打？
**QST-105-L033｜魏航**：想啊。所以下一段别又叫我去搬桌子。

常客先弯腰捡起自己的水瓶，笑一声，再伸手接走原准备留给魏航收的轻物件；初学者走过边线，先确认对方已退出才接球。镜头在魏航把鞋袋放到空凳上的动作结束时回到玩家原位，操作权交还

<a id="qst-105-s003-k05"></a>

### QST-105-S003-K05 · 他终于穿鞋

K04 之后新手确实连续试用：玩家可看初学者持球练习、失手自己追回后继续，没有常客每回合进入。完成这一轮现场观察后用同一场内转场抵达所选表上的新手段结束，初学者亲手把球交回常规组；不以现实等待填预算。A 此时进入唯一常规段，B 此时进入早已排定的后一个常规段。玩家操作“把散物收回侧边”，只收自己够得到的公共轻物件，常客带走已接手的一份。魏航坐下，左右手拉开鞋舌，把便鞋脚跟踩实后换上球鞋；鞋带拉紧，他抬头看还留给自己的场段

**QST-105-L034｜魏航**：这回真有我的份了。你们拍照的别站底线后面。

魏航起身入场，等候者仍不被拉进比赛。出口：安排与实际使用成立，转 S004。途中可离开；已试过的片段不要求再打，未完成的交接留在下一轮同类约定点续接

<a id="qst-105-s004"></a>

## QST-105-S004 · 不用补一个“终于加入”

入口：活动进行中，等候者坐在已试过的位置，朋友尚未从出口出现。陈知夏在边线外检查刚才未公开的试片，镜头看得见球，也看得到边缘椅背。兄妹位于她侧后方，不替等候者答应授权

<a id="qst-105-s004-k01"></a>

### QST-105-S004-K01 · 标题先露出问题

玩家镜头，查看陈知夏相机上的试片与暂拟标题。她用拇指在标题末字停住，把相机转给玲，画面中等候者双手抱袋，从未持球

**QST-105-L035｜屏幕文字**：大家一起运动
**QST-105-L036｜陈知夏**：他一球也没碰。我标题倒先替他打完了。

若 QST-108 已完成，她先站在当时学到的不挡路一侧再说下句；未完成不出现照片回忆

**QST-105-L037｜陈知夏**：上次我知道先给通路让开，今天又差点替画里的人想好了要干什么。

<a id="qst-105-s004-k02"></a>

### QST-105-S004-K02 · 已经知道照片会漏掉什么

玩家镜头。仅已核对 QST-004 完整底片时，玲点一下相机画面边缘，不拿出未取得的历史原件

**QST-105-L038｜月城玲**：那位接班的人也一直在边上。剪掉一点，事情就少了一截。
**QST-105-L039｜陈知夏**：嗯。这次先让他自己说。

未核对时直接进入 K03／K04，不展示历史人名与接班事实。陈知夏蹲低一点与坐着的人平视，相机垂在胸口，不先拍再补问

**QST-105-L040｜陈知夏**：我想留一张椅子和通路的照片。你愿意在里面吗？不愿意，我等你们走了拍空椅子。

<a id="qst-105-s004-k03"></a>

### QST-105-S004-K03 · 获准的人像版本

条件：等候者愿意留下当前人物照。玩家镜头，等候者将包放在膝上，指向出口，不接受持球摆拍

**QST-105-L041｜球场等候者**：可以。写我在等朋友就行，别写我来比赛。
**QST-105-L042｜屏幕文字**：球场边有人练球，也有人等朋友；椅旁保留出入通路。本人同意此图用于街坊记录及比较通路

玩家执行“确认取景内通路可见”，陈知夏向外退半步，在等候者不挡出口时按一次快门。快门声后她立即递出回看，等候者点头，她才把此照片记作获准版本；拒绝回看确认则撤出人物版，去 K04。拍照操作不由跳过代做。照片由陈知夏保存，汇入 K05

<a id="qst-105-s004-k04"></a>

### QST-105-S004-K04 · 不留人像的版本

条件：本人不愿出镜，或未确认试片。等候者把手掌抬到相机与自己之间，动作很小，陈知夏便垂下镜头

**QST-105-L043｜球场等候者**：我不入镜。椅子你等我们走了再拍，使用说明可以写。
**QST-105-L044｜陈知夏**：好。刚才那张不留下，我把它撤掉。

陈知夏向本人展示撤去人物试片，不把缩小或背影当绕过拒绝的方法。实际送别在 K05 完成，随后回到此镜拍摄空椅子与旁边物件，通路从一侧穿过画面；玩家确认画面无人后触发快门

**QST-105-L045｜屏幕文字**：这把椅子供人等朋友；坐下仍能看见出口，旁边保持通行。照片不含等候者人像，使用说明获准公开

<a id="qst-105-s004-k05"></a>

### QST-105-S004-K05 · 他等的人到了

短镜在朋友从出口实际到达时接管，机位在椅子斜后方中景，能见等候者先抬头、将包背带从膝上拿开、站起让椅脚离开裤脚；朋友递出自己的包让他接一下，两人并肩离开，不邀请上场。禁移动与取物，允许暂停、跳过；跳过落到两人已经离开、椅子仍原地，空椅路线仍需执行 K04 快门

**QST-105-L046｜陈知夏**：我还在等他拿一次球。他等的人已经来了。

镜头回到陈知夏身侧玩家原位。出口：只有经本人确认的人物照或空椅照留下，使用说明随同保存；后做 QST-108 只能读取这一个真实版本，不能将空椅换成人像

## QST-105-S005 · 收走与留下都要说一声

入口：该轮活动结束，魏航已经换回便鞋，球鞋在打开的袋子里晾着；叶真回到公告栏取借用条，等候者已走，椅子留在实际试位处。玩家保有照片说明，借椅不因拍完而完成

<a id="qst-105-s005-k01"></a>

### QST-105-S005-K01 · 下一轮怎样用

玩家镜头，叶真用手压住卷边的借用条，给出已有的归还或确认继续放置两条路径

**QST-105-L047｜叶真**：这轮用完了。收回公告栏后面，或者登记接下来继续用，别只留把椅子让我猜。
**QST-105-L048｜屏幕文字**：按约归还椅子／确认接下来继续放置
**QST-105-L049｜魏航**：我接下一轮，散场后由我收。位置就留试过的这一处。
**QST-105-L050｜叶真**：好，我把接手人写上。挪过位置还要重新走一遍。
**QST-105-L051｜叶真**：我在这边接，你把椅脚收拢就行。

<a id="qst-105-s005-k02"></a>

### QST-105-S005-K02 · 手松开以后归谁

玩家镜头。归还路线：玩家执行收椅，曜确认无人坐，抓椅背向上提一点，折好椅脚，提到公告栏后；叶真握住椅背，曜待她接稳才松手，她把椅子放进原借用位并收走借条。留置路线：玩家把借条交给魏航，魏航签下本轮接手，叶真收走条的原份，椅子留在试位处；不演一遍假归还

**QST-105-L052｜屏幕文字**：折椅已归还，接收：叶真
**QST-105-L053｜屏幕文字**：折椅继续放置于已试位置；下一轮接手：魏航，散场收回

两条路径此处汇合，物件去向不同且持续到重访。镜头始终归玩家，不以结项画面盖住接手动作

<a id="qst-105-s005-k03"></a>

### QST-105-S005-K03 · 还有一句不好用

魏航把纸压在自己鞋袋上，写下本轮安排，把“另约”旁没有勾的意见留着。他伸手要把纸折起，想了想又摊开给玲看

**QST-105-L054｜魏航**：常规那段少了，这句我留下了。今天能打，不等于以后都这样排。
**QST-105-L055｜月城玲**：那下次把鞋先穿好，再看表。
**QST-105-L056｜魏航**：你说得轻巧。……行，鞋放门边。

他把鞋袋提进店内而不是重新放回凳下。出口：本轮试用、照片许可和椅子交接结束；兄妹自由离开，球场仍按公共安排使用，没有永久和解或独占权

### QST-105-S006-K01 · 离开后接哪一轮

玩家镜头；未排定时回来，魏航保留已听取需求与已试位置；已排定而错过实际试用时，他用同一纸在下轮空位旁标记，不重演当晚仍在场的人

**QST-105-L057｜魏航**：前面问过的我留着。就差选这轮先怎么交场，你不用再把人叫来问一遍。
**QST-105-L058｜魏航**：这场已经散了。下轮照这张试，轮到交场你再看；椅子的位置没白找。

前者回 S003-K01 的未读／未选项，后者在下一场实际发生时回 S003-K03；若照片已拍、交还未做，只回 S005-K01，椅子不复制

### QST-105-S006-K02 · 一张照片究竟能说什么

玩家镜头，结项后来店。魏航把鞋从门边提起来，手不离鞋带，玲可查看留在公开板的当前安排

**QST-105-L059｜魏航**：今天我先打。有人等朋友就用那边，别见他坐着，就喊他差一个人。
条件：保存的是获准人物照片时，只说下一句

**QST-105-L060｜陈知夏**：那张他看过了。能留在小册里，也能拿来讲通路；不是所有人同意这张时间表的签名。
条件：只保留空椅照片时，改说下一句

**QST-105-L061｜陈知夏**：我留的是空椅子。下次拿去比较位置，也只拿这张，不补他的人像。

归还路线在公告栏后看见折椅，留置路线按魏航当前已接手的下一轮看见它在试位，若那轮也已散场则已收回；重访不撤销第一次交接。此镜结束于魏航系好鞋带出门，玩家保持自由行动
