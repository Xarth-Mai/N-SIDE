# 第三章 · 没有放学的那一天：完整制作脚本

[故事正文](../../../../player/story/main/no-school-bell.md) · [共用写法](../script-format.md) · [正式台词](dialogue.csv)

阅读顺序：S001 当下出口 → S002 停印 → S003 底片 → S004 交接与改约 → S005 第一段离场 → S006 两路窗口 → S007 恢复与展出 → S008 主动调查；S009 为结项后的条件重访。对应[分场纲](../campaign-sequences.md#第三章-没有放学的那一天)八场；整章设计预算 75–105 分钟，操作、调查与自然转场包含在内，镜头未实测，不把重访再次计入主线预算

主要演员：旧点名录音中的声音 CHR-063，玲 CHR-002、曜 CHR-001、巧克力 CHR-003、陈知夏 CHR-020、顾文珍 CHR-030、郑文良 CHR-018、郑拓 CHR-031、乔伊 CHR-024、叶真 CHR-023、校方工作人员 CHR-059、维修顾客 CHR-038。点名者使用 CHR-063 对应的固定旧录音，称呼残音本身不可辨认，不新增可以问话的现实学生或给旧声音赋予新意图

开场继承第二章已关闭的声响输出、首轮校样失约及现有工作预约，不重新播放这些事件。本章先核对现时学生去向，再查历史；玲单独潜梦，曜全程清醒接应。两队的次序影响当轮操作，学校隔离结果、重画、替补校样及顾客的新约是持久后果

<a id="qst-004-s001"></a>

## QST-004-S001 · 今天从哪一边出去

入口：放学后的校外等候庭，校园内访问尚未开始。玲由南门外步道进入，曜背着设备包落后她半步；陈知夏靠今日路线牌站立，摄像设备朝下。校方工作人员在开放出口旁核对工作夹，顾文珍应邀来讲照片，站在等候庭内侧。旧门关着，门件可见而非可通行。现实接送者走公共出口，不需要进入异常范围找人

<a id="qst-004-s001-k01"></a>

### QST-004-S001-K01 · 先看正在使用的门

触发：首次进入等候庭

玩家镜头，操作玲。开放出口与旧门都在庭内可见范围，镜头不锁向发声处。陈知夏听见旧门方向的呼唤，先向那边抬头，随后把摄像设备收回胸前，横走一步让出当前接送通道；工作人员将工作夹合上一半，挡住个人资料

**QST-004-L001｜陈知夏**：今天大家走这边。那道门已经不用来接人了
**QST-004-L002｜校方工作人员**：当前学生的去向已经逐项核过。你们查声音，我守着现在的出口

玩家可查看公开路线牌，或先从护栏外观察旧门；任一路都不会得到现实名册中的私人姓名

<a id="qst-004-s001-k02"></a>

### QST-004-S001-K02 · 两种变化分开记录

触发：查看今日路线牌或旧门

玩家镜头的局部查看不改变站位。路线牌朝公共步道；旧门下缘的垂片发生短促抖动，门扇没有打开。玲靠护栏观察，手留在栏外；曜将独立录音设备放在不挡路的墙台，先拍门件再记录声音。玩家分别选择“记录门件”和“记录声响”，记录框显示取得的各项，未看见的一项保持空白

**QST-004-L003｜屏幕文字**：今日出入：南门外开放出口／等候区旧门：关闭，不作接送出口
**QST-004-L004｜月城曜**：门没有开。动的是下面这一片，声音另记一项

若先记录声响，玲先举起掌心示意曜不要碰门，等看见垂片动作后才将两项并列；若先看垂片，声响记录保留独立来源，不自动写成机械摩擦

<a id="qst-004-s001-k03"></a>

### QST-004-S001-K03 · 人走开以后

触发：两项变化均已有现场记录

短演出接管，机位从护栏外中景移到顾文珍侧后，旧门留在画面深处；禁移动和取物，允许暂停与跳过。声音由门后方向出现：先是两个断续人声残音，保留开口与尾音但不组成可辨姓名；中间有同一处吞音，接固定的集合指令。顾文珍依据自己认识的旧称呼节奏认出对象，玩家只能把它作为她本人的辨认，不能据此补出现实名单。

**QST-004-L099｜旧点名录音中的声音**：叫到的，到门边来。没接上的，回原处等

顾文珍原先端正抓着包带，听见称呼残音后松开一只手，朝门口迈了半步。陈知夏没有拉她，先将自己的站位移到前方，指向外带铺旁的空座

**QST-004-L005｜顾文珍**：他早就不用那个名字了
**QST-004-L006｜陈知夏**：顾老师，我们到那边坐。这里还在录

顾文珍望着门缝，等又一次纸张般的翻动声过去才转身。陈知夏陪她沿公共步道离开。曜目送两人越过墙角，在录音标记上按一下；门边旧称呼继续，垂片又动一次。跳过落到两人已离开、当前这段录音已取得，恢复玲在护栏外的控制，不替她读取记录

<a id="qst-004-s001-k04"></a>

### QST-004-S001-K04 · 持续的一段

触发：顾文珍已离开录音范围，玩家查看本次记录

玩家镜头，玲点开离场前后的两段声音，手指停在曜刚加的分隔记号上，两段均重放 S001-K03 的同一条旧录音，连姓名残音的吞音位置也一致，未多录出一条新指令。曜取回设备，关好防尘盖，示意可以沿公共步道过去

**QST-004-L007｜屏幕文字**：现场记录｜顾文珍离开前：旧称呼与门件活动；离开后：旧称呼持续，门件仍有活动／当前学生去向已由校方核验
**QST-004-L008｜月城玲**：她已经走了，那里还在叫
**QST-004-L009｜月城曜**：先带着这一段，别把老师当开关

出口：旧门由校方保持关闭，录像与录音归本案，设备随曜携带。玲可先去外带铺旁与顾文珍核对原画，或在已有授权时先取底片，之后 S002 承认已取得材料；校园没有因任务开始自动开放。离开后续接从尚未查看的材料继续，不重演顾文珍被声音引走

<a id="qst-004-s002"></a>

## QST-004-S002 · 先别印

入口：同一时段的外带铺旁等候座，陈知夏把饮品放在桌边不压稿纸，顾文珍坐靠墙处；玲将原稿从图样夹抽出，曜站桌外侧听现场消息。乔伊通过小册协作消息确认候选页，本轮尚未印制

<a id="qst-004-s002-k01"></a>

### QST-004-S002-K01 · 画面先替人说了话

触发：玩家将主题原稿放上桌面

玩家镜头，取纸时玲先托住下缘，再将压角从画面中央移开。近看可见一个突出的教师身影，门边余下空间几乎被暮色填满；原题字完整保留

**QST-004-L010｜屏幕文字**：《今天的街坊》主题页候选｜最后离开的人／插图：月城玲／待本人核对，尚未付印

顾文珍沿着画上的门框看了一圈，食指停在自己的肩线附近；她把纸推回一小段，没有折起来

**QST-004-L011｜顾文珍**：画得很好。先别印
**QST-004-L012｜月城玲**：是哪里不像吗？
**QST-004-L013｜顾文珍**：我后来回家了。有人来接我的班

<a id="qst-004-s002-k02"></a>

### QST-004-S002-K02 · 把待印的一格撤下来

触发：顾文珍提出停印；若此前已核对底片，使用后半句承认而非重新猜测

玩家镜头，玲打开协作消息。玩家实际选择“撤下这一页的待印版本”，她将候选图退回修改夹，协作栏中的图标随之变为待改。若玩家暂不操作，只能离开并稍后继续，乔伊不会自行印制

**QST-004-L014｜屏幕文字**：主题页暂不付印，需核对完整照片与交接记录；其他已确认页面保持原进度
**QST-004-L015｜月城玲**：我先撤下来，再查原来的照片

条件：已经在 S003 取得完整底片时，以本句替代上一句

**QST-004-L016｜月城玲**：底片边上确实还有人在。我撤下来，再把交班时间对上

两句互斥，同一撤稿动作只发生一次；顾文珍听见确认后把压在原稿上的手收回，开始从包内找旧教案的封面照片

<a id="qst-004-s002-k03"></a>

### QST-004-S002-K03 · 不把等待写成采访

触发：待印版本已撤回

短演出接管，桌边侧面中景，保留顾文珍、玲的手和未喝完的饮品。禁移动与翻私人包，允许暂停或跳过到原稿收回图样夹；顾文珍只拿出自己愿意展示的一张教案封面，不把整包交给玩家

**QST-004-L017｜顾文珍**：以前我也说过。有人以为我是客气，就又把那个标题留着
**QST-004-L018｜月城玲**：这次我改完给您看，再送出去

顾文珍点头，端起杯子发现吸管还没拆。陈知夏把自己手边未拆的纸套推近，顾文珍摇摇头，从杯侧找到原来的那根，自己撕开。镜头在她喝到第一口后退回玲原位，不以落泪或释怀作转场

出口：原稿只暂停付印，不销毁；顾文珍安排休息后回家，S004 的本人确认可按新的约定到场，不要求她一直留在异常门边。待印撤回后离场，回来直接转向尚缺的底片或交接表，陈知夏无声地指向待改图样夹，翻出仍夹在其中的原稿，不再触发第二次停印

<a id="qst-004-s003"></a>

## QST-004-S003 · 底片多出来的半只手

入口：FLASHBACK 获准查看的工作台，郑文良在灯箱内侧，郑拓在外侧留出拍摄比较的位置。玲持候选画和授权照片复制件，曜带着门件记录。原底片由郑文良操作，文具店交付的授权打印件在文件袋中；领取只查看本人订单，不开放其他学生文件

<a id="qst-004-s003-k01"></a>

### QST-004-S003-K01 · 先打开完整边缘

触发：玩家将裁切照片放在灯箱外沿

玩家镜头，可放大授权数字复制件；原底片不能拖走。郑文良用两指捏住底片保护套边缘，将整幅影像平放，另一手压住套袋滑动处。郑拓放下相机，不先替玲指出答案

**QST-004-L019｜郑文良**：这张是整幅。拍的时候我在门对面，这以外的人，我没拍到
**QST-004-L020｜郑拓**：你那页是从这里裁开的。把边框向外拖一点

玩家向外展开裁切框：先露出一只伸向登记桌的手，再露出周转箱和临时通行牌。若一次拖到完整范围，直接取得全部可见边缘，不强制分三次发现

<a id="qst-004-s003-k02"></a>

### QST-004-S003-K02 · 认得标签，不等于认得整晚

触发：玩家查看周转箱标签和临时通行牌

玩家镜头局部查看。玲俯身时图样夹碰到台边，曜接住夹底，等她重新站稳才松手。标签磨掉的部分不被补全，能辨认的小店字样写入可读原文；临时牌只证明当时这一处限制用途

**QST-004-L021｜屏幕文字**：周转箱侧签｜月台杂货／周转，交回店内
**QST-004-L022｜屏幕文字**：临时通行牌｜联络工作通道／接送请绕行
**QST-004-L023｜月城玲**：这个是我们家的箱子。我记得那阵子不让我们从那里走
**QST-004-L024｜郑文良**：箱子我认得。是谁送到那里、送了几趟，得问送的人

玩家能标记“问父母箱子与绕路”，不能把父母登记为实验人员。未看箱子而先读通行牌时只增加通行问题，之后回看标签再接同一家庭线

<a id="qst-004-s003-k03"></a>

### QST-004-S003-K03 · 让照片停在它拍到的地方

触发：完整边缘已可见，玩家保存用于比较的授权复制件

玩家镜头。郑拓将当前布局图压在照片下面，照片边缘保留，没有做覆盖式修图；郑文良把原底片重新装回保护套，再收进自己的编号袋

**QST-004-L025｜郑拓**：这只手在接东西，可只靠这一张，还看不出交接已经做完
**QST-004-L026｜月城曜**：我们去看同一天的交接表

出口：玩家取得完整复制件、原裁切版和可公开的拍摄说明，原底片留在 FLASHBACK。先到本场的玩家返回 S002 完成停印再到 S004；先停印者直接继续。任何重看都使用相同授权范围，不凭放大恢复原图没有记录的姓名或清晰脸孔

<a id="qst-004-s004"></a>

## QST-004-S004 · 两个人的下午

入口：服务中心授权资料桌接入本场前半，随后以明确时段转到月台杂货和学校受控访问。玲把交接抄本铺在完整照片旁，陈知夏坐对面，顾文珍按约来核对个人经历；曜站文件柜侧。乔伊的替补校样消息尚未回复，店里同一维修顾客已约检查试用，不是正式交付日

<a id="qst-004-s004-k01"></a>

### QST-004-S004-K01 · 交到别人手上才算交班

触发：玩家翻开与拍摄当日对应的授权交接抄本

玩家镜头，操作对照同日记录的先后栏，不要求输入虚构钟点。抄本中除顾文珍本人外的姓名按既有公开范围遮去；交接、离场、次日返岗三件事均有可读记录

**QST-004-L027｜屏幕文字**：事件期·同日联络点交接记录｜顾文珍完成当轮学生与家长联络，未完事项交下一班；接班教师已签收，姓名不公开；顾文珍交接后离场，次日返回／抄本仅公开上述事项
**QST-004-L028｜顾文珍**：这后面还有第二天。我回来以后接着做，也有别人回家

玩家把照片中的接手动作放到“交接期间”，而非“所有人已经离开”。若先得抄本，先保留时序，待完整底片到手再对齐空间；两份均齐后才确认原标题与记录不符

<a id="qst-004-s004-k02"></a>

### QST-004-S004-K02 · 不能只换题字

触发：时间与照片范围已对齐

短演出接管，机位在桌面低斜角，原画、完整照片、空白纸同时入镜。禁移动和翻页，允许暂停与跳过到玲另起新稿。玲用橡皮轻擦“最后”两个字，准备在原构图上换标题；陈知夏把完整复制件覆到原画上，边缘半只手恰在原画之外

**QST-004-L029｜陈知夏**：那后面接班的人，还是没地方站呀

玲捏着橡皮没落下，将两张纸分开，另拿一张画出更宽的门。顾文珍见她把教师缩得只剩一个小点，手掌按在新纸空白处，不碰未干笔线

**QST-004-L030｜顾文珍**：我也不是碰巧站在那里
**QST-004-L031｜月城玲**：那您原来站的地方留下。把后来接上的这一段也画进去

镜头顺着玲重落的第一笔回到玩家原座位。跳过只完成另起构图的行为，尚未决定这批实际交什么

<a id="qst-004-s004-k03"></a>

### QST-004-S004-K03 · 名字已经发出去了

触发：玩家查看乔伊发来的替补安排

玩家镜头，在月台杂货工作台继续；自然转场前文件已装袋，镜头不把服务中心桌直接变成店内。玲坐图样夹一侧，曜在维修件旁。乔伊的消息与学校安排显示在同一协作页，玲迅速回复两人的名字，发送动画结束后才抬头把屏幕递向曜

**QST-004-L032｜乔伊**：替补校样安排在下一个已空出的下午，能先收已确认的页；学校同意同日下午受控核对路线，请确认到场人员
**QST-004-L033｜月城玲**：我和曜一起到

曜没有接手机。他把顾客预约单旋到玲面前，食指停在“检查、试用”一栏

**QST-004-L034｜屏幕文字**：维修预约｜设备现状：待当面检查与试用／预约时段：上述同日下午／正式交付：另行确认，本次不作交付完成
**QST-004-L035｜月城玲**：学校不能随时进去
**QST-004-L036｜月城曜**：他也不是随时能来
**QST-004-L037｜月城玲**：那我的样张就能？

玲说完看向板上已错过的首轮校样框，曜沿她的目光看了一眼，将手从预约单上收回，没有把第二章的事拿来抵消这次冲突

<a id="qst-004-s004-k04"></a>

### QST-004-S004-K04 · 没有那句没关系

触发：两份预约已被玩家实际对照

短演出接管，侧面中景保留维修件、玲与曜；禁移动和取走手机，允许暂停或跳过到改约记录完成。曜拿起自己的手机，拨通 CHR-038。响铃结束后，他先报出维修件，目光仍落在预约单上

**QST-004-L038｜月城曜**：是我，月台杂货的曜。约好的检查得改一次，我这边排重了
