## QST-108-S001 · 光先从墙上走了

入口：河岸小广场当前开放边缘，普通配送时段。郑拓将支架架在自己觉得最干净的角度，相机朝石墙与椅背，暂存箱被椅背挡住，苗架在画外。阿东从日常通路推车进入，车上只有本趟实际货件，乔伊尚在路上。兄妹站在支架后，不知道这条线一直有人使用；郑拓只知道今天要交一张空间照片，未确认当前卸货流程

<a id="qst-108-s001-k01"></a>

### QST-108-S001-K01 · 先收一条支架腿

玩家镜头，阿东推车到支架前收步，车轮停稳后才松一点手肘，既不撞脚架也不倒退绕进非开放区。郑拓从取景器抬眼，视线沿车轮找到自己伸出去的支架腿

**QST-108-L001｜阿东**：借一步？这边每天都得过车。
**QST-108-L002｜郑拓**：马上，这边的光——

玩家操作“协助退开器材”后，玲扶相机肩带，郑拓握住支架中柱，曜从靠通路一侧收拢突出腿，三人将已收稳的器材移到墙边空位；阿东见人和脚架都退出才推车通过。没有执行退让，不能跳到已完成配送

墙上的亮斑已越过郑拓原先取景范围，乔伊到达时她把支架脚锁扣压得比需要更重一点

**QST-108-L003｜乔伊**：这一页还空着，今天能给我一张吗？
**QST-108-L004｜郑拓**：我刚找到的位置，正好挡着人家的路。先让我看完这趟。

原光线的损失保留，不用倒时或天气循环补同一完美角度。控制一直归玩家

<a id="qst-108-s001-k02"></a>

### QST-108-S001-K02 · 有旧照片，也得看今天

玩家镜头，可在不挡人的边缘观察车怎样进、箱怎样落地、阿东留哪侧转向。陈知夏拿来的材料只按 QST-105 真实结果出现

条件：QST-105 已完成且人物照获准，陈知夏展示本人确认过的人物与椅子画面，手指不盖通路

**QST-108-L005｜陈知夏**：这张本人看过，允许拿来讲通路。那天他坐这儿等朋友，我们把椅子挪开才让人过得去。

条件：QST-105 只保存空椅照，展示的是无人的椅子与物件，不能以剪影重新加回被拒绝的人像

**QST-108-L006｜陈知夏**：那位不出镜，我留的是空椅子。说明可以用，今天也先找人实际从哪边过。

条件：QST-105 未发生，陈知夏空手蹲下看车轮转向，无旧图可给郑拓

**QST-108-L007｜陈知夏**：没有现成照片，就看这一趟。阿东，转弯时这侧也得留出来吗？
**QST-108-L008｜阿东**：得留。我卸完还要从这边掉头，不能只算车往前走的时候。

玩家执行“比较通路与新取景位”，站到墙边能看见来路和卸货点的位置；只是比较旧照片不完成当前观察。郑拓把支架转向，承认不是原来那一张而不说新图必然更好

<a id="qst-108-s001-k03"></a>

### QST-108-S001-K03 · 不能再演一次的卸货

玩家镜头，阿东从车上托起本趟最后一只箱，先放稳在指定暂存处，再提起签收夹确认实际接收动作已经发生。郑拓没有按下快门，阿东抬眼问她

**QST-108-L009｜阿东**：刚才拍到没有？
**QST-108-L010｜郑拓**：没有，刚才在收脚架。
**QST-108-L011｜阿东**：那就这会儿。我不能再给你演一趟。

玩家操作“拍下当前交接”前能看到阿东接回签收夹、车轮和暂存箱各自占位，郑拓不把箱子重新举起制造旧动作。快门在玩家确认时响，阿东随即把夹子收进车侧袋，推车从已空出的通路离开；短动作观察不接管移动，也不抢拍成任务自动完成

若此前离开使这一趟已结束，回到 S007-K01 记录目前真实收整或另一次正常交接，图注按那次动作写，不请阿东复演本趟。出口：取得的是待本人确认用途的试片，照片暂归郑拓，支架收回侧边，去 S002

## QST-108-S002 · 那件衣服特地熨过

<a id="qst-108-s002-k01"></a>

### QST-108-S002-K01 · 先递过去那张不自在的

玩家镜头，委托人摊开衣袋露出准备的衣服，郑拓看见颜色后仍朝工作服袖口比了一下，未碰对方身体

**QST-108-L013｜肖像委托人**：那件特地熨过。

委托人把刚展开的衣袋往身边收，指尖握住提手，肩膀比先前窄下来。郑拓将相机放低到胸前，先请求一张仅供本人回看的试片

**QST-108-L073｜郑拓**：先试一张给你看，可以吗？这张不公开，你看过再决定留不留。

**QST-108-L074｜肖像委托人**：可以先试。但最后那张，我还是想换这件。

玩家执行“拍一张给本人看”，郑拓抬相机，等委托人把衣袋放稳并表示可以才按快门。本人没有示意则保留玩家操作，不自动生出试片；拍下后玩家选择回看，郑拓将屏幕转向对方，对方先看自己绷住的嘴角，再看衣袋

**QST-108-L014｜肖像委托人**：能不能换好衣服再看？
**QST-108-L015｜郑拓**：能。你慢慢换，我重新找光。

郑拓手从快门移到电源旁，垂下相机；委托人带衣袋独自去换衣处，镜头留在外部器材区，不跟拍私人换衣

<a id="qst-108-s002-k02"></a>

### QST-108-S002-K02 · 反光板移到另一边

玩家操作“把反光板移到新位置”，曜先握板框下边，玲扶上边，绕开支架腿；郑拓站到原先嫌背景复杂的一侧，手背试反射亮度，不往人眼里直照。委托人换好衣服出来，旧工作服已装进衣袋放在自己的椅下

**QST-108-L016｜郑拓**：再往旁边一点。对，就这里，别把他整个照白。
**QST-108-L017｜肖像委托人**：这回拍到了吗？

对方说话时两手由领口向下抚平布面，脸刚抬起。玩家在这段连续自然动作中执行确认快门，郑拓拍下后立即翻转屏幕，不要求复演刚才的整理动作；若错过则继续取得对方此刻自选姿态，不强制回到同一“自然瞬间”

**QST-108-L018｜郑拓**：拍到了。先看这张，你觉得自己像不像今天想留的样子？
**QST-108-L019｜肖像委托人**：这张。我想要这张。

<a id="qst-108-s002-k03"></a>

### QST-108-S002-K03 · 选定不等于公开

短镜只在本人已经明确选定时接管，从相机屏幕旁近景看指尖指向照片与郑拓的反应；禁取物和换相，暂停、跳过可用。郑拓看一眼自己偏爱的工作服试片，指尖离开它，给已选照片作私人交付标记；获准保留的试片单独存，未获准试片当面撤去

**QST-108-L020｜郑拓**：这张先给你。要不要放小册，我等你看过成片再问，不先勾上。
**QST-108-L021｜屏幕文字**：本人选定肖像；私人交付。公开展示尚未获准

接管结束回到反光板旁玩家原位，已选照片与公开许可保持两项。玩家收起反光板后才可离开，不自动给镜头里的其他人一并授权

**QST-108-L075｜郑拓**：给你试一张，只留给你自己，不进小册。现在想拍吗？

**QST-108-L076｜陈美惠**：好，拍完先给我看。我就留自己的这一张。

只有同意试拍时继续以下衣服回应。QST-101 已交付使用 L022，尚未交付使用 L023，两句互斥，随后共用玲的回应

**QST-108-L023｜陈美惠**：今天我挑的这件，拍它就好。那件还没改完，别替我去取。

同意路线，母亲按上面的实际改衣进度选择穿着，用当前口袋自然放手；玩家先确认器材与通路再触发快门，郑拓拍下、翻屏给母亲看，母亲指一张表示保留，郑拓将本次试片经母亲确认的私人渠道交给她。已有改衣按真实版型呈现，未完成时不生成新口袋

### QST-108-S004-K02 · 把喜欢的一张亲手拿掉

入口：乔伊排版桌，只有待本人确认用途的空间候选与未获准主肖像的工作预览；空间图未授权前只留工作预览，不进入公开列。短镜在玩家打开实际待印页后接管，机位越过郑拓肩膀看页面和她的手；禁移动与其他交互，允许暂停、跳过至公开页已撤下私人照，不能跳成另一张照片已获准
