# 雨棚下的第二条路：完整制作脚本

[故事正文](../../../../player/story/world/rain-shelter-route.md) · [共用写法](../script-format.md) · [正式台词](dialogue.csv)

本任务主动游玩预算为 30–45 分钟，转场不以现实等待计时。以下镜头使用相对地标锁定构图与切换条件；自由操作段保留玩家机位，短接管仅完成已触发的表演，未操作的证据、选择和交付不会因跳过得到完成。台词阅读呈现由同目录 CSV 回填

## 阅读顺序与出演索引

- S001 → 按原去向进入 S002；已交接的只核原记录
- S002：当面送交完成实检后收尾；待阿东托运者跳已收镜，S004-K04 实际送到后续 K01、K03
- S003 → S004；已经做完的父亲离场与路线不重播
- S005：结项后的普通重访

稳定角色身份：`CHR-001`、`CHR-002`、`CHR-004`、`CHR-008`、`CHR-015`、`CHR-034`、`CHR-035`、`CHR-038`；台词表使用这些身份，SYSTEM 仅为屏幕或纸件文字

| 场次 | 阅读位置与出演 |
| --- | --- |
| `QST-023-S001` 被划掉的时间 | 曜、玲；顾客按实际交接当面或通话，阿东在侧院 |
| `QST-023-S002` 交给下一双手 | 曜、玲、陆成按实际送交在场；顾客当面或电话，阿东仅承运路线 |

<a id="qst-023-s001"></a>

## QST-023-S001 · 被划掉的时间

入口：第六章的失约电话已经结束，顾客 CHR-038 已决定退款取回或同意转修。月台杂货营业时间，玲为操作角色，曜在维修交接台内侧。桌上只有尚在本店的设备；设备已到陆成处或已归顾客时，该位置留空，放原交接凭条。顾客只在本次尚需当面取件时带空袋到场，其余情况按已经约好的电话核对，不让其带回设备重演。阿东在侧院整理其他货物

<a id="qst-023-s001-k01"></a>

### QST-023-S001-K01 · 先读已经说好的

玩家镜头。玲可自由绕到台前，对照原约、已做检查和电话后留下的去向。玩家打开凭条才显示对应文字；两种去向互斥，已经支付或接收的格子保持真实结果。旧交付时间的划线仍可看见，不产生第三次承诺

**QST-023-L001｜屏幕文字**：原约交付：未完成。已答复：退款取回。实物交接与退款分别核对。

**QST-023-L002｜屏幕文字**：原约交付：未完成。已答复：明天营业交陆成免费接看；新维修另报工期和费用，本人同意后才开工。原单款按原约结清。

曜拿起纸角，手指已经摸到背面空白处；玲把印有原约的这一面朝他推近。没有人写上“顺便再试一次”。玩家确认原记录后进入下一镜；只看过部分时离开，保留已读项

<a id="qst-023-s001-k02"></a>

### QST-023-S001-K02 · 空袋还在

尚待顾客当面取件时，玩家主动开始交接才短接管：机位在台面端头，以中景同时容纳空袋、原凭条和曜的手。顾客把袋子立在脚边，取出折过两次的旧凭条，放在曜准备翻面的纸上。曜手指从纸下抽出来

**QST-023-L003｜失约维修顾客**：我把今天的事挪开了。电话里说好的，就照那样办吧。

**QST-023-L004｜曜**：好。已经试过的和没确认的，都在这张上面。

已交清或设备已在陆成处时，镜头保持玩家查看记录，电话只在玩家选择核对后接通；顾客的袋子和设备均不出现在本店

**QST-023-L005｜失约维修顾客**：东西已经按上次说的交了。你核对单子就行，别再替我改一回。

两路汇合：短接管结束回玲原站位，凭条仍在台面。跳过只结束这次说话，不签收、不退款、不改变设备位置

<a id="qst-023-s001-k03"></a>

### QST-023-S001-K03 · 没写在纸上的那一晚

玩家查看“未完成检查”一栏，曜把那页单独摊开，沿已写的项目用指背划到空着的一行。他开口前先将旁边的工具盒扣上

**QST-023-L006｜屏幕文字**：已做：外观与接点检查。未完成：连续使用确认。原约前已知无法如期交付，通知晚于应通知的时间。

**QST-023-L007｜曜**：那天我还想再试到晚上。我知道赶不上，却没有马上打电话。

**QST-023-L008｜玲**：前一次检查预约，是我替你答应的。这一行也别收起来。

完成 QST-104 时，玲在交接旁划开“已做、可领、交到谁”；未完成时由眼前实物逐项建立，不提何芸

**QST-023-L009｜玲**：何芸那张牌后来分开写了。这里也分开，免得收了纸就当收了东西。

**QST-023-L010｜玲**：检查纸是一项，东西是一项，款项也是一项。我陪你逐件对。

出口：先进入 S002 处理实际尚欠的交接；已全办妥时从 S002-K03 的原记录确认继续，不补做操作。暂停或离开只保留已读信息，不让顾客无限等在柜台；返店在正常营业联系窗口续办

<a id="qst-023-s002"></a>

## QST-023-S002 · 交给下一双手

入口：退款路径留在月台杂货。转修沿第六章原约：顾客同意明天营业时交陆成接看，本次接收及复核已有检查不另收费；新维修的工期和费用须本人另行确认，未同意不开工，原单款按原约结清。已有第七章实际交接结果者直接读取。尚未交出的转修按已约定的交接方式分流：曜当面送交时，设备在原承诺接收时段才从月台带到小修理铺；阿东已约托运时，设备封好留月台，仅传已有检查纸，不播放实物复核、顾客新报价答复与 K03 已收台词，先进入 S003 和 S004，等 S004-K04 实际接收后才回到本场 K01 的复核段。这里没有新增配送选择菜单。玲为操作角色；当面送交时曜双手托住封好的底板，陆成台上让出检查垫，其他维修保持原顺序

<a id="qst-023-s002-k01"></a>

### QST-023-S002-K01 · 把不知道的也交出

设备已经按原接看同意送到陆成处、尚欠实际复核时，玩家镜头沿工作台查看原记录；较早只传过记录不算完成本镜。曜当面送交时把设备放在空出的防滑垫上；阿东送到时由陆成从已接收盒内取出放稳，曜可通过原电话核对记录，不能隔空亲手放设备。随后在对应实物一侧，放置者先松一只手，确认稳妥后再抽另一只；陆成只对照排查纸，不用笼统完成卡代替实检。玩家指认检查纸中已经检查的接点，陆成在实物上按记录复核，示出与原记录对应的现象，再把未做确认的一页单放在旁边

**QST-023-L011｜陆成**：别说剩一点。你试到哪一步了？

**QST-023-L012｜曜**：到这里。连续使用没确认，不能当成已经好了。

**QST-023-L013｜陆成**：你把不知道的也交给我，才算交全了。我的台子也排满了，这次按我确认的时间来。

原本同意的免费接看至此已经发生，不再次询问是否同意。陆成沿原接点位置复核：用绝缘工具轻推已断开使用的接点固定部位，松动固定件出现与原排查纸对应的位移；他将这个具体部位指给曜或通过原接看记录发给顾客，暂不直接修好。玩家查看下面完整工单，新增修理总价直接以原单已经记载的工费为参照，可明确核算；剧情交付日以实际接收日推算，不靠现实等待。顾客本人确认新范围后才允许开工，玩家不能代选。此前已经完成这一检修确认者只读原保存工单，不重问、不重收原单款

**QST-023-L042｜屏幕文字**：陆成检修工单：复核确认内部接点固定松动，本次重新固定并完成连续使用测试。原约的接收与已有检查复核免费；新增修理总费用等于原维修单已收工费，含本次固定小件，不另加零件费。以实际接收日为起点，第二个营业日收工前交还；不能按时通过测试时在到期前联系本人，不擅自续修或追加费用。其他故障另报，本人未同意不开工。原单款由月台杂货按原约结清。

顾客接受本件新维修工单时使用下句

**QST-023-L014｜失约维修顾客**：新的维修工期和费用我看过了，同意按这份做。

顾客拒绝本件新维修工单时使用下句，两句互斥

**QST-023-L015｜失约维修顾客**：这次维修安排我不接。接看已经做了，东西退回我，原单还没结清的按原约办。

接受后由玩家递交或核对已随件交出的设备附页，陆成把接看记录补上本人授权的新维修范围，设备进入他的实际工作进度。顾客拒绝新检修安排时，免费接看记录仍保留，陆成将机体和散件逐件按原清单放回盒内、检查纸放在上层，封好后交曜带回月台杂货；若由阿东托运，则另按已确认的正常返程交回月台，不把设备瞬移回来。到本店实际接收后才进入 K02，由顾客取回并只结清原单尚未结清部分。跳过说话不代搬运和签收；已经触发的交接表演可落到实际收条回到交付人手中的稳定点，物件位置与回执一起保持

<a id="qst-023-s002-k02"></a>

### QST-023-S002-K02 · 取回也是交付

退款未办妥路径，月台杂货玩家镜头。设备尚在本店，曜打开盒盖，玲逐项核对机体、原散件、已做检查纸。玩家把对应物品放入同一盒内，缺任一已登记件时不出现“交给顾客”。顾客站在台外看着，不因选择取回被额外要求去小修理铺

**QST-023-L016｜曜**：这些是原来的散件，这张是我试过的部分。后面谁接着看，都能从这里开始。

玩家确认原收款清算后，凭条显示已退回的原款结果；已退款者仅显示现存回执，不再支付。顾客确认后才接过盒子，放入自己的袋里，两手试稳重量，折好凭条

**QST-023-L017｜屏幕文字**：原单款项已结清。原物与登记散件已由本人接收。检查记录随物交付。

**QST-023-L018｜失约维修顾客**：数量对了。我先带走。

若离开或崩溃发生在签收前，设备留在当前实际安全交接位，未支付部分仍待确认；发生在款项已结清而实物未交出时，只继续交物，不能再退款。已完成交付的记录不因重载变空

<a id="qst-023-s002-k03"></a>

### QST-023-S002-K03 · 已经到手的那一份

仅退款实际退物结束、转修实际接收且新维修决定明确、或开场已经具备这些结果时，玩家查看对应原收条；尚在月台待阿东托运者跳过本镜全部已交台词，从 S003 续到 S004-K04。这里的转修接收不能靠传过检查纸触发。转修设备留在陆成处，退款设备留在顾客处；本镜不再次搬动。曜将自留副本插入已办文件夹，原排查纸的已交去向旁留下抄录标识

仅实际由陆成接手且顾客已同意新维修时使用以下两句

**QST-023-L019｜陆成**：这件在我这儿。有什么新情况，我按约直接和顾客说。

**QST-023-L020｜曜**：好。店里那张只记接手的去向，我不再写一个自己的完工日。

仅设备退回本人且原款已按原约结清时使用下句

**QST-023-L021｜曜**：东西和退款都交完了。剩下不是等他改口。

出口：已交路径结果可独立保存，顾客和陆成各自离场或继续工作，随后从尚未做的 S003、S004 继续普通配送；S004 已做完的回返路线直接续 S004-K04 的回执末段，不再让父亲重复赴约或重走路线。未交路径只保留原接看授权、原接收时段和设备实际留店的位置，不出现 QST-023-L019／020；最终实检与新维修确认在 S004-K04 接收后续本场 K01，待明确顾客决定才进入本镜

<a id="qst-023-s003"></a>

## QST-023-S003 · 父亲也有约

入口：月台杂货前后场交界，曜回到自己未收完的店务，玲在通往服务门的一侧。月城修已经收好帮班用的围裙，私人物品在随身袋里；他来承担的那段帮班已结束，不继续坐回收银位。阿东只在侧院等已答应的普通货，不等曜陪车

<a id="qst-023-s003-k01"></a>

### QST-023-S003-K01 · 外套拿起来以后

玩家镜头。曜先把顾客自留单收好，再从椅背提起外套，目光追着阿东的小车。玩家靠近父亲触发短表演：机位在柜台内侧，中景保留曜的外套与父亲提着的袋子，父亲已迈出的脚停在门边

**QST-023-L022｜曜**：你今天还能晚走一会儿吗？我想跟着把那一段跑完。

月城修先看一眼时刻，再抬头看曜，没有将袋子放回柜台

**QST-023-L023｜月城修**：这次不行，我也约了人。你这边还没收完呢。

曜沿父亲手指看回柜台，把外套挂回原处，衣角掖到椅背之外。父亲向玲点一下头，沿前场公共门离开，不穿服务门搭配送车

**QST-023-L024｜曜**：知道了。你走吧，我收。

跳过落在父亲正常离场、外套归位；不替玩家整理柜台。控制交还玲原站位，曜开始自己负责的一叠单，玩家帮助把已交物的空包装归位后才进入共同核路线的时间

<a id="qst-023-s003-k02"></a>

### QST-023-S003-K02 · 腾出来的是谁的时间

玩家镜头，玲将空盒叠入后场，曜将当天继续营业的物件放回取货位置。操作只整理本次已知店务，不把新一轮小店经营数值设为任务门槛。工作完成后两人到服务门同阿东确认路线

**QST-023-L025｜阿东**：我不是等你跟车。我得知道下一处有人接，车才往那里去。

出口：父亲离场保持有效，整理结果保存；玩家先离开时曜按自己职责继续营业，返回从未收的本次物件续接，不把父亲再叫回来重演拒绝

<a id="qst-023-s004"></a>

## QST-023-S004 · 图上的近路

入口：兄妹和阿东在城市交通服务厅核对当日开放信息；邵敏位于办理台，线路图朝公众。没有开放渡口就保留停用信息；较晚参与、已恢复通行则使用当日可用线路，不为了这条任务重新封路。随后通过正常公共道路到需要比较的台阶和缓路，玩家始终可控

<a id="qst-023-s004-k01"></a>

### QST-023-S004-K01 · 今天可走的那条

玩家查看当日通行板，将配送表上的旧线同当前路线叠看。邵敏用可擦标记标出服务交接位置，不借私人住家开后门

**QST-023-L026｜邵敏**：按今天这张。开放的是公共通道，这一段给行人走；推车要从另一头接过去。

**QST-023-L027｜邵敏**：渡口今天按这张通行。原先那张停用说明收起来，交接的位置再核一次。

**QST-023-L028｜屏幕文字**：行人通行与货运交接分别确认。台阶不作为推车路线。旧改约记录留存。

<a id="qst-023-s004-k02"></a>

### QST-023-S004-K02 · 轮子停在哪一级

玩家镜头在台阶下，阿东停住车，前轮与第一阶保持可见间距。玩家可走上一级比较路径，阿东不会抬整车追上来；再沿公共缓路经过转角，玩家确认车宽、可停靠位置与无遮雨的一段。不能只把地图线连起来就提交路线

**QST-023-L029｜阿东**：空手能走，不等于这一车能过去。还有盖布、停下、叫人来接的时间。

若终章已拆檐，镜头保持自由，原檐段所在空间露天空，玲在路线纸上留断口；尚未拆檐则按现有遮雨边界记录，不预言必须拆除

**QST-023-L030｜玲**：这一段今天没有檐了。我把断口留着，不画成连在一起。

**QST-023-L031｜玲**：雨棚到这里就断开。中间这一截要算进装车的安排。

<a id="qst-023-s004-k03"></a>

### QST-023-S004-K03 · 备料也有下一班

桥畔轻食屋收货侧的玩家镜头，唐惠将当班备料单放到可供核对的干燥台面，阿东以本次实际路线提出能确认的到达安排。玩家逐项对照当班可到和下一趟才到的备料，唐惠自己划去当班无法提供的份量

**QST-023-L032｜唐惠**：晚到的我放下一班。你照能到的说，我照能到的卖。

QST-102 已完成时使用下句，旧饭局安排只作为分段经验；未完成时使用下一句，均不调用未经许可的合照

**QST-023-L033｜唐惠**：上回两段饭都各有到的人。这回也一样，别把晚到那一段写在开门前。

**QST-023-L034｜唐惠**：这一班就少备一些。下一次什么时候到，我们在另一行说清。
