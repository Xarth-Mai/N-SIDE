# 把今天带回来 · 完整制作脚本

[故事正文](../../../../player/story/main/bring-today-back.md) · [台词表](dialogue.csv) · [脚本约定](../script-format.md) · [终章操作规格](../QST-009/development.md)

主动任务预算 45–75 分钟，准备集中在小店后场、现有联络和一次有目的的现场核对。八场依次建立人物责任、真实目标、可执行范围和实际演练；不用全城集人头延长准备。玲在本章演练及终章潜梦，曜始终清醒接应，巧克力随有效人类连接进出

出场：月城曜、月城玲、巧克力、陆成、乔伊、塞拉、罗宾、叶真、邱立、固定核验员、邵敏、艾玛、老钟、郑文良、郑拓、安可、悠真、贺佳、遥、月城修、陈美惠。主会谈可用当轮已建立的联络，不将所有人集中到小店或假定他们离开现场岗位

<a id="qst-008-s001"></a>

## QST-008-S001 · 两次不是一次

入口：第六章之后的白天，月台杂货后场桌面清空。玲站在靠住家门一侧，把首轮校样与替补预约前后叠放；曜在对面放下同一顾客的维修单。该单的退款取回／同意转修和实物当前去向已经存在，只供查阅，不能重开补救选择。巧克力靠桌短边，前场基础接待由原有店员机体继续

<a id="qst-008-s001-k01"></a>

### QST-008-S001-K01 · 纸还没收完

短接管桌边近景。巧克力伸手将已答复维修单与两张预约收向文件夹，玲先用两指按住最上面预约一角，再将两张纸抽回摊开；巧克力停手，把空夹子放到旁边，退开桌边视线。曜本来扶着维修单，看到她的动作后把单据放平，不以交清货物结束这次谈话

**QST-008-L001｜月城玲**：这两次，我们还没说完。
**QST-008-L002｜月城曜**：那时现场缺人，你最清楚那些录音。我以为校样晚一天还能补。
**QST-008-L003｜月城玲**：你问的是谁？

镜头留住曜短暂没有回答的表情；他把当时“玲协助核验”的记录翻面，拿笔写下先答应后告知的顺序，才交还桌边玩家镜头

<a id="qst-008-s001-k02"></a>

### QST-008-S001-K02 · 另一张没有作废的约

玩家按两张原预约和维修检查记录比较先后，不要求回跑第二、三章地点。玲把替补预约推到桌中，手指沿自己报上两人姓名的位置停住；曜将顾客检查预约挪到它旁边，纸张不相叠，任何一份都没有替另一份消失

**QST-008-L004｜月城玲**：我那页重画过，你知道。我抢到替补位置，就以为你陪我把图核准，前面的事能补回来。
**QST-008-L005｜月城曜**：我知道。但检查时间已经留给顾客了。我看见新安排的时候，你把我的名字也报上去了。
**QST-008-L006｜月城玲**：这一笔是我改掉你的时间。不是你上次欠我的。
**QST-008-L007｜屏幕文字**：旧约对照：录音现场核验由曜先代答应，玲错过首轮校样；替补校样由玲先报两人姓名，挤掉已约设备检查；正式交付延期另由曜承担

<a id="qst-008-s001-k03"></a>

### QST-008-S001-K03 · 一个人先报自己的时间

玩家镜头跟着玲拿起终端，接通乔伊的语音通话，说明首版缩减范围；曜在她旁边等待对方回答，没有插话代报剩余画稿。玲划去尚未核实页，保留已承诺插图的补绘安排；乔伊在通话中答复后，她把自己的制图格子加下划线。未完成 QST-025 时不用苗木安排充作与乔伊的共同回忆

**QST-008-L008｜月城玲**：首版先不放还没核实的几页。已经答应的插图我另排补绘，时间由我直接给你，不再写我们两个都有空。
**QST-008-L009｜乔伊**：把首版和补绘分开发给我。我按确认过的那份往下排，不替你预留整天。

<a id="qst-008-s001-k04"></a>

### QST-008-S001-K04 · 有一项被退回来

曜把“其他维修”清单发给陆成，同一失约顾客设备另夹原决定，不混入可重新分配列表。陆成在联络画面中打开收到的清单，圈出能接的条目，将最后一行单独标成未承接，再把纸面副本向镜头转正；曜读完把被退回项放到自己跟前，拿起电话给那一件的当事人发正式改约文字，本场不新增有姓名配角或无来源语音

**QST-008-L010｜陆成**：这几件能接，最后这一项排不进去。你还得问物主怎么安排，别把它写到妹妹那一格。
**QST-008-L011｜屏幕文字**：维修改约说明：本项尚未取得接手确认，原时间不能保证。请回复可接受的处理安排；未收到同意前，物件留在月台杂货
**QST-008-L012｜月城曜**：这项我接着问。你的制图时间，我不往上加字了。

出口：两张旧预约仍留在记录夹，双方分别落实今天的安排；未同意的改约只记待回复，不构成准备完成障碍中的假承诺。中途离开可继续未发送的本次答复，已退款、转修或交清的原设备不复演。日程板不再默认两人同步，转 S002

## QST-008-S002 · 已经处理，到哪里为止

入口：同日核心工作桌。兄妹、塞拉、罗宾和叶真在现场；邱立与邵敏从值守位置联络，艾玛发送温室当前观察，郑文良与郑拓带来获准现场照片，悠真提供当轮声响参照。桌面按来源摆放，私人照片不进入公共记录

<a id="qst-008-s002-k01"></a>

### QST-008-S002-K01 · 不能把三个夹子合成一个

玩家自由镜俯看三组材料：旧输出隔离、仍在本地的活动、待处理新增联系。罗宾把旧提示页夹入第一组，将庭院仍有局部活动的记录放第二组，檐段剩余接触放第三组；只摆示例，余下由玩家对照来源归入，错误归类时相关证据保持原文可读，不扣分清空已经认识的事实

**QST-008-L013｜罗宾**：声源停了，不等于候船结构也没了。这里写的是本地还在活动，那边才是今天新接上的部分。
**QST-008-L014｜叶真**：图上没有这次记录的地方，先留空。过去量到哪里，就只画到哪里。

<a id="qst-008-s002-k02"></a>

### QST-008-S002-K02 · 谁说到哪一格

玩家逐项检查来源栏，曜把笔停在尚无报告的一格。邱立在联络端低头查原记录后指向具体构件；塞拉将他的报告接入相应位置，没有替另一个地点填完。郑拓取开压住照片角的袋子，郑文良把图背面的当前拍摄说明翻给兄妹，画面时间不冒充过去

**QST-008-L015｜邱立**：旧提示和前一处隔离保持。檐段剩余接触要等前段拆开后再复核，今天不能先写它会留下。
**QST-008-L016｜塞拉**：缺谁的结果就找谁。曜，你这边先保留未确认，不用替各处把表填齐。
**QST-008-L017｜屏幕文字**：联合处理范围：旧输出隔离保持；安全局部活动保留；仅处置已核验新增联系。各处结果附本轮来源，缺项保留未确认

出口：共同输入建立，缺项清楚，不以全员相信主角解锁下一步。桌面原件交回提供者或在许可范围留副本，物件无所有权转移，转 S003。重新进入可直接打开待讨论页，不重复索取已获准材料

<a id="qst-008-s003"></a>

## QST-008-S003 · 两种都能停下来的办法

入口：工作桌保持，塞拉将 A 与 B 两张方案纸放开；艾玛的苗盘安排与邵敏的绕行图在联络画面中可读。玩家站在两页侧面，玲手中的小册草图暂不压在作业范围上

<a id="qst-008-s003-k01"></a>

### QST-008-S003-K01 · 安全也有生活代价

玩家镜头查看 A 页。塞拉按受影响的一组活动划出可控休眠范围，艾玛指向需要多搬一次的当前苗盘而非已完成种植；邵敏用笔沿延长绕行的路线走一遍，指尖停在仍需协助的转运节点

**QST-008-L018｜塞拉**：A 能把受影响的这一组活动收进可控休眠，记录能保存。服务和环境使用要多停一段，继续施工和安排恢复。
**QST-008-L019｜艾玛**：这些是仍要安排的当批苗盘。多停用，就得再改接班；以前已经安置的，不拿回来重做。
**QST-008-L020｜邵敏**：绕行继续，转运按新安排。行人能过，不等于所有车还能按原时间到。

<a id="qst-008-s003-k02"></a>

### QST-008-S003-K02 · 多留一点，要多做什么

玩家转看 B 页。邱立在图上从前段连接指至附属连件，指针停在与檐段相接的位置；罗宾对照活动间隙，玲用透明纸把“能观察到的窗口”覆盖在实际待处理段上。没有出现一按 B 就自动通过的选择按钮

**QST-008-L021｜邱立**：B 要在可验证的窗口里改接触。前段按范围拆开，留下的檐段还得重新检查，不能先签原位保留。
**QST-008-L022｜罗宾**：一处窗口不等于所有地方同时稳定。每段都有自己的现场结果，按次序接起来。
**QST-008-L023｜屏幕文字**：B 执行条件：当前连接有效；梦内窗口可观察；现实操作在核验范围；位置与固定分别确认。任一项不成立即停止推进，按预案保护并转保守隔离

<a id="qst-008-s003-k03"></a>

### QST-008-S003-K03 · 留一个真正能走的出口

短接管桌边中景。塞拉把 A 页移到 B 页旁边，边缘仍完全露出；曜没有把它压在图下面。玲点了点“每段复核”，把手收回；团队暂按 B 做准备，待联测通过才正式采用。跳过停在两页都留在桌上，S006 与 S007 未执行前不能进入终章

**QST-008-L024｜月城玲**：先把 B 要做的试出来。试不成，停用和后面的修缮也要照实安排。
**QST-008-L025｜月城曜**：停止这一项我留在手边。不是出了事再找。

出口：方案条件与代价清楚，采用 B 仍待演练。准备期间离开不推进现场拆除；重新进场从未完成核验继续，A 的状态与已发生代价保存

<a id="qst-008-s004"></a>

## QST-008-S004 · 想留下的不是样品

入口：在渡口开放观察位置核对原檐段；不重复第六章整段调查。老钟握着旧照片，郑文良带相机，郑拓拿当前图纸；玲的草图在板上，邱立在围挡内外许可交接点说明现场。拆卸范围仍沿第六章已核验部分，公众不进入檐下

<a id="qst-008-s004-k01"></a>

### QST-008-S004-K01 · 这儿原来能站两个人

玩家镜头从公共一侧看低檐投下的阴影。老钟把照片摆在视线下方，用空手在允许区域比出从前并排等船的位置；没有走入封闭区重演。玲将自己画好的檐口露出一半，另一半仍压在板夹下，怕风吹起便按住

**QST-008-L026｜老钟**：旧木头放进展屋当然能留。可下雨的时候，人在这里能并排站一会儿。
**QST-008-L027｜月城玲**：我也想留这个。小册那页已经画好了。

<a id="qst-008-s004-k02"></a>

### QST-008-S004-K02 · 虚线还不能描实

邱立把共同接触图转到两人可看的一面，食指沿附属连件向上停在檐段底部，再指向导向部位。玩家检查可拆范围、承托架位置和留样记录；三项可任意顺序看，未看齐不将原位保留涂成已完成。郑拓将纸角按牢，让玲能在对应檐段外圈虚线

**QST-008-L028｜邱立**：我会尽量留，但不能先答应。最后这组如果仍把输出接过去，必须先支撑，再把连件和这段檐一起卸下。
**QST-008-L029｜邱立**：另做独立承托要重新设计，原样挂回会恢复接触。卸下来之后，遮雨位置也得继续挪开。

<a id="qst-008-s004-k03"></a>

### QST-008-S004-K03 · 背面也拍下来

短接管中景，老钟听完将照片从手心转向郑文良，另一手指向木料背面的钉孔方向；郑文良先征得现场安全位置许可，再从开放拍摄位取得对应细节，不站到未支撑的结构下。玲翻开留样页，写好可读展记，原位照片仍留老钟手里

**QST-008-L030｜老钟**：背面的钉孔也拍一张。真得卸，就把今天为什么动它一起留着。
**QST-008-L031｜郑文良**：照片先交你们核对，再按同意的用途存。背面我从允许的位置拍。
**QST-008-L032｜屏幕文字**：候船檐段记录：争取原位保留，拆后按剩余接触复核；必要时支撑卸下并留样。独立承托待设计，临时候船位置继续使用

出口：原位保留仍是条件项；留样、支撑、可拆范围和临时遮雨代价已说明。照片按许可进入联合资料，原票与原照片不被收作奖励。返回小店用明确移动转场，非全城跑点清单

## QST-008-S005 · 作品不是一句“快好了”

入口：回小店后场作品桌，玲的首版范围已经发出；安可与悠真在排练工作桌上通过当次联络答复。贺佳从 AFTER 9 发送较短空档，遥只提供必要活动特征，随后恢复自己的编辑工作

<a id="qst-008-s005-k01"></a>

### QST-008-S005-K01 · 电话要自己挂掉

短接管至安可桌侧中景。她把外地宣传确认放到能读的位置，手指在回覆键上停住，先拨电话再开口；悠真靠自己的工作表坐着，不替她拿终端。对方确认以手机文字呈现，安可看完才扣下手机，屏幕不是被瞬间反转藏去后果

**QST-008-L033｜安可**：这次外地宣传我不参加。我先把《晚点见》和这里的合作做完，空出来的位置不用再替我留。
**QST-008-L034｜屏幕文字**：档期方确认：已取消本次位置；后续机会另行联系，不能保证保留同样安排
**QST-008-L035｜贺佳**：AFTER 9 能商量的是这个较短空档，布置和检查都得重新排。河岸那场已经取消了。

<a id="qst-008-s005-k02"></a>

### QST-008-S005-K02 · 已经选过的那一版

玩家查看 QST-020 的实际状态。已选 A 时悠真翻到连续过门标记，安可跟着轻拍拍点，在原长停顿处合上手；已选 B 时悠真指向第二句后的换气空隙，安可按住想抢入下一句的手势，等器乐尾音过后才继续。两条只播实际选定一条，不请玩家重投票

**QST-008-L036｜安可**：第一版已经定了。长停顿这次不留，按排好的过门唱完。那一句我以后还想再试。
**QST-008-L037｜悠真**：第一版的排练顺序保留，今天只核对缩小场地后的分工。
**QST-008-L038｜安可**：第二版照做。第二句后我等尾音，不抢唱；衔接按我们已经约好的那次排练准备。
**QST-008-L039｜悠真**：停顿保留，衔接那一项也得保留。场地变小，工作不会自己少完。

未做 QST-020 或此前只暂缓决定，悠真先让安可试唱两版对应片段，给出当次可承接的工作。片段原文沿用该任务歌词，两份实际唱词在下镜展开；本章完成主线不需要追溯补做整条试听支线
