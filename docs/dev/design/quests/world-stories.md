# 五条世界任务：行动、交付与重访

## 故事输入与范围

完整故事在[街区还在继续](../../../player/story/world/index.md)，人物与地点继续由百科维护。本页按日常片段模板集中记录五条任务的行动、结果和恢复，跨任务门槛以[故事目录](../catalogs/quests.json)为准；这些是制作规格，尚未接入运行任务或存档

五条任务均为可选世界支线，不新增 Black Case、梦魇或潜梦动作。完成它们改变人物的交付、作品、生活安排和具体场所细节，不提供终章必需能力、隐藏信任数值或成功率加成。主线中必要的修缮、交通通知和安全工作由原职责人员完成

## QST-023 · 雨棚下的第二条路

故事：[完整正文](../../../player/story/world/rain-shelter-route.md)，前置为第六章结束后的失约与改道。接单对象是正文已经失约的普通小设备，第七章交接与本任务读取同一份事实；先做任一场景都不能制造第二件失约设备

| 节点 | 玩家动作与可见信息 | 人物决定与持久变化 |
| --- | --- | --- |
| 一张未结清的单 | 在小店将实际已做、待做、配件和已收费用对照，联系当事人 | 顾客知道实际状态，曜承认原交付失效，不用危机替自己免除责任 |
| 把选择交回去 | 呈交退款取回或由陆成重新报价排期的可行安排 | 顾客决定处理，玩家负责准确转达；拒绝转交仍有完整结束路径 |
| 用今天的路 | 与阿东核对当前配送、向邵敏确认开放道路；区分人能走的台阶和推车能走的路线 | 仅在开放路段安排交付，地图不用新增捷径；未恢复的渡口不因任务完成开放 |
| 交到下一双手 | 执行确认后的退款退物或有记录的转交，将改动告知收货方；唐惠按实际到货调整备料 | 物件、费用与责任人一一对应；陆成自己的安排可要求另约，曜不站在旁边继续控制 |
| 收回旧小票 | 交付方确认接收，旧配送说明撤下，当前说明保留 | 顾客今后仍可选择别处维修；兄妹完成的是本次履约与交接，信任不会立刻恢复满格 |

转交与退款是当事人作出的排他决定，不能两种都计为交付。退回原物、清算实际约定费用也可完成任务；不得为了让所有人必经修理铺而拒绝合理退款

## QST-024 · 名字写回去以后

故事：[完整正文](../../../player/story/world/names-returned.md)，第三章照片与交接已经核对后出现。学校当前出入恢复是主线成果，本任务补充展签与家庭记忆，不承担源头终止或新通路判断

| 节点 | 玩家动作与可见信息 | 人物决定与持久变化 |
| --- | --- | --- |
| 认出旧章 | 将照片边缘的送货箱、旧站章与现有展签放在一起 | 同一地点的旧称与现名可以并存，不据一个旧称推导城市另有隐秘身份 |
| 找到各自能证明的部分 | 在 FLASHBACK 看授权底片，到服务中心查可公开的转录件，再与老钟核对票据 | 照片证明画面，票据证明当次候船，交接记录证明职责；三者不能任意替代 |
| 走过怕走的路 | 先问父母，再按现有开放公共路线重访；对照进货记录与临时改道说明 | 兄妹补全当年不知道的工作背景，旧日恐惧不被写成撒谎，也不新增秘密研究血统 |
| 两种空白 | 区分遗漏的记录者姓名与仍未确定的异常来源，提交展签修订 | 署名经当事人或可用记录核对；不愿署名可保留匿名，未明来源仍可写未知 |
| 展签换上以后 | 将获准内容交给展屋负责人，旧版本留作修订记录 | 回访能并读旧称、今日名称与已确认贡献；不是给所有未明档案强行填同一来源 |

资料缺失时只刊登已经得到支持的内容，将未明项明示保留即可结项；查遍全城或获得全部私人授权不是完成条件

## QST-025 · 空着的一格

故事：[完整正文](../../../player/story/world/empty-planter.md)，第四章温室局部稳定、苗木损失已经发生后出现。任务结束是完成一次能持续照料的安排，长成满架不是结项条件

| 节点 | 玩家动作与可见信息 | 人物决定与持久变化 |
| --- | --- | --- |
| 保留苗牌 | 在温室区分存活、受损和空位，查看艾玛原本的交换安排 | 原先未能履行的赠苗明确说明，既有损失保持 |
| 先问谁照料 | 联系顾文珍与罗宾，在屋顶公园、林缘自然观察庭核对容器、实际使用与照料时段 | 科学观察、社区育苗和好看陈列的需求分开，空地不默认可摆满 |
| 按能承担的量来 | 比较优先保留连续观察小组与屋顶照料现存苗、林缘重新播种的安排，协助当事人决定本轮数量与位置 | 两种方案都允许留空；不把给更多居民送苗当唯一好结局 |
| 这一轮先种下 | 安置选定数量、标记开始日期与照料者；玲按现状修改相关插图 | 放置、耗材与照料安排一次性完成；未完成 QST-108 时不凭空出现共同拍过的照片 |
| 过一阵再来 | 后续剧情时段重访，看新叶、暂未出苗或调整后的摆放 | 时间前进而稳定初秋不变；不会重复进出温室就让苗瞬间长大 |

故事可以在终章之后开始，按当时实际苗架继续。没有承接委托不意味着苗木无人照料；艾玛继续自己的基础工作，玩家参与的安排与图像回收保持可选

## QST-026 · 不是备用的那一天

| 节点 | 玩家动作与可见信息 | 人物决定与持久变化 |
| --- | --- | --- |
| 另留的一格 | 在书店核对遥的新稿需求和约定时间，听见维恩自己的安排 | 两人各有今天要做的工作，不把私人时段默认设为调查待命 |
| 先问这次谈什么 | 诺拉转交本人愿意分享的稿件，玩家读后提出具体使用或阅读反馈 | 遥选择哪些修改保留、哪些回应谢绝；旧病程和验证记录不进入本次阅读 |
| 把改约说完整 | 在需要变化时明确新的时间与参与形式，按双方确认的安排继续 | 当事人可改约或少参与一段，玩家不能替伴侣承诺出席，也不能用录制冒充实时同场 |
| 到点结束 | 交还确认版本与可公开范围，结束本次交流 | 生活约定得到实际执行；远程交流和仅交书面折页均可结项，不增加梦内访问 |

具体交流方式沿正文选择，本任务不新增远程接入能力；现实照护仍在街区外。未做本任务时，第五章历史会谈、终章安全处置和两人的共同生活照常成立

## QST-027 · 寄往新地址

故事：[完整正文](../../../player/story/world/new-address.md)，米娜离城并主动分享近况后开启。前置引用 QST-002-B016，与既有尾声来信片段一致，不因“主线任务完成”自动推定任何私人地址已经取得

| 节点 | 玩家动作与可见信息 | 人物决定与持久变化 |
| --- | --- | --- |
| 新消息不是旧订单 | 读取米娜主动发来的需求、收件方式与允许用途 | 巧克力保留旧资料但不擅自补齐缺项；寄送所需确认与公开小册授权分别记录 |
| 今天用得上的东西 | 在小店、PLAYROOM 与桌游卡牌店核对尺寸、用途及可寄物件，让苏弥的建议接受实际限制 | 已带走的玩具仍在米娜处，仓内物件按上次去向处理，不从旧箱无限复制礼物 |
| 一份就够 | 米娜确认实际需要，选择寄物或只取得资料在当地制作，玲放下替她补齐整套旧生活的想法 | 收件人选定内容；未被选中的方案不自动成为下一件待办 |
| 封箱与轮班 | 在店里核对物件与可选的周然规则卡、完成包装，按本次确认地址交给正常寄送服务；资料路线确认内容可打开 | 巧克力只核对已取得资料，家人分担店务；发出后不再更改已经交运的包裹；资料路线不生成物流或扣取邮费 |
| 收到以后 | 选定物件或资料实际收到、米娜给出使用回应后结束，可选分享照片或私人回信 | 物流完成、本人感受与公开展示分别成立；不要求米娜为证明感谢拍照，不把沉默写成异常复发 |

寄出后按剧情转场或后续联系取得物流结果，不能要求玩家原地等待真实数日。收件人不方便回复时保留待确认或通过正常寄送渠道核对，不伪造本人回信；尾声可以先结束，支线后续仍可继续

## 共用状态、时序与恢复

| 情况 | 处理规则 | 后续可观察结果 |
| --- | --- | --- |
| 接受后离开或改约 | 保存已取得资料、当事人决定及未交付部分，下一次正常营业／预约继续 | 不重置失约、停渡、离城或苗损，不要求主角占住 NPC 全天 |
| 提前取得资料 | 承认已知内容并进入核验或下一动作 | 不强制为了听到提示再次走同一路线 |
| 对白跳过 | 当前约定、需求、范围与下一联系人写入已取得记录 | 关键事实仍可查看，语气与私生活不被自动公开 |
| 未完成支线进入尾声 | 只展示主线已经产生的结果，保留正常人物工作与之后预约 | 不出现寄件已收到、展签已换或亲手补种等冒称经历 |
| 终章中途到访 | 以现场开放范围和当前人物职责为准，可留消息 | 支线暂停不消耗隐藏倒计时，不把专业人员从正式处置中叫走 |
| 终章后继续旧请求 | 开始时重核当前路线、苗架、版本和约定 | 不为演完旧分镜重新关渡口、撤回维修或召回已离城人物 |
| 分支决定前后读档 | 以最近有效保存恢复当事人确认和实际交付状态，暂未提交的操作可重做 | 退款、物件、包裹、授权展签与种植不重复结算或凭空增生 |
| 重访／重复互动 | 区分正在处理、已交付与后续新变化 | 旧物件还在该在的位置，最新对白不撤销既有成果 |

场所的运行开放与安全判定始终来自所属主线或正常经营，五个支线完成标记不能统一控制渡口开放或温室安全。任务奖励是清楚的世界后果和关系反馈；如后续引入经济报酬，需按实际委托另定，不给公益场景附加未经设计的刷取收益

## 制作与验收

复用既有店面、公共道路、纸质小票、物件、展签、苗牌与通信界面，新增需求是文字、道具摆放和小型人物演出。正式内容数据建立后再将本页节点映射到稳定 Beat／台词 ID，迁移 catalog 成果引用，避免同时维护两套执行状态

静态检查核对身份、门槛、成果来源、主线无可选硬依赖、链接和双站发布。语义走查采用全部跳过、各自完成、终章后补做、拒绝展示和中途离开五种阅读路线；实际场景接入后再验证输入、物件交付、读档与重复进入

待制作事项包括可达的推车路线、NPC 预约表现、正文选择的持久记录、种植阶段推进和包裹结果通知。此处未给出经过实测的时长、动画或存档保证，文档通过不替代这些运行结果
