# 河没有倒流 · 完整制作脚本

[故事正文](../../../../player/story/main/river-did-not-reverse.md) · [台词表](dialogue.csv) · [脚本约定](../script-format.md) · [分场纲](../campaign-sequences.md)

本章主动任务预算 90–120 分钟，八场按下表连续推进；调查、走位与梦内操作占主要时间，现场核验与普通等待通过动作和明确转场衔接，不增加倒计时玩法。曜潜梦、玲现实接应，两次潜梦之间实际退出；旧提示输出、设施运动和本地候船结构分别记录

出场：月城曜、月城玲、巧克力、邵敏、邱立、老钟、罗宾、塞拉、固定核验员、阿东、艾玛、唐惠、安可、悠真、失约维修顾客；陆成只通过本次联络确认能否接看，不被默认为已经接手设备

## QST-007-S001 · 今天从哪里走

入口：白天，兄妹从河岸小广场进入渡口上层开放区。邵敏站在通往低层的岔口外，左臂抱着今日引导牌；邱立在封闭线旁检查公众不能误入。老钟靠近上层长椅，面向河面。玲的记录板夹在左臂，曜空着手，巧克力跟在公共通道边缘，未进入维护范围

<a id="qst-007-s001-k01"></a>

### QST-007-S001-K01 · 一块举到眼前的牌

玩家镜头沿步行方向进入，先看见邵敏将牌转向被旧声音吸引的人群，右手张开指向上层路线，再收回低层岔口前。旧叫号有规律传来，远处停泊点没有相应船只靠岸。玩家可先看牌或先看停泊点，邵敏不会要求听完欢迎词才允许观察

**QST-007-L001｜邵敏**：今天从上面绕。低层入口已经关了，别跟着那段声音下去。
**QST-007-L002｜屏幕文字**：低层入口暂时关闭。请沿上层公共通道前往当日候船位置；推车转运另向现场人员确认

<a id="qst-007-s001-k02"></a>

### QST-007-S001-K02 · 熟悉的停顿

玩家镜头停在长椅一侧，老钟先朝报站方向偏头，在熟悉的停顿处抬起食指，下一声出现后缓缓放下。玲把记录板移到他能看见的位置，笔尖未落纸，等他说完；曜看过河面，再回头看今日班次牌

**QST-007-L003｜老钟**：就是这里停一下。以前那一班，我听惯了。今天的船不在那边。
**QST-007-L004｜月城玲**：我记下你认得的这一段。今天有没有船，我们再看班次和现场。

<a id="qst-007-s001-k03"></a>

### QST-007-S001-K03 · 比较两次到达

玩家在公开牌面核对当日入口，在允许观察位看完旧提示对应的一个重复间隔，再将现场录音与当天引导放在记录板两侧。巧克力只显示玩家已经比较过的两项。录音的旧低层放行与现实无船靠岸相互矛盾；提前完成比较可直接请求定位，不强制沿错误入口走一次

**QST-007-L005｜屏幕文字**：现场比较：旧提示指向低层；低层已关闭；对应提示期间没有船在该处靠岸
**QST-007-L006｜月城曜**：先处理这段提示。它从哪里出来，范围就先查到哪里。

出口：邵敏将牌固定在公共岔口，继续现场引导；老钟留在上层，兄妹由邱立带到可接应位置。玩家离开可在牌旁续接已取得比较，未做的观察仍在原位，不重开低层入口

<a id="qst-007-s002"></a>

## QST-007-S002 · 叫号以后

入口：现实接应点在经现场人员许可的安全区域，曜已坐稳，玲在身侧检查连接，巧克力随有效连接进入。梦内是重复叫号的候船厅，长椅、放行口与返回侧门形成可观察回路；没有需要营救的真实旧乘客

<a id="qst-007-s002-k01"></a>

### QST-007-S002-K01 · 留一个返回位置

短接管中景从玲肩后看曜手指松开椅沿，玲把水杯移离设备，确认退出操作在自己手边。曜闭眼后切至梦内长椅侧面的固定参照，再立即交还玩家镜头；跳过停在同一观察位，不替玩家走一轮

**QST-007-L007｜月城玲**：你先看叫号到返回的整段。我在这边，只隔离已经定位的提示输出。
**QST-007-L008｜月城曜**：我回到长椅就报位置，先不追后面的船影。

<a id="qst-007-s002-k02"></a>

### QST-007-S002-K02 · 同一张长椅

玩家可从侧面跟随一支队列，或留在长椅旁观察队尾从返回门出现。镜头保持玩家控制，椅背磨痕与地面折返线共同说明是同一处；叫号到放行后队列从侧门绕回，船影在另一方向继续经过。先见返回路线的玩家能直接绕到放行口侧后，不必完整跟走一次。曜停在队伍外侧，让一个身位空当从自己面前过去，不推动形体、不阻塞出口

**QST-007-L009｜月城曜**：放行口通到侧门，侧门又回这张椅子。船影不接这条路。
**QST-007-L010｜屏幕文字**：长椅／侧门：已比较

<a id="qst-007-s002-k03"></a>

### QST-007-S002-K03 · 让这一轮走完

玩家利用叫号后队伍转向的空当沿外侧接近联系部位，完成工具安放并保持当前放行路线；工具触碰后，队尾不再被插入的引导拦回，这一轮走完。曜先看队尾越过出口，再报窗口。现实镜只在玩家操作确实建立窗口时插入：玲转向现场人员递出本轮记录，隔离操作由专业人员完成，玲不跨进封闭区替人拆线

**QST-007-L011｜月城曜**：这一轮到出口了，提示联系现在能处理。
**QST-007-L012｜邱立**：收到窗口。现场按已定位的提示输出做隔离，其他项不动。

受扰时曜将未落定工具收回胸前，沿长椅外侧退回 K02；已观察回路保留。连接失效立即执行退出，现场保持保护，未隔离前不记完成；隔离已完成则重接不再演一次拆改

<a id="qst-007-s002-k04"></a>

### QST-007-S002-K04 · 只停了一件事

短接管从现实引导牌旁拍邵敏试走公共入口：她先停在原声源附近听，再转身向远处同事作正常通行引导的手势，没有用夸张欢呼结束。旧提示不再响，现场人声清楚可辨。玲核对已隔离标注后呼叫曜退出，巧克力随连接撤回。回到现实，曜张开眼，等玲取下设备才站起

**QST-007-L013｜月城玲**：旧提示这一项已停，现场引导听得清楚。结束这一轮，你可以回来。
**QST-007-L014｜邵敏**：这张牌继续留着。通行还按今天的安排。

出口：旧提示隔离保持，工具取回，设备由玲收妥。邱立从维护侧带来另一份运动记录，走到兄妹面前时仍压着纸角，转 S003。重访不重复首次潜梦，旧声源安静是可检查现状

<a id="qst-007-s003"></a>

## QST-007-S003 · 声音以外的动作

入口：兄妹在维护观察位外，脚下安全线与水面都可看见。邱立握着运动记录，固定核验员在许可维护位置检查支撑；曜和玲不进入封闭区。浮动设施正常随水位升降，导向构件有额外反复小幅运动

<a id="qst-007-s003-k01"></a>

### QST-007-S003-K01 · 两条不同的线

玩家镜头由允许观察位看水面参照，再转到导向构件。水面短暂平稳后构件仍往回动，专业人员的手停在尚不能完成固定的位置，先撤到保护位。玲将旧提示停止时刻记在图上，笔从安静声轨移到仍起伏的构件轨迹

**QST-007-L015｜邱立**：声音停了，固定还做不完。它正常会随水位走，这一小段回摆不跟刚才的水面一起停。
**QST-007-L016｜固定核验员**：支撑保持着。刚才的位置又移开了，固定核验不能写完成。

<a id="qst-007-s003-k02"></a>

### QST-007-S003-K02 · 已做的没有撤销

玩家可以先检查提示隔离记录或先对照运动曲线。曜蹲在安全线外，将旧隔离照片与现状对齐，封闭位置没有变化；玲将两份记录分开夹入板上，旧提示一页朝左，构件一页朝右。查看一个不自动取得另一个

**QST-007-L017｜月城曜**：这里仍然隔离着，旧声音也没有回来。我们刚才完成的不是假的。
**QST-007-L018｜月城玲**：另一条还在动。先给它单独一页。
**QST-007-L019｜屏幕文字**：已完成：旧提示输出隔离。未完成：导向构件反复运动的接触定位与处置

<a id="qst-007-s003-k03"></a>

### QST-007-S003-K03 · 不伸过去试一试

玩家镜头跟随邱立在公共侧平移到能看到棚架背面的位置；他隔着安全线用图纸指明下一步比较的接缝，不引导主角触碰构件。固定核验员把保护状态记入表，目送兄妹退回公共路

**QST-007-L020｜邱立**：支撑由我们守着。你们拿材料更换记录和旧照片来比，别把手伸进去试。

出口：公众路线继续绕行，支撑由专业人员维持。兄妹沿公共路到旧帆展屋，运动记录随身，现场原件不带离值守。中途离开从记录页续接，不重新制造广播复发

<a id="qst-007-s004"></a>

## QST-007-S004 · 一道没有画进去的接缝

入口：旧帆展屋的桌面清出一角，老钟把旧候船照片平放，手指按住翘起边缘；邱立带来的当前接缝照片置于另一侧，玲草图夹在板后。随后只在开放公共观察位核对，老钟不跟进维护区

<a id="qst-007-s004-k01"></a>

### QST-007-S004-K01 · 缺角的位置

短接管俯斜中近景从桌外拍照片和玲的笔。老钟指向低屋檐，指腹停在缺角处；玲把纸移近，先勾轮廓再抬眼求证。他没有碰她的笔，只把照片转正

**QST-007-L021｜老钟**：以前等船，都先往这边挤。这块缺角也留着，别画成刚搭好的。
**QST-007-L022｜月城玲**：这边阴影我留着。下面这一组，是后来加的？

交还桌边玩家镜头，尚未比较的材料仍需玩家翻看

<a id="qst-007-s004-k02"></a>

### QST-007-S004-K02 · 旧票不替今天作证

老钟从票夹抽出旧票，双指捏边递给玲，玲放在透明护页上，未拿笔在原件写字。票面城市旧称与日期沿已存原票图像呈现，本场不替未定历史专名另造字符串；本次可读新增记录完整如下。玲问起当时檐下的人，老钟先朝照片空处看，再摇头，把票夹合上

**QST-007-L023｜月城玲**：那一天，谁和你站在这下面？
**QST-007-L024｜老钟**：不记得了。这张我留着，人可没都记住。
**QST-007-L025｜屏幕文字**：旧票核对：旧称与票面日期留在原件；同站者未能确认。此票说明过去的候船使用，不证明今天的构件接触

<a id="qst-007-s004-k03"></a>

### QST-007-S004-K03 · 按今天接到哪里画

玩家在材料更换记录上比较旧檐段、维修新增连件与导向部位，再到公共观察点看雨后接缝和水线。调查顺序自由；未取得温室支线素材也有主线 QST-005 的必需干湿观察可对照。玲把只按道路远近连起的线擦去，保留铅笔淡痕；玩家逐段对照已获得响应后，才画对应接触，不因“同样潮湿”一键连全图

**QST-007-L026｜屏幕文字**：维护记录摘录：原檐段保留；附属连接后装，沿支架接至导向部位。雨后填充层未干。现场需复核接触与运动，不凭外观判定
**QST-007-L027｜月城玲**：这边也湿，却没跟着动。要留下的是能对上响应的这一段。

<a id="qst-007-s004-k04"></a>

### QST-007-S004-K04 · 它也在承重

公共观察完成后，兄妹沿原开放路线返回旧帆展屋桌边；邱立仍在维护现场，通过当前联络展示同一张图，固定核验员保持现场保护。短接管以桌面联络画面与玲、老钟同框，邱立在画面内把图纸一边折起，露出连件下方承托关系。手指先沿支承方向，再沿已核验可拆范围移动。玲笔尖仍停在希望保留的檐线外；老钟看完图，把照片按回自己面前，没有点头答应一切

**QST-007-L028｜邱立**：这组连件既连着导向部位，也接住檐段。抽掉它，不能让檐还悬在这里。
**QST-007-L029｜邱立**：能确认的工序是先支撑、整段卸下、留样。想留在原位，得另做独立承托；眼下还不能答应。
**QST-007-L030｜老钟**：展屋不缺一块旧木头。我想的是下雨时还在那儿站一会儿。

镜头结束交还桌边。玲将草图夹回板后，原票交还老钟，取得许可的复制照片进入本次记录；不把原物当任务奖励收走

出口：确认可比较的当下接触和本轮有限可操作范围；原位保留尚未承诺，照片与留样方案留到第七章。离开后记录可重看，老钟的票留在他手中，不重复获得副本

<a id="qst-007-s005"></a>

## QST-007-S005 · 返回的另一条路

入口：回到原安全接应点，曜重新接入，玲守在现实，巧克力随本次连接进入。现实旧提示保持安静，梦中叫号仍反复；本地活动存在与旧现实输出隔离同时成立

<a id="qst-007-s005-k01"></a>

### QST-007-S005-K01 · 安静的一端

短接管先拍玲把两张完成范围分开放，再切梦内玩家镜头。曜站回长椅旁，听到旧叫号却没有立即追问旧隔离是否失败。玩家查看当前联络页即可看到现实旧声源复核记录，不必再次走完 S002

**QST-007-L031｜月城玲**：现实旧提示仍然安静。今天要看的是构件那一条，别把梦里的叫号当成声源又开了。

<a id="qst-007-s005-k02"></a>

### QST-007-S005-K02 · 标记什么时候动

玩家从关闭窗口外侧看见另一支队伍沿檐下返回，现场人员在许可范围内观察接触，玲逐段送入实际标记变化。曜对照同一轮哪一条梦内联系响应，船影仍按旧次序经过。玩家可先观察队伍或先读现场标记，二者齐全后指认操作点；巧克力只保留取得过的变化位置

**QST-007-L032｜月城玲**：当前这段又回摆了。我把这次位置记给你，下一段还没有结果。
**QST-007-L033｜月城曜**：檐下这条同时回送。船影刚才照旧经过，它没有跟这个标记变。

<a id="qst-007-s005-k03"></a>

### QST-007-S005-K03 · 等候者转身以后

玩家沿队伍外缘到候船者转身形成的空位，侧身让队尾通过，再将工具落在已指认接点；曜一手扶稳工具，一手指给巧克力退回路线。工具对准并保持后这一轮不再回送，现实专业人员完成对应局部处置。只走进空位而未安放工具不会自动完成。失去空当时收回工具退至长椅，已获观察保留

**QST-007-L034｜月城曜**：这一轮回送断开，我能守住当前这一段。其他位置还没看见。
**QST-007-L035｜邱立**：对应接触已处理，当前这一项输出降下来了。旁边那份记录开始重复同样的间隔，先别追。

<a id="qst-007-s005-k04"></a>
