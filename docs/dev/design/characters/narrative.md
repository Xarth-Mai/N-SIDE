## 出场节奏

35 位角色分为核心、常驻和次要，分类表示叙事使用重点。序章重点认识林屿、林澄、粒粒、陆衡、米娜和乔音，其余人物沿生活动线与对应事件逐步出现

不具名居民、员工、学生与顾客构成日常生活。每个人可以拥有独立的生活目标，街坊小册《今天的街坊》提供创作和往来的理由，不是异常传播媒介或搜集私人秘密的借口

人物的关联场所表示工作、探访、协作或远程参与，不表示拥有相应建筑。住宅编号表示角色居住在住宅组中的一户，不开放整栋住家供玩家任意进入。未列住宅的配角无须为了补齐索引而制作住家场景

许遥先以编辑意见和当下作品参与故事，再由本人补充历史；其在影像书店与共享工作室的参与采用预约远程交流或经授权的潜梦访问，现实照护位置在街区外。父母住在城市其他地方

## 关系的叙事职责

兄妹的成长建立在亲近、双向照顾和共同决策上，不用强行决裂制造成长。粒粒参与家庭生活，不作为制造廉价失去的牺牲品

季闻与许遥在正篇开始前已经确认真实共梦。主线呈现确认以后的生活和两人对历史的主动补充，不重新把许遥的真实性设成悬念

## 认知与表达检查

对白以档案中的亲历和当前认知为边界：兄妹开场不了解实验细节，陆衡不是全貌见证者，顾竹、钟帆与郑泊各自保存片段，季闻和许遥也不知道所有地点今天的状态。楚青的当前测量不能直接证明十二年前的条件

粒粒的亲自记录、外部文件和推测结果要分别表达；它能辅助比对，不能补造从未获得的证据。人物愿意协作，不等于可以公开其全部私人信息

林启明的表达落在普通经营经验上，不赋予隐藏实验室身份；陈静禾的关心落在具体生活和完整倾听上，不用反复唠叨代替个性。配角保留工作之外的目标，兄妹帮助人们继续生活，不替他们作出人生选择

云端 Agent 属于游戏世界设定。其表达、工具操作与支援由游戏内逻辑实现，不引入现实在线 Agent 或大模型作为叙事成立的依赖
