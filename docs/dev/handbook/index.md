# 开发手册

先用[Codex 工作入口](codex.md)定位任务，再按[任务卡规则](tasks.md)读取依赖与证据；编辑或迁移知识遵循[文档规范](documentation.md)和[Wiki 发布](wiki.md)

[制作管线](../production/pipeline.md)连接方向、具体设计、制作、工程与验收。按任务选择专业 Skill，原版方法与项目契约通过 nside 适配入口关联；不要求每项工作调用全部专业技能

新对象与工作记录按[模板](templates/index.md)选择阅读任务。当前未决问题与执行结果写入 todo，已支持的长期结论回写所属规格
