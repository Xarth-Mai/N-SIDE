# 项目方向

N:SIDE 将城市生活、现实调查、潜梦行动与现实后续连接成出门与回家的体验，完整故事与地点身份由[游戏百科](../../player/index.md)维护

首发支持 PC，系统为 Linux 和 Windows，输入支持手柄和键鼠，图形接口采用 Vulkan。体验主要由城市生活、调查、动作和叙事推动，数值养成保持轻量

当前制作目标为完整游戏：将正式总纲的序章、八章、尾声及支线目录中的生活故事接入可独立完成的游戏，并使真实运行的地图、人物、材质、光影与界面达到README概念预览所确定的日系都市表现方向。[Demo 定义](demo-scope.md)继续约束中途的代表性样板，不再作为项目终点

当前优先完成画面、地图与人物资产：城市体量和地形关系、建筑外观与公共空间、街道设施与植被、材质贴图和光影，以及人物模型、真实UV、骨骼、蒙皮与基础动作。人物沿用镜厅预览左侧人物海报的日漫画法与已定年龄要求，未认可的配色保持候选；先让一个完整资产家族在真实行走和连续镜头中成立，再按对象清单扩展

随后集中完成生活、调查、潜梦、行动、现实后续与回家的完整流程，包括所需室内、人物演出、UI、声音、存档恢复、兼容与发布。完整城市中可通行、可进入和可交互范围分别依据正式地点与玩法规格制作；共享模型、材质和动画服务统一品质与可维护的生产成本

现有城市框架、Viewer 与工具验收按各自范围复用，不能代替人物、任务、存档或独立游玩的完成证据。最终完成依据真实完整流程、实际画面、作者体验、双平台双输入和独立发布验收；概念图、灰盒、部分角色、文档或单段录制都只构成阶段成果
