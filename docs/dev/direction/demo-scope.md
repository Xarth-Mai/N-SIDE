# Demo 定义与体验支柱

本页的体验支柱与既定约束已有作者确认，具体制作预算继续按实际动作与场景验证收口。既定内容与待验证问题在本页分开维护，执行状态和实际反馈由任务卡记录

## 完成时玩家做成什么

玩家从营业的小店参与一次日常，回应求助，在现实与梦境间核对异常，通过行动改变维持条件，看到当事人与场所的后续，再回到仍然亮灯的小店和楼上住家

## 三个体验支柱

| 支柱 | 玩家要实际经历什么 | 可观察的结果 |
| --- | --- | --- |
| 生活给行动以牵挂 | 与家人共同做一件小事，认识求助者在异常之外的生活 | 能说出为何出门、为何愿意回来；结束后当事人有自己的下一步 |
| 调查改变判断与做法 | 观察、询问、核对事实，发现最初解释不足 | 能指出哪个观察改变判断，并据此改变下一次行动；记录区分已知事实与推测 |
| 理解规则后采取行动 | 看懂危险，用移动、回避、工具和支援创造处理机会 | 能说明改变了哪个条件、产生什么可见后果；失败后可重试、退出和恢复 |

三者在同一委托中连接。生活的选择由当事人保留，调查给行动提供依据，动作处理有害影响，现实后续说明处理有什么意义。它们将[核心体验](../../index.md)和[创作流程](../production/narrative.md)落实为 Demo 的体验判断依据

## 直接沿用的约束

| 领域 | 既有或本次明确收录的基础 | 维护入口 |
| --- | --- | --- |
| 家庭 | 兄妹温柔亲近、共同经营；父母在世并有联系；小店全天营业 | [家庭](../../player/encyclopedia/characters/family.md)、[小店](../../player/encyclopedia/locations/shop.md) |
| 潜梦 | 同一次行动只有一名兄妹入梦，另一名清醒接应；Agent 依托人类连接，重在探索、操作与保护 | [潜梦工作](../../player/encyclopedia/gameplay/dream-diving.md)、[Agent](../../player/encyclopedia/characters/agent.md) |
| 世界 | 梦中受击不直接损伤现实肉体；非生物介质可产生有限物理输出；现实空间稳定、实物去向可追查 | [噩梦与梦魇](../../player/encyclopedia/world/nightmares.md) |
| 历史与结局 | 原始梦魇已终止，今天的风险来自局部结构的新联动；伴侣继续共同生活，处理有害影响与保留安全生活可以并行 | [大共梦事件](../../player/encyclopedia/world/great-shared-dream.md)、[完整故事](../../player/encyclopedia/story/index.md) |
| 城市 | 复用地图主数据，区分可见、可走、可进、可互动；91 个命名场所不等于 91 栋楼，也不等于 Demo 必做清单 | [场所设计](../design/locations/district-places.md)、[场所与故事](../../player/encyclopedia/locations/place-network.md) |
| 实现与交付 | Rust／Bevy，Linux／Windows，键鼠／手柄，离线独立完成；云端 Agent 是虚构设定，其表现由游戏逻辑驱动 | [工程](../engineering/index.md)、[玩法制作](../design/systems/index.md) |

## 完整游戏与本次范围

《回声之后》的序章、八章、尾声、人物关系与生活故事纳入正式项目设定，分别在[故事百科](../../player/encyclopedia/story/index.md)、[人物](../../player/encyclopedia/characters/index.md)和[场所](../../player/encyclopedia/locations/place-network.md)维护。完整游戏的设定与本次 Demo 制作范围分别管理

首个委托已选择优先细化[《最后的玩具》精简闭环](../design/quests/QST-002/README.md)，保留现实／梦境往返与回家，站前送行留给完整版。原路线建议的 25—40 分钟、小店与住家加一处现实室内、一名可操作兄妹、2—3 名相关 NPC、一种工具与一种有效支援，都保留为待确认预算；试玩后校准时长

## 尚需确定的设计边界

| 类别 | 需要解决什么 | 对应规格与验证 |
| --- | --- | --- |
| 待细化与选择 | 首委托的操作因果、分支与恢复，以及主控兄妹 | 首委托机制与输入规格 |
| 待选择 | 可达边界、室内与 NPC 数量、可选内容、时段 | 可达空间与内容预算 |
| 待设计与实验 | 镜头、跨阶碰撞、输入、交互距离与工具手感 | 输入、人物尺度与潜梦动作原型 |
| 待设计与实验 | 调查信息层级、对话与返回逻辑、声音和角色比例 | 调查 UI、叙事与表现样板 |
| 待验证 | 参考设备、存档恢复、场景生命周期、双平台启动与发布资源定位 | 工程、状态恢复与独立包验证 |

有效基线只确认会影响大规模返工的方向与边界；镜头参数、详细布局和动作数值交给对应原型验证。历史工程盘点保留在 `todo/evidence/setting-v1/integration.md`，当前实现以工程源码与实际检查为准
