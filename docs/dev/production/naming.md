# 命名规范

## 正式基线

名称以当前人物与场所目录为准，世界、故事、对白、界面和地图使用同一套称呼。名称变更保持稳定对象 ID；本规范约束后续命名，迁移前后的名称对照仅保存在任务证据

整体采用现代都市的自然称呼与清晰辨识度，允许东亚现代姓名、简短单名、外来名、艺名和长期街坊称呼共存。人名首先应好读、好记、适合直接称呼，使用常用字，区分相邻角色的音节和字形

后续人物以约四至五成东亚现代姓名、二至三成简短高辨识度名字、一至两成外来或国际化姓名，加少量艺名与昵称为方向；这些是创作参考比例，不是必须凑齐的配额。保留普通居民的自然感，核心角色、明星和特殊职业可以更鲜明

避免整批同构的文艺双字姓名，也不堆叠常见幻想字。章节标题保持各自的文学表达，不随人物命名风格统一重命名

## 人物称呼

人物档案标题和身份字段使用正式名；对白与熟人交流主要称月城曜为“曜”、月城玲为“玲”。称呼中的爸爸、妈妈、老师和师傅依说话人与关系选择，不机械将全文姓名缩为一个字

安可是公开职业名，不强制补全法定姓名；遥直接使用单名；巧克力是正式角色名，日常不改用技术编号。老钟、小满等长期称呼可以独立成立，不据称呼反推国籍、亲属或未写明的法定姓名

[人物目录](../../player/characters/index.md)维护姓名、身份与关系；新增对象先核对当前人物全集及常用称呼的撞音、形似和阅读节奏，再分配从未使用的稳定 ID

## 城市层级与场所

| 层级 | 正式名称与用法 |
| --- | --- |
| 项目 | N:SIDE；与城市、街区名称分开 |
| 城市 | Null City |
| 核心街区 | Null Site |
| 河流 | 白沙河 |
| 主车站 | Null Station，日常简称 N站 |
| 异常处理机构 | Null Response Bureau，简称 NRB；不将所有研究者或专业团队都归为同一机构 |
| 日常场所 | 月台杂货、白页书店、星见学园、四季温室、流光公园、西环渡口、北坡、摘星台、Null Site 服务中心、镜厅 |
| 青年文化与商业场所 | AFTER 9、BYTE BEAT、FRAME、PLAYROOM、FLASHBACK、MONO、LATE BITE |

流光公园是滨水公共区域的统称，内部花园、广场、露台与渡口分别保留身份和进入边界；北坡是既有山地区域的称呼。月台杂货与楼上住家、镜厅与同楼的其他用途也分别管理

LATE BITE 对应音乐街的夜间茶食场所 `82`，晚班汤饭店 `53` 仍是另一家店。白页书店对应站前书店 `34`，MONO 对应影像书店 `73`。完整场所对应由[场所目录](../design/catalogs/place-catalog.json)及[地图源](../../../source-assets/district-map/README.md)维护

居民对白可以说“去店里”“在车站见”或自然使用场所名称；第一次需要定位时给出明确对象。行业描述如书店、模型店、Live House 可以用于说明业态，不因此成为另一套正式店名

城市旧称曾存在于历史记录，当前尚未另定专名。废弃的命名稿不作为世界内历史别名继续使用

## 世界术语

Null、Black Case、潜梦、梦魇、联合梦境、持久梦境继续沿用。后续大型事件、组织和研究计划采用短正式名称与必要的民间简称，不为风格统一而全部英文化或诗化

## 使用与检查

命名输入为对象职责、既有关系、所在文化与全体称呼清单；先辨认对象，再决定正式名和日常称呼，最后更新正文、目录、源地图和可见界面。路径需要调整时保留旧 URL 跳转，稳定 ID 和内部技术标识保持不变

检查同字异义、亲属称谓、地图归属、历史记录及发布产物。变更旧名只针对已确认对象，不对单字或通用行业词做全局替换。发现人物、店铺或地理边界混淆时先修对应关系；未定名称留在任务中，不写入玩家正文
