# 室外人物尺度实验

本入口验证中性代理在既有城市网格上的移动与观察，正式主控及可达内容范围由对应设计任务决定。地图、建筑、道路与台阶继续使用 `source-assets/district-map/district.json`，输入设计见[输入与交互](../design/systems/input.md)，命令见仓库 `game/README.md`

## 运行契约

正式入口追加 `--walk-preview`，场景准备任务从 `PreparedScene.parts` 创建 `CollisionWorld`，再在 `/nodes/home` 向下扫掠确认胶囊有可行走支撑。必需碰撞网格或出生支撑失败沿用加载失败页；返回标题清理玩家、碰撞缓存与输入意图，下一次进入重新建立

查询采用固定的 Parry 0.30.2，只使用静态三角 BVH、胶囊和球体扫掠，不启动刚体世界。Bevy与Parry的向量版本通过数组边界转换，地图米制坐标不变；索引与无索引 TriangleList 均可接入，每段三角保留源对象映射，许可与版本见仓库 `THIRD_PARTY_NOTICES.md`

包含地形、道路及台阶、建筑外壳与派生门框、窗框、雨棚等立面构件、平台和结构设施；水面、植被和导入模型道具暂不参与碰撞。建筑门洞尚未切穿外壳，入口仍是实体墙；实验覆盖小店周边与短登高室外路线，不使用穿墙转场来代替室内

## 本轮参数

| 项目 | 实验值与职责 |
| --- | --- |
| 胶囊 | 总高1.7m、半径0.3m，脚点记录物理最低点 |
| 行走 | 3.2m/s，输入按镜头水平方向转换，摇杆径向死区0.15、对角限幅 |
| 碰撞 | 表面间隙0.02m，另留0.001m数值余量；每步最多4次扫掠滑动，近零接触时给投影后的剩余位移增加1µm向外分量再完整扫掠，避免切向舍入导致原地停滞 |
| 台阶 | 最大尝试抬升0.26m，依次验证头顶、前向空间与落点支撑 |
| 支撑 | 最小实际踏面法线Y为cos45°；圆帽命中共享棱边时先沿接触方向偏移10mm核对踏面，若失败，再沿几何边两侧各核对一次同范围实际踏面，避免高处近竖直接触的水平误差，重力18m/s²，行走时保留向下贴地范围 |
| 镜头 | 目标为脚点上方1.35m，期望距离3.8m，0.18m球体与0.04m间隙防穿墙；距离低于0.8m时隐藏代理，移远后恢复 |
| 镜头输入 | 右键拖动、Q E或右摇杆；俯仰限制约−7°至66° |

这些值用于原型比较，不构成作者确认的角色或关卡预算。角色使用 Bevy `FixedUpdate`；普通启动沿用Bevy默认64Hz固定时钟，capture将固定步长设为脚本fps，证据必须记录该值。输入先于固定循环采样，鼠标位移每渲染帧消费一次；固定时间不保证不同GPU的像素一致

## 检查与恢复

窄测验证薄墙高速扫掠、上阶及低顶阻挡、墙边离开，以及从实际小店节点沿道路网格移动；相机扫掠与人体扫掠分别保留检查。场景录制继续使用共享capture，不创建替代街景或脚本设定完成位置

脚本记录脚点、是否有支撑、碰撞源、恢复次数和相机距离，断言按真实路线声明范围；机器通过后检查连续画面的角色可见性、遮挡和台阶表现。`walk-ascent-entry.json` 覆盖小店至首段登高台阶，`walks_complete_short_ascent_and_return` 从真实出生点按源 `hill-short` 节点逐段给水平输入，再沿原路回店，分别检查64Hz和30Hz；CPU路线探针与GPU画面分别记录。`walk-ascent-full.json` 沿同一路线从真实入口录制完整上山过程，驱动仅观察玩家并发送常规输入，按节点留下状态与连续画面。`walk-round-trip.json` 继续覆盖同一会话的完整下山与回店，峰顶只计一次、共259次节点到达；零恢复和最后节点的真实位置共同约束回店。物理手柄、作者手感、角色动画和全城导航需要各自证据

R／Select执行显式回到已验证出生点；越出静态世界边界或出现非法位置时记录警告并执行同一路径，所有恢复增加计数。capture限制恢复次数，避免把自动复位当作正常走完。主窗口失焦先请求暂停，在固定更新前阻止移动、重力、贴地、镜头和复位；保留角色的速度和当前位置，继续后恢复同一会话。加载完成时仍失焦也走同一路径；无窗口录制不会因缺少窗口而暂停。Esc／Tab／Start／东键进入暂停，人物与镜头保留；暂停输入先于固定循环处理，开菜单当帧停止移动、转向与复位。继续时要求旧玩法输入释放后再操作，包括相抵的按键或摇杆输入；回焦本身及持有的确认输入不会继续游戏，系统自动重复的菜单按键忽略，释放后重新按下才能确认；返回标题退出实验

`walk-pause.json` 覆盖键盘与模拟手柄暂停、持有输入、继续、标题清理和再次进入；`walk-focus.json`追加模拟窗口焦点的加载／恢复路径，CPU调度测试另检查0／1／3个固定步、鼠标继续、代理实体唯一，以及真实输入插件处理的迟到重复按键。暂停不重建碰撞缓存，也不暂停Bevy全局时钟；后续接入的动画、NPC与声音必须分别约定暂停职责

相关工作与本轮结果由 `todo/tasks/TASK-014-human-scale-prototype.md` 记录，长期保留通过验证的接口和已知边界

手柄连接由Bevy InputPlugin在PreUpdate处理，断连移除Gamepad但保留设备实体；入口在固定循环前消费同批连接消息，复用待暂停门禁冻结人物与镜头。当前所有连接设备都参与聚合输入，任一断开触发保护；不按最后输入设备排除其他手柄。加载时的断连请求延续至World首帧，标题／新加载／失败清除；恢复不重建代理或碰撞，连接与回焦共用菜单释放门槛。`walk-gamepad.json`与CPU调度测试检查模拟连接的实际行为，物理设备恢复另验

## 地点提示

人物入口从同一地图读取场所名称和公共到达路径的末节点，没有公共到达路径时使用原场所位置。HUD只显示水平32m、竖直4m内最近地点的「附近」标签，其他位置回退Null Site；这是街景位置提示，不表示已经进入室内。稳定地点ID保持原数据，暂停与标题隐藏世界HUD，重入重新加载目录

左上地点与左下操作提示使用街区信号tokens，按当前实际输入设备切换；标签只在状态变化时更新。`walk-places.json` 通过真实行走验证离开、回店、暂停、键鼠／模拟手柄切换与清场；CPU检查高差边界及缺失公共到达节点的诊断
