# 画质与显示设置

正式入口的设置包含「通用」和「画质」选项卡，使用当前 Bevy 0.19.1 渲染路径与窗口系统。画质数据维护在 `game/src/graphics.rs`，保存与失败保护复用 `settings.rs`；Viewer 的开发命令行参数继续用于独立场景检查

## 操作与选项

Q／E、手柄肩键或点击页签切换通用与画质；上下选择、左右降低或提高当前项，Enter／南键或点击行切换到下一值。画质每页四项，PageUp／PageDown或页面按钮换页，上下导航可跨页；返回沿用来源菜单的焦点与输入隔离

| 选项 | 范围与职责 |
| --- | --- |
| 抗锯齿 | 关闭、MSAA 2×／4×／8×、FXAA、SMAA、TAA |
| FXAA／SMAA质量 | 低、中、高、极高，作用于当前后处理抗锯齿算法 |
| 环境遮蔽SSAO | 关闭、低、中、高、极高 |
| CAS锐化 | 关闭、30%、60%、100% |
| 动态阴影 | 开启／关闭，控制太阳阴影图 |
| 阴影贴图 | 1024／2048／4096／8192 |
| 阴影距离 | 250／600／1200／2400m |
| 阴影过滤 | 硬件2×2、高斯、时域抖动 |
| 接触阴影 | 开启／关闭，沿用场景的长度与厚度 |
| 泛光Bloom | 关闭、柔和、标准、较强 |
| 距离雾 | 开启／关闭，颜色与起止位置沿用场景 |
| 曝光补偿 | −1至+1EV，间隔0.5EV；相对场景曝光基线 |
| 色调映射 | Tony McMapface、关闭、Reinhard、Reinhard亮度、ACES、AgX、Boring Display、Blender Filmic、Khronos PBR |
| 渐变去色带 | 开启／关闭 |
| 场景视距 | 1500／3000／5000／7000m，修改相机远裁剪面 |
| 垂直视角 | 45°／55°／65°／75°／90° |
| 垂直同步 | AutoVsync／AutoNoVsync，由窗口后端选择支持的呈现方式 |
| 窗口模式 | 窗口／当前显示器无边框全屏 |

这是当前项目已接入渲染与显示选项的完整清单，场景太阳位置、材质与灯光颜色继续归美术数据，内部HDR渲染不作为显示器HDR选项。FSR、DLSS、光追、动态分辨率、运动模糊和景深尚未接入，本页不显示无效开关，也不为画质设置更换渲染器或增加插件

## 生效与兼容

配置变动后更新真实相机、太阳与窗口组件。开启SSAO时若当前为MSAA，自动切换TAA；选择MSAA时关闭SSAO。切换抗锯齿移除旧算法的时域状态，再为当前TAA、SSAO与接触阴影建立实际需要的预渲染组件，避免残留组件影响后续算法。Bevy 0.19.1在关闭MotionVectorPrepass时未清理RenderApp的背景运动向量pipeline／bind-group缓存，本模块在Prepare之后、Render之前移除无对应预渲染组件的两项缓存；这是当前版本的动态切换修复，升级时重新核对源码与同一路线

应用前检查设备采样数与SSAO所需限制；调整抗锯齿时沿切换方向跳过不支持的MSAA，首次读取外来设置中的不支持值时回退FXAA；不支持的SSAO关闭，设置页显示原因。保存实际采用的设置，界面、后续启动与渲染保持一致。图像目标capture保持脚本分辨率，窗口尺寸与VSync的桌面效果单独验收

默认值保留当前白天场景的MSAA4、4096阴影图、2400m阴影距离、55°垂直视角与7000m视距。偏好文件使用版本2，读取版本1时保留字号与镜头灵敏度并补入默认画质；未知字段、越界索引、无效组合和损坏文件仍走原文件保留与错误反馈，不静默覆盖

## 显示确认与启动恢复

修改窗口模式或窗口分辨率后立即试用，并打开15秒确认面板，默认焦点为「恢复原显示设置」。选择「保留显示设置」才接受本次显示值；选择恢复、Esc／Tab、手柄东键／Start、窗口失焦、手柄断开或倒计时结束均恢复试用前的窗口模式与分辨率，然后返回原设置行并等待旧输入释放

倒计时使用 `Time<Real>`，不受游戏暂停影响。`DisplayTrial` 仅保存试用前的窗口模式与分辨率；其他画质、字号和镜头设置保留当前值。保存快照在确认前使用原显示值，包含异步写入队列和退出时的最后保存；未确认的显示值不会进入设置文件

画质页末尾的「恢复默认画质」恢复19项默认值，保留字号与镜头偏好。若窗口模式或分辨率随之改变，同样进入显示确认；取消只恢复原显示两项，其他画质已恢复默认

若保存的显示设置使启动画面不可用，可在正式入口追加 `--reset-graphics`。加载偏好后只恢复默认画质，文字大小和镜头灵敏度继续使用原设置；正常文件由既有保存流程备份并更新，原文件读取失败时继续保留坏文件，本次恢复仅在会话内有效。启动脚本透传该参数，命令见仓库 `game/README.md`

## 检查与证据

CPU测试核对选择边界、AA／SSAO互斥、实际组件切换、旧设置迁移与保存，以及显示确认、真实时间超时、失焦／断连恢复、退出保存和启动重置。GPU沿正式步行入口进入真实城市再切换选项，检查shader编译、截图、组件采样与恢复；不能用保存值代替实际组件。窗口模式、分辨率、VSync的系统呈现和物理输入另记录实机覆盖，性能成本不从截图推断
