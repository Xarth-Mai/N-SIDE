# 示例：最后的玩具

本例演示如何让调查线索、玩家行动与人物变化共同构成一个委托，供叙事制作与试玩设计使用

Mina 即将离开 Null City 读大学。她梦中的收集者搬走童年玩具，对应物件随后从现实消失。玩家前往一间永远停在打烊前的玩具店调查

表面解释是收集者在偷窃；深层机制是保留室持续复制物件与空间，收集者则执行打包与离开的过程。Mina 反复拆箱的行为与梦境增生相呼应

## 可玩结构

检查房间与箱封 → 进入梦境追踪 → 看见收集者归还玩具 → 回现实核对拆箱痕迹 → 隔离收集者或跟随运输线 → 观察物件退出打包后货架增生 → 恢复运输 → 帮助 Mina 选择随身物与收纳物 → 观察现实后续

隔离路线通过运输中断显现后果；跟随路线通过检查运输过程发现原因。两条路线使玩家理解同一规则，再据此改变行动

## 信息与体验

箱封、日期和照片说明反复打包；归还动作改变对收集者的判断；运输与货架的联动呈现维持机制。结尾通过整理行李表达携带记忆继续生活

试玩关注归还动作是否看清、拆箱与增生的因果是否理解，以及玩家能否说明自己的操作带来了什么
