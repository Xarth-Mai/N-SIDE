# 项目愿景

N:SIDE 发生在 Null City。一对年轻兄妹经营着一家全天亮灯的生活杂货店，与家庭 Agent 一起处理异常，再回到他们与街坊的日常生活

## 核心体验

第一优先级：“我真的在 Null City 生活过一段时间。”

第二优先级：“这座城市让我忘不掉。”

小店、住家、熟客、邻居和普通生活本身承载故事。动作战斗、调查、探索、人物、谜团、氛围与音乐共同服务于这段生活体验

## 叙事方向

现代都市与日系动漫化表达，都市日常和潜梦行动相互连接

故事采用小人物视角，关注被异常打乱的具体生活。跨事件线索与长期谜团按故事需要展开，每个当事人的问题有自己的原因与结果

整体温暖，允许少量无法完全挽回的遗憾。处理异常后，记忆、关系和已经作出的选择可以留下痕迹；生活的下一步由当事人决定

## 平台与驱动力

首发支持 PC，系统为 Linux 和 Windows，输入支持手柄和键鼠，图形接口采用 Vulkan

体验主要由城市生活、调查、动作和叙事推动，数值养成保持轻量
