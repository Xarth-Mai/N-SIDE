# N街区

## 街区气质

车站社区商店街的生活与客流，结合坡地街区的高低层次。整体坡度适中、住商混合，适合日常步行、停留与经营

中等高度能够遥望河流、对岸和地平线。主据点的日常季节基调为初秋：清爽，仍有较多绿色，呈现晴天、黄昏、夜晚与雨后的变化

## 空间关系

```text
下方：车站与较热闹的商店街
  ↑
中段：N主路的缓坡生活区，小店与楼上住家
  ↑
上方：逐渐安静的住宅与通往山顶的步道
  ↑
山顶：小神龛与摘星台
```

以上为相对空间关系。主路承接日常通行，住宅与步道随高度上升逐渐安静

## 地名

本文以 `N街区` 和 `N主路` 分别标识主据点及主要缓坡道路，山顶观景点名为“摘星台”
