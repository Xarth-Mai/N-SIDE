# 小店与楼上住家

## 店铺定位

一家年轻化的独立生活杂货店，融合潮玩、文创、设计小物、玩具与实用日用品

店铺延续父母留下的经营基础与熟客关系，经过兄妹主动年轻化，选品与陈列体现两个人共同的喜好。大部分商品是普通生活商品

## 选品与经营

兄妹共同决定选品、陈列、进货和店面改造

选品兼顾日常实用、设计感与玩具的趣味。文具、杯子和收纳用品适合带回家使用，毛绒玩具、挂件、设计小灯与拼装模型则让人愿意停下来细看

陈列整洁、容易寻找，同一图案或角色可以延伸到不同品类，形成彼此呼应的小系列。拼装与模型商品保留动手组合和展示的乐趣，实用品与小玩意共同呈现兄妹的审美

## 营业

小店全天营业。AI 店员在兄妹休息、外出和潜梦时承担基础接待与店务，复杂售后、设计需求和异常委托另约时间

全天营业让不同作息的客人都能与小店建立关系。夜班熟客可能先熟悉 AI，之后才遇到兄妹

## 建筑与住家

楼下为店铺，楼上为住家，经营与共同生活位于同一栋建筑中

小店位于 N街区中段、日常人流经过的缓坡位置。向下连接车站与商店街，向上连接住宅、步道与山顶

店铺连接街区的公共生活，楼上住家承载兄妹与 Agent 的共同日常。经营、休息与出门处理委托，都围绕这处熟悉的据点展开
