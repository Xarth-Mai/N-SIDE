# 往事与时间线

## 小店的共同异常

事件影响了小店、兄妹和少数熟客。不同的人开始梦见同一家“不太对劲的店”，醒来后，对店里的人、物件或某段经历出现错认

兄妹共同经历了熟悉生活被打乱、求助迟迟得不到理解的处境。这段经历成为他们后来帮助熟人、逐步承接异常委托的动机

## 已知次序

| 前一事件 | 后一事件 |
| --- | --- |

| 兄妹接手小店 | 哥哥制造和整合家庭 Agent 与店员机体 |

这些经历串联起兄妹的技术能力、帮助他人的动机与共同经营的生活
