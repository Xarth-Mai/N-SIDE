# 往事与时间线

## 异常进入公共认知以前

异常自古存在。旧日记、地方传说和私人经历留下过零散记录，但很少能够彼此核对。近代研究逐步建立统一观察方法，早期潜梦设备已经能接触部分现象，可靠验证和长时间维持仍然困难

Null City 所在的河谷与低丘具有更容易留下异常结构的自然条件。过去有人偶然梦见相同地点，也有物件在特定环境中表现异常，这些经历没有被识别成一个始终活动的大系统

城市同时沿着渡口、坡脚道路与车站发展，学校、住宅和文化场所服务着居民的生活。研究在这座已经存在的城市中展开，而不是城市为实验建立

## 十二年前的大共梦事件

十二年前，Null City 发生大规模共梦与现实投影。最初有人在梦中进入相似的房间，随后出现能够交叉核对的行动与细节。不同梦境逐步连接，局部梦魇活动通过特定介质投影到现实

旧声响在清醒时重现，物件与设备出现可以记录的重复动作，部分区域的环境状态偏离常态。新发生的客观变化与认知干扰相互交叠，形成后来被称作“大共梦事件”的城市级经历

居民没有共享完全相同的内容，每一处建筑受到的影响也不相同。灾情来自不同强度、不同类型的影响与现实连锁后果：有人遭遇严重后果，有人只留下几个一直无法解释的片段

事件后来停止向外扩张，救助、隔离和现场管理减少了伤害，也保留了证据。分散的经历逐渐得到可以互相核对的资料，异常进入公共认知，研究、设备与专业处理体系在之后十二年间迅速发展

## 兄妹的童年与成长

大共梦事件发生时，[林屿](../characters/brother.md)八岁，[林澄](../characters/sister.md)七岁。父母林启明与陈静禾经营小店，努力维持孩子的生活，也照应几位熟客

兄妹记得的只是具体片段：提前关店的日子、父母带回的晚饭、熟客讲起同一个梦，以及一条当时不敢独自走的路。父母不是实验参与者，兄妹也没有与事件绑定的天赋血统

他们后来从档案和讲述中知道这些片段属于同一事件。两个人的童年是认识城市历史的一个视角，其他人的记录与经历仍然不可替代

约三年前，林屿开始学习潜梦设备维修，在有经验的技术人员带领下接触维护和基础支持。林澄发展插画与小商品设计，参与选品、包装和陈列。两人都喜欢店里的工作，也各有朋友和去处

## 一年前的小店共同异常

一位准备搬离街区的熟客，反复梦见自己来到小店，却找不到记得的人与物。梦中店铺不断整理，所有东西被强行归入一套已经不适用于当下的分类

在特殊条件下，一个重复“归位”的局部梦魇形成，并与店内长期摆放的一件旧物建立联系。兄妹与少数熟客开始梦见同一家不太对劲的店，醒来后出现商品、人物和经历的错认

求助最初被分散受理，看起来分别像记错、睡眠困扰和店务纠纷。兄妹对照不同人的讲述，才发现稳定重复的关联。林屿检查设备与现场，林澄整理布局和叙述差异；陆衡和合作处理者提供设备、接应训练与首次行动支持

他们后来辨认并改变梦魇的维持条件，结束了有害影响。熟客按照原定计划搬家，大家另选一天道别。解决异常没有要求这个人留下，也没有要求以某种固定方式证明自己已经放下过去

这是一件具有独立来源的 Black Case。这段经历成为兄妹后来帮助熟人、逐步承接异常委托的动机，也让他们理解：即时身体伤害不明显的小事件，仍可能让人难以继续日常生活

## 接店与正篇起点

父母原本已有调整生活安排的计划，兄妹主动接下小店。两人更新部分商品与设计，保留熟客关系，继续把楼上作为共同生活的家

林屿在接店后制造店员机体，整合[家庭 Agent 粒粒](../characters/agent.md)。粒粒从基础店务逐渐融入家人的习惯，记得谁常来、哪些东西还没收好、谁答应给橱窗换一个新摆件

兄妹从帮助熟人开始，通过介绍与联系网络逐渐承接委托。正篇开始时，他们已经能够处理有边界的工作，复杂事件仍然需要专业协作

### 季闻与许遥的共同生活

季闻是早期潜梦研究者，正篇时四十三岁；伴侣许遥是图书编辑，正篇时四十二岁。事故发生以前，他们已经共同生活，各有工作、朋友和兴趣

一次与异常无关的普通现实事故，使许遥长期无法以常规行为表达回应，被外界理解为处于植物状态。在本世界的技术条件下，后续研究发现其残存认知能力足以支持特殊接入

季闻的第一目标只是重新收到一个回应。随着连接改善，两人能够相见、交谈，再逐步形成共享环境。联合梦境让他们继续共同生活，并不是一项以控制现实为目标的工程

最初的家参照旧住家布置。季闻尽量复原熟悉物件，许遥却把桌子移向另一扇窗，换掉不喜欢的灯，要求看新出版的书，也会因为季闻迟到而不高兴。这些行为确实来自许遥本人，其交流能力属于这个角色在虚构技术条件下的具体经历

当时的技术尚未完成严格的独立验证。设备能看到双方响应，却难以排除共享环境和季闻自身补全了具体回答的可能。熟悉的语气带来安慰，也加深了疑问：这些都是他记得的东西，所以眼前的一切也可能由他自己梦出来

### 持久梦境与“旧日回放”

两人希望新经历可以接着上一次继续。季闻与合作团队逐步发展持久化方法，让梦境在一次接入结束后仍留下完整状态

他们成功保留了共同生活，也保留了反复出现的噩梦。季闻最害怕的是眼前的回应并非许遥，而是自己不自知的幻想。这种恐惧不断产生类似片段，在适合的介质条件下获得持续性

最初的梦魇“旧日回放”没有自我意识，也没有欺骗、报复或扩张的目的。它不断将过去的声音、动作和场景叠进当下，使昨天的一句话干扰今天尚未说完的回答

真实共梦从来没有因此变成假的，失常的是共同环境对当下的呈现。季闻原本缺少验证，梦魇成形后又进一步破坏了验证条件，形成相互强化的困境

### 三个条件相遇

持久联合梦境实验建立了连续活动的人为起点。与此同时，区域性自然扰动使当地介质更容易形成和保留联系，Null City 的天然环境提供可扩展的空间范围

三者相遇，触发大规模连接与现实投影。自然条件不等于地面道路或城市电网，后来的研究需要根据实际痕迹推断哪些区域曾经相连

范围扩大后，维持连接与活动的条件更加苛刻，自然窗口也逐渐变化。事件最终抵达新的稳定边界，自行停止向外扩张。现场救助减少了伤害，却不是停止扩张的根本原因

当年曾经自行停止，不意味着今天可以放任危险。当前连接与供能条件已经不同，需要重新查明正在发生的活动

### 独立验证与源头终止

事件之后，独立团队在季闻无法接触、共享环境没有提前获得相关内容的条件下，让许遥接收新信息。许遥在后续交流中主动使用这些信息，结果经过独立记录与重复交互确认，真实共梦的事实得到建立

验证解答了两人的疑问，并未自动清除梦魇。随后，季闻找到“旧日回放”的维持结构，将它与正常共同生活分开，实际终止了源头

已经获得本地条件的城市局部结构继续存在。部分延续了旧模式，部分与新的梦境接入形成独立关系；它们不再接收源头的新活动，也不受源头统一指挥

历史次序为：停止扩张 → 独立验证真实共梦 → 实际终止原始梦魇。保留共同生活与处理城市中的局部结构，是分别完成的工作

### 此后的日子与今天的新联动

季闻与许遥至今仍在共同生活。许遥持续接受现实照护，通过适当的接入与辅助通道参与沟通、阅读和少量编辑工作。两人的居住与照护安排在 N街区以外，私人空间的访问需要单独预约

季闻有时在影院综合体的共享工作室参加小型研究会谈，许遥经授权远程参与创作讨论。两人依然会争论书架的位置、某本书的结尾，也会安排一次普通的晚饭。社区诊所承担本地日常服务，两人的照护没有将它变成大型研究设施

公众与专业人员掌握的信息层次不同，来自研究进展、分散记录和隐私边界。许遥的病程与两人的生活并非任意开放的材料，城市名称和公共认知的形成见[Null City](null-city.md#名称与术语)

正篇的危险来自局部结构之间新形成的有害联系。原始梦魇没有复活，一年前的小店异常也具有独立来源；已经完成的处置不会被无条件撤销。结束新联动对现实生活的危险，可以与保留安全梦境及两人的共同生活同时成立

### 相对时间线

| 时段 | 关键变化 |
| --- | --- |
| 更早的历史 | 异常存在于世界，留下零散记载；城市按普通交通与生活需要发展 |
| 大事件以前数年 | 季闻参与研究；许遥遭遇普通事故；交流接入、联合梦境与持久化逐步建立 |
| 正篇十二年前 | 自然条件与实验相遇，发生大规模共梦与 Black Case；扩张自行停止 |

| 正篇三年前左右 | 林屿学习设备维护，林澄继续设计与店务；各自能力逐步形成 |
| 正篇一年前左右 | 小店共同异常；兄妹在支持下参与处理，之后逐渐接手小店并建立 Agent |
| 正篇 | 城市日常变化与新的环境窗口改变部分遗留联系；兄妹从具体委托进入主线 |
