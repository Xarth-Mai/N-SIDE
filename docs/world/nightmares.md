# 噩梦与梦魇

## 形成

反复的噩梦提供形态，特殊条件促使梦魇真正成形。两项共同构成诞生门槛

形成前提决定梦魇如何诞生，维持机制决定它成形后如何继续活动。每个事件分别建立这两层因果，调查据此寻找处理异常的切入点

## 表现与意识

梦魇的来源围绕噩梦展开，表现可以涉及空间、感知、记忆、声音、物件与局部环境。多样性体现在各事件的形态和局部规则中

大部分梦魇只有本能，或反复执行固定行为。少数拥有自我意识，能够交流、欺骗和改变打算

## 与睡眠的关系

随梦魇强度与事件规模，可以出现三种表现：

| 表现 | 活动方式 |
| --- | --- |
| 依赖睡眠 | 梦主醒来后活动暂停或关闭，影响可以残留，并在之后再次活跃 |
| 独立维持 | 与人、物件或地点建立联系，依靠这些联系持续活动 |
| 多梦连接 | 多个人的梦相互连接，形成范围更大的事件 |

具体事件选择适用的表现与连接关系

## 现实影响与伤害尺度

直接影响落在精神、感知、记忆、情绪与日常判断上。梦中受击在梦境内表现，梦魇对现实肉体的直接损伤为零

异常可以间接引发普通现实意外。身体伤害的创作尺度为皮外伤至骨折，上限为骨折；意外过程与结果都按这一尺度设计

永久精神影响、受困与救援属于具体事件的剧情安排。异常处理后保留下来的记忆或关系变化，由对应故事记录
