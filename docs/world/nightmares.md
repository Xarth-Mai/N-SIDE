# 噩梦与梦魇

## 梦境与异常介质

普通梦境由生物神经活动形成，通常不会在外部留下持续结构。某些普通物质在特殊条件下进入异常态，能够与复杂神经活动建立精细的双向对应，使相关体验结构在外部留存、被重新接入，并在进一步条件下产生有限的物理作用；承担这些作用的非生物物质称为异常介质

信息留存在物质的排列与状态中，梦境不是可以直接收集的电流，磁场本身也不是脱离物质的存储空间。天然环境与人工设备遵循相同规律：环境可能偶然形成适合的条件，设备则帮助识别、维持和控制接入。异常介质不依赖某种独有矿石，也不等同于城市电网

## 形成

反复的噩梦提供形态，特殊条件促使梦魇真正成形。两项共同构成诞生门槛

相似的体验结构在异常介质中留存，反过来影响之后的体验，并被后续活动强化。获得持续活动条件后，梦魇成形

梦魇诞生的原因和维持活动的条件并不总是相同。人已经理解自己的困扰，外部结构仍可能继续活动。查明两者，才能找到处理异常的切入点

## 表现与意识

梦魇的来源围绕噩梦展开，表现可以涉及空间、感知、记忆、声音、物件与局部环境。多样性体现在各事件的形态和局部规则中

大部分梦魇只有本能，或反复执行固定行为。少数拥有自我意识，能够交流、欺骗和改变打算。重复行为不等于恶意，保存了记忆也不一定拥有独立人格

梦魇可以表现为可见的形体，也可以表现为声音或一套反复运行的空间规则。击破眼前的形体，未必已经改变全部维持条件

## 与睡眠的关系

随梦魇强度与事件规模，可以出现三种表现：

| 表现 | 活动方式 |
| --- | --- |
| 依赖睡眠 | 梦主醒来后活动暂停或关闭，影响可以残留，并在之后再次活跃 |
| 独立维持 | 与人、物件或地点建立联系，依靠这些联系持续活动 |
| 多梦连接 | 多个人的梦相互连接，形成范围更大的事件 |

## 保存、活动与连接

持久梦境在一次接入结束后仍能保留状态，供之后继续接入。保存一段经历，与断开后仍持续发生新事件，是不同能力

活动依靠外部供能与有限蓄能。供能中断后，储能可以维持一段活动；耗尽后进入休眠，稳定保存的记录仍可留存。重新获得合适条件后，活动才可能恢复。情感提供内容和重复模式，不提供活动所需的能量

新活动传到远处，需要当下有效的连接。通路可以由设备建立，也可以沿天然介质逐段形成。曾经相连的物件可以分别保留共同记录，断开后却不能继续隔空同步

局部结构获得本地维持条件后，可以在远端断开后独立活动，仍受本地供能限制。断开连接、停止活动、删除记录与终止源头因此会产生不同结果

## 现实影响与伤害尺度

### 活体的信息接入

活体参与信息接入，能够写入梦境，也能够接收感知、记忆、情绪与行动体验。活体组织不进入承担宏观物理输出的异常态。梦中受击可以带来疼痛、惊恐、方向混乱或接入失稳，梦魇对现实肉体的直接损伤为零

感知干扰可能使人误判，现实环境的改变也可能引发事故。梦中伤口不会转写成现实伤口，接应者仍需要保护现实中的人和现场

### 非生物介质的物理输出

非生物异常介质可以通过具体物理过程影响现有物件、设备、声音、材料状态与热量交换，作用受材料、能量与范围限制。现实物件离开原位后仍有实际去向，材料变化也会留下对应痕迹

梦中可以出现无限走廊、复制货架和错接空间；现实道路不会随梦境直接重新连接，物质不会凭空无限生成，时间不会倒流

“梦境覆盖现实”是共享感知、旧记录干扰和局部物理输出相互交叠的表现。人所感受到的变化，与现场物件实际发生的变化，需要分别核对

## Black Case

Black Case 是梦魇活动成功投影到现实后形成的具体异常现象或事件，包含直接影响及后续现实连锁后果。一次投影需要已经建立、可以追查的连接，并非所有梦魇活动都能传到现实

结果由梦魇行为、连接条件、介质状态、可用能量与现实环境共同决定。投影可以有意，也可以无意；梦中与现实的表现未必同形，局部扰动还可能被现实中的连锁过程放大。后果大小不能单独说明梦魇强弱或意图

例如，梦中的反复撞击可以沿已建立的连接，让现实中的薄板短暂振动。声音导致现场人员误判，再叠加设备原有的机械缺陷，便可能引出更大的事故。调查需要区分最初的输出、人的判断与后续故障，才能找到实际需要处理的环节

同一梦魇可以引发多个 Black Case，一个现实事件也可能涉及多个结构。委托是求助与处理工作的组织方式，可以包含多个事件，也可以只是普通日常

持续出现的新投影需要活动结构与维持条件，受损物件则可能只是旧事件留下的后果。异常平息不一定意味着一切恢复原样，记忆和关系的变化仍可能留在生活中

::: details 科幻机制说明

生物电、电磁耦合、磁性留存与反馈为这套规则提供科幻类比；异常态对体验的精细接入与有限物理输出属于作品的虚构规律。肉体伤害边界也是世界规则，不以电磁现象天然无害为理由

天然环境与人工设备使用相同的异常规律。电学类比约束保存、活动、连接与供能的关系，具体事件仍然通过人的经历、地点与生活呈现
