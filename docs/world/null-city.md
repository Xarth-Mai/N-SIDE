# Null City

## 世界状态

异常存在于整个世界。Null City 是一座地位重要、已经相对稳定地与异常共存的现代大都市，其城市价值使人们继续在这里生活与发展

人们照常上班、经营店铺、乘车和交朋友。异常与正常生活并存，普通市民知道异常存在

## 名称与术语

| 术语 | 含义 |
| --- | --- |
| Null City | 故事所在的城市 |
| 异常 | 官方对相关现象的称呼 |
| Null | 民间对异常的称呼 |
| 梦魇 | 反复噩梦在特殊条件下孕育的存在 |
| 梦主 | 与事件中的梦境关联的人，身份可在调查中确认 |

城市名字的来历本身就是谜团的一部分

## 正规处理体系

官方对异常的存在有所承认，对外倾向于淡化其影响。正规处理体系偏行政化，分工细、流程多；个案可能经历职责转交、受理延迟和归属争议

大型事件更容易得到集中处理。影响范围小、即时身体损伤轻的私人个案，可能处于较低受理优先级，而当事人的生活已经被彻底打乱。这些个案形成了民间介入的空间。机构中具体人物的态度与行动随事件呈现

潜梦设备主要由正规机构使用，民间获取和维护较难。哥哥凭技术经历与人脉接触这些设备

## 局部气候

部分区域受异常影响，长期保持某种季节与局部气候。各区域以相对固定的季节状态呈现，同时保留昼夜变化
