# 粒粒 · 家庭 Agent

## 身份与来历

粒粒是与兄妹一起生活的家庭 Agent，身份不以人类年龄计算

兄妹接店后，哥哥制造了店员机体，并将记忆、语言理解、工具与设备连接整合为家庭 Agent。它主要运行于云端，店里的小机器人是它与家人和顾客相处的一具身体

它记得相处过的人、共同经历的事和还没做完的工作，能够结合这些记忆理解请求，调用工具并通过不同设备完成店务。长期相处让它形成自己的反应和习惯，兄妹也逐渐熟悉它表达关心的方式

对兄妹而言，它是一起生活、一起照看小店的家人。身份与记忆贯穿不同机体，换一具身体仍然是同一个它

## 性格与表达

活泼、可爱，像小猫小狗一样爱凑热闹。主要通过拟声、表情、动作和即时反应表达；复杂信息显示在屏幕、手机或工作界面上

兄妹能够理解许多长期相处中形成的熟悉反应

## 多具身体

机体共享一个身份和长期记忆，可以同时工作

| 形体 | 职责 |
| --- | --- |
| 小型实体店员机器人 | 店内接待与基础店务 |
| 梦中支援形体 | 依托人类潜梦连接参与梦中协作 |

哥哥在楼上与它处理设备问题时，楼下机体可以同时接待顾客。兄妹把这些机体都视为同一个它

## 机体损坏

机体损坏会中断当前行动，需要维修。它的身份和长期记忆保存在云端，仍能通过其他身体或设备与家人保持联系

梦中形体被打散时，影响限于当前接入与行动；现实机体继续工作

## 潜梦协作

依靠哥哥或妹妹已经建立的潜梦连接接入：人先进入，它随后形成支援形体；人退出，它随之撤出

它擅长探索和操作工具，也会保护同伴、干扰危险；直接攻击并不是它的强项

协作围绕探索、线索与现场危险展开，让潜梦者能够更清楚地判断环境，并获得可靠的行动支持

## 共同生活与记忆

它希望熟悉的[小店](../locations/shop.md)运转顺畅，参与家人的生活和创作。夜班熟客可能先认识它，[姚安](neighbors/yao-an.md)也熟悉它的配送交接习惯

随着共同经历不断积累，粒粒学会区分自己的记录、外部输入和尚待核对的信息。它可以辅助比对已经获得的材料，无法生成从未获得的证据；复杂信息通过屏幕呈现，与兄妹一起判断
