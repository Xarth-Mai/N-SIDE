# 林屿 · 哥哥

20 岁，生活杂货店的共同经营者，潜梦设备技术人员与异常处理者

## 经历与能力

共同异常发生前已经学习潜梦设备维修，做过学徒或初级技术支持。先掌握设备技术，随后积累调查、潜梦与处理梦魇的经验

具备软硬件综合能力，在兄妹接店后制造和整合家庭 Agent 与店员机体

## 日常与工作

参与选品、陈列、进货和店面改造，也参与潜梦与现实接应。家庭互动见[家庭关系](family.md)

他想让小店和家人都能放心依靠自己，也想保留亲手制作的乐趣。面对新的调查，逐渐从习惯先独自弄清问题，发展为主动说出未知、分工验证并接受帮助

## 关系与认知

[林澄](sister.md)是共同决策者，两人轮换潜梦和现实接应；[陆衡](neighbors/lu-heng.md)是技术前辈，[赵晏](neighbors/zhao-yan.md)会带设备来请教。家用物件、游戏设备与音频设备需要不同专长，他与街坊各自承担擅长的部分

与林澄一起知道自己的共同异常和基础潜梦方法；[《回声之后》](../story/main/index.md)开始时，两人尚不掌握十二年前实验的细节

住在[小店楼上](../locations/shop.md)，也常往来于[小修理铺](../locations/places/b03.md#place-11)和[游戏设备维修店](../locations/places/b02.md#place-38)

## 表达与习惯

说话具体，常先复述现场情况；会把关心藏进帮人收好工具的小动作
