# 家庭关系

## 兄妹

兄妹相差一岁，日常温柔亲近。两人愿意分享、表达关心、认可对方，享受一起生活与经营小店

照顾和信任是双向的，工作分歧在共同经营中处理。技术与设计是各自专长，两人在经营和异常处理中互相补充

## 父母

小店原本由父母经营。兄妹从小接触商品与经营生活，真心喜欢这些事，因此主动接手

父母现已搬到别处生活，仍与兄妹保持家庭联系。他们知道兄妹会帮助别人处理异常，掌握的是部分工作情况。兄妹报喜不报忧，常讲“事情解决了”，较少讲处理中间的麻烦

## 家庭 Agent

兄妹把家庭 Agent 当作家人。亲近感来自共同经营、生活互动和长久相处
