# 日常与时间

## 生活内容

小店经营、楼上住家、邻里往来、熟客关系、街区散步与高处观景，构成兄妹的日常生活

参与店务、与邻居交谈，或只是找个地方坐一会儿，都会让这里的人与生活逐渐熟悉起来

## 昼夜

昼夜改变灯光、人流、店铺活动与街坊的话题。异常也可能出现在不同时间，你可以按时段安排经营、走访与委托活动

## 区域状态

不同区域保持各自的季节，昼夜仍会交替。[N街区](../locations/n-district.md)停留在初秋，其他地方也可能受到[局部气候异常](../world/null-city.md)的影响
