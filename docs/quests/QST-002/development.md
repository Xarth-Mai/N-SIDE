# 最后的玩具：行动、信息与恢复

## Pitch

米娜准备离城，旧玩具却反复离开原位。玩家先追踪看似偷窃的收集者，再从归还与运输结果修正判断，恢复梦中运输、协助现实隔离，帮助米娜按自己的意愿打包，最后回家

本轮落实已选的 Demo 方向，完整章节见[故事](../../story/main/last-toy.md)。固定夹、归架摆臂与具体供能关系是供 M1—M3 验证的机制设计，尚无手感或实机证据

## Synopsis

小店的日常交接让玩家先认识米娜准备离城的处境。受邀进入住宅后，玩家检查清单、箱封和柜底磨痕；仔细检查的人可以提前找到玩具，故事承认这一发现，但新的扰动还会继续

第一次进入梦中玩具店，玩家看见收集者把玩具放回等待打包的位置。暂时隔离收集者会使运输中断、货架堆积；直接跟随的人则看见出口翻板把箱子退回原架，同样可以理解循环。回到现实，玩家依照梦中观察检查周转箱与柜底，核对数量和新痕迹，确认实物移动与梦中增生的区别

玩家再次入梦，用固定夹保持出口翻板朝向送出通路，在归架摆臂的空当完成操作。箱子经过出口后不再返回，重复活动进入低扰动窗口；清醒的林屿依据实时确认，隔离现实柜体的输出接点。米娜随后按自己选择打包，异常停止无需她先放下感情或丢弃玩具

## 本案的条件与规则

| 层次 | 具体条件 | 玩家怎样获得依据 |
| --- | --- | --- |
| 形成经历 | 打包与留下的反复噩梦，在旧柜局部异常态中留存 | 米娜讲述与箱封日期相互补充；不把情绪当作能源或过错 |
| 介质与供能 | 柜背接缝与旧金属导轨处于异常态，窗侧与阴面柜背的温差为局部活动提供有限能量 | 接应者记录温差和活动变化；不是拔掉某根电线就能解决所有异常 |
| 现实输出 | 导轨小幅运动使轻小物件沿柜内既有缝隙进入低位周转箱／夹层 | 磨痕、位置标记与清点前后对应，不穿墙、不移动整柜、不生成新物件 |
| 梦中循环 | 出口翻板反复将已打包物件退回保留室，收集者继续执行送出，货架因此堆积 | 隔离路线看到停运导致增生；跟随路线直接看到退回动作 |
| 玩家改变的条件 | 固定夹保持翻板朝出口开启，让一轮运输实际完成 | 箱子离开后不再回到原架，增生停止、相邻回收摆臂归位 |
| 现实处置窗口 | 重复输出降到可安全分离的间隙，接应者确认后隔离柜体局部输出接点 | 梦中出口与现实位置标记分别反馈；仅梦中操作成功还不能完成委托 |
| 持续结果 | 输出接点隔离后保持隔离，残留记录不会靠米娜再次怀念而自动复发 | 同条件开合和位置检查无新增位移，再清点实物；后续状态保存 |

温差的数值、储能持续时间、柜轨几何与工具时序在灰盒验证后确定。本轮固定的是可追查的供能、有限作用范围与双侧确认关系，不能以等待一段动画代替观察结果

## Treatment 与节点

信息和状态键以 [narrative.json](narrative.json) 为维护源，下表解释各节点的动作与反馈。预计时长全部待测

| 节点 | 玩家动作与目标 | 信息／状态结果 |
| --- | --- | --- |
| B001 | 在小店完成一处陈列交接，听米娜说明并接受帮忙 | 目标是帮助她准备离城，记录哪些是观察、哪些是推测 |
| B002 | 受邀进住宅，核对实物清单、箱封与磨痕 | 建立可比较的基准，可以先查缝隙或先准备潜梦 |
| B003 | 提前检查低位周转箱／夹层 | 找回实物并核对数量，否定无痕消失；后续对白承认提前发现 |
| B004 | 检查接应位置与退出方式，进入梦中 | 人类先进入、粒粒随后接入；现实有清醒接应 |
| B005 | 从必经视线看见收集者归还玩具，再查看打包位置 | “收集者只会偷走”的解释被否定；错过动作可在同一位置重看 |
| B006 | 选择暂时隔离收集者或沿运输线跟随 | 两种行为均可恢复，正确判断者可以直接跟随 |
| B007 | 用现有闸门短暂截停运输，再打开闸门 | 看到货架堆积，恢复通行后堆积减缓，确认运输与增生的关系 |
| B008 | 沿运输线看一箱物件经过出口再退回 | 找到翻板退回动作，同样确认循环，避免强制先犯错 |
| B009 | 退出现实，按标记复核周转箱、夹层和物件 | 首次找到或确认此前找到的实物；物品唯一，不重复发放 |
| B010 | 将柜体位置标记、开合结果与接应记录对照 | 确认局部输出点与同条件验证方法，再进入处理准备 |
| B011 | 再入梦，辨认出口翻板与摆臂的预警 | 处理目标从追逐形体变为完成一轮运输，建立动作检查点 |
| B012 | 等待摆臂空当或回避，放置固定夹，必要时请求粒粒护线 | 出口保持开启；受打断可退回安全位置重试，无永久损失 |
| B013 | 观察箱子送出、确认窗口并等待现实接应确认 | 双侧确认后提交“有害联系已隔离”，不按清空敌人血条完成 |
| B014 | 回现实重复同条件检查、清点物件 | 无新位移且总数对应，向米娜说明实际停止了什么 |
| B015 | 按米娜的决定帮忙分类、封箱和交付 | 打包去向由她决定，保存交付结果；不是解异常的情绪开关 |
| B016 | 回小店与家人相处，经过明确的离城后时段再看消息 | 陈列／小卡与楼上住家体现后续，委托完成，小店继续营业 |

## 场景与动作规格

### 现实住宅

只有受邀调查范围开放，出生与退出点避开柜门运动和私人通路。清单、箱封、磨痕和周转箱是四个观察焦点，现实玩具各有唯一 ID 与位置；检查动作移动或登记原物件，不生成另一份可领取副本

提前找到玩具时，米娜与接应者承认发现，任务目标更新为“弄清并停止再次移位”。第一次潜梦仍提供现实检查无法说明的运输关系，回现实段改为验证新位移和此前数量，不把玩家当作什么都没发现

### 梦中玩具店

同一个紧凑场景容纳打包区、运输线、保留室与出口，首次观察与再次处理复用空间。入口有安全观察位；归还动作、翻板退回和货架变化分别有可见轮廓和短声音，不依赖屏幕角落文字

收集者不作为必须消灭的敌人。危险来自反复把物件推回货架的归架摆臂：先收缩并发出声音，再横扫运输通路，随后归位。玩家能等候、回避，或在后续动作原型中验证基础攻击是否只提供短暂打断；本轮不锁定攻击键、体力条或数值

关键工具为固定夹，操作对象是出口翻板，不是收集者。接近可用位置后出现交互提示，放置前显示朝向，确认后夹住翻板；受打断回到未放置状态。成功通过箱子真正送出表达，不能只弹出“工具使用成功”

粒粒的支援是一次明确的护线：玩家请求后，它在摆臂下一次干扰中保护工具操作，随后退回支援位置。玩家仍需选择翻板和时机；支援不自动指出真相或完成夹取。失败重试恢复该次支援可用性

### 回店与后续

处理结束后先回家，再由明确的时段推进进入米娜已经出发的重访状态，不要求玩家原地等真实日历。小卡或消息是当事人愿意分享的生活；读取后不会重新开放领取玩具。现场送行和更多邻里核对保留在完整章节

## 保存与恢复责任

| 情况 | 保存的结果 | 恢复与再次进入 |
| --- | --- | --- |
| 线索乱序、先找到实物 | 已获信息、实物唯一位置与已清点标记 | 后续观察承认已知，补齐尚未理解的关系，不撤销正确发现 |
| 跳过对白 | 已完成节点的信息与必要目标 | 调查记录可回看，必需观察另有交互入口，不靠一句台词解锁后永久丢失 |
| 主动退出第一次潜梦 | 已观察信息与隔离／跟随记录 | Agent 随退出，返回现实接应点；再入梦时闸门恢复可通行，知识保留 |
| 第二次潜梦失败 | 处理前的持久调查状态 | 从安全观察位重试；摆臂、工具未放置状态和支援一致恢复，不重复扣除剧情物品 |
| 放置工具但未完成双侧确认 | 保存知识；未提交的处理动作不当作永久完成 | 重试或主动退出会先安全撤回操作，再从处理检查点继续；现实接应不独自提交成功 |
| 双侧确认已经完成 | 一次性 `resolution_committed`，柜体输出隔离与梦中完成状态共同提交 | 退出、崩溃恢复或重访直接进入验证／后续，不能重新消耗工具或再次制造危机 |
| 打包与交付完成 | 米娜选择的物件去向、交付事件和消息已读状态 | 重访给出后续对白，同一玩具、礼物与消息不重复发放 |

这张表规定需要实现与测试的行为，JSON 的 `state_changes` 目前只声明效果。原子提交、引擎条件、检查点快照、场景清理和存档版本仍须在 M1—M3 通过实际恢复测试

## 因果走查与下一步

分别沿“提前找回／先潜梦”与“隔离／直接跟随”的四种组合阅读节点，检查每条路线是否都能回答：玩具实际去了哪里、收集者在做什么、为什么固定翻板会停止循环、现实还需要完成哪一步

下一步在 M0-03 将林澄的移动、观察、交互、回避、工具与支援需求映射为最小动作集，再在 M0-04 确定室内、路线、人物与资产预算。具体供能表现、摆臂节奏和固定夹手感在原型中验证
