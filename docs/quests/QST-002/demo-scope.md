# 《最后的玩具》Demo 范围

Demo 采用精简闭环，站前送行留给完整版，具体制作预算仍由 M0-04 收口。M0-02 的行动、信息与状态细化集中维护在[委托开发稿](development.md)；完整章节保留在[完整章节](../../story/main/index.md#qst-002)

## 一句话与人物处境

米娜即将离城读大学，准备带走的旧玩具却反复离开原位。兄妹从看似偷窃的收集者追到被阻断的运输，让玩家通过观察修正判断、用行动停止扰动，再帮助米娜执行她自己的打包选择，最后回到小店

求助者、受影响者与梦主均为米娜。哥哥和妹妹一人潜梦、一人清醒接应，具体主控在 M0-03 选择；完整章节由林澄潜梦、林屿接应，Demo 操作方案在 M0-03 落实。Agent 利用人类连接探索和保护，以游戏内逻辑提供一项可感知支援

## 因果链与信息转折

米娜围绕打包与留下反复做梦 → 局部异常结构使梦中保留室持续复制 → 收集者执行打包送出的运输 → 阻断运输使货架增生加剧 → 观察归还和运输结果，修正“收集者就是偷窃者”的解释 → 创造运输与处置窗口，现实接应解除有害联系 → 新的实物扰动停止，米娜按自己意愿继续离城准备

现实中旧柜与抽屉的局部机械变化将玩具移入附近周转箱或夹层。数量、路径和痕迹可核对；梦中复制不会在现实制造玩具。玩家先取得实物基准，再通过梦境提示回来验证去向，不能靠策划旁白直接揭晓

## 建议的最小流程

| 段落 | 玩家行为 | 获得或修正的信息 | 可见状态结果 |
| --- | --- | --- | --- |
| 日常与请求 | 在小店完成一次陈列或交接，听米娜描述 | 区分亲眼观察与醒后推测，知道她正在准备离城 | 小店陈列回应参与；记录本案目标 |
| 现实基准 | 受邀进住宅，核对箱封、清单、磨痕 | 物品有限且存在局部移动线索，“被偷”尚为推测 | 标记检查位置，保留可回看的事实 |
| 首次潜梦 | 追踪收集者，看见归还，再隔离或跟随 | 收集者不只搬走；隔离使运输中断、跟随可见阻点 | 两条观察路径得到同一必要因果，错误假设可恢复 |
| 返回核对 | 回现实按观察检查周转箱与夹层 | 找回对应实物，否定无痕消失与凭空复制 | 清单数量可对上，下一次潜梦目标改变 |
| 规则与行动 | 再入梦，利用搬运空当回避危险、使用工具恢复运输 | 行动针对异常维持条件，而不是消灭收集者 | 梦中增生放缓并出现处理窗口；现实接应停止新扰动 |
| 后续与回家 | 确认停止扰动，帮助米娜执行打包，回店与家人相处 | 米娜决定带走、留下或寄售什么 | 箱封和去向变化；稍后重访收到她的新生活消息，小店继续营业 |

## 保留与压缩

保留现实／梦境往返、归还动作、隔离或跟随的可恢复差异、运输与增生反馈、一次工具处理、一项 Agent 支援与现实后续，它们共同构成辨识度

建议把零件与包装核对合并为一次顺路邻里互动。模型店、旧物交换店、修理铺不全部制作独立室内；寄存店与车站送行留在完整版，Demo 用经米娜同意的小卡或消息展示离城后续。街坊小册只承担生活联系，不在首 Demo 展开全城征集

采用这一方向减少必做室内、NPC 演出与往返路线，代价是 Demo 不呈现现场送行段落；米娜离城后的联系仍通过回店后续保留，预算在 M0-04 收口

## 下一轮要验证的设计问题

收集者的归还动作需要在玩家必经视线中看清；隔离与跟随各自提供独立可理解的反馈，已经正确判断的玩家应直接推进，不强制犯错

工具改变通路、梦中窗口与现实隔离之间的规则尚需灰盒验证。具体供能条件、输出上限和终止判据应在任务运行规格中列清，不能把现实“断电”写成所有异常的通解

状态设计必须覆盖主动退出、普通失败、再入梦、乱序线索、跳过对白、重复交付、重访与读档；当前设计索引和本页没有实现这些行为

## 体验走查

体验基线与站前送行留给完整版的范围已获作者确认。本轮沿“小店 → 实物基准 → 梦中归还与运输 → 回现实找回 → 再入梦处理 → 米娜打包 → 回家”走查具体行动，判断固定夹保持出口、运输创造处置窗口与现实接应隔离之间的因果是否清楚

行动、信息、分支与恢复矩阵已整理在[委托开发稿](development.md)。M0-02 按本轮机制走查结果验收，后续游戏阶段分别验证实现和实际体验
