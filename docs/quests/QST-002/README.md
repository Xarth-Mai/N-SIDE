# 最后的玩具：任务制作

完整故事见[主线第一章](../../story/main/last-toy.md)，Demo 沿已选的[精简范围](demo-scope.md)制作。这里维护可玩流程与实现规格，当前为 M0-02 的设计交付

## 故事与职责

| 问题 | 内容 |
| --- | --- |
| 求助与生活 | 米娜准备离城读大学，旧玩具反复离开原位；她希望带着自己选的东西继续生活 |
| 初始解释 | 玩具被偷走，梦中收集者像是偷窃者；均需实际观察核对 |
| 实际原因 | 局部介质使柜体产生有限机械扰动；梦中保留室的重复流程让副本累积，收集者承担送出运输 |
| 信息转折 | 归还动作、运输受阻后的增生，以及现实容器内可核对的实物，改变玩家的判断 |
| 行动目标 | 恢复运输并创造稳定处置窗口，现实接应解除有害输出联系 |
| 潜梦配置 | 完整章节由林澄潜梦、林屿清醒接应；粒粒依托连接支援，店员机体继续照看店面 |
| 现实后续 | 新扰动停止，米娜自己决定打包去向；Demo 回家后收到离城后的联系，现场送行留在完整版 |

## 制作入口

## 当前验收

检查实际玩家动作能否解释故事因果，隔离与跟随两条路线是否都能取得必要信息，提前找回物件是否得到承认，处理与米娜的生活选择是否分开

静态检查使用 `bun run check:narrative`。游戏状态、动作与存档恢复由 M1—M3 的原型验证；M0-02 的作者走查与当前进度记录在 `todo/demo-worklog.md`
